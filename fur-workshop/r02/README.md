## 本轮真正改变的内容

R01 的毛根分散在整件衣身上，仅毛领模式只是隐藏非毛领纤维；透明毛丝不写深度，光滑基底主导外观。R02 改成按实际生长域采样：默认仅毛领，780000 个显示根全部落在毛领，不浪费在隐藏衣身。

C3 使用两种不同职责的纤维群：624000 根短底绒写入深度，负责遮底和厚度；156000 根较长针毛使用连续透明覆盖，负责独立毛丝、渐细毛尖和外轮廓。每个窄带代表一根显示纤维，不是粗圆管，也不是摄影多毛卡片。短底绒使用 3 段中心线，长针毛 7 段，按纤维类型区分，而非距离分档高低模型切换。

不能把显示根数当成真实生物毛囊密度。底绒设置连续亚像素宽度下限以表达未解析的密实毛层，是实时显示近似，不代表每根真实毛的物理直径都随视距变化。

重塑了渐缩卷领轮廓；毛向沿领口向外并向下；新增有局部差异的毛束吸引、长短分布和束内明暗。默认棕褐配方采用更暗的底绒、较浅的针毛毛尖，避免均匀米黄色短绒外观。界面毛长是配方尺度，叠加随机长度、梳理与弯曲后不是每根毛都具有完全相同的弧长。

素面衣身降低镜面反射，增加可按像素足迹衰减的程序化细粒变化。为减轻原承载模型圆肩重叠造成的硬投影，圆肩补片不参与投影/接收阴影。衣身仍是原参数化展示载体，不是裁片缝合完成的服装，也仍可见肩部拼接与较硬的衣身形态。

四种视图（完整大衣、仅毛领、帽子、样片）、六种材质外观、毛长、底绒、卷曲、聚束、粗糙度、密度、分层观察、相机和 JSON 配方导出保留。当前专项的主要视觉验收对象是默认毛领，不把其他所有形态都声明为同级成品。

## 性能与真实物理边界

本版约 602 万绘制三角形。软件渲染器冷启动及完整帧读取较慢，诊断读取上限放宽到 90 秒，没有减少正式几何来通过检查。此上限不是正常交互的目标帧时间。没有认证用户显卡 60 FPS，也没有手机真机性能测试。界面静止/截图时的 FPS 计数不能作为连续运行基准。

遮蔽、透光、束内暗部与散射为局部解析近似，不是完整毛皮多重散射或逐毛光线追踪。高密毛层有显存、顶点处理及透明像素成本。未来成衣运动还需独立解决毛根跟随、衣领接触、穿模和碰撞，不能用当前静止外观宣称这些已完成。
