## 失效原因与重构

R01 的总根数分散在整件衣身上，进入仅毛领视图后仍生成大量无效衣身根；毛领实际单位面积密度低。透明随机顺序混合且不写深度，使根部基底主导画面、远端纤维仍显得浮散。底绒过短，针毛与底绒形态层次不足。

R02 按真实生长区域采样，默认 260000 个显示毛根全部在毛领。密底绒占约 73%，较长针毛约 27%，极少游离针毛。计数是显示采样，不冒充真实生物毛囊测量。

重写毛丝曲线、内外轮廓、下垂方向、毛束聚合、渐细和暗根浅尖。每个窄带只代表一根纤维，不用粗圆管或摄影多毛卡片。毛层使用深度写入与多重采样覆盖，避免原来的无序透明雾丝；局部透光和光学深度为解析近似，不声称完整散射模型。默认仅毛领、静止观察，点击启动微风后使用原有有界导向毛梢响应。

衣身去除原来的高光皮革感，保持素面深棕高粗糙度承载材质。四种承载形态、六种材质、可编辑参数、分层观察、EB1 调光和配方导出继续存在。
