KAOPU / FIRST CONTRACT

导入动物 · 乐谱与乐器

乐器负责生成或运行动物，乐谱描述形体、参数和已有动作。新增动物还需提供米制跨度和千克体重，缺失时可在预览后补填。先验证和预览，再加入目录；展开下方说明查看支持格式。

GLB ≤ 64 MiB · JSON ≤ 90 MiB · 程序化谱 ≤ 100 KB
选择文件后先验证和预览，通过后再加入动物目录。

哪些模式可以成功导入？
导入模式成功条件
程序化动物谱
K4|… / K5|…		完整 .txt 谱，或包含 notation 的靠谱 JSON。必需段与数值范围通过原乐器校验；当前只生成静态四足动物。
模型动物
.glb		glTF 2.0，网格、骨架及贴图全部内嵌，最多 200 万顶点；有动画片段才会显示动作。PNG/JPEG/WebP 普通贴图；先解压 Draco、Meshopt 与 KTX2。
靠谱动物包
.kaopu.json		kaopu/animal@1：注册乐器 + 动物谱或内嵌 GLB + 参数谱。内置对象引用包需要接收平台已包含同版工作台。
参数乐谱 / 旧配方
.score.json / .animal.json		乐谱使用 kaopu/score@1；旧配方使用 animal-atlas/recipe@1。仅有参数时，要先安装对应动物，版本、模型指纹和参数必须匹配。

首版不接收 HTML、JS、FBX、OBJ、外置 .gltf 或未注册乐器。模型不会自动获得年龄、生长或新动作。目录保存在当前浏览器；移到其他浏览器请导出靠谱动物包，原工作台 HTML 不会自动加入新动物。

把动物带进同一个工作台

左侧选择大类，再点击真实模型缩略图。中央展示已有动物与场景，最右侧参数栏显示当前动物支持的动作与参数，可切换“展示与光线”调整环绕和灯光。桌面可拖动旋转、滚轮缩放；手机点击右上角“参数”。

GLB 导出当前可见动物的姿态、几何与基础材质，不包括环境和动画。独立 HTML 保留原有动作及复杂程序化材质，可双击打开，也可嵌入其他网页。JSON 配方用于重新导入本平台继续编辑。

靠谱乐谱保存形体与参数；靠谱动物包携带可重新导入的内容。内置动物包需要接收平台包含同版工作台。对象说明、来源和版本可在参数栏展开查看。

原工作台还没有生长模型的动物，年龄暂不开放。参数版犬、猫、灰狼、北极熊与陆龟来自已有静态谱，不把相机运动当成动物动作。模型与动作的原始来源、版本及许可随导出保留。

const loader = new GLTFLoader();
loader.load('animal.glb', ({ scene: animal }) => {
  scene.add(animal);
});

独立 HTML 对象提供 window.AnimalRuntime：查询设置、调整参数、播放已有动作与暂停。高级接入说明保存在项目 README。
