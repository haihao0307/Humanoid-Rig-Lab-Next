# 固定暖主光与冷辅光展示

本页记录第一版固定暖冷灯。当前灯光已升级为 [产品摄影棚风格](PRODUCT_STUDIO_LIGHTING.md)，固定灯位与移除栖息场景的规则继续保留。

动物展示窗口使用 `warm-cool-fixed@1`：暖主光 `#ffe0b8`，冷辅光 `#99c6ff`，低强度中性环境光。灯的世界方向与灯位固定，不跟随鼠标观察方向、自动环绕、动物位移或尺寸滑块。Z-up 原模块按坐标轴换算相同灯组。背景与圆台改为中性灰，去掉沙色颗粒和绿色装饰。

以 Y-up 展示坐标表示，主光位置为 `[4.64, 6.24, 2.72]`，辅光为 `[-5.76, 3.04, -4.4]`，目标固定在原点。它们是平行光，位置决定固定方向，影子覆盖范围随对象尺寸更新，不移动灯。初始主光/辅光/环境光/曝光为 `3.8 / 1.35 / 0.65 / 1.15`；数值是渲染强度，不声明物理光度单位。

所有 19 个动物及导入模型共用右侧灯光面板：自动环绕、环绕速度、暖主光强度、冷辅光强度、柔和环境光、曝光、背景。固定灯位没有方向滑块，也没有栖息环境切换。旋转镜头仍可观察动物，动物原形态参数和生命动作保留。

Three.js 场景隐藏原场景节点、灯、背景及 IBL，保留动物根对象和明确打开的检查辅助线。生命世界的 HDR 通道在清屏前设置中性背景，鲨鱼的全屏水下雾色与海洋焦散关闭，避免隐藏场景后仍残留海水色。新增沙滩与海底渲染器不再创建；鱼使用同样的数学透视投影，猫和海雕使用原 WebGL 材质中的固定方向和彩色光项，鸡的程序化羽毛/皮肤材质同步读取灯组强度。动物的原生活环境数据仍可服务于其算法，不作为展示场景绘制。

历史参数 key 和枚举保留用于旧谱校验：`displayStage=habitat` 导入后归一为 `turntable`，`studioLightAngle` 固定归一为兼容值 35（不再参与方向计算），`environment` 归一为 false，蟹的 `stage` 归一为 lab。已移除的水体/海草参数作为历史数据接受，不创建或启用场景。旧浏览器保存的展示光线首次打开新版时迁移到新默认值；之后用户调整的光强、曝光和背景继续保存。

完整动物包、配方、GLB、活动烘焙和独立 HTML 的结构不改变。灯不进入动物网格或烘焙材质，不把暖冷灯色永久染进动物本色；静态 GLB 在接收网站使用其灯光。新导出的 HTML 保留固定灯组，活动烘焙继续调用原动物生命算法。历史运行器指纹保留在兼容清单。
