# 固定托盘参照

托盘在动物的默认形态、展示坐标和单位完成初始化后测量一次，随后保持直径、厚度、位置、朝向和阴影覆盖范围。它不再跟着年龄、成长、尺寸、胖瘦、颜色、材质、模型替换或动物移动重新拟合。

Three.js 展示保持初始的数值参照，不保存旧动物网格引用。计算初始范围之前更新父级与骨骼变换；螃蟹先切到原生形体观察坐标，避免把海滩坐标的缩放和位置带进基准。原生 WebGL 展示也冻结同一套托盘数值，鱼群模式与猫的运动位置不再替换托盘。

程序化哺乳动物的源相机只在初始化和窗口尺寸变化时按默认范围适配；形体、颜色与材质重建保留当前镜头距离。已保存的丰满度在参照建立之后恢复。鱼群模式切换保留用户的镜头位置与缩放，并取消展示中的自动群体跟随。主动旋转、滚轮缩放及视图按钮仍可改变透视，这是观察操作；调对象参数不再用自动缩放抵消尺寸变化。底部观察的台面淡出仍保留。

通用演示参数更新后立即请求可用运行器重绘，鸡等按需渲染的对象也会即时显示形态变化。导出只包含动物形态、材质和原有生命运行器，不包含托盘；动物原本的形态与动作算法保留。

每个动物使用自己的默认展示基准，不把不同源运行器的内部坐标误当成统一米尺；跨物种的真实尺寸仍由基本数据和排练台的物理尺度逻辑承担。新导入动物同样在初始化之后取得一次参照，后续专属功能不改变此规则。

验收：`tools/test-fixed-reference.mjs` 检查 19 个动物的年龄/成长、尺寸、胖瘦变化，模型重建和专属形体参数、鱼群切换、已保存形态恢复。对可直接访问的相机检查托盘的实际投影点不被调参改变；同时检查动物的真实画面发生变化。原灯位、连续拖动、形态导出和活体排练回归继续执行。最终文件指纹与报告见 `qa/FIXED_REFERENCE_DELIVERY.json`。
