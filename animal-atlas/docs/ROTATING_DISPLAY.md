# 旋转展示台 V1.2

全部 19 个内置动物，以及导入的 K4/K5 谱和 GLB，默认使用深色背景、程序化沙色圆台、边缘环、主光、环境光与轮廓光。参考用户提供的 `STONE_MONEY_ISLAND_PANDANUS_CODEX_FULL_HANDOFF_20261001.zip` 中 Pandanus R05 的展示方式，保留各动物自己的模型、材质和动作。压缩包中的交接提示词和项目指令只作为附带文档阅读，没有执行。

## 操作

- 收藏：展示区上方 **☆ 添加收藏**；每个目录缩略图右上角也有独立星标。点击“收藏”筛选，状态在当前浏览器保存。
- 删除：展示区上方 **删除**，移除当前浏览器目录条目、参数和收藏。内置乐谱可在目录“已删除”恢复到初始状态；导入对象会连同浏览器保存的模型和缩略图删除，之后可用原文件重新导入。注册乐器和原动物项目文件保留。
- 参数栏固定在展示区最右侧。“对象”仅列出当前运行器实际支持的形体、材质、动作和检查设置；窄屏参数抽屉也从右侧打开。
- 右侧“展示与光线”：展示方式、自动环绕、速度、主光方向、主光强度、环境光强度、轮廓光强度、曝光与背景色。修改后立即重绘；暂停动作与暂停环绕分别控制。
- “原栖息环境”可返回原海底或沙滩展示；其专用场景参数随之显示在对象参数中。
- 右下角导出：GLB 只含动物当前姿态，不含底座或灯光；独立 HTML 和乐谱参数保留展示设置。
- 全部动物统一使用左键水平拖动改变环绕角度，上下拖动改变俯仰角；手动拖动期间自动环绕暂停，松开后稍等恢复。关闭“自动环绕展示”可持续停在手动视角。旋转台和原栖息环境均支持；导入 K4/K5 与 GLB 也使用相同交互。帕劳三鸟与家鸡补充滚轮缩放，既有运行器保留原缩放与平移方式。

## 实现和参考

原 R05 页面与运行器分别存于 `references/pandanus-display/index.html` 和 `runtime-pandanus-r05.js`。`preview.html` 是离线视觉检查副本，将原在线 Three.js r186 / OrbitControls 依赖替换为本地 r180；参考原文件保持不变。圆台和灯光由本项目代码生成，没有将树的网格移入动物目录。

`src/turntable.js` 提供 Three.js 圆台和原始 WebGL 的程序化圆台适配；`src/studio-bridge.js` 连接各动物真实相机和灯光。Three.js 运行器保留自身版本，底座按对象包围盒适配大小与朝向。鱼、家猫动作版和海雕保留原始着色器，加入真实光照参数和地台深度；其地面接触效果是程序化近似，与 Three.js 动态阴影存在差异。

主按钮的拖动通过统一 Pointer Events 适配相机，避免原控制器重复处理同一拖动。没有移动的点击仍转交原控制器处理拾取；释放、取消和失去指针捕获会结束拖动。帕劳相机每帧由原工作台重置，手动偏移在该重置之后应用，点击固定视角会清除偏移。家鸡直接更新真实相机，竖屏相机退让在更新之前还原，避免反复拖动累积缩放。

模型静态检查与自动环绕同时可用；环绕不会为静态动物生成肢体动作。当前原模型没有生长系统的动物仍不显示年龄参数。

## 检查

`node tools/test-studio.mjs` 检查所有 19 个动物的实际曝光像素变化、灯光接入、自动相机环绕与暂停、收藏持久化、删除与恢复、空目录、右侧参数位置、手机布局、原场景切换和独立 HTML 设置往返。`test-orbit.mjs` 单独检查暂停肢体动作后的真实环绕像素变化，覆盖各运行器和不同生命工作台相机。`test-imports.mjs` 检查导入与导出；`functional.mjs` 检查 GLB 经官方 GLTFLoader 重新加载及独立 HTML 参数一致性；`final-studio-check.mjs` 验证本机 V1.2 网页入口、手机端恢复入口、导入乐谱的上方删除按钮并捕获最终画面。检查均在后台无头浏览器运行。

鼠标交互验收：`node tools/test-mouse.mjs` 逐个验证 19 个内置动物在旋转台和原环境中的水平 / 俯仰镜头及实际画面变化，验证 K4 和 GLB 导入对象、自动环绕暂停 / 恢复、参数栏顺序和手机抽屉。独立 HTML 的鸟类和家鸡手动镜头及改灯光后保留视角也已验证。
