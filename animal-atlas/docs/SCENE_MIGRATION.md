# 展示环境更新 · 2026-10-01

## 海底

参考：[深海鱼群](https://threejs-fish.vercel.app/)。下载的部署脚本保存在 `references/fish-scene/deployed.js`，来源 URL、文件名和 SHA256 见同目录 `PROVENANCE.json`。

保留参考的场景工厂与着色节点：400 × 400 分段起伏沙床、26 块种子固定的岩石、220 株海草、水面折射窗口、7,000 个悬浮颗粒、432 个气泡，以及水中吸收、焦散、云影、体积光柱、Bloom、扭曲和调色。场景几何及视觉算法来自下载的实际项目，不是凭截图临摹的背景图。参考自带的鱼与应用入口没有接入；动物继续使用现有完整 R13 模型与 30 条互动鱼群。

适配和改善：

- 使用参考所带的 WebGL2 后端，修正共用画布时的 framebuffer 状态问题。
- 展示相机采用透视投影；鱼与环境共享深度。后期完成后恢复沙床 / 岩石深度，避免鱼被全屏后期遮住。
- 岩石细分从 4 提高至 7，合并相同位置处的法线，保留原来的分布和侵蚀形状。
- 海草改成 6 × 64 分段卷曲叶片，添加叶缘、纵向波纹与中脉明暗；保留原来的实例分布及水流摆动。
- 降低沙床焦散过亮程度；鱼体加入轻量水色衰减。
- 右侧增加水体浓度、光柱、光晕、海草密度。暂停冻结水流、焦散、光柱与颗粒的统一时钟。
- 鲨鱼也使用该海底。其原生 Three.js r169 与参考 r186 分属两个渲染器，因此通过随相机更新的背景层连接；这一适配不提供鲨鱼与背景海草之间的逐像素遮挡。原鲨鱼活动及周围猎物继续运行。

保留原场景构造不等于逐像素相同：展示相机、对象尺度、渲染后端和上述优化均已改变。没有宣称像素级 1:1 验收通过。

## 沙滩

参考：[Tidewater](https://dgreenheck.github.io/tidewater/)；源代码固定在 `4811ba48d795197de5621985f404e765c0b7c0ef`。下载文件逐项使用 Git blob SHA1 与该提交的树匹配，证据见 `references/tidewater/PROVENANCE.json`。完整 MIT 许可保留在 `vendor/tidewater/LICENSE`，并内嵌到使用它的独立 HTML。

复用原来的海湾海岸、缓坡、浅海沙床、海滩尖角、沙堤 / 沙坝细节和四种经破裂面切削的岩石形状。地形解析采样缩小到展示区域；原来 2048² 的完整岛屿高度图、游戏人物、村庄、码头和钓鱼系统没有引入。

本项目程序化生成干湿沙粒 / bump、湿沙粗糙度、深浅水色、多方向波纹、近岸波峰 / 泡沫 / 上冲退水、天空云层、弯曲棕榈、羽状叶片和海岸草。岸浪沿用参考的上冲 / 退水节奏原则，由 WebGL GLSL 实现，未冒充其完整 WebGPU 海洋引擎。

中心活动区平整，保留既有动物的落脚坐标。猪、田园犬、狸花猫、Cat V4.40、K4 / K5 五个动物条目以及家鸡接入同一沙滩。已有动作仍由原运行时计算；参数版 K4 / K5 和家鸡保持静态形体检查能力，不添加虚假骨架动画。Cat V4.40 使用同一 GL 画布与近似接地阴影，原脚掌锁定和姿势修形保留。

## 运行和验证

```powershell
node tools/prepare-reference.mjs
node tools/build.mjs
node tools/verify.mjs
node tools/scene-check.mjs
```

- `qa/REFERENCE_fish.png` / `REFERENCE_tidewater.png`：已安装 Chrome 后台浏览器中实际运行的参考站点画面。
- `qa/BROWSER_REPORT.json`：全部 19 条目的加载、参数、动作和浏览器错误记录。
- `qa/SCENE_REPORT.json`：场景工厂计数、真实参数、暂停时钟、全部沙滩对象开关、shader / GL 错误检查。
- `qa/SCENE_EXPORT_REPORT.json`：本次改动涉及的 12 条目真实导出与重新加载。
- `qa/FINAL_PLATFORM.png` / `FINAL_SCHOOL.png` / `FINAL_PIG.png` / `FINAL_SHARK.png`：交付版本实际截图。

GLB 仍只导出当前动物的静态姿态，不包含环境。独立 HTML 保留动物动作、当前参数和新的展示环境。场景均可离线运行。
