# 产品摄影棚灯光

当前展示使用 `product-softbox-fixed@1`。暖白主光从斜上方塑造体积；较弱冷白补光保留暗部；背侧冷白轮廓光分离身体与背景。台面压暗、取消装饰圆环，保留灰色圆台与无网格背景。没有恢复海底、沙滩或动物场景。

后续的连续观察修复取消巨大实体地板，背景保持稳定；镜头适配不再移动源相机；底部观察时圆台平滑淡出。见 [展示观察稳定性](STUDIO_ORBIT_FIX.md)，当前对应交付记录为 `qa/STUDIO_ORBIT_DELIVERY.json`。

默认主光 / 环境反射 / 冷辅光与轮廓 / 曝光为 `4.2 / 0.35 / 1.5 / 1.05`，背景 `#24272d`。冷辅光与背侧轮廓使用同一个现有滑块，前方补光取其 0.3 倍；没有增加面板负担。原 9 个展示参数保留，包括 2 个隐藏兼容字段。

主光、补光、背光方向分别为 `[-.62,.76,.32]`、`[.65,.3,.7]`、`[.25,.58,-.78]`，各乘 8 为固定位置，目标固定原点。主光 `#fff0df`、补光 `#d6e7ff`、背光 `#d9edff`。灯不跟随镜头、动物移动或尺寸变化；只允许修改强度、曝光和背景。

`src/product-lighting.js` 统一灯组默认值、方向、颜色和 GLSL 响应。Three.js 动物增加数学生成的 128 × 64 HDR 灯箱反射，经 PMREM 预滤波；按渲染器复用，生成器和原始纹理用后释放，输出纹理随页面释放。输入数值暂存 128 KiB，不包含下载图像。阴影改用 512 × 512 VSM 与 8 次滤波，降低硬边；这是柔光阴影近似，不声明完整的面光源光线追踪。

鱼、猫、海雕和鸡的自定义材质使用相同的宽光瓣、弱补光、背侧光和缓和高光曲线。原模型、骨架、花纹、形态与动作算法保持，材质本色不被永久染入灯光。GLB 烘焙仍输出本色与形态，独立 HTML 重建这套棚灯。旧运行器指纹继续接受，历史场景参数仍归一到中性展示台。

参考实现原理：[Three.js PMREMGenerator](https://threejs.org/docs/pages/PMREMGenerator.html)、[LightShadow](https://threejs.org/docs/pages/LightShadow.html)。当前版本具体资源与兼容方式以仓库实现和实际渲染检查为准。
