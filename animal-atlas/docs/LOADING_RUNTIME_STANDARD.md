# 按需加载与左向缩略图

仓库只初始化当前动物。离线交付仍为一个 HTML，模型、动作、材质与参数没有减少。构建注册的运行器才能执行；导入文件不能提交任意程序。

加载链路是：选择对象 → 读取当前压缩包 → 后台解包 → 初始化原乐器 → 恢复参数 → 实际渲染帧 → 开放调参。Worker 使用单队列，结束后销毁并释放 Blob URL；不支持 Worker 时使用串行本地解包。相同包的并发请求合并。解压文本缓存最多两项，按 UTF-16 上界计最多 64 MiB，超大项不留存，没有隐藏 GPU 运行器池。重复点击已加载对象不重建；重置和指定初参仍执行加载。

帕劳鸟把共享代码、动作与三份物种数据分别内嵌。当前鸟只读取自己的一份，按模板准确重组运行器并核对注册指纹。原始曲面求值的分辨率、控制点、焊接与浮点顺序保持；样条基函数按精确 `(n,t)` 缓存，每组最多 4096 项，生成结束即清空。逐顶点的 Float64 临时累计数组复用并清零。普通原生参数动物先合并有效初始颜色、粗糙度和丰满度，再生成形态。

沙滩以真实空 Group 登记到场景，显示时才执行原地形、岩石、植被、水面、纹理和灯光生成。Raw 猫也延迟创建沙滩渲染器，环境开关在生成前可用。物体生成器、默认采样曲面和生活逻辑继续保留；犬类的曲面求值和首次 shader 编译仍可能较慢，不能宣称全部对象都获得相同倍率。

旧活动烘焙只接受 `LEGACY_MODULES.json` 中逐项固定的上一版指纹，仍验证压缩长度和完整解包 SHA。旧 native 参数配方只增加 `LEGACY_SOURCES.json` 中明确的已知源指纹兼容关系；未知指纹继续拒绝。

缩略图来自 19 个原生三维对象实际渲染。拍摄时暂停自动环绕，调整真实相机，使头部或蟹类口器朝左；帕劳鸟采用略抬高的侧面。不会镜像模型数据、修改物种结构或调用图像生成。右上角星标保持原位。新缩略图使用 `node tools/capture-left-thumbnails.mjs`，更新后重新构建。

后续新动物应把共享函数和物种数据分离，独立声明依赖、支持参数、基本数据与动作，形态参数一次合并后生成；隐藏环境按需求值。优先使用可转移的紧凑数值字段和确定性函数，不能在包内另加重复烘焙网格作为加载替身。

研究依据：[MDN Compression Streams](https://developer.mozilla.org/en-US/docs/Web/API/Compression_Streams_API)、[MDN Web Workers](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers)、[Three.js compileAsync](https://threejs.org/docs/pages/WebGLRenderer.html#compileAsync)。本轮采用后台解包与按需数学求值；没有全面改造旧 shader 管线或预热一池隐藏动物。

验证依据是 `qa/LOADING_BEFORE.json`、`qa/LOADING_AFTER.json`、`qa/LOADING_INDEPENDENT_REPORT.json` 和本轮 receipt。同机窗口 1680×1000，每次记录实际 ready/渲染帧；首次和重复选择分别记录，单次测量含机器波动，不能当作通用 FPS 或总 GPU 内存结论。
