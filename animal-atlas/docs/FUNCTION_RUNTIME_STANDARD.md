# 函数化乐器与演奏台

此轮目标是保留原有可见效果，减少重复数据与逐帧工作。仓库继续负责注册、参数接口、展示、尺度和烘焙；动物知识、生长规律及具体生成函数由动物乐器提供。

## 可执行的表示

一个形态写成 `S(u,v; seed, parameters)`，一个姿态写成 `P(S; time, coefficients)`，材质写成 `M(S, normal; parameters)`。稳定的曲面采样和索引只建立一次。播放只更新低维状态：骨骼、连续场、视线、瞳孔和参数。烘焙是在选定参数与时间上求值，输出可移植的当前形态；它不是重新构建一套动物知识。

现有鱼沿用原脊柱、鱼鳍、下颌和鳃盖场，其权重保留 Uint8、分区与 UV 保留 Uint16、八面体法线保留 Int16，GPU 按原除数解码。眼睛的视线与瞳孔曲面也在 GPU 求值，每帧只上传两个眼睛的参考系与系数。没有减少顶点、纹理精度、阴影分辨率、像素比例或动作频率。海雕沿用原双四元数函数及原 Uint8 颜色。现有采样表面与贴图继续兼容，不能把它们宣称为已重新研究完成的纯解析动物。

`src/function-kernel.js` 是已落地的构建注册内核：给定 `id`、`uniforms`、`glsl`，将 `animalDeform(rest, restNormal, outPosition, outNormal)` 接入原 PBR 材质。鱼与海雕已经使用这一接口。只有平台构建中注册的代码可执行，导入乐谱不能提供任意 GLSL 或 JavaScript。

## 新动物接入约定

1. 动物作者交付确定性生成器、参数定义、动作定义和基本数据；明确哪些知识未知，禁止仓库推断或编造。
2. 构建注册函数乐器的 ID、版本与源码指纹。优先使用连续曲面、SDF、骨骼或低维场；有必要的稳定采样是求值缓存。
3. `stageBinding()` 给出实际可见对象与坐标约定；`describe()` 声明支持的参数及动作；`configuration()` 保存参数；`set()` / `playAction()` 修改状态；`meshes()` 在当前参数和姿态上求值。
4. `S` 应由稳定种子和形态参数决定；`P` 只依赖动作时间及声明状态。参数不变时不重建网格。静态几何只共享于同一运行器内同一源 geometry；不同动物的可变曲面不能共享。
5. 长度以米、体重以千克声明。`metersPerUnit` 固定，后续形态变化不重新归一化；展示倍率不自动推算体重。
6. 全部生命动作由乐器执行。排练台只计算同一时刻的人工位置关系，不能把追随、避让、绕行叫作生物学结论。
7. 固定种子、参数、姿态和相机核对画面及生成结果，再测试暂停、恢复、旋转、光照、烘焙往返和资源释放。通过后才替换旧乐器。

现有 K4/K5、`kaopu/content@1`、`kaopu/score@1`、动物包及 `kaopu/bake@1/@2` 格式继续使用。新动物的知识可放在 content 的 `knowledge` / `extensions`，仓库原样保存。尚未注册的新生成器不能仅上传一个 JSON 就获得执行权限。

## 内存与调度

- 烘焙快照内部使用紧凑 TypedArray。Float32 仅用于原值可以完全表示的数值；真正的 Double 使用 Float64，索引和图片字节在验证后才转换。文件出口通过 `stringifyData()` 还原旧格式普通数组。
- `geometryCopier()` 为同源 geometry 只分配一次宿主几何；跨 iframe 不使用原 geometry ID。实例矩阵保留实例除数，骨架重新关联。释放按资源集合去重。
- 几何与实例属性只有源版本变化时才复制和上传。每个目标属性记录源对象与版本，不能仅按源属性全局跳过同步。
- 活动动物保持逐帧求值；暂停和静态画面按变化重绘。旋转、阻尼、缩放、光照、参数、单位、增删、复位与失败恢复会使画面失效，并保留收尾帧。
- 排练台显示时，兼容的工作台渲染器暂停不可见绘制，原对象参数与生命状态保留，关闭后恢复。鱼在排练台中交出可见 GPU 表示后，原 WebGL 网格、纹理和渲染循环被释放，仅保留原数学生命控制器，由宿主时钟推进。其他旧乐器的隐藏 iframe 尚未全面消除，仍可能保留额外的生命计算。
- 压缩乐器采用最多两个模块的精确输入缓存。只有模块指纹、压缩数据和解压长度都对应已验证内容才能复用；更改后的压缩输入仍重新校验。不能凭相同 SHA 声明跳过文件校验。
- 排练整体位置使用无向量临时分配的同步数学步进。所有关系读取前一帧位置，避免对象遍历顺序改变结果。
- 排练运行器按需装配，宿主不重复打包 Three.js。单 HTML 保留全部离线依赖。

## 可复现实测

`tools/profile-functions.mjs before <baseline.html>` 和 `after` 在同一离屏 Chromium、1680×1000 窗口及设备像素设置测量：启动、鱼、熊/猫/斑鸠、播放/暂停及删除后内存。CDP 堆数据与 backing storage 分开记录，不能把 JS heap 当成总 GPU 内存。几何属性统计按 ArrayBuffer 去重；快照统计是数值存储大小。暂停绘制次数与活动帧的 CPU 求值耗时分开，不能用暂停零帧来宣称活动帧无限加速。

`tools/compare-function-pixels.mjs` 在同一鱼场、下颌、鳃、眼参考系、个体色彩、相机和形态偏移下比较像素。浮点求值允许极小的边缘差异，不能更换动物、镜头、材质或采样密度掩盖差异。原始模块指纹、全目录回归和离线零网络仍是验收条件。
