# 连续观察时的展示稳定性修复

用户提供的 16.75 秒椰子蟹录屏，在拖动与自动环绕中出现圆台消失、亮灰地板占满背景、低角度观察被台底遮住的问题。此次修复保留产品棚灯、动物本身和全部鼠标观察方向。

- 移除 Three.js 展示台的 1000 × 1000 实体地板，只保留有限圆台承接阴影。背景颜色不再随相机仰俯变成受光地面，也消除了巨大共面接收面的深度竞争风险。原生 WebGL 展示也只绘制圆台范围，不再生成无限地面。
- 窄窗口适配使用镜头投影，不修改动物运行器的相机位置、朝向或轨道半径。每帧从镜头公开参数重建投影，不叠加上次适配；保留实际显示投影供原生点选使用。近裁剪按台面尺度临时改善，渲染后恢复公开近裁剪参数。
- 椰子蟹和普通螃蟹已有横向适配，不再重复缩小；鼠标输入只更新源运行器的 yaw/pitch，交给原循环绘制，避免穿插旧镜头帧。捕获画面等待源循环更新相机。
- 相机下降到圆台平面时，圆台按高度平滑淡出；在台面上方正常观察保持实体圆台。允许观察腹部，避免一块全黑台底挡住对象。不限制水平环绕或仰俯方向。
- 自定义 GLSL 灯光的强度归一基准与产品灯组默认值统一，修正上一版仍引用旧灯组基准的遗漏。

`tools/test-studio-orbit.mjs` 使用离屏浏览器检查 19 个动物的真实鼠标拖动和画面变化；对可直接访问的 Three.js 相机检查连续 20 次重绘不改变位置、朝向、镜头公开近裁剪参数或累积投影。椰子蟹另检查窄窗口、浅角度、俯视及底部视角、四角实际背景像素和台面可见性。固定灯位、统一调参、活体导出与排练回归继续运行。验收报告绑定实际 HTML SHA256；不把单帧截图当作连续交互验证。

镜头参数原理参考 [Three.js PerspectiveCamera](https://threejs.org/docs/pages/PerspectiveCamera.html)。以仓库中使用的 Three.js 版本和实际运行检查为准。
