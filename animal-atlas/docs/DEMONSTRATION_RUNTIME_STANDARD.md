# 统一演示映射 kaopu/demo-map@1

用户明确选择先使用统一的程序化演示规则，后续由动物自己的算法替换。此层作用于实际对象变换、材质和原生动作时钟，不是生长学、医学或体重预测模型。原动物几何、花纹、骨架、动作和专属参数保留。

## 一份数据与一套控件

`src/parameter-catalog.json` 的 demonstration 段定义六个运行参数。`parameter-ui.js` 生成全部控件，`profile-ui.js` 只负责共用布局。它们独立于个体档案 `kaopu/profile@1`，按原运行参数写入 `score.parameters`。已注册的新运行器可使用同一桥接层；旧版本活动包没有此层时，不假称支持。

| key | 控件 / 值域 | 默认与作用 |
| --- | --- | --- |
| demoAge | 滑块，0–1000 年，0.01 精度 | 1；决定演示成长比例。滑块位置采用四次方映射，低龄区间更易操作 |
| demoMaturity | 滑块，0.1–50 年 | 1；演示成熟年限，任意校准值，不是物种资料 |
| demoSize | 滑块，0.25–3 倍 | 1；附加整体倍率，不修改声明体重 |
| demoCondition | 滑块，0–100 | 50；改变横截面比例，保留长轴 |
| demoHealth | 滑块，0–100 | 100；降低或恢复原生动作时钟速度；没有原生动作时界面禁用 |
| demoTint | 颜色选择器，#RRGGBB | #ffffff；乘性叠色，保留原花纹，不代表多色生成规则 |

“成长阶段”使用同样的滑块，五个位置为初生、幼年、成长中、成年、老年。选择阶段将年龄设置为成熟年限的 `0 / 0.25 / 0.65 / 1 / 2` 倍；拖动年龄后，阶段按年龄/成熟年限的 `0.1 / 0.45 / 1 / 2` 分界刷新。最后操作生效，不维护两份相互矛盾的模型状态。成年后的尺寸保持成熟值；当前没有衰老形态规则。

## 明确的数学规则

```js
x = clamp(demoAge / demoMaturity, 0, 1)
growth = 0.35 + 0.65 * x*x*(3-2*x)
crossSection = 0.75 + 0.5 * demoCondition/100
activity = 0.15 + 0.85 * demoHealth/100
longitudinalScale = demoSize * growth
transverseScale = longitudinalScale * crossSection
```

默认值产生单位变换和白色叠色，保留原样。健康为 0 仍保留 15% 的生命活动；暂停通过已有动作播放开关控制。年龄为 0 的 35% 大小是演示约定。胖瘦是整个对象横截面的比例变换，会作用于附肢，不重建解剖、骨长或组织。该方法只是可替换的展示适配器。

鱼、猫、鹰及 Palau 鸟使用原模型 X 长轴，其他运行器使用 Z 长轴；Z-up 原模块在显示和导出时转为 Y-up。Three.js 使用额外 Group，原骨绑定不改变；鱼使用已有 GPU 个体比例与叠色字段；原生 WebGL 猫/鹰使用模型矩阵和颜色 uniform。鸡的程序材质通过颜色 uniform 叠加，保留原着色过程。健康乘到鱼、猫、鹰、生活动物、蟹、Palau 鸟及有动画片段的导入模型的原生时钟，环境光线与展示环绕不被它替代。

## 保存、导出与导入

直接调整演示控件同时记录对应档案字段。未知档案仍允许 null，默认演示值不自动伪装成真实年龄或健康资料。原生主体色与 demoTint 叠色分开保存。成熟年限不自动写入物种知识。

乐谱、完整动物包、配方与独立 HTML 保存实际六个参数。烘焙 JSON / GLB 保存已变换的实际几何与颜色，GLB 仍是静态当前姿态；程序着色器本身不转换为 glTF 材质。需要原材质及动作时使用独立 HTML；活动烘焙保留原运行器供排练台继续活动。

静态烘焙/GLB 再入库不会根据 profile 重复应用原成长/胖瘦/叠色。随后调整快照时，新的附加形态用活动包 presentation.scale3、tint 与 activity 传递；这些值受有限数和范围校验约束，旧文件不含它们仍兼容。

未来真实成长或健康算法应由乐器提供声明参数和算法，替换对应演示映射，并声明能力及单位。规范不限制额外功能；仍归入专属参数，禁止暗中把演示数值宣称为科学事实。

## 切换进度

使用原生 progress 元素，四个已完成阶段：文件解包、开始生成画面、绑定参数动作、准备完成。开始为 0/4，完成为 4/4；进度由真实事件驱动，失败停在未完成位置，重试/切换重置，旧 iframe 消息不能推动新对象进度。不用转圈或定时假百分比。这里衡量完成阶段数量，不估计剩余秒数或字节百分比。

平台接口参考 [MDN progress](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/progress)。运行验证记录见 qa/FUNCTIONAL_SLIDERS_REPORT.json；验证涵盖实际几何、控件事件、原动作时钟和离线往返，不能自动代表用户视觉验收或生物准确性。
