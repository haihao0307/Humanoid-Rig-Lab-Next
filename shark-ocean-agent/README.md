# Pelagic Shark Ocean Agent 0.1.0

A procedural Three.js juvenile white shark candidate. Dedicated scope: shark-ocean-agent/ and .github/workflows/shark-ocean-agent.yml on experiment/shark-ocean-agent-v1. No changes to main, gh-pages, existing applications, Ocean Mother or frozen Weather sources.

## Source basis

source/weather-contract.js retains the exported adapter bytes. ocean.js adapts the 24-component wave generator and adds an inverse horizontal Gerstner lookup. It does not import or replace the frozen cloud kernel. Water optics, underwater current, seabed and vegetation are new illustrative components, not measured bathymetry or validated CFD.

The uploaded Mother Unified Evolution Method 1.0.0 candidate and the user's World Human System Direction guide the separation of bind structure, pose, execution, environment and evidence. SharedWorker multi-window synchronization and the full original strict policy schema/validator are not integrated here.

## Anatomy and provenance
- NOAA White shark: https://www.fisheries.noaa.gov/species/white-shark
- Florida Museum Shark biology: https://www.floridamuseum.ufl.edu/discover-fish/sharks/shark-biology/
- Ram ventilation study: https://pmc.ncbi.nlm.nih.gov/articles/PMC3730586/
- Three.js SkinnedMesh: https://threejs.org/docs/pages/SkinnedMesh.html

The shark uses one actual SkinnedMesh, normalized skin weights and inverse bind matrices, 22 axial controls, skull, hinged jaw, paired pectoral/pelvic controls and a caudal control, totaling 29. This is a control rig, not the anatomical vertebra count. All surface geometry, eyes, gills, fins and teeth are generated from code. Reference-guided approximate proportions are not CT or specimen measurements. Motion coefficients are uncalibrated graphical parameters.

## Runtime
User text -> compositional parsing or explicitly connected semantic service -> BehaviorPlan -> live world grounding -> constrained steering -> desired local rotations -> final skeleton -> skin and mouth contact -> event-backed completion.

No AnimationClip assets, fixed route waypoints, scheduled autonomous hunting, prerecorded capture, or unconditional timer-based prey removal. Hunting requires current-epoch authorization plus swept mouth contact and jaw opening. A contact grip brings the same fish into the mouth before consumption. New instructions cancel the old plan and release a grip. Fish school and flee reactively; consumed fish never respawn without a user spawn instruction.

Default language support is a bounded compositional parser, not unlimited natural-language intelligence. Quantities, sequences, target identifiers/colors, depth, duration and directions can be combined. A browser LanguageModel adapter checks Chinese support and reports unavailable honestly. An optional user-selected HTTPS service accepts {instruction,world,schema,plannerContract}, returning a validated plan or {error}. No key or secret is embedded; no command is sent to a third party by default. Real inference requires an available connected model. Adding new motor skills still requires implementation.

Modes: ocean, neutral, studio and cartilage diagnostic. Light controls change presentation only. Fixed solver step 1/120 second; simulation time and display time recorded separately. Long-frame debt is retained; background rendering is explicitly suspended.

## Build and review
Online repository shims pin Three.js 0.185.1 via jsDelivr. CI replaces them with locally vendored engine bytes and LICENSE in the candidate artifact. Serve the artifact directory over HTTP. The independent source implementation has local rig/grammar checks; qa.cjs captures actual Chromium images and verifies core runtime and capture conditions. Evidence remains tied to the workflow head. CI passing does not imply anatomy or visual approval.

Current source is an experimental candidate. visualApproved=false; productionApproved=false. Open-language model inference, precise anatomical validation, hydrodynamics, complete methodology adoption and final user visual approval remain outstanding.
