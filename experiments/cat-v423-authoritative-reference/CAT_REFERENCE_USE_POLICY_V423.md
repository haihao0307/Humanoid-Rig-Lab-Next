# CAT V4.23 权威完整身体参考使用规则

## 已选主参考

主参考固定为 University of Edinburgh Open.Ed 发布的 `Domestic Cat (Felis catus)` CT 衍生家猫骨架模型，Sketchfab UID 为 `7c99ca836d834c39872ecf5e9b5e2087`。

## 使用职责

该模型负责完整骨架拓扑、颅骨与脊柱关系、胸廓、肩胛、骨盆、四肢骨段及掌跖趾关系。V4.22 DigiMorph TMM M-628 继续负责高精度颅骨函数真值。

活体外轮廓、肌肉体积、筋膜与皮下滑动、耳廓软组织、肉垫、胡须及皮毛均须使用独立证据。不得由骨架外扩一个固定厚度直接得到成品猫。

## 原件进入工程后的固定顺序

1. 保存下载原件，不改名，不重导出。
2. 计算 SHA256、文件字节数及压缩包目录。
3. 保存来源页、模型 UID、许可声明、作者与机构。
4. 锁定坐标、单位、静止姿态与左右方向。
5. 提取只读参考几何副本。
6. 按头、颈、胸廓、肩胛、前肢、前足、脊柱、骨盆、后肢、后足与尾椎分区。
7. 每区记录中心线、截面、局部坐标、函数系数和误差预算。
8. 从参数和函数重新生成项目自有曲面。
9. 同时测量参考到复刻、复刻到参考两个方向的距离。
10. 达标区域冻结，失败区域单独细化。
11. 参考原件退出正式运行时。

## 商业与发布边界

来源页面声明 CC Attribution。正式使用前仍须保存官方下载包随附许可和下载回执。当前阶段全部第三方参考仅用于研究、测量、验证和函数反求。正式网页与 App 运行时只读取项目自有参数、函数和二进制数据。
