## Important limits

The tests use a deterministic fake adapter. The soak checks long-horizon scheduler/state-machine integrity under varied accepted dt values, not actual elapsed-time simulation. The 50-cycle fake-adapter soak does not call the renderer, GPU or published life-room website. The route soak exercises the actual controller and IK in source code but does not render skin or measure actual surface self-penetration. The new route soak executes the actual repository locomotion controller and leg IK in a flat test world, but it is not the full skinned character and does not render the published life-room website. The additional existing-core tests do execute source-level kinematics/attachment/release algorithms, but still do not render the published room or establish visual naturalness. The 166 gate probes prove each declared gate can reject a deliberately failed observation; they are not 166 physical scene tests. Trace-auditor tests also use synthetic traces; the auditor has not yet consumed a real exported character trace. The motion speed/acceleration thresholds are initial configurable guardrails and need calibration against real captured motion and the actual full-body controller. The module is an isolated orchestration candidate, not a learned motion policy and not a claim that the character can autonomously solve unseen environments.
