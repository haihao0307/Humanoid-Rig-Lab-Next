# 常驻人物函数显示流程

## 可复用入口

`src/workspaces/photo-female-001/resident-r03/index.html` 为本轮隔离验证入口。原母体函数不改，照片肤色候选与默认女性变量仍按各自来源保存；本轮不把运行成功当作真人复刻验收。

## 资源与更新

1. 准备原函数平面及原 trim、器官分层、原法线和材质高低系数。
2. 固定形态的保守支持域及搜索 BVH 在加载时准备并常驻显卡；支持域不是人物显示表面。
3. 直接对原参数化平面复合女性正向函数求交，并使用其解析 Jacobian；同一交点的源坐标和 Jacobian 随结果传到法线及材质阶段，避免重复逆变形。
4. 眼球各层、折射后的内层、角膜出口及头部遮挡保持分别求交。数值边界使用补偿算术精化，按原 trim 和原首交比较；不确定项不能当作空域。
5. 常规转动只提交相机，所有源表和材质表继续驻留。交互调度只保留最新待绘视角，停止拖动后不启动另一套 CPU 重建。
6. 改形时更新相应形态资源和支持域；改材质只更新材质变量；三种更新的失效范围分别记录。

## 色彩与观察光

照片拟合的中性色照明增益与组织吸收色彩分开。皮肤、嘴唇、眉毛、眼周湿组织和真实眼线覆盖采用各自的已有组织权重及吸收方向。不能通过截断反照率或局部涂亮来掩盖错误。

统一的中性观察环境供皮肤、眼睛和口腔使用；旧观察场景保留作对照。单张照片的光照与反照率分离仍有先验歧义，属于可检验的重建假设。

## 验证规则

- 记录源版本、加载上传量、首次准备和冷绘制；预热后记录完成整帧而非提交命令的时间。
- 检查新角度、真实连续拖动、停止拖动后的最后一帧；准备完成后的源上传及重新下载应为零，常规视角更新的 CPU 求交次数应为零。
- 原权威核在相同相机下对照组件、owner、首交深度、法线和 trim 边界。平均误差不能掩盖漏层或局部极大差。
- 每次物理材质修改分别检查反照率、直射、环境、镜面和法线，使用当前图与分量数值；有限相机验证不代表全部姿态已验收。

本记录由当前结果持续补充；性能与视觉数据以 `qa` 下本轮实测记录为准。

## 已验证的交互边界

预热期间的相机/材质/灯光请求也必须置dirty；预热不并行续帧，完成两bank后兑现最新dirty状态。已用第二个GPU预热帧在飞期间的实际输入验证。显示标签引用已完成renderView，不能引用尚未显示的请求姿态。

旧GPU fence完成后的续帧使用MessageChannel排task，保留scheduled和drawing门；第一笔交互仍以rAF合并输入。?schedule=raf可比较，A/B/B/A数据在`qa/female-continuation-ab-20261107/`。

`tools/build-female-adaptive-banks-20261107.cjs`是早期一次性生成记录，包含后续人工修复前的模板，默认已阻止运行，避免覆盖当前已验证模块。后续复用直接维护resident-r03当前模块和上述验证脚本；若确需重新生成，先同步生成模板并重新验证全部模块。
