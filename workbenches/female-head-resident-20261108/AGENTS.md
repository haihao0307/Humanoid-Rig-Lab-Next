- 不要抢用户的鼠标。视觉检查使用无窗口浏览器或其他不干扰桌面的方式。
- 不要只做少量任务就停止；在授权范围内持续完成并自行检查结果。

- 用户未主动询问时，不要在任何工作台的进度或交付汇报中重复报告历史主要板块的数量或验收状态；只报告当前任务实际相关的完成情况和限制。历史记录保留，用户明确询问时再查询说明。

# 人物函数显示：资源常驻与相机交互

用户于 2026-11-07 要求彻底解决转动头部后再次等待数秒的问题。本目录内人物交互工作台共同遵守：

- 加载阶段准备原函数、当前人物变量、保守搜索索引、原分层、材质及光照资源，并完成绘制程序预热；常规转动只更新相机和当前帧显示。
- 默认交互不能每换一个角度就回到 CPU 逐像素重建、重新上传整份函数或重编译程序。原 CPU 核保留作离线权威对照。模型参数、材质参数与相机更新必须有明确的不同失效范围。
- 指针交互只保留最新待绘视角；已访问角度缓存不能代替对全新角度和连续拖动的性能验证。
- 报告真实完成一帧的耗时及连续拖动结果，分别记录首次准备、冷绘制与预热后的绘制；仅提交绘制命令的耗时不能称作帧率。
- 性能修复继续服从原函数、原 trim、原器官层与首交遮挡要求。加速包围域只负责排除搜索；数值不确定项必须精化，不得用删除、涂色、填洞或放宽验收容差冒充通过。
- 照片照明、皮肤反照率及展示灯光分别表达。高光或暗斑应先按分量定位原因，不能只凭整体图片修改粗糙度、亮度或局部肤色来掩盖。

# 头发形态表达：先于材质的硬性验收规则

用户于 2026-10-29 明确要求先解决发丝折线、抽象折角和机械整齐的成排头发，并要求所有状态、所有姿态的形态无限接近真实头发。后续头发工作必须先阅读并遵守 [HAIR-MORPHOLOGY-RULES.md](HAIR-MORPHOLOGY-RULES.md)。

- 先解决形态表达，再推进材质；静止好看不能代替动态与姿态过渡正确。
- 任何状态下出现折线式发丝、非自然折角、机械等间距成排、重复束片或同步成排折弯，均判定为失败候选。
- 必须修复产生错误形态的函数、插值、分束或变形原因；不得用材质、模糊、加粗、随机抖动或遮挡隐藏。
- “所有状态、所有姿态”是持续约束；有限截图、抽样与技术测试不能证明已经覆盖全部情况。未检查范围必须明确列出。

# 人物函数化重构：原数据一比一复刻规则

用户于 2026-10-23 明确要求：

> 不能自己擅自地去做近似的处理，全部都是得按照原数据进行一比一复刻，然后再去用我们的这个参数逻辑去调整。

本规则适用于本目录内人物头部、身体、器官、附件与相关控制的函数化重构。

1. **先忠实复刻母体，再用参数调整。** 原始表面数据及其分层、边界、尺度、位置、法线、曲率与遮挡关系是重建依据。默认母体和参数默认状态必须对应原数据，不能把改过的形体作为迁移基准。
2. **禁止擅自近似或改形。** 不得为了方便实现、提速、去波纹或让页面能显示，自行简化、平滑、合并分层、加厚、填洞、删结构，或用猜测的球体、椭球、椭圆开口等替换原有表面。函数形式必须服从原数据，不能让原数据迁就预选函数形式。
3. **函数化不等于简化。** 人物权威形体由函数、变量和噪波表达，显示直接求交函数。不得恢复人物三角网格显示，也不得将原顶点/面连接改名为变量来冒充完成转换。离线原模型可以作为对照和误差验收基准。
4. **结构必须分别保留。** 眼球与眼睑、鼻翼与鼻孔、耳廓各层、唇缘与口腔等必须依据各自原始数据重建；不能用一张外包络或高度图丢弃内层、折返和开口。
5. **先与原版验收，再开放参数变化。** 必须用同机位、同比例、相同观察条件检查正侧背面与局部近景，并比较表面位置、法线、边界、分层和首交遮挡关系。原控制的默认状态和已有调整效果也须保留。数值容许范围必须明确记录，不得自行放宽，更不能只用平均误差掩盖局部缺陷。
6. **运行正确不能代替复刻正确。** 编译、交点残差、帧耗时、按钮与存档测试通过，只证明相应技术行为；不能据此宣布一比一重建通过。
7. **未通过就保留为失败候选。** 对照中出现明显差异，必须记录具体部位、差异、原因及证据；不得以“完整重构”“迁移完成”交付或覆盖已通过的原版。研究性候选须隔离保存。
8. **有意改形属于后续参数阶段。** 只有原数据复刻验收通过后，才使用用户的参数逻辑改变人物。未经用户明确授权，不得把偏离原数据的改动混入母体重建。
