# Bird Mother｜Seagull A 精确运行时交接包 R0.12

R0.12 承接已经完成来源限位、异常回退和公共相位时钟的 R0.10–R0.11。它不制作新鸟、不重建羽毛，也不补造尚未提供的飞行姿态；本版把同一份来源拍翼状态封装成一个可校验、可复算、可拒绝损坏数据的固定二进制交接包。

## 本版完成

- 固定包长为 **66 字节**，小端序；
- 直接保存 R0.11 的精确整数 `phaseTicks`，不再用浮点时间或刷新率近似相位；
- 保存周期编号、采样率、事件序号、事件掩码、五个 Q16 控制量、11 个活动通道和两个只读腕部通道；
- 控制量先量化，再通过 R0.10 重新计算通道，因此解码后可逐通道复算；
- 使用 FNV-1a 32 位校验和检查传输损坏；
- 解码时检查 magic、schema、flags、采样率、相位范围、事件位和校验和；
- 解码后必须以已存控制量和精确相位重新执行 R0.10，每一个 Q16 通道不一致都会拒绝；
- 建立确定性重复编码、解码—重编码、单字节损坏、重算校验和后的伪造通道、非法采样率和精确事件相位测试；
- 来源鸟体保持只读，交接包不修改来源网格。

## 为什么需要这一阶段

网页里“看起来一样”不足以保证以后进入游戏运行时仍是同一段运动。普通实现常见的失败包括：浮点相位漂移、字段顺序变化、不同机器采用不同默认值、损坏包被接受，以及通道数据与控制量互相矛盾。R0.12 把这些风险压到固定字节布局、整数相位、明确量化、校验和及合同复算中。

## 边界

66 字节是这一份来源合同的运行时交接格式，不是鸟类动作的生物学标准。它不能补足来源中没有证明的外翼扇面、展向扭转、飞羽展开、空气载荷，也不能生成滑翔、翱翔、转弯、起飞、着陆或逃逸。
