# Quick Shorts R4

A fast, card-driven approximate shorts preview for `human-r001`.

- Uses the audited R3 measurement card as the starting point.
- Loads the preserved browser reference surface of the target human.
- Hides the original shorts parts.
- Generates a lightweight, adjustable shorts preview around the person.
- Preserves all current settings in `card-data.json`, local storage, and an export button.

This is deliberately a rough fit shell, not a physically solved garment. It does not claim cloth dynamics, continuous collision, motion acceptance, real-world sizing, or production readiness.
