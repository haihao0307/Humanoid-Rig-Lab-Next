## 已确认的错误与修复

原 R05 线体的三角形绕序向内，FrontSide 渲染剔除了外壳，只显示内侧。直线检验、带孔射线和控制台零错误不足以证明弯曲线体正确。现在对整条弯曲线体每个三角面检查朝向，并检查两端端盖；没有用 DoubleSide 隐藏错误。

旧一般圆滑算法在孔口产生过小转弯半径，管状线体自折。新版本使用切线连续的入孔、出孔转弯与均匀弧长采样。普通成品每排是一根连续线，第一孔不再把三根短管加端盖接在一起；双色诊断仍可辨认同一根线的 A/B 两端。

皮革上层粒面、底面与孔壁/切边有独立材质角色。经源码与测试确认，截图中主要的内翻根因是线体绕序，不能简单解释成所有皮革顶面都贴反了。

针孔使用与线径匹配的较小开口、微小不规则轮廓、浅槽和孔口转折。正面、背面、孔壁保持真实几何。此版不是用照片盖住孔与线，也没有放弃连续穿过两层皮革的针路。

## 收线后，皮面如何变化

site/contact-surface.mjs 是独立于 R04 的局部弹性表皮模型。给定针孔转向处的线张力，构造局部接触载荷，求解带弹性基底的薄皮层方程，以及侧向弹性响应。正面、背面、孔壁和线体都使用同一个形变场；不是固定皱纹贴图。

正常收线出现局部压陷、邻近微隆起和侧向牵动；增加张力会增加这些变化。零张力时，载荷引起的形变为零，针孔和预设浅槽仍保留。逐针展示中，当前孔的局部加载随收线阶段变化，未缝到的孔不预先施加全部载荷。

默认示例：张力0.8 N、线径0.40 mm、每层皮厚1.4 mm。当前模型的最大局部压陷约51.8微米，最大侧向位移约12.0微米；2.4 N 对照的压陷约155.5微米。这些是未标定模型的计算输出，不是实测数据，也不能直接当作所有皮料的通用响应。

局部方程为 (K+S L+D L²)w=p，使用共轭梯度求解；参数与残差在源码/导出中保留。当前是线性薄皮层加弹性基底的近似，尚未处理非线性屈曲皱褶、整根线张力传播、摩擦、自接触、缝制残余应力、针孔撕裂、永久变形或收尾打结。不能把小压痕等同于完整皮具缝合力学已经完成。

## 如何直接观察

点击「针脚微距」，再打开「掠射光检查」。依次对比「松线」「正常收线」「过紧对照」。按住「无牵拉形变对照」时，保留当前针路和镜头，只关闭载荷导致的表皮形变，便于确认变化来自哪里。

「翻看背面」「剖面穿线」「双色针路」仍保留。「隐藏线看针孔」可以独立检查孔壁。剖面是观察方式，不是把表面切开后冒充成品；A/B 是同一根线的两端，不是两根机器缝纫线。

## 写实外观与老师

AMANN Serafil / Serabraid 的制造商资料用于认识连续长丝、紧凑线芯、细捻纹与皮革用线的微光泽。Coats 缝口起皱资料用于区分适度压痕与过大张力导致的缺陷；该资料主要讨论织物缝制，不当作皮革实测弹性标定。

写实粒面采用 Poly Haven 的 Brown Leather，作者 Rob Tuytel，CC0-1.0。原8192×8192纹理对应400 mm；本版使用原像素3072×1536裁切区域，对应150×75 mm。使用独立底色、OpenGL法线和粗糙度图，保留源文件与处理文件SHA-256。未分发第三方预览渲染图来冒充本工作台。

默认「精细涂饰粒面」对真实底色作薄层颜料覆盖的视觉近似，减弱原始做旧色斑，并降低大褶皱凹凸强度；「原始做旧粒面」保留为对照。这是独立外观处理，不是重新测量出一种新皮料。不同配色并不代表八种独立实测皮革。

原 R02 程序材质可切换对照，其源文件未改动。原 R02 工坊在保留标签页中仍是历史版本，旧装饰缝线不作为 R05.1 的结果。
