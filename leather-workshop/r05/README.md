采用其预打孔、槽线和双针马鞍缝逻辑：一根线两端各穿一针，第一孔将两端关联，后续孔由相反方向穿过，再收紧。A/B 不是机器的面线和底线，而是同一根线的两个端。

## 实际改动

新针路以孔 ID、线 ID、线端 ID、正面段、穿孔段、背面段记录。双针马鞍缝的两个端在第一孔相接；后续孔使用相反方向、分开的穿孔通道。单针平针提供一条正反交替路线作对照。每排有自己的单根线，不把两排独立针路冒称为一根线。

皮样由两层真实几何组成；针孔具有前后开口和完整孔壁。针距、线径、每层厚度、孔向、孔数、排数与线形松紧可调。孔口带浅槽，线在入口与出口作有界圆滑转折，不再使用无连接的表面短圆柱。松紧为几何松弛参数，不是牛顿单位张力。

线体使用连续实体线芯、浅捻纹和程序化纤维法线/颜色细节。第一轮实际微距检查发现分离三股太像绳索，已改为紧凑缝线；同时修正自阴影条纹、针在阶段停止时的穿孔轴向、整体与背面的取景以及背面照明。这里的曲线/管状几何是显示连续线体的工具，旧问题是缺少真实针路而不是“用了曲线”本身。

逐针演示提供第一端就位、穿孔、第二端反向穿孔和收线阶段，可暂停、逐阶段检查、返回成品。针模型为缩短的局部示意，路径按教程规定，不是缝纫机运动学或针线受力求解。

原 R02 LeatherKernel 按原字节复用；原 R02 HTML 也完整保留在材质标签页。用户可把其中的外观配方传给新缝制。原材质页里的旧装饰缝线保留为历史，不作为 R05 的新穿线结果。新针路没有擅自写回冻结的 R04 动力学。

## 观察方式

先点「针脚微距」，再看「翻看背面」「剖面穿线」和「双色针路」。剖面仅将前半皮革从显示中移除以看内部，线的路径不变；双色只用来辨认同一根线的两个端，不意味着真的使用两根不同线。

「隐藏线看针孔」可以独立观察真实孔壁。「看一针怎么穿」自动进入局部剖面；「下一阶段」逐步检查针与线的路线。最初的孔、针数和两层厚度在侧栏显示，标尺是观察中心的投影参考。

支持保存/恢复、配方导入导出和完整路线 JSON 导出。routes.points 是圆滑后的实际显示中心线；parts 保留制造逻辑分段和孔 ID。没有把只有表面截图的文件当作可复用针路。

## 边界与成本

没有实现机器 301、自动回针收尾与结、逐针张力、摩擦、孔边撕裂或与 R04 的动态耦合。自由线端仍是自由端，不用暗藏断线冒充已打结。两层皮革位置是指定的制造状态，孔为旋转长圆近似，不是切削/断裂仿真。

显微线体比旧表面短线有更多几何开销。默认总上限为每排25孔、两排；捻纹细节可关闭。桌面2K、窄屏1K材质分辨率。没有把皮革原材质或已经认可的物理调差以迁就缝制。
