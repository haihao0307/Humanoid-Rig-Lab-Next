## 本版实际新增

8 套基础配方：原色细粒、油蜡棕革、荔枝纹革、磨砂牛巴革、交叉压纹、矩形鳞片压纹、毛囊珠点压纹、绒面反绒革。名称为生成器外观类别，不等于真实动物扫描或原作材质认证。

7 种独立涂饰：透明染色、颜料涂饰、油蜡抛光、消光、漆皮、金属箔、珠光。可与基础粒面交叉组合，不把组合数冒充已经逐个验收的素材数。金属 / 珠光为实时 PBR 涂层外观近似。

多尺度粒面场加入非均匀畸变、可变谷宽、微孔、细皱褶、裂纹 / 擦痕与分区色差。底色、法线、粗糙度和遮蔽从同一生成场派生。着色不是对最终画面作锐化或加静态图片。

几何工艺包括菱形、方格、条形三类绗缝，一类经纬交错皮条编织；圆孔、分区圆孔、长圆孔三种贯穿孔设置；单排、双排、交叉、锯齿四种针法，以及关闭缝线、包边开关。针距、线径、颜色、厚度、绗缝尺度 / 起伏、编织目标间距、孔径与孔距可调。球体只做基础材质校验，不展示这些几何工艺。

孔洞有前后开口和孔壁，不是黑点贴图。编织是分离皮条，没有下面垫完整皮片来冒充交错。绗缝仍是静态参数曲面，不是力学仿真。

## 看图后的修正与回归

第一轮画面暴露菱形线迹相位偏移、平铺镜头裁角和编织表面法线不足。修正后，线迹与绗缝凹槽读取相同整数周期；双排针用于内外缝线；编织法线从实际皮条几何计算；平铺取景重新居中并退开。工艺按钮移到视口上方，免去在长侧栏内寻找。

R01 原生成算法已保留为同曲面、同相机下的按住对照。新增粒面没有 R01 同类时明确提示，不用另一种纹理假冒旧版对照。R01 的独立固定链接仍有效。

## 导出与体系接入

材质谱升级为 kaopu/leather_material@2。支持导入 R01 @1，保留已有颜色、粒面、凹凸等设置，并补入 R02 参数。无效类型、范围与配方拒绝载入。

完整材质包包含 baseColor.png、normal.png、roughness.png、ao.png、height16.png、recipe.json 和 README.txt。高度图是实际 16 位灰度 PNG；源高度场用 GPU 半浮点计算，不声称拥有实测扫描的完整 16 位信息精度。

坐标为一 UV 单位 = 96 mm。PNG 底色为 sRGB，法线 / 粗糙度 / AO / 高度为线性数据；法线为 OpenGL +Y。高度毫米值 = PNG 像素整数 / 65535 × depth。GPU 的 maps.height 为 RG 字节打包，采样解码为 (R×65280 + G×255)/65535，再乘 depth；不能把它当普通灰度贴图直接接入位移通道。

贴图包只包含可平铺的皮革基础材质。绗缝、穿孔、缝线和编织属于真实几何，需要依照材质谱中的工艺参数重建，不在这五张平铺贴图中。没有声称已经向人物或裁缝铺写入生产适配。

site/leather.js 提供 LeatherKernel / DEFAULT / PRESETS / FINISHES；site/craft.js 提供 buildCraft；site/export.js 提供材质包及 PNG 编码。接入已有衣服时只替换明确的材质槽，保留身体、服装网格、骨骼与静止 UV，另外明确毫米尺度映射，不能缩小人体或放大整件衣服来迁就纹理。

## 重建与保留历史

在仓库中运行 python leather-workshop/r02/assemble.py。需要 Python 与 Node；不需要 Adobe 软件或在线素材下载。它验证 R01 原始源码哈希，继承已经审核的 R01 lookdev，再应用 R02 适配和 corrections.json，输出可直接打开的 preview.html 与哈希清单。

site/ 中的 app.js / template.html / legacy.js 是完整的已展开源码，保留全部已应用修正。后续只读原始 R01 或绕过 R02 assemble 都不能算本版。完整项目包包含必要的 r01 继承输入与 r02 源码，以便复现。
