## 实际源码

site/sewing.js 使用冻结 R05 的 saddle buildSeam、continuousRoutes、auditSeam 和局部接触场。只在构建装配时扩展针孔数量、厚度的输入范围，不改写 R05 文件。针脚不是散放的短 Cylinder/InstancedMesh；一根连续线按原针路经过正面、真实孔壁和背面，映射到产品纸样曲线。显示截面为扁蜡线，附带原线芯微纤维法线。孔内转向时有退化切线保护，不能把圆管轮廓改扁就算完成穿线。

site/panels.js 创建真实粒面、背面、切边和贯穿孔，局部纵向与侧向形变来自 R05 contact field。松线、正常收线、较紧及按住关闭局部形变使用同一对象/镜头。长皮带采用避开完整孔口的纸面分区，降低一次性三角剖分成本；不会在分区边界增加假切边。surface-integrity.js 在索引生成前清理重复轮廓点，并去除周期参数接缝处不应存在的切壁，防止帽冠上出现假的黑色裂缝。数值测试用真正的射线穿孔检查，而不只检查原 R05 参数是否有效。

site/products.js 构造卡包、腰带、肩包、牛仔帽、三角海盗帽和皮样。帽子具有独立帽冠、帽顶、宽帽檐、帽带和固定件；是本项目原创造型研究，不是付费纸样的复制。原 R02 八种材质预设与 R06 的全部十三个材料/涂饰入口保留。绗缝（菱形/方格/条形）、穿孔和交错编织可用于卡包、肩包和皮样。帽子与腰带不显示不适用的工艺结果。

新旧变化使用边角、折转、暴露方向和细划痕的材质响应，包括磨亮、褪色和边缘磨损。三个外观状态不是有实测依据的服役年数，也不是化学氧化/紫外老化求解。绗缝鼓包为构造形，尚无填充物压缩、气腔或逐根编织摩擦模型。

## 抓取并非物体整体旋转

点「抓手」后光标为抓取手形；按住皮面取得当前物理三角形的重心权重，目标来自鼠标与相机平面的交点。ProductShell 根据重力、惯性、膜内响应、弯曲、连接和接触更新节点。高精度皮面、孔壁、缝线与五金绑定到这个节点场。松开后保留速度；「归位」明确恢复初始构造姿态。初始陈列姿态不是已经求出的重力平衡。

site/grip.mjs 是独立 R07 积分器。它使用 R04 SurfaceLaw 的 NL 零应变切线及 signed dihedral 导数，膜内为客观 Green strain 的耦合 XPBD 近似；不能称为完整 R04 非线性本构加原隐式积分器。米、千克、秒统一；质量依曲面面积、实际厚度、假设密度700 kg/m³及指定五金质量计算。弯曲刚度为0.002×(t/1.39 mm)^3 N·m的未标定输入。厚度改变几何、质量、膜参数与弯曲，而不仅改变颜色。

抓取目标有有限追随速度；固定子步1/240秒，不为了追上帧率加大时间步。小连接片应变过大时增加约束迭代，而不是夹住显示坐标或播预设摇摆。节点数、物理时间、伸长、抓点误差和抓力可查看。强烈甩动并不保证收敛到工程精度。

自接触仍是非邻接粒子接触，不是三角面连续碰撞。快速折叠、穿插、细五金接触仍有局限。完整缝线张力传播、摩擦、孔口损伤、断裂、永久折痕、皮革真实鞣制差异及实物标定均未完成。外观类型不自动等于独立实测材料。夹克未在此轮实现。

## 检查与交付

python build.py 装配单体 public-lite.html，内含核心脚本、纹理、物理内核及冻结 R05 字节。node test-numerics.cjs 验证穿孔、连续线、受力/释放、局部接触对照和厚度缩放。python qa.py 验证实际浏览器、相机、材质、工艺、抓手和手机视口；公网同样执行，不把本地运行等同于对外可达。

缩略图仍是可旋转的三维几何，但不运行受力积分；点选主视图后才挂接抓取场。孔口、连续线和局部纹理仍真实生成。高密度缝线与孔网格有加载、CPU和显存成本，不承诺所有手机60帧。桌面 Chrome/SwiftShader 与390×844视口模拟不代表手机实机。

卡包和腰带提供当前纸面轮廓与孔位的毫米SVG试作文件，必须按校准尺打印并先用废皮打样。削薄、五金配合、孔型、装配余量和实物尺寸仍需检查；帽子和肩包没有生产定版纸样。
