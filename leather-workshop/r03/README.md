## 本轮任务与保护边界

用户要求把指定的三项皮革研究用进现有系统，而不是再次列举通用布料软件。任务从 ffcfea8bae4cda68cc0a6f528daccca212fba4f3 继续，仅新增 leather-workshop/r03 及专属 CI；没有合并主分支，没有改动 R02、人物、骨骼、版型或已认可的皮革材质源码。

保护基线为 R02 固定构建 07b36be4163c6cc0013326a07272136e1ff34a74。构建时校验 R02 HTML、Three.js 与皮革生成模块的 SHA-256。原 R02 完整 HTML 在新网页内按原字节嵌入，独立标签页显示；物理试样复用同一 R02 LeatherKernel。用户在 R02 调好的材质可以通过「将当前 R02 材质用于物理试样」传递，不改变物理配方。不传递 R02 的绗缝、缝线、编织等几何。

本轮主要缺陷为上一研究版没有完成真实三维运行、离线直开和公网交付；本版已打通。并补入物理时间与求解迭代分离、材料传递测试、源公式原页核对。

## 可以直接操作

拉伸/释放：20×4 mm 皮条，20×10 mm 宽皮条以及中央 3 mm 孔的试样。两端施加轴向位移，内部及横向节点根据能量梯度求解。显示反力、应变、力平衡残差、网格和应力场。松手到零是准静态卸载，不是动态回弹。天然革模型中的显示厚度根据面积变化作不可压近似更新。

方向对照：AL、NL、PNL 三套筑波参数，两套 ITWM 宏观对照，以及鞋面论文的小应变对照，分别保存来源和适用范围；不将不同材料参数混合成一套万能皮革。0°/45°/90°裁向影响模型响应，而外观换色不改变物性。

松弛：保持应变，显示应力随模拟时间变化。蠕变：保持载荷，显示计算应变随时间增加；卸载后显示随时间恢复。二者是独立的均匀材料点历史算法，尚未耦合到非均匀 FE 网格。g=[0.20,0.15]、tau=[5,60] s 是显式未标定的演示谱，不是 Fraunhofer 实测数据。1×与10×表示模拟时钟倍率；有限元迭代次数不当作物理时间。

导出：物理配方 JSON、节点/单元/结果 JSON、时间或已收敛采样 CSV。数据包含来源、单位、状态、未完成项和实验标定=false。

## 三项研究怎样使用

### 1. Nakahara / Matsuda（2020），筑波大学
https://www.jstage.jst.go.jp/article/mej/7/4/7_20-00072/_article

独立实现其式14–17的各向异性能量体系，录入表2–4的三个皮样参数；采用不可压平面应力降维。2026-10-08 核对 PDF 第8–10页原始渲染图，确认多项式中的 1/2、1/3 系数与表值。

式16印刷排版为括号内的平方项；当前默认按这一形式转录。代码保留正部激活的实验开关，但没有把它宣称为作者原实现。压缩分支及其数值处理仍未独立验证，不能用内部梯度一致性证明原作者全部公式语义或完整试验曲线已经复现。

materialPoint 为对角 F、横向零应力而剪切受限的均匀点。网页拉伸 FE 允许自由横向位移与剪切，边界与材料点曲线不同，不能要求二者逐像素重合，也不能冒充原论文完整三维模拟。

### 2. Fraunhofer ITWM / FILK
https://www.itwm.fraunhofer.de/en/departments/processes-materials/technical-textiles-nonwoven/aif-project-simulation-mechanical-leather-performance.html
https://pmc.ncbi.nlm.nih.gov/articles/PMC8070376/

学习纤维结构、接触滑移、松弛与宏观试样的分层方法。相关论文表4的两套宏观方向性常数作为独立对照录入，有限应变能量扩展为我们自行实现，不宣称是其 ANSYS 或 FISFT 原求解器。真实孔网格用于局部响应观察；没有把未做的逐纤维网络、损伤、接触滑移描述成已实现。

独立标量时间层只保留可检验的历史更新结构，不复制未取得的松弛谱。材料参数必须重新对应具体皮料标定。

### 3. Seul 等（2023），鞋面静态结构研究
https://www.mdpi.com/1996-1944/16/22/7203

当前录入其 E=20 MPa、nu=0.4、厚度2 mm 的线弹性对照。3%是本版人为保守测试限值，不是论文的失效应变。部件装配、鞋楦接触与逐针受力没有实现；不能仅因录入材料常数便声称鞋面装配系统迁移完成。

## 验证内容

qa/numerics.json：28项通过，包括零应变能量/应力、解析应力与有限差分、旋转客观性（小应变SHOE除外）、方向响应、输入拒绝、自由节点能量梯度、带孔/无孔求解收敛、Prony解析松弛、恒载蠕变与卸载恢复、弹性无虚构永久变形、翻转单元拒绝。

qa/browser-local.json：21项通过。1440×1000真实 Chromium/SwiftShader 文件直开，检查可见三维、微距像素变化、拉伸反力和顶点变化、释放、裁向、松弛、1×时钟、蠕变/恢复、实际导出文件、R02保留和材质传递、力学参数保护、核心零网络。另检查390×844手机视口与错误，不是手机实机。

qa/browser-public.json：12项通过。真实浏览器打开固定 HTTPS 链接，确认当前版本、真实图像、相机变化、力响应、孔洞、卸载、R02运行和材质传递，以及控制台零错误。

内部目视检查了桌面整体、孔洞、R02材质传递和窄屏截图。外观仍是 R02 质量，未把物理接入声称为 Adobe 一比一材质质量通过。

数值示例仅为求解输出：AL 20%拉伸方向对照的反力约15.421 N与7.697 N；NL默认条形8%到10%应变，反力约13.263 N到16.226 N。这些值不是新增实物测量。

重要：带孔网格为径向离散，外矩形角部存在离散近似。带孔/实心对照只是当前离散模型自检，不能当作孔边应力集中、净截面强度或网格无关性已被工程验证。仍须补入角点精确约束、网格收敛与试验边界匹配。

## 开发与文件

site/physics.mjs：独立材料/试样/有限元/时间算法，无Three依赖。
site/runtime.js：R02材质接入、真实三维、交互、计时和导出。
site/template.html：中文界面和研究边界。
build.py：核对R02依赖并构建单文件。需要Python和Node，不需要npm或在线CDN。
test.mjs：纯数值测试。
qa.py：真实浏览器测试。

从包含相邻 r02/r03 的目录运行：
node leather-workshop/r03/test.mjs
python leather-workshop/r03/build.py

浏览器QA另需Playwright和Pillow，正式CI已配置。用户只需打开preview.html。
