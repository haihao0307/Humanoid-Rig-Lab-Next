## 用户纠正与真正的故障原因

用户 2026-10-10 截图中的漏边、锯齿和线像栏杆的问题是真实缺陷。R07 配置了非零皮厚，但细分后的弯曲皮面与另行生成的粗切边没有共用边界；名义厚度存在不代表实际曲面封闭。旧知识文件保持不变，也不等于新产品已经正确继承能力。不能再用旧文件哈希、有限坐标或单一远景检查代替集成验收。

R08 的 `site/closed-shell.js` 使用同一份最终约束纸面网格生成粒面、背面、切边和针孔壁，边缘有实际圆滑封边截面。不能通过双面渲染、暗部或镜头避让掩盖缺面。`site/pattern-physics.js` 与 `site/panels.js` 统一纸面插值及节点切线/法线，使皮面和切边在抓取后仍保持一致，不再在形变时张开。

纠正已登记为 `regressions/CURVED_LEATHER_BOUNDARY_20261010.json`。同名牛仔帽的缩略几何 CPU 对比中，R07 四个裁片存在 700/200/784/784 条未匹配边；R08 对应结果全部为零。这是明确标注范围的几何对比，不能扩展为所有产品或所有动态情形的证明。高分辨率产品及变形后的厚度另由正式测试覆盖。

## 当前可以实际操作的内容

七个真实三维对象：三层手缝卡包、手缝黄铜扣腰带、翻盖肩包、牛仔皮帽、三角海盗皮帽、立领皮夹克与工艺皮样。夹克包含实际袖窿、成形袖片、折叠袖口、肩部裁片、领口和口袋；不是贴在平面上的服装图片。

十三个材质/涂饰入口与原 R02 八种皮料预设保留。不同涂饰不冒称独立实测皮革。新界面恢复了绗缝鼓起高度、绗缝间距、编织尺度、针距、线径、线色、孔径、孔距、孔型、皮厚、刚度、封边/包边，以及表面凹凸、粒面尺度、粗糙度、涂饰和底色控制。菱形/方格/条形绗缝、透气穿孔、交错编织可在适合的产品部位或皮样上查看。夹克的工艺变化作用于补袋；不宣称每项工艺都无条件适用于每个部件。

参数位置在右侧折叠的“皮匠参数”“皮面参数”中。默认由配方提供可查看的设置，不要求用户调参来修复结构。完整原 R02 工艺工作台另通过“打开完整旧工艺台”保留并可运行，不用削减版假控制代替。R05 原针路字节保持完全一致；原 R04 皮料承重、投放/取走石块与恢复试验仍可独立运行。

缝线继承 R05 连续针路和局部接触场：经过真实孔壁连接正反两面，外露部分为扁蜡线。可使用马鞍缝、平针、双排、折线、交叉针样，并以松线/正常/较紧和无牵拉对照检查皮面响应。不使用散放短圆柱作为针脚。较复杂针样仍是构造针路加局部皮面响应，不是所有针法完整线力学求解。

“切边”将镜头定位到当前产品的实际曲边，“皮厚检验”用于检查正背面与厚度分布，右侧可读生成后的皮厚，而不只读输入配置。厚度同时进入几何、曲面质量、膜参数和弯曲参数。新制、使用磨亮、风化旧物保留边角磨损、细划痕与褪色对照。

## 抓手、性能与物理边界

抓手选中当前物理三角片的重心位置。鼠标拖动施加抓取约束，产品壳体按重力、惯性、接缝、弯曲和接触更新；松手后保留速度。高精度皮面、孔壁、线体、五金绑定到同一动态场。计算通过独立 Worker 执行，避免受力积分阻塞主界面。不是对整个刚体播放预设摇摆。

本体仍是未标定的近似皮革壳体：只读继承 R04 材料切线与弯曲导数，使用独立积分；四个 1/960 s 子步对应一个名义 1/240 s 步。不能称为完整原 R04 非线性本构。密度、阻尼、摩擦、弯曲和接缝参数并非当前皮料的实测结果。

闭合网格不等于完全没有穿插。自接触仍是粒子级，不是三角面/五金的连续碰撞；极端甩动或多层折叠还有限制。整根线的摩擦、张力传播、损伤与断裂未完整求解。绗缝填充和使用风化是受控的几何/材质近似，不是填充物体积、紫外线或真实服役年限模拟。高密度孔口/针路仍有计算与显存成本，复杂对象可能慢于真实时间；不承诺所有设备实时或 60 帧。

卡包和腰带可导出按当前裁片与孔位生成的毫米 SVG 试作纸样，仍需打印校准、废皮打样、削薄和五金试配。帽子、肩包、夹克不声明已具备生产定版纸样，整个系统不是可直接投产的皮具 CAD。
