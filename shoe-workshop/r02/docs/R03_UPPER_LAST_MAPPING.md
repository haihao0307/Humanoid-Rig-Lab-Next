# Shoe R03 Upper-Last Mapping

## 状态

基于 R02-S1 研究台继续开发。

R02 已证明：

- 原始鞋楦可以稳定显示。
- 原始平面部件可以进入网页检查。
- 参数变化可以影响研究网格。
- 缝线试片可以验证针路结构。

R03 不进入成鞋渲染，而解决真正制鞋中的关键关系：

`鞋面部件 → 鞋楦区域 → 边界方向 → 缝份 → 绷楦变形`

## 第一目标

选择一个真实鞋面部件，建立：

1. 部件边界识别。
2. 鞋楦表面对应区域。
3. 方向场记录。
4. 展开/包覆误差记录。
5. 失败位置可视化。

## 不允许

- 不把一张贴图变成鞋面。
- 不用颜色变化表示材料完成。
- 不用动画模拟缝合。
- 不把九个几何片自动称为工业纸样。

## 验收

通过条件：

- 修改鞋楦后映射误差可检测。
- 部件边界变化可追踪。
- 包覆过程有数值误差。
- 保存后可恢复参数。

未通过条件：

- 没有真实部件对应。
- 没有缝边关系。
- 没有材料方向。
