# KAOPU 鞋履研究台 R03-B｜厚片组成鞋面

本轮从用户已允许继续的 R03-A 接手，固定前版提交 a8e47da0bc9ef801f3ad4e609b73ce2117add8d4。原 R02、R03、其他工作台均不改。新实现位于 r03b，旧六个工位直接继承。

九块原裁片不再只作平片陈列：主鞋帮、前帮／连体鞋舌、三块原例补片、后缝长短条与底片进入三维形面候选。每片有独立厚度、内外面、外边墙和贯穿孔壁；默认主片2mm、补片／后条1.2mm、底片2.5mm。数值是本项目的结构研究默认，不是作者标定的皮革参数。

主片使用原鞋楦和原片边界建立独立谐波参数域对应；曲面区域重新三角化，孔轮廓随映射保留。原裁片数据不变，但渲染曲面是派生新几何，不能称原顶点未变或无损制造纸样。三块补片复用其主片对应。原工程中的真实三维鞋底对象26经刚性对齐加入，不把另造的鞋底冒充原例。

8组几何连接、219对针孔（438个片上针孔），沿贯穿孔建立连续三维线段／线管。短后条接口仍为跨缝候选。缝线与针孔是几何结构，不是张力、摩擦或绷楦求解。鞋面到中底／鞋底的粘接或热焊没有模拟。

界面提供整体形面、分层拆开、九片厚度陈列、独立选片、厚度变化、剖开观察、鞋楦叠加、针孔近景、保存恢复和JSON导入导出。分层仅是检查位置，不用插值动画冒充装配物理。

构建：Node22，three0.179.1，esbuild0.25.10，playwright1.56.0；CAD读取采用rhino3dm8.17.0。运行tests/kernel.mjs、tools/build.mjs、tests/browser.mjs。public-lite.html内嵌全部核心运行时及数据；最终以PUBLIC_URL.txt、BUILD_MANIFEST.json及当次evidence为准。手机只做视口模拟，非实机。
