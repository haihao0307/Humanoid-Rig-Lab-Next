# KAOPU 鞋履工坊 R12 — 四种新结构

本版基于原鞋台 R10.1 的固定提交 `cafab0889b612ed6cbf461683dfe2851909df3be`，在新目录中增加四种可调鞋款。原 R10 文件与原有十二组材料配方保留。当前为等待浏览器渲染和视觉复核的开发候选，不能将本文件视为交付通过证明。

| 新款 | 实际结构差异 |
|---|---|
| 便士乐福鞋 | 低鞋口、环绕帮面、独立 U 形前片、带贯穿孔的横向鞍带 |
| 切尔西短靴 | 连续前帮至靴筒、两侧 V 形弹力嵌片、后帮接缝与拉环 |
| 双搭扣皮鞋 | 一体前帮/鞋舌、跨脚背覆盖片、两条带孔皮带、真实扣框与扣针 |
| 帆布网球鞋 | 独立帆布裁片与鞋舌、十个贯通金属鞋眼、扁棉鞋带、橡胶包边和连续外底 |

## 科学依据与边界

先核对原厂结构资料和鞋楦、绷楦、鞋帮材料研究，再建立共享的三维鞋楦截面及各款裁片拓扑。完整来源、设计选择、研究结论与未验证事项见 [RESEARCH.md](RESEARCH.md)。

四款均由本目录代码生成，无外部成鞋网格导入。鞋面包含内外表面与实际切边，侧松紧片替代皮革区域，鞋眼与扣带孔切穿对应裁片。皮面继承原鞋台的 PBR 材质体系；帆布和松紧片使用独立织物外观模型。

尺寸是设计值，未标定为标准鞋码。鞋楦参数不等于人体脚型；几何厚度不等于材料受力求解。弯折是协调各部件的几何观察，尚未校准跖趾关节轴。尚未验证生产纸样、绷楦应变、胶合强度、耐久、防滑或穿着舒适度。当前四款不宣称完成原生人体试穿匹配；保留原 R10 完整工作台入口。

## 使用与复现

构建后打开 `public-lite.html`。核心 JS、CSS、原鞋数据和皮面纹理均内嵌；仅主动打开的原厂参考照片需要网络。

```bash
cd shoe-workshop/r12
npm ci
npm run build
npm test
npx playwright install --with-deps chromium
node tests/browser.mjs
```

可使用鞋长、前掌宽、脚背、厚度和弯折控件；支持旋转、左右成双、四款对照、灰模、剖面、拆件、单部件检查、配方保存与 JSON 导出。所有数值检查及实际 Chromium 渲染证据应与 `BUILD_MANIFEST.json` 中同一 `sourceCommit` 对应。
