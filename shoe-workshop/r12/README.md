R12 在原鞋台基础上增加四种程序生成、可调尺寸的鞋款，并在同一工作台保留原 R10 鞋款及 **12 组材料配方**，共五款可选。原款基线为 `cafab0889b612ed6cbf461683dfe2851909df3be`；页面也保留“原 R10 完整工作台”入口。

## 四种新鞋款

| 鞋款 | 已实现的结构特征 |
| --- | --- |
| **便士乐福鞋 · Penny Loafer** | 低口套入结构、环绕帮面、独立 U 形前片与围缝、带真实贯穿开口的横向鞍带，配薄前掌和独立后跟。 |
| **切尔西短靴 · Chelsea Boot** | 连续前帮过渡至靴筒、两侧 V 形弹力嵌片、后帮接缝和拉环、可见踝口内壁；弹力片替代对应皮革区域。 |
| **双搭扣皮鞋 · Double Monk** | 一体前帮与鞋舌、开放后帮和跨脚背覆盖片、两条带真实孔洞的厚皮带、独立扣框与扣针、鞋头盖片。 |
| **帆布网球鞋 · Canvas Court** | 独立圆前帮、后帮和鞋舌、五对贯通金属鞋眼、贴合鞋面的扁棉鞋带、连续橡胶包边与外底。 |

四款从鞋口、帮面覆盖关系、裁片、闭合件和鞋底结构形成差异。几何由本目录代码生成，没有导入外部成鞋网格。帮面具有内外表面和实际切边，鞋眼与扣带孔切穿对应裁片。皮面沿用原鞋台的材质体系；帆布和弹力片使用各自的织物外观模型。

## 怎么使用

1. **选择鞋款。** 左侧切换四种新款或“原款 · R10”。选择原款后，可在“原款材料组合”中切换 12 组既有配方。
2. **查看形态。** 拖动旋转、滚轮缩放；视角按钮提供整体、侧面、鞋口俯视、鞋头、后跟、鞋底和近看。“左右一双”显示镜像配对，“四款同看”并列展示四种新结构。
3. **调整新款。** 鞋长比例、前掌宽度、脚背高度和鞋面厚度参数驱动模型重新生成；外形尺寸显示当前模型的宽、高、长。原款沿用既有配方，新款参数滑块对原款禁用。
4. **检查部件。** 使用拆件、灰模、剖面、线框、缝线开关及部件下拉框，查看裁片内外表面、切边和闭合结构。前掌弯折控件用于几何联动观察。
5. **保留设计状态。** “保存配方／读取配方”使用当前浏览器的本地存储；“导出 JSON”保存鞋款、参数、显示状态、源版本和外形尺寸，不输出网格或制造纸样。“恢复默认”重置当前款的参数与检查状态。

构建后的 `public-lite.html` 内嵌核心 JS、CSS、原鞋数据和皮面纹理，三维核心无需联网加载额外资源。展开原厂参考照片或打开外部参考页面时需要网络。

## 研究依据与实现边界

本轮先核对原厂鞋型结构，并阅读参数化足模型、曲面展平、鞋帮材料实验、弯折位置及帮底粘接资料，再建立共享鞋楦截面和各款部件关系。来源、阅读范围与研究建议见 [RESEARCH.md](RESEARCH.md)。

- **设计鞋楦与人体测量：** 四款采用共享的设计断面曲线和采样内核，再叠加各鞋型参数。当前没有导入实测足部、足部扫描或放余标定；预设毫米值是设计值，未标定为标准鞋码。尺寸与形状界面只有鞋长、前掌宽、脚背和厚度参数，没有跖围、脚背围或后跟宽滑杆。
- **三维裁片与制造纸样：** 已实现实体厚度、开口、切边和部件定位。曲面参数域与 UV 用于几何和外观；尚未实现纸样展平、展开畸变求解、制造缝边配对或制造纸样输出。
- **弯折与力学：** 弯折围绕距设计楦后端 `0.63L` 的设计轴平滑变形，`L` 为设计楦长。该轴没有根据穿着者实测跖趾关节（MTP）定位，也没有材料标定、足鞋接触或绷楦应变求解。
- **尚未验证的现实性能：** 胶合强度、耐久、防滑和穿着舒适度仍需工艺试验及实物试穿。当前不宣称完成原生人体试穿匹配；结构与外观检查不构成生产或合脚认证。

## 本地构建与复现

在仓库中执行：

```bash
cd shoe-workshop/r12
npm ci
npm run build
npm test
npx playwright install --with-deps chromium
node tests/browser.mjs
```

构建产物为 `public-lite.html`。复现时请保留对应的 `BUILD_MANIFEST.json`，并用同一次构建运行数值与浏览器检查，避免把不同源版本的结果混合使用。
