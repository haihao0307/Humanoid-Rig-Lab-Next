# R14 研究与实现依据：附件联动、靴筒过渡与静态扣合

本轮执行用户已接受的 [R14 计划](../plans/r14-20261018/PLAN.md)，延续 [R13 研究](../r13/RESEARCH.md)。实际生产基线是 `0f105165964795b4895c3a5d8d2440deac1add91`，计划提交是 `ec7d80c9f99dc978735245d463306075f5a287d5`。执行先重新运行 R13 的实际几何诊断，再改变生成源码。当前模型属于自有鞋型的构造研究，不宣称测得商业鞋楦、纸样或遮挡处安装尺寸。本轮没有使用中国网站资料。

## 1. 结构参考能支持哪些决定

[Crockett & Jones Chelsea 8](https://us.crockettandjones.com/products/chelsea-8-black-calf-city)用于核对连续脚背、短靴筒与两侧 V 形松紧片的关系。原厂照片中的自然过渡是视觉参考，不能推出一个固定曲率半径；本轮的半径和位移来自自有模型的实际坐标。

[Lowndes 原厂说明](https://row.crockettandjones.com/collections/mens-monk-strap-collection/products/lowndes-black-calf)可确认双搭扣、横向鞋头片、开放后帮与连成一片的前帮/鞋舌。[Closing 工序](https://us.crockettandjones.com/pages/in-the-making-closing)提供制帮顺序及裁片装配背景。由此建立本项目检查关系：带根支承于覆盖片，固定座支承于外侧后帮，扣针从框杆进入选定带孔，固定结构与自由带通路分开。

照片没有揭示 Lowndes 的隐藏安装方式。本轮使用明确标注为本项目设计的静态双柱扣座：连接柱通过皮革座的真实孔，到达现有金属框的实际三角面。它不冒充原厂被遮挡的包杆或折返做法，也不是可开合的机构模型。

## 2. 先复现鞋眼失真，再选择变形方法

R13 的前掌检查对每个顶点使用随纵向位置改变的转角，因此金属鞋眼也像柔软布料一样改变形状。30° 时最前排左右两个眼扣的上口静态对向弦长约 4.3 mm，最短值分别降至约 2.9115 / 2.8859 mm。该读数是最终顶点之间的三维距离，不是实物鞋眼的检定内径。

第一候选将一个刚体变换与原柔性位置场按局部权重混合。独立检查发现孔前区域出现新增折叠；生产诊断的局部雅可比行列式为负。只替换局部框架的旋转提取方法也未解决。原因在于位置混合的导数包含权重梯度与两个位置场差值的乘积；即使两个单独变换均正常，混合场也可能折叠。失败源码、实际顶点及探针保留在 `evidence/iterations/`，没有用降低门槛来接受它。

进入根因复核后，第二候选改为整鞋共享的弯折角度场：

- 从最终静态网格读取每个金属件、两层真实布孔的外/内边界、穿孔鞋带端环，取联合包围范围并加 0.05 mm 数值余量。
- 每侧在这些纵向范围内保持常量转角，让整个附件体积接受同一个刚体旋转。各平台的转角取原弯折场在相应鞋眼中心的值。
- 平台之间使用三次 smoothstep，保持位置和一阶导数连续。左右恒定区覆盖两侧所有附件范围，仅在中央自由鞋带区域混合两侧微小的角度差。
- 金属、两层布、针脚、鞋带、独立前帮、鞋舌和鞋底共同使用这个场，避免只修金属却让周围部件留在另一套位置上。

实际弯折带内部的位置会因此改变。0° 不施加姿态变换，原弯折带之外保持原位置映射；不能声称整个前帮在非零角度下逐点维持 R13。

## 3. 可直接检查的变形导数与法线

设设计弯折轴为 `z0=0.13L`，高度基准为 `b=soleTop(0.63)`，`y'=y-b`、`z'=z-z0`。本轮场的转角为 `theta(x,z)`，位置为：

```text
X = x
Y = b + y' cos(theta) + z' sin(theta)
Z = z0 + z' cos(theta) - y' sin(theta)
```

由于转角不依赖 y，该位置场的雅可比行列式可化为 `1 - (y-b) * dtheta/dz`。这使局部翻折风险可以直接在生成后的整个模型上检查；只检查鞋眼中心或预设角度不够。正行列式仍不自动证明离散三角形都合格，所以独立测试另查最终三角形及附件的实际相对位置。

曲面法线满足与每条切向量正交。变形后切向量乘以 J，因此法线应按 `normalize(J^(-T) * n)` 变换。这一结论由正交关系直接推导；[Three.js r170 Matrix3 源码](https://github.com/mrdoob/three.js/blob/r170/src/math/Matrix3.js)中的 `getNormalMatrix` 也使用逆转置。项目仍使用已锁定的 Three.js 0.170.0，未升级依赖。R14 实现包含纵向和横向角度导数，没有只旋转旧法线。

## 4. 孔边界为什么需要非线性反求

独立检查额外发现静态第三排鞋眼附近的布孔被拉成不规则轮廓。旧方法只用孔心处一次雅可比将圆周映回曲面参数；有限孔径跨过鞋口到鞋襟变化较快的区域，线性近似不足。

R14 对 Canvas 孔周逐点反求实际切平面投影，使真实曲面上的孔边界落到目标圆周。只更新孔周径向网格的内部位置，外侧裁片边界与孔数保留。其通过条件仍是从最终三角网格提取实际孔环，核对法兰覆盖、套筒与内外孔壁、贯穿射线和鞋带端环；没有把 `realOpening` 名称或名义半径当作证据。

## 5. Chelsea：切向连续不能代替自然轮廓

R13 筒根在 `v=.48` 保持 C1，但默认前中线下侧曲率约 1.2207/mm，上侧约 0.0710/mm，转弯集中到一圈狭窄区域。这解释了实际侧视与灰模中出现的底座状肩线。

第一项局部五次桥接诊断引用旧曲面的分段二阶导数，产生新跳变和法线翻向，未写入生产。最终局部三次 Hermite 桥只使用连续的位置与一阶切向，范围为 `v∈(.36125,.6425)`，两端位于原有共边采样行。皮革片、松紧片和针脚继续由同一曲面生成。域外、鞋头、踝口和拉环被单独保护。

这项修改改变真实位置，并未声称整个靴面达到 C2。曲率下降只是数值证据；是否形成自然轮廓，另由相同机位的皮料和灰模图独立检查。

## 6. 几何闭合与材料物理的边界

扣座增加真实小孔后，最终缓冲区检查发现一个孔周扇形三角的最小高只有约 0.00056 mm。此时很小的位置和 UV 舍入也能造成约 2% 的极值统计差异。原始双精度、只舍入位置、只舍入 UV、两者均舍入的对照明确定位了条件数放大。局部修复让孔周角度来自参数域的雅可比，保留三角面数和孔口，改善该三角的形状条件。没有改变全局材质坐标算法或放宽 1% 门槛。

另一次完整审计捕获后帮报告两个标量与稍后扣座的数值相同，而最终网格和其余分位数仍对应后帮。较短构造追踪与一次 `--jitless` 完整对照均未复现；这些观察不足以证明 JavaScript 对象别名或 V8 引擎缺陷。原始失败、每个部件的冻结统计、环境和对照结果全部保存，精确写入路径仍未确定。正式候选须在锁定环境中重新通过完整审计，不能用推测替代接受证据。

[XPBD 原始论文](https://matthias-research.github.io/pages/publications/XPBD.pdf)提供柔顺约束、时间步与迭代稳定性的研究背景。[SATRA TM180](https://www.satra.com/test_methods/detail.php?id=140)针对真实缝合试样的强度评价。它们不能直接提供本鞋的弹性、厚度实测、摩擦、针线拉力或胶合参数。

R14 完成的是几何附件约束、静态装配与外观表达。没有实现完整 XPBD、足鞋接触或开扣动力学，也没有经过实体打样、适脚性、强度、疲劳或制造纸样验收。表面 UV 的原有独立检查和 1% 统计一致性门槛继续保留；R13 历史统计异常仍明确记为根因未解，没有把本轮几何改动写成那个历史问题的解决。
