# R13：缝线、形态、裁片和材质审核

本轮从冻结的 R12 开始。R12 已通过的原检查记录保持原样；本轮补充近景、侧向射线和截面检查，发现旧检查范围没有覆盖的问题。本文把观测、修正和验收分开记录，不把通过旧测试当作形态自然的证明。

## 基准与检查方法

- R12 源码：`7fd5527f475908d615db4f1fd36357f47e68ce46`；公开构建：`d27ef0f200257741fa67f1c6291418cf771443e9`。
- R13 分支起点：`fd6c7ca5a338f85ae6c6152b2b23ccf126687c5d`，含 R12 最终回执。
- 先读真实裁片生成代码，再检查 R12 实际 WebGL 截图和几何。数字均来自本项目的生成模型，不能当作商业实鞋测量值。
- 新回归先对 R12 运行，默认参数的 14 项均真实失败，记录见 `tests/fixtures/r12-regression-before.json`。R13 复用这些行为检查并扩展参数范围。
- 在真实浏览器中重新渲染 R12 和 R13 的后视及拼缝近景，复用相机矩阵，见 `evidence/before` 与 `evidence/browser`。证据目录仅在实际运行后产生。

## 研究如何约束实现

1. [Crockett & Jones：Closing](https://us.crockettandjones.com/pages/in-the-making-closing) 介绍裁片、处理边缘、缝制和鞋眼等制帮工序。本轮据此按独立裁片、真实厚度、共边和穿孔审查，而非只看颜色分区。
2. [Crockett & Jones：A guide to loafers](https://www.crockettandjones.com/blogs/the-article/a-guide-to-loafers) 提供前片手工收拢等鞋型结构参考。照片只用于识别轮廓和构造关系，没有用它推算不可见的精确商业尺寸。
3. [SATRA：Learning from footwear failures – part 2](https://www.satra.com/bulletin/article.php?id=2774) 的接缝案例说明边距、削薄和针线选择会参与实际失败。当前几何可检查穿插、悬空与支承，尚不能推出缝制强度。
4. [SATRA TM180](https://www.satra.com/test_methods/detail.php?id=140) 的对象是真实鞋帮/内衬缝合试样的强度。本项目没有做该实体试验，不宣称通过该标准。
5. [Lévy 等：Least Squares Conformal Maps](https://www.cs.jhu.edu/~misha/Fall09/Levy02.pdf) 用作曲面参数化和纹理畸变的背景。R13 的有界样条坐标拟合是原创实现，不是该论文算法的完整复现，也不是鞋面生产展开、等距映射或布料应变求解。

6. [Liu 等：A Local/Global Approach to Mesh Parameterization](https://cs.harvard.edu/~sjg/papers/arap.pdf) 用作局部三角形旋转与全局连续映射的数学背景。本实现保留小规模连续样条空间、有限次数迭代及局部畸变保护，并不继承该论文未实际验证的性能或制造适用性。

来源均为研究机构、研究论文或制造商一手资料；本轮未使用中国网站资料，没有导入商业鞋网格或新增商业照片贴图。

## 真实渲染追加发现

第一次本地预审完成了 8 组操作和 39 个当前视图，并重新渲染 8 个同镜头旧版视图。它揭示了两个已被纯曲线/拓扑检查漏过的缺陷：包边内外底端面穿出，以及实际鞋帮的高窄后脊。二者分别增加端面遮挡射线和实际外表极后端高度检查；第二次真实渲染确认整条包边穿出线及高窄后脊消失。独立后视进一步发现 .45 mm 外展尚不足以覆盖偏置 .85 mm 的后帮，修正为按最外层另留 .45 mm 余量，并把真实 quarter/vamp 纳入端面首命中检查。最终接受仍须绑定 GitHub 的真实源码提交和新生成 CI 证据。

首份 GitHub 源码候选 `961996dca84b110191405a1e5b840cec51de0a65` 已通过当时的几何、材料与浏览器门禁，但独立逐图审核仍在 Penny 后口发现细小亮三角，随后用相同办法在 Monk 后口找到同源缺口。它不是灯光或皮料颜色的问题：固定后视镜头的射线穿过后帮，先击中远处的前片内表。后口起点为归一化纵向参数 `.035`，原网格恰好没有在该点采样，包边与实际三角形边界之间便留下缺口。

下一次修改仅在 Penny、Monk 后帮各自的采样序列中插入这条精确边界，保留全部原采样点与其他裁片。新增回归用实际网格和同一镜头测量，两款 × 三组参数共 135 条后口射线：首份候选有 47 条失败、六组均失败；修正后 135 条均先击中预期近侧外表。原拒绝记录原样归档在 `evidence/iterations/961996dc-collar-gap.json`，Monk 补充记录在 `evidence/iterations/961996dc-monk-collar-gap.json`，负例由 `tests/fixtures/r13-collar-gap-before.json` 固定。此历史候选没有被提升为公开 R13 工作台。

## 独立材料坐标测量

以下是同一份最终曲面上的原始 seed UV 与新外观坐标的对比，**不是把不同几何的 R12 / R13 误差直接相减**。数值取自默认设计参数，由独立脚本从最终 Float32 三角形重新计算。各向异性是局部两个主方向尺度之比，1 表示两方向尺度相同；p95 按实际三角形面积加权，并不代表最大值。

| 默认面片 | 原各向异性 p95 | 新各向异性 p95 | 新最大各向异性 |
| --- | ---: | ---: | ---: |
| Penny 围帮 | 8.095 | 2.045 | 119.016 |
| Chelsea 整片前帮 | 6.358 | 1.927 | 30.492 |
| Monk 后帮 | 11.087 | 1.601 | 151.887 |
| Canvas 左后帮 | 6.703 | 1.214 | 144.901 |

三组参数合计 66 个适用面片：每组 Penny 3、Chelsea 5、Monk 8、Canvas 6。诊断核对了几何位置、法线和索引完全不变；没有新增翻向、退化或非有限值。生产报告与最终缓冲区独立统计之间的最大相对偏差低于 1%，该差异保留了 Float32 极小三角形的影响。

残余畸变集中在收拢端部的很小三角形，三组最大各向异性为 159.387；在任一受检面片内，各向异性超过 10 的面积占比最多为 0.22925%。Chelsea 的偏小、偏大前帮 p95 仍约 3.628 / 3.113。完整报告 `evidence/MATERIAL_COORDINATES.json` 保留每片最坏五个三角形的位置、面积和奇异值。没有以大部分面积的改善代替极端值检查，也不据此宣称得到无畸变纸样。

### 保留一次未查明原因的诊断异常

后口修正后的首次本地全量审计中，`default/monk-integral-vamp-tongue` 的生产统计对照字段出现相对差 `0.7593546585077461`，超过原有 1% 门槛，该次审计真实失败。完整原始记录及命令、环境、源码散列保存在 `evidence/iterations/local-collars-uv-first-failure.json` 与相邻 context 文件中。原审计没有保存该次读取的 raw claimed 值，故这次异常的原因保持 `ROOT_CAUSE_UNRESOLVED`。

同一片最终 Float32 网格的全部实测 before/after 指标与独立 GitHub 环境逐字段相同；GitHub 对照差为 `0.00021053347534305983`。两位生产人员的只读排查没有找到报告共享或后续改写，66 片保留对象检查也未观测到共享、改写。异常数值恰好等于前帮实际 after RMS 与另一个鞋头片 before RMS 的相对差，这只是诊断线索，不能追认为已知赋值路径、Float32 舍入或运行时错误。

最终验收脚本按裁片身份立即保存原统计快照，在 seed 构建与测量期间检查其不变，并记录具体 actual、claimed、最大差字段和 Node/V8 版本。实测公式和原门槛保持不变，生产材料算法没有为这次未明异常而改动。源码 `8b05ebd8b0755216743792034e3cbb58b8d9ff54` 已在独立 GitHub 环境通过这份加强后的门禁；66 份快照及 132 组 before/after 对照从保存的原值重新计算均一致，所有最终三角形测量值也与前一份 CI 逐字段相同。新证据的通过不抹去首次失败，也不等于首次异常的根因已经修复。
