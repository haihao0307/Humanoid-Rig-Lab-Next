# R04 皮革整鞋结构候选

鞋履基线：R03-B / 9dfa6eed26793aad69f1c85249db43abbad0a287。该版被指出整体破碎，不作为已认可成鞋。材质来源：用户指定 R10 / af389cc216ddd01e3b1aa66c972f42b2587bc797。旧 R02/R03/R03B 及皮革工作台不改。

本轮把指定 R10 的原材料内核、13项皮料目录、扫描通道和马鞍针路迁入同一套九片派生鞋面。不是另造一双鞋替代原裁片。重做后跟 P20/P21 端部搭接，把独立径向场造成的约8.18mm基面空隙改为同一连续表面；原源片不变，搭接变更为本项目的几何研究值。

鞋底不是用材质遮住空隙。原装配变换下，895个重叠原表面测点的底面至底部距离中位数为11.189mm。现在减去底片/薄层/装配偏移后，用该测量重定位原CAD鞋底和底片。中部90%样本残差约-0.533至0.425mm；这不是全鞋接触误差或制造公差，极端样本仍需检查。

所有九片保留内外面、切边和孔壁；补片边缘作2mm过渡的削薄形状，厚度约为内部的55%至100%，不是统一等厚片。R10原13项材质配方保留，三维可切换。材质UV改为原裁片毫米坐标/96，保留R10纹理重复与法线镜像修正。四个原孔用于鞋带和空心孔扣，不增加假孔黑点。

针路采用R10实际使用的R05 buildSeam/continuousRoutes；原文件逐字保存，另生成与R10相同的count/thickness验证范围扩展。三维映射与蜡线扁截面是本轮适配。没有运行缝线张力、滑移摩擦或完整壳体物理。

构建：`node shoe-workshop/r04/tools/prepare.mjs && node shoe-workshop/r04/tests/kernel.mjs && node shoe-workshop/r04/tools/build.mjs`。运行与发布检查以新evidence文件和PUBLIC_URL为准，桌面与手机视口不等于实机。PUBLIC_URL仅在真实公网浏览器完成后写入。
