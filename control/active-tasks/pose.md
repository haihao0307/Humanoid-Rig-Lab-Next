# 动作与物理当前任务

基线：`pose@0.4.0`，兼容 `rig@0.4.0`。

## 本轮新增：单张图片复刻动作

1. 动作面板新增“图片复刻动作”工作区，可上传 PNG、JPEG、WebP 和 AVIF 图片。
2. 浏览器首次使用时加载 MediaPipe Tasks Vision 与 Pose Landmarker Full 模型，输出 33 个人体关键点、近似三维世界关键点、可见性和置信度。
3. 图片关键点映射到当前人物的稳定关节 ID，并通过固定骨长、四点刚性骨盆、人体活动范围、地面碰撞和全身求解生成三维姿势候选。
4. 普通图片姿势流程只写入姿势、IK 目标、固定点、接触和约束数据，不修改父子层级、绑定局部位置、骨长和人物比例。
5. 单图校准提供左右镜像、前后深度翻转、深度强度、自动脚底接触和当前根位置保留选项。
6. 源图叠加显示 33 点识别骨架，面板显示置信度、骨长误差、刚性骨盆误差、方向误差、脚底接触和警告代码。
7. 姿势可以直接应用到中央三维人物，也可以保存为网站动作资产。
8. 网站动作资产保存 PoseObservation、局部四元数 PoseSnapshot、IK 目标、固定点、脚底接触、约束、旧视口兼容姿势、质量报告和来源摘要。
9. 原图保存在当前网站的 IndexedDB。项目状态中只保留图片摘要、动作数据和资源引用。
10. 保存后的动作可以重新应用到当前人物。应用时会按当前绑定版本重新重定向，因此人物比例变化后仍能使用同一动作来源。
11. MediaPipe 输入图像在设备内处理。正式发布前仍需补充 SDK 性能与使用指标说明、用户同意流程、第三方许可和模型来源登记。
12. 标准局部四元数快照与当前世界坐标三维视口桥接使用同一时间戳，动作导出会同时携带两种表示并明确标记桥接模式。
13. 动作库当前保留最近 24 个图片动作，支持载入源图、应用、导出 JSON 和删除。

## 已完成验证

1. 修改前完整 `npm test` 基线通过。
2. 合成左手举起、右脚迈出姿势能够生成图片姿势候选。
3. 左右镜像后，举手侧和脚底接触侧正确交换。
4. 图片世界关键点缺失时自动退回二维加深度估计，并要求人工复核。
5. 重定向前后绑定签名完全一致。
6. 图片候选最大骨长误差低于固定骨长阈值。
7. 刚性骨盆误差和最大关节范围越界低于现有求解阈值。
8. 所有根节点和关节四元数保持归一化。
9. 标准 PoseSnapshot 可以在同一绑定版本的新 PhysicsRig 中重新应用。
10. 图片动作资产库的保存、恢复、删除和 Node 内存回退通过测试。
11. 标准局部四元数快照与旧三维桥接可以同时导出。
12. 完整 `npm test` 在新增功能后继续通过。

## 当前人工验收重点

1. 使用正面全身图、侧身全身图、单臂遮挡图和明显躯干扭转图检查自动识别。
2. 检查镜像照片中的左右判断。
3. 检查双脚着地、单脚抬起、下蹲和迈步中的脚底接触。
4. 比较深度强度 0、1 和 2 时的前后关系。
5. 保存动作后刷新网站，再从动作库应用并检查三维人物。
6. 在另一人物比例版本上应用同一动作，检查重定向和关节范围警告。

## 后续增强

1. 将 Pose Landmarker 推理迁移到 Worker，降低大图分析时的主线程停顿。
2. 增加二维关键点拖动、单骨链深度翻转、躯干扭转和膝盖方向的局部校准。
3. 增加多人图片中的人物选择。
4. 增加同一动作多角度图片融合。
5. 将连续图片转换为 PoseSequence，并交给动画板块生成 MotionClip。
