# Bird Mother｜Seagull A 源拍翼循环解剖台 R0.06

本版严格只学习用户来源文件中真实存在的一段 50 帧、24fps 拍翼循环。

- 保留来源静态网格：4,416 顶点、5,624 三角面；
- 使用来源蒙皮关节、权重和每帧骨骼矩阵；
- 支持逐帧、慢放、固定视角、动态骨架、翼尖轨迹、身体耦合图；
- 不补造滑翔、翱翔、转弯、起飞、降落或逃逸动作；
- 原参考许可为 CC-BY-NC-SA-4.0，只作为研究和校准老师；
- visualAcceptance=false；productionReady=false。

## 数据封装

静态几何复用 R0.05 已核验的五段同源载荷；R0.06 只新增源动画数据。骨骼矩阵按矩阵元素做 uint16 量化，最大绝对误差约 1.37e-5；关节位置按轴做 uint16 量化，最大绝对误差约 1.41e-5；权重使用 uint8 并在着色器内重新归一化。

动画载荷：73,828 raw bytes → 22,793 gzip bytes → 30,392 Base64 chars。
