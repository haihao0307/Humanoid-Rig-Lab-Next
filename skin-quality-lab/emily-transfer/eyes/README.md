# ET02 — 双眼、角膜与共同注视目标

在已通过公网验收的 ET01（a08f7fff098dad3a18fb655418660ddaae4ecb35）上继续开发。原 Lee Perry-Smith 头部扫描、皮肤纹理、原 R01/R02 代码不改写。新版本仍使用 skin-quality-lab/emily-transfer/preview.html；旧固定提交入口继续保留。

## Emily 实际教给本版的内容

参考原页：https://alteredqualia.com/xg/examples/emily.html 。本次源文件由 GitHub Actions 实际读取，参考的不是截图猜测。

原页 createEyes() 分开建立内眼曲面和外层镜面材质，外层使用高指数 Phong 加法反光；updateDynamicEyeTexture() 将光方向映射到虹膜局部平面，产生聚光近似，并使瞳孔随照明收缩/扩张；updateEyeRig() 让左右眼从各自位置看向同一个平滑目标。原页还有头部与视线的不同响应速度。

本版独立实现：凸角膜几何、通过折射射线求交的凹入虹膜面、随瞳孔变化的径向纤维与色环、眼白细血管、独立光滑湿反射、光向驱动的虹膜聚光近似、光照瞳孔响应。渲染使用当前 Three.js，未复制 Emily 的 CTM 眼球、虹膜贴图或 XG 引擎；不是原引擎逐像素移植。聚光仍是实时近似，不是完整波动光学或病理模拟。

## 闭眼头模的适配

Lee 原资产是闭眼扫描。本版通过原几何射线采样获取眼周位置、UV 和法线；保留眼区以外的皮肤。将闭眼局部替换为上下眼睑环面、湿润睑缘和成对独立眼球。边缘使用很窄的羽化重叠避免采样/细分曲面裂缝。眼球在眼裂外被遮挡，防止眼球从眼皮外露。眨眼由眼睑几何开合完成，不是把眼球整体缩小。

眼睑开口和眼眶中心是根据闭眼扫描拟合的候选，不能声称恢复了该人物未经提供的真实睁眼形态。视角极近时仍受原眼皮纹理拉伸、原扫描分辨率影响；该边界需继续接受视觉检查。

## 视线与坐标

左右眼独立转心；目标保存为世界坐标。看向镜头、跟随鼠标、锁定当前目标三种模式。锁定后，鼠标移动不再修改目标；头模转动时重新计算眼球局部四元数以保持双眼对准。到达转角限制时限制转角，不会翻转眼球追逐脑后目标。限幅是本演示参数，不冒充个体医学测量。

头模转动当前是整块扫描头颈/肩部的刚体转动，用于检查注视锁定；不是已完成的颈椎/肩部骨骼动画。默认不开启自动头模跟随，避免影响原皮肤观察。

不启用摄像头，不进行真人眼动追踪。网页使用鼠标、触控和虚拟相机作为目标输入。

## 使用

“跟随鼠标”后在三维画面移动鼠标，再点“锁定目标”。通过头模左右转动、俯仰滑块检查共同注视；“看向镜头”恢复与观察者对视。顶部保留原视角，新增“双眼近景”“眼球特写”。可检查角膜反光、折射、虹膜聚光、手动瞳孔；自动瞳孔开启时禁用手动滑块。眨眼可单次触发或自动播放。“对照原闭眼扫描”恢复原眼区，便于验证不是更换整个人头。

眼部配置沿用原工作台的保存/读取/JSON 配方，包括锁定目标。原皮肤模式、材质预设、灯光、A/B 划线继续保留。

## 开销与验证

每眼角膜曲面 12,096 三角形；眼睑和睑缘是额外局部几何。虹膜/血管在着色器内生成，没有新增眼部图片或外部模型下载。已有皮肤纹理仍有数十 MB 的首载成本。参考模式在没有扩散时跳过不必要的扩散通道；增强皮肤与 A/B 通道仍会增加 GPU 开销。

eyes/qa.cjs 检查共同目标、头模转动后目标误差、后方目标限幅、瞳孔像素变化、角膜反射像素变化、闭眼、明暗瞳孔响应、参数恢复和手机视口。公开入口必须额外用真实 HTTPS 浏览器访问检查。Chromium/SwiftShader 验证不等于手机硬件帧率保证。
