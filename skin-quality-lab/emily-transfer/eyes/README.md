# ET02 — 在 ET01 原人头上安装眼球

保留 ET01 的人头网格、皮肤纹理、灯光和材质对照。不是替换整个人头，也不是 iframe 原站或生成图片。旧版固定网址仍保留在 BUILD_MANIFEST.json 的 baselineURL。

## 从 Emily 学习的内容

参考：https://alteredqualia.com/xg/examples/emily.html

学习对象是眼部内外层分工、独立高光、瞳孔变化、共享三维注视目标以及左右眼分别旋转的控制方式。原站使用 XG、曲面眼内部件与外层镜面部件；本实现使用 Three.js 参数曲面、角膜曲率、折射方向查询虹膜及湿润反射。不是 XG 原码或原资产逐像素移植。

## 眼睛不是白球加一张平圆片

眼球前部具有角膜隆起，虹膜与瞳孔按折射后的观察方向查询，具有侧视差。左右眼各有自己的旋转中心，共同注视一个三维目标，因此近距离目标不是简单让两眼保持平行旋转。

当前男性扫描原本闭眼。本实现保留其原始顶点，仅在受限眼窝区域替换显示；新眼睑从同一头部曲面采样位置、UV、法线与遮光。眼睑根据实际旋转后的角膜包络求解，避免球体穿过眼皮。眼睑外缘位移采用一阶连续衰减，内缘降低皮肤位移避免角膜穿出。薄眼睑不使用低分辨率自阴影，而对眼球采用头部坐标中的接触阴影近似。

“安装新眼球”关闭后恢复原始闭眼扫描。这个开关用于真实同头模对照，不会暗中换一个模型。

## 操作

看向镜头：双眼看向当前观察相机。

跟随鼠标：指针位置映射到眼前的三维目标平面；无需摄像头。

锁定当前点：固定当前三维目标，之后移动鼠标不会改变它。旋转观察相机不会把这个目标重新绑定到屏幕上。

放松观察：在限定范围内进行轻微观察变化。

双眼特写、虹膜近景和眨眼测试用于检查。可控制虹膜色彩、自动瞳孔、手动瞳孔直径、湿润度、眼睑开度和光学深度。眼部参数随原有皮肤 JSON 配方保存和恢复。

## 边界

当前眼位与眼睑拟合只针对这个头模。不同人物还需重新测量眼窝、瞳距、眼球尺度、UV 和活动范围，不能直接复制这组坐标。

角膜、眼窝阴影及瞳孔光响应均是实时视觉模型，不是完整眼部物理或医学模拟。转眼超出设定范围会限幅。当前没有为所有极端侧视和最大开合状态宣称通用的绝对无穿插保证。

继承的多张 4K 皮肤纹理和多通道渲染仍是主要开销。手机尺寸浏览器检查不代表手机实机帧率。运行与交互检查见 qa-report.json；最终公网交付必须另外验证固定提交的 HTTPS 页面。
