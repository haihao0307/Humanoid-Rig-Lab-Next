# ET01 — Emily 皮肤方法迁移到另一人物

本实验继承 `skin-quality-lab/r02` 的渲染与扫描资源。原 R01、R02 和人物核心工作台不修改。目标模型为 Lee Perry-Smith / Infinite 的扫描头部（CC BY 3.0），不是 Digital Emily。没有重新托管 Emily 的模型、扫描贴图或 XG 引擎。

## 原站实际做法

2026-10-08 实际读取 https://alteredqualia.com/xg/examples/emily.html 的 HTML 源码，并在 Chromium 中打开原站取得真实截图。`createScene2()` 的皮肤配置约位于 1630–1647 行。

确认的组合是 `XG.PhongMaterial`、扫描原色、凹凸贴图、光泽贴图、额外重复 64 倍的细凹凸、`wrapAround` 和偏红的 `wrapRGB`。原配置为 shininess 1.2、bumpScale 0.7、detailScale 0.95，RGB 包裹参数为 (0.75, 0.5, 0.5) × 0.9。原站还有阴影、色彩校正、CLUT 和独立眼部处理。不能把其质感简单归结为完整物理皮下散射，也不能把扫描贴图的贡献算作着色器自行生成。

本实验没有审计 XG 引擎的全部内部实现，不宣称逐像素相同或原引擎完整移植。

## 两种可比较的方法

默认“Emily 参考思路”：在 Lee 自己的扫描贴图和曲面上，使用 RGB 包裹漫反射、分层凹凸和皮脂高光。反射使用现有 Three.js GGX，不是 XG 原有 Phong。包裹光是独立重实现；扫描细节来源仍是 Lee，而不是从 Emily 脸上搬过来。

“增强皮肤”：继承 R02 的颜色分离、深度约束 RGB 屏幕空间扩散、光源方向几何厚度透光和短绒毛。这些增强不冒充原 Emily 页已经使用的同一实现。组织扩散、薄部透光与绒毛参数用于增强模式；Emily 包裹光滑块用于参考模式。

支持完整材质、基础 PBR、实时左右划线对照；可单独开关光扩散、微细节、皮脂反射、透光和绒毛。对照使用同一模型、相同肤色参数、相同实际位移、相同灯光与相机。分界不是换两个头模，也不是静态图片。

肖像、正面、面颊近景、耳部近景、灯光方向、检查图层、分辨率质量、材质预设、保存恢复和 JSON 参数导入导出继续继承已有功能。

## 可复用成果与现实约束

`EmilyTransferKernel.js` 提取了不含头模顶点和面部坐标的光照响应及材质开关规则。其余皮肤贴图、UV、头部区域和厚度设置仍需目标模型适配。这是其他模型上验证皮肤思路的网页，不是整个参数化人体的皮肤接入已完成。

高质量扫描颜色、法线、粗糙度、UV 和尺度不可缺省。只复制着色器到缺乏这些数据的粗模型，不会得到相同级别效果。全身目标需要自己的贴图/程序曲面映射、区域尺度、接缝、动态法线与性能验收。

浏览器首次载入会读取数十 MB 扫描纹理；不是小于 1 MB 的最终游戏资产。实际浏览器报告：原色、中尺度法线、微细节法线和表面数据均为 4096×4096，基础法线为 1024×1024。多张纹理与多个渲染缓冲会使用显存，集成到大规模 NPC 场景前需压缩纹理、LOD 和共享资源。当前手机检查为 390×844 浏览器视口，不能冒充手机实机性能。
