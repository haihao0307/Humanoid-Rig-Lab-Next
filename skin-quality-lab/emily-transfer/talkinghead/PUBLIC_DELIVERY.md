## 实际复用

TalkingHead 1.7.0，固定上游提交 `b3e277b3b46f88e557bf28a2c5612a5b04e075c3`。
提取并实际运行 35 段未改动的源代码块，包括眼神和眨眼模板、动画队列求值、缓动、优先级及点头/摇头模板。来源行号和逐块摘要保存在 `vendor/EXTRACTION.json`。

外层初始化、语义输出与 `IntegratedEyes` 是本项目适配器。没有实例化完整 TalkingHead 类，没有导入其另一个人物，也没有把整个语音/全身/渲染系统硬塞进来。

保留原人头、眼睑接触模块和皮肤资源。旧自动驱动与新驱动互斥；手动闭眼优先，固定三维目标不被随机观察覆盖。世界目标经同一个头部变换转换到眼部局部坐标；转头后重新求解两眼朝向。修正皮肤厚度光照采样的局部/世界坐标混用。

页面仍使用一套 Three.js r180 核心、一个画布、一个渲染器及原网页的动画循环。新驱动没有独立音频、相机、联网或帧循环。

完整 MIT 许可和署名已随原始源码及独立 HTML 保留。源码文件头的署名年份为 2024，仓库 LICENSE 为 2023–2024；许可证文件原文未被改写。新增 HTML 许可说明没有改动任何可执行脚本。

## 操作与边界

进入网站后，右侧顶端是 TalkingHead 行为面板。可以先用“双眼特写”观察单次/双次/单眼眨眼，再回“肖像”测试点头和摇头。“自然观察”使用原库眼神时序；“转头与锁定测试”可手动转头检查视线是否保持。关闭“启用原库驱动”可回到 ET03 的驱动方式。

TalkingHead 不会替当前闭眼扫描补出真实睁眼几何。本次保留 ET03 的眼角、睑缘和纹理拟合限制；不是照片级眼睛的新模型。未启用说话、嘴形、语音服务或额外角色。当前没有 API 密钥、麦克风授权或新增收费服务。

多张高分辨率皮肤纹理与多通道渲染仍有加载、显存和绘制成本。采样接触测试不代表全部三角形、所有动态中间帧及任意姿态的绝对无穿插。
