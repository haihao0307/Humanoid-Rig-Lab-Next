# ET08-S1 — 第一阶段：灰模轮廓约束

用户指定基线：`5be35195ad40d57507f7ab1785e4eecda6c648de`，不是早期 ET04 或 ET06。仅在独立分支修改，不合并、不强推、不修改任何历史提交。

## 本轮范围

同一头模、同一眼球/角膜网格、同一眼球半径、同一虹膜比例、同一深度拟合结果。新增左右眼分别定义的上睑、下睑、闭合线样条；内外眼角位置独立锁定；灰模显示不使用皮肤纹理、法线纹理、局部修复、睫毛、泪膜或眼球光学。

`Contours.mjs` 中的数值是显式的拟合约束，不是这个人物的真实睁眼扫描或医学测量。上睑峰值位于鼻侧到颞侧的约 40–42%，下睑最低点约 56–58%。宽度初始锁定为人物右眼 23.4 mm、人物左眼 23.0 mm。尺寸最终以 `qa-report.json` 的实际生成几何为准，不能只引用预设值冒充网格检测。

`ContourEyes.js` 继承原有绑定、眼皮截面、内部接触面及行为控制。眨眼终点使用每只眼自己的共同闭合样条，不是缩小一个统一椭圆。原版轮廓对照调用未修改的父类轮廓方法，在相同相机、灰色材料与照明下比较。

`GrayReview.js` 使用现有唯一渲染器与原有动画时钟。灰色虹膜只是可关闭的无折射投影参照，不是新的虹膜/角膜效果。可一键查看中性睁眼、四分之一/半/四分之三/完全闭眼、左右眼特写、侧斜角、低角度和全头；可显示独立曲线控制点和闭合线。

## 没有越级实施

未重建第二阶段的泪阜/半月皱襞/泪湖、眼角联合、上睑截面和下睑体积；未做第三阶段材质坐标重建；未宣称完成第四阶段的体积守恒、弧长守恒、卷入折叠或连续碰撞；未做第五阶段的皮肤及眼球光学。原有这些结构和算法保留，只跟随新的轮廓。

## 验证

`build.cjs` 严格核对指定基线 app 的 SHA-256 后定点集成，并将网页资产锁定在该不可变提交。构建检查最终 HTML 中的脚本语法、唯一 Three.js 核心和上游许可。

`verify.cjs` 检查实际网格有限值、公共边界、完整闭合接触、三维眼角固定、眼球接触采样、原头模保留、无材质伪装、按钮、参数恢复、源入口/单文件入口一致性，以及 390×844 手机视口。

`public.cjs` 在发布后直接打开包含不可变提交的 htmlpreview 公网网址，检查真实画面像素和主要操作。证据在当前 GitHub Actions artifact 的 `public-report.json` 和 `public-*.png` 中。

样本检查不等于穷尽性的连续碰撞认证。手机视口不等于手机实机。最终艺术与自然度验收仍需用户看灰模；不能因为自动测试为绿就声称达到身份级真实。

## 构建

在仓库根目录、具备 Node.js 22、esbuild 0.25.10 和 Playwright 1.56.1 的环境执行：

```sh
node skin-quality-lab/emily-transfer/stage1/build.cjs
# HTTP 服务提供仓库文件后运行：
node skin-quality-lab/emily-transfer/stage1/verify.cjs
```

沿用原扫描与上游组件许可证。原材质和原版 HTML 可通过基线提交恢复；不删除原预览。
