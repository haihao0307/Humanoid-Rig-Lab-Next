# Bird Mother｜Seagull A 连通组件与分离羽片拓扑台 R0.14

R0.14 从运行时封装返回到直接服务于羽毛替换的来源形态解剖。它不制作新鸟、不重建羽毛，也不补造用户尚未提供的飞行姿态；本版只拆解 `seagull (A).zip` 中真实存在的 4,416 顶点、5,624 三角面和 147 个连通组件。

## 本版完成

- 以共享来源顶点为连通标准，重新建立 147 个组件的确定性编号；
- 编号按每个组件的最小来源顶点排序，避免不同实现因并查集根节点不同而改变 ID；
- 为每个组件记录顶点、三角面、表面积、边界边、包围盒、质心、薄片度、展长比和前三主导蒙皮骨骼；
- 建立 70 对左右镜像组件和 7 个中心组件；
- 镜像配对同时检查拓扑数量、面积、镜像质心、包围盒、主导骨骼和反射后的对称最近邻误差；
- 将来源组件划入翼连续表面参考、翼根/中段/远端分离薄片、尾基参考、尾部独立薄片、身体头部参考、腿足参考和未决细节；
- 129 个分离翼片/尾片明确标记为 `must_rebuild`；
- 13 个连续结构组件标记为 `learn_only`；
- 5 个来源语义不足的小组件保持 `unresolved`；
- 提供逐组件筛选、镜像配对、独立三维检查、面积与主导骨骼审计；
- 来源主鸟仍保持只读；组件检查台不会把任何来源薄片提升为未来 Bird Mother 羽毛母体。

## 关键结论

来源网格不是一个连续羽层。147 个组件中有 129 个必须重建的分离薄片，它们占来源总表面积约 53.98%。这批薄片可以教授轮廓、位置、展向排列和拍翼穿插，但不能直接成为最终羽毛系统。

分类名称只表达来源几何位置和蒙皮关系，不宣称已经识别出真实生物学上的初级飞羽、次级飞羽或覆羽。精确羽区必须结合后续用户提供的真实鸟类资料重新建立。
