## 读取与检查

读实际原生生成的裁片和网格，不构造一个替代衣服。逐点对比mesh UV与原mapPanelUV，分别记录纸样毫米、显示材料米制坐标及原函数旋转矩阵。页面轮廓来自这些原裁片的边界边，仅用于查看关系，不是新纸样，不是成衣图。

分别核对准备的成衣person四项身份摘要、动作宿主targetIdentity、人物源码提交、明确的proportion_revision/proportionRevision。源码版本和身份摘要不能被猜成比例版本；只在明确读取字段缺失时报告UNKNOWN，并说明字段检查范围。

原字段materialSHA256对应裁片材料域几何（panels与seams），不等于外观面料版本。供体runtimeDonor、有效材料参数摘要与材料网格身份分开，避免材料同名就宣称独立R17.2已进入R10。

R10目录中牛仔显示默认倍率6，原经纬间距显示参数按倍率变化，物理厚度参数保持原值。这里只检查原代码参数之间的关系，不证明实物经纬密度或厚度标定。

显示方向、物理各向异性方向、制造丝缕证据是三项；前者可核对不自动提升后两者。旧模板staticGate通过也不能替代分级后目标人体的新验收。
