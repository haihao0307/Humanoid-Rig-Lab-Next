## 实际新增代码

local-solve.mjs在原联合门拒绝引导和法向提案后，允许中央三角面的可动角点分别位移，再尝试一圈可动邻点。试算分别从零、原引导、原法向三个确定性起点开始，使用原完整身体查询计算顶点、面心、边中点和实际交叉见证点的局部线性条件。

minimumNormHalfspaces用对偶坐标扫描寻找线性半空间中的最小范数步。最多12次非线性更新、160次线性扫描，线搜索1/0.5/0.25/0.125；最多24个可动点、128个受影响面。位移被原提案大小及20mm上限约束，边长比暂限0.75—1.25。后两项是本实验保守的额外范围约束，不是实物材料标定，不能称为原衣物的真实力学本构。

这些局部迭代是额外成本；原32轮没有增加不意味着总计算不增加。线性迭代达到上限时保留残差，不伪造可行性。

所有试算使用独立数组，真实状态不写。提交前须原非线性查询复核：已有安全点不恶化、无新增交叉、所检查的全部受影响面严格交叉为0、采样达到原margin、变形与位移预算通过。然后先验证全部提交节点，再一次写回。没有通过就保持原状态。本轮实际没有任何提案到达提交条件。

本法不是IPC、连续碰撞检测或全衣物求解器，不能继承这些研究的保证。IPC官方资料参考 https://ipc-sim.github.io/ ，其可行性边界与本实验不同。我们没有引入其代码或外部运行依赖。

## 根因复核：仅移动中央点的范围可能先天不足

新boundary-audit.mjs使用Run39570430770真实冻结的完整身体和衣物数组，逐个检查受影响衣物面的边：若一条边两端都不在可动集合内，它在这次局部搜索中完全不动。

第30步仅可移动427/448/449时，关联面中的边48—49两端均固定，却严格穿过身体的两个三角面。body face offsets为27114和26946；segmentFraction分别约0.065647735与0.553629210，均为边内部，身体三角面重心坐标也全部严格为正。原数组逐字保留。

在身体冻结、边端点不动、拓扑不变的局部问题中，改变第三个角点不能使这条固定交叉边本身与身体分离。这是当前三点范围的结构性阻碍，不是凭迭代失败推测的全局无解。

把48/49也纳入后，五点范围没有再检出这种固定边障碍，但这是必要条件，不是充分条件。本轮原生十三点搜索仍未通过全部约束，不能把扩大范围当作已经找到可行移动。

第102步原三点范围有两条固定边交叉。按交叉边端点逐步扩张，3→6→9→13→16点后，最后检查仍存在固定边交叉。不能默认“一圈邻点”就把相关接触问题封闭起来。

边界审查沿用严格segment-triangle判据：不覆盖共面、边界擦碰或运动过程，不能当作完整CCD。每个交点保存原几何、身份、线段参数、重心坐标与重构误差检查。捕获阶段本身没有应用新移动；其原180步轨迹与S3.11完全一致。
