## 实际新增算法

reachPlan在原固定边预检后，构造初始接触行。单条线性条件a·delta>=b在原坐标盒中最多得到box*sum(abs(a))支持；不足时优先补入能减少缺口的未选可动端点，同时重新检查固定交叉边，直到满足单条必要条件或达到原节点/面预算。第102步可从21点补入447、448、50到24点。每条条件单独可达不等于同时可达。

constrainedDirection不再先算一个忽略形变的方向再全部拒绝。它在同一个scratch方向问题内处理：弹性接触半空间、真实边向量的上界球、沿当前边方向的保守下界半空间、原累计坐标移动盒及内部信赖范围。内部接触弹性权重100用于恢复阶段，允许记录未满足量，但最终采纳门仍要求原接触余量和全部独立检查通过；没有把惩罚残差当成功。

采用有限循环对偶/Dykstra投影，160扫描上限。停止同时检查变量与乘子/修正量变化，避免只看变量暂时不动就误认收敛。有限扫描后仍保留接触与硬条件残差，不称为精确凸问题解。内部方向没有合格下降时缩小试算信赖范围，但仍消耗同一个12外层预算，不增加隐藏迭代。

三个起点保持零/原引导/原法向。非零起点先用既有1/0.5/0.25/0.125/0缩小到满足原形变与坐标盒，并记录实际seedScale；若缩到0，不能称为额外独立初态。

提交前仍通过原完整身体非线性查询、全部受影响严格端点交叉、原安全样本、全部接触采样余量、原边长比与位移检查。增加的面法向反转检查是保守候选限制，不是放宽门。所有试算只在复制数组上；即使合成正例找到合法位移，也只返回预览，不写原状态。

## 真实对照与结果边界

对每份原生冻结状态按reference、shape、reach_shape、reach_shape、shape、reference对称运行。reference是S3.13固定边预检+原方向；shape只改方向；reach_shape同时使用可达性补点。每次新建独立身体查询，数值确定性摘要、输入不变、参考末次交叉数均核对。

这不是新的完整走路序列，也不是此前未执行的5秒运动ABBA。内部局部候选若没有通过全部门禁，不继续运行无可用改变的180步，也不复用旧运动结果冒充本轮验收。

实测候选可以守住最终试算的边长限制，但真实三例仍有交叉/接触残差，不能接受。某些试算交叉比原状态多，仍原样记录，不能挑一个正的顶点距离宣传成功。节点数更大、联合约束更多，实际计算成本需报告，不承诺更快。

## 组合线性条件的独立证据

单条条件的支持量预检仍不够：若干接触条件组合可能与同一坐标盒冲突。linear-certificate.py仅在离线审计中使用SciPy HiGHS寻找证据，不是生产求解依赖。模型是原始冻结状态的初次线性化，分别检查接触条件和接触加线性化边长。

证据采用非负行权重lambda。若sum(lambda*b) > box*sum(abs(sum(lambda*a)))，这些已保存线性条件不可能同时在该盒内满足。Python Fraction把原binary64值作为精确有理数，独立重算这个严格不等式；不只相信LP状态或浮点容差。保存权重、原行、原坐标盒、精确分数差。

网页certificate.mjs用BigInt重新解析相同binary64和权重，逐分数验证，不信任报告中的成功布尔值。错误分数、负权重、非有限数和非线性无解升级会被拒绝。

重要边界：该证据只针对已构造的初次线性模型，不证明实际非线性布料全局无解。去掉形变限制仍有接触组合冲突，提示需要审视接触法向/最近面选择和局部模型的联合一致性，而不能只放宽材料边长或增加同一个线性问题的迭代。缺口是线性条件的共同余量下界，不是物理穿透深度或必须移动的距离。

参考官方方法文档：[SciPy linprog HiGHS](https://docs.scipy.org/doc/scipy/reference/optimize.linprog-highs.html)、[GAMS SNOPT elastic mode](https://www.gams.com/latest/docs/S_SNOPT.html)。本实现不使用SNOPT或IPC代码，不继承它们的鲁棒性或连续碰撞保证。弹性恢复只用于内部候选，不降低最终接触门。
