# RF01 S3.7 · 适配后的接触异常起点

2026-10-21，接续S3.6。仅限原D03、T03上衣/P02下装及当前冻结人物。保留S3.6事务模块原字节、原1.45门限、原ReducedCloth接触和源工作分支，不做碰撞修复或生产合入。

## 原生结果（Run39537947995）

三组都完成48步原生渐进适配，并分别读取：适配提交、原区域模型构造结束、动作选择但尚未推进，以及12个1/60秒物理步。先完成诊断才向原应用发首个初始化响应，避免原自动walk提前推进未知帧。静止条件只固定人体动作，布料仍受原重力/动力学；不能称为已达静态平衡。

三组适配提交及区域模型构造后的受检状态SHA256相同。walk与walk-repeat的15个阶段记录逐步状态摘要、实际距离/计数/见证数据完全一致（耗时不参与等价比较）。

适配刚提交：上衣/身体最小有向距离3.796326mm，下装/身体3.279182mm，上衣/下装2.101000mm。区域模型构造后：身体两通道各4.0mm，衣物间2.101000mm。全部已采样点此时没有负值。有限离散采样不能推断整个表面和整个初始化过程绝对无穿插。

关键结论：人体保持静止也会在后续布料推进中发生接触失败，不能把一切归因于走路。

- 上衣/下装：static与walk都在第4步首次出现超过0.05mm记录余量的负距离，分别约-2.2055mm、-2.0452mm。最差样本为上衣右前身right_ftorso的边中点，目标为pant_f_r。该最近面组合没有严格局部三角交叉证明，报告为原法线有向距离违反，不自动升级为封闭体积穿透深度。
- 下装/身体：static第8步首先出现，最小约-0.5923mm；对应身体绕数约1.000197，且选中原三角面对有严格局部交叉。walk第9步出现，最小约-1.5938mm，身体绕数约1.000201。这些额外证据支持身体接触确实失败。
- 第12步：static下装/身体约-3.5082mm，上衣/下装约-15.1213mm；walk约-5.8579mm和-15.4210mm。上衣/身体这段样本仍为正，不宣称所有上衣区域无碰撞。

本轮定位到原区域动态阶段，不是适配事务留下同样的采样负值，也不是由自动walk的未知进度混入。仍不能从这组结果单独判定究竟是粗粒子接触覆盖、细网格重建还是投影次序导致；下一任务应锁定静止第7→8步下装/身体的首次局部交叉，逐阶段测量原接触修正及重建传播，不首先更改走路动画。

## 读取与证据语义

contact-probe.mjs基于原mesh-contact模块，但对独立复制的表面建立/更新BVH，不调用world.audit，不共享原查询缓存。每次采样前后独立SHA256核对受检人体、服装位置/速度/old/output/法线、区域delta/velocity/ref状态、参考长度和时钟/版本不变。它不是全进程无副作用的无限证明。

记录全物理控制顶点和全部面重心；上下装额外检查上衣约束边中点，沿用25mm搜索和目标重心系数>0.001的内部点筛选。每个最差样本保存节点/原裁片归属、原始测点、最近点、目标三角面与本地相邻面。局部面位置是诊断证据，不是烘焙人体或替代衣服资产。

0.05mm为预先冻结的数值报告余量，不是制造公差。保留所有负值计数与原始最小值。原距离符号由最近面插值法线决定；身体最差点另计算全表面立体角绕数；开口衣物不具有同样的全局内外含义。局部相交为严格线段/三角面交叉，只覆盖这一对见证面；共面/边界接触不冒充已证明，未检出不等于全网格无交叉。

一手依据：libigl官方教程Signed Distance（https://libigl.github.io/tutorial/）说明法线符号测试的闭合/非自交等前提及绕数替代。这里只学习测量边界和独立交叉核验，不迁入外部求解器或复制资产。
