# REALITY-HC-S3 · 布料与皮革世界规范和缺失地图

本阶段延续 S2.1 公共核心，只处理人物与服装相关材料。接入顺序为牛仔、针织/毛衣、皮革、丝绸、棉布、腈纶、亚麻。建筑、飞机、地形、动物、植被和展示世界不在范围内。

## 产品形态

S3 是固定来源的只读规范化模块。它把已存在的源码声明、固定公网浏览器证据和工程候选转为统一状态、量纲、来源和缺陷格式。它不是新的材质渲染器，也不是原工作台的替代品。

页面提供：

- 七类材料对象与接入优先级。
- `PASS / FAIL / WARNING / UNKNOWN / NOT_APPLICABLE` 五种状态独立统计。
- 厚度、经纬间距、纱线直径、针脚节距、Tex、Denier 等标准覆盖表。
- 原生参数原义，防止把无量纲控件冒充毫米。
- 来源、固定提交和证据边界。
- 缺陷派单；全部 `repairAuthorized=false`、`verificationRequired=true`。
- 观察距离与像素足迹计算器。
- 当前对象、全部材料和缺陷 JSON 导出。
- 返回 S2.1 人物/鞋履/裁片公共入口的链接。

公共页面不保存任何私有访问密钥。原工作台链接可能仍要求用户已有的私人访问参数；S3 本身只需要固定公开数据，不处理凭据。

## 当前材料结论

### 牛仔

R17.2 明确了 60 ends/in 和 40 picks/in，对应经纱间距 0.423333 mm、纬纱间距 0.635 mm；3×1 显示重复尺度 1.693333 mm，11针/30mm 对应 2.727273 mm 针脚节距。

0.45 mm 是可见缝线显示代理，不是 Tex、显微纤维直径或实物受压线宽。R03/R15 的 0.7 mm 厚度和 0.45 kg/m² 面密度是另一版本的物理工程候选。视觉 R17.2 和物理 R15 没有绑定为同一已标定运行时，因此页面保留跨版本警告。

### 针织 / 毛衣

R15 保留原生几何、光学和物理。可读候选包括 5.5 mm 原生针目节距参数、约 2.970454 mm 厚度估计、约 0.654545 kg/m² 面密度估计，以及求解器拉伸、剪切和摩擦参数。

原生 `gauge=5.5` 和 `yarn-size=0.85` 尚无到标准针号、针数/英寸或米制线径的公开映射，不能直接当作现实单位。纱线 Tex 和接触标定也仍缺失。

### 皮革

R17 的数字缝线节距配置为 3.4 mm，可见线体直径配置为 0.32 mm。它们是数字几何和工艺显示参数，不是制造认证，也不能直接反推 Tex。

`thicknessScale=1` 只是相对倍率，不等于 1 mm。绝对皮革厚度、皮纹每米重复数、面密度和物理标定仍为缺失。

### 丝绸

R15 保留原生光学、几何和物理。0.24 mm 厚度与 0.08 kg/m² 面密度为工程估计；求解器拉伸、剪切和摩擦参数只在当前求解器定义中有意义。经纬间距、材料轴和 Denier 尚未导出。

### 棉布、腈纶、亚麻

当前 R03 入口明确为 appearance-only。`scale=5` 是原生显示控件，不是毫米、每米重复数、线径或针目密度。厚度、经纬间距、面密度和物理参数保持未知；页面不会制造数值。
