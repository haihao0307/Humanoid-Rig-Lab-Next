## 已实现效果

平台按优先级接入七类固定材料对象：牛仔、针织/毛衣、皮革、丝绸、棉布、腈纶、亚麻。成衣宿主只登记，没有制造试穿、碰撞或尺寸假结果。

每个材料对象可查看：

- 五类状态独立统计：`PASS / FAIL / WARNING / UNKNOWN / NOT_APPLICABLE`。
- 核心标准覆盖：厚度、经纬纱中心间距、几何纱线直径、针脚节距、Tex、Denier。
- 全部测量项的值、单位、依据类型与边界说明。
- 原生字段原义，避免把 `scale`、`gauge`、`yarn-size` 或 `thicknessScale` 当成毫米。
- 固定来源、提交与证据版本。
- 不可自动修复的缺陷派单。
- 当前对象、全部七类材料、全部缺陷的 JSON 导出。
- 给定细节宽度、距离、垂直视场和像素高度的像素足迹计算器。
- 返回 S2.1 人物/鞋履/裁片公共入口。

平台没有源工作台写入接口。所有缺陷固定 `repairAuthorized=false`、`verificationRequired=true`。

## 主要材料结论

### 牛仔

R17.2 声明 60 ends/in 与 40 picks/in，规范化得到：

- 经纱中心间距：`0.423333 mm`。
- 纬纱中心间距：`0.635000 mm`。
- 3×1 显示重复尺度：`1.693333 mm`。
- 11针/30mm 对应针脚节距：`2.727273 mm`。
- 可见缝线宽度代理：`0.45 mm`，只作为显示代理。

R03/R15 的 `0.7 mm` 厚度和 `0.45 kg/m²` 面密度保留为工程候选。R17.2 视觉尺度与 R03/R15 物理不是同一版本，因此平台明确显示跨版本未绑定警告。Tex 与裁片材料轴仍未知；0.45 mm 不能反推 Tex。

### 针织 / 毛衣

保留 R15 的原生几何、光学和物理。当前固定证据包括：

- 原生针目节距参数：`5.5 mm`，仍为工程参数。
- 厚度估计：约 `2.970454 mm`。
- 面密度估计：约 `0.654545 kg/m²`。
- 当前求解器的拉伸、剪切与摩擦参数。

`gauge=5.5` 与 `yarn-size=0.85` 没有到标准针号、针数/英寸或几何线径的明确映射，不能直接解释为现实单位。Tex 仍未知，`yarnContactCalibrated=false`。

### 皮革

R17 可追溯的数字配置包括：

- 针脚节距：`3.4 mm`。
- 可见数字线体直径：`0.32 mm`。

这些是数字几何和显示参数，不是制造认证或 Tex。`thicknessScale=1` 是相对倍率，不是 1 mm；绝对皮革厚度、皮纹每米重复数、面密度和实物物性仍未知。

### 丝绸

R15 的 `0.24 mm` 厚度和 `0.08 kg/m²` 面密度保持为工程估计。原求解器拉伸、剪切和摩擦参数只在当前求解器定义中可比较。经纬间距、材料轴和 Denier 没有导出。

### 棉布、腈纶、亚麻

当前 R03 明确为 appearance-only。原生 `scale=5` 只保留为无量纲显示控件，不转换成毫米、每米重复数、线径或针目密度。厚度、经纬间距、面密度和物理仍为未知或不适用。

## 边界

- 当前是固定证据规范化，不是所有材料工作台的实时导出。
- 没有修改 shader、灯光、几何、物理或 S2 纸样警告。
- 牛仔视觉与物理仍是两个版本。
- 针织和丝绸力学仍是工程估计。
- 皮革绝对厚度仍缺失。
- 棉布、腈纶和亚麻仍是外观入口。
- 没有成衣宿主、人物试穿、碰撞、动作、制造或实物物性认证。
- 手机只验证 CSS 视口，没有实体手机、Safari、Vision Pro 或消费级 GPU 认证。
- 用户尚未视觉验收，当前不是生产门禁。
