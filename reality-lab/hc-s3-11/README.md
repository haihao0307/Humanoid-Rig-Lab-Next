# RF01 S3.11 · 联合位移检查候选

只接续世界规范中已定位的D03下装接触问题，不启动其他框架，不覆盖原生产源。基线4ab4a1c6efefe005d5c90b51c5a6726b0281dd31 / S3.10 / Draft PR110。

## 要验证的问题

S3.10已复现：走路第30步最后一轮，面心引导将面offset2598（三角面866，节点427/448/449）平移约16.0625mm，节点448从+2.170022mm变成-0.673847mm。源程序只检查所作用的面心，不同时保证受移动角点和邻面。

这一步不预设某种修复一定成功。需要区别：已知坏提案能否被拦住、真实静止/走路结果是否改善、剩余接触是否仍失败、新增成本是否可用。

## 实际候选边界

joint-guard.mjs提供通用联合决策器，但本次源端试验只在最后一轮已经触发crotchEscape的面心平移上安装。普通顶点修正、普通法向面心流程不加这层门。它不是全接触联合求解器，不能宣传为所有移动均已保证安全。

采用独立完整身体MeshContact/BVH，取被移动的全部可动角点、所有关联衣物面心，以及这些关联面与身体面之间的严格端点交叉对。提案在独立scratch数组里计算，不修改真实求解位置，不改变原查询缓存。

检查规则：原来已在当前余量外的样本不得被移到余量内；原来不满足余量或负距离的样本不得继续恶化；被修正面心必须取得进展；不得新增严格面交叉对。比较容差1e-7m，只用于浮点比较，不是制造公差，也不是允许穿插的物理标准。

先检查原完整引导位移，再检查原程序已算出的完整法向位移。选择通过者，否则返回阻塞，真实位置保持不变。没有盲目增加迭代、厚度、最后补一遍顶点或回灌fine残差。拒绝留下的原有交叉和面心残差必须继续显示。

共同检查中的“全关联面”覆盖范围比S3.10单目标点的六邻面更大；交叉对数不能和旧页面的局部交叉数直接当同一指标。端点严格判据不覆盖连续/扫掠、边界擦碰、共面、全部渲染纱线或衣物自碰撞。

## 原生实验与信任边界

原宿主冻结为guilin-dem-pipeline@c5c0bedbc35f24cbb35426ab9c14b74ca7fc5f49/kaopu-tailor-workbench/material-products/mp05-studio-r10-3fc034fa91ef。保留S3.8覆盖候选完整SHA256 b0ac0923ff63895d14ae1f5c60f0354c521e598f8e146416a69f95f9ccd5675a、S3.6渐进事务、D03人体衣服材料、1.45拟合门、原32轮与4mm→1mm余量策略。

静止和走路各在同一CI主机顺序执行coverage参考→guarded候选，各180步/3秒；两个动作采用不同主机，不能跨动作比较机器速度。这不是此前未执行的5秒/300步ABBA实验，也不是多轮硬件benchmark。

参考变体只在准确坏操作上做不应用决策的离线式预览，并要求全部43个端点和最终状态与S3.9覆盖参考完全相同。候选要求拟合后、区域创建后、动作选择后三种初始状态完全相同；允许运动不同，但保留原失败、安全门和全部三接触通道。

报告明确记录9类主要量：原生完成或失败、三通道采样、联合提案被接受/阻塞、保留的局部残余、额外距离/BVH交叉查询、guard时间、步骤时间和源状态摘要。准许一个提案不代表原有交叉已解决。

## 计时

原重型完整接触诊断在每步计时外。原fine观察器开销及参考变体中仅供回归用的联合检查时间分别扣除；真正候选的联合检查保留在步骤成本中，另单列自身时间。

当前实现第一次需要构建独立完整身体BVH并生成法线，可能出现明显单步尖峰。这是候选实际成本，不能从结果抹掉或只报中位数。源视觉渲染、GPU耗时、实体设备和多NPC性能未测。构造邻接表位于区域创建之后，属于初始化而非逐步成本。

## 结果原则

以同版本ANALYSIS、DELIVERY、浏览器和原生报告为准。代码检查成功不代表物理合格，180步完成不代表接触安全，零超0.05mm报告余量不代表没有更小负距离或交叉。上衣与上下装失败不得被隐藏。

## 后续
