## 使用与检查

用项目现有 Python 服务打开 `npc-tailor.html`，或部署完整仓库到支持静态模块与 Worker 的 HTTPS 站点。不能只复制这一张 HTML：完整原人体参数与重建模块必须保留。

页面可旋转、缩放、正侧背查看、麻布近看、切换素色版型、调衣长和包络外放松量、显示同光线 16×16cm 样布，导出原 NPC 配方及本轮量测 JSON。

松量控件是安全包络之外的追加参数，不等于成衣胸围减人体胸围。表中衣围为设计包络估计；肩关节间距与外肩宽也不是同一定义。经纬坐标按衣片边长以厘米计，不用整件归一化 UV 拉伸原麻布。它仍不是已证明无应变的二维展开。

## 尚未通过

当前只有固定的原动作系统试衣站姿与无袖上衣。长袖试验存在折叠和局部穿入，已排除；没有把失败袖子混入成品。行走、抬臂、连续碰撞、布料动力学、真实缝合、二维生产纸样以及用户视觉验收均未批准。离散三角面采样不能证明所有连续表面或所有姿态都不穿模。

材质公式及参数相同不意味着不同曲率、距离、灯光下的屏幕像素相同。保留同光线样布用于对照，不承诺未经实测的跨场景视觉一致性。

浏览器测试由 `tailor/tests/browser_review.py` 真实执行，不替换 Worker 或 NPC；证据放在 Actions artifact 内，不在源码中保存人体生成后的三角网格。
