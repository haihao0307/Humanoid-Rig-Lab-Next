# Bird Mother｜Seagull A 通道分离与关节限位台 R0.09

R0.09 承接 R0.08 的 8 锚点控制器迁移审计，不制作新鸟、不重建羽毛，也不补造任何用户尚未提供的飞行姿态。本版只把同一份来源拍翼循环进一步拆成四组可迁移通道，并为每一个已经被来源证明的通道建立来源限位与连续性检查。

## 本版完成内容

- 保留来源网格、来源蒙皮、50 帧源动画和 R0.08 控制器双生体；
- 明确拆分四组通道：
  1. 翼根驱动；
  2. 翼肘折叠；
  3. 身体耦合；
  4. 显式左右不对称残差；
- 对左右翼根、中翼、外翼、翼肘、平均翼尖高度、翼展、身体高度和镜像 RMS 建立来源最小值/最大值限位；
- 继续使用 R0.08 的 8 个来源锚点，并分别检查平滑重放与线性重放；
- 对来源曲线与重放曲线执行：
  - 帧 50 → 帧 1 的闭环差；
  - 最大一阶差分；
  - 最大二阶差分；
  - F10 与 F41 反转点前后的速度跳变；
  - 来源限位越界计数；
  - 重放限位越界计数；
- 外翼末段折角继续以只读锁定状态呈现，不把约 0.007° 的来源变化误写成有效扇面关节；
- 桌面端与 390×844 手机端工作台继续一按直开，零外部运行依赖。

## 为什么需要这一阶段

R0.07 回答了来源动作发生了什么，R0.08 回答了用多少锚点可以重放主要曲线。R0.09 继续回答：未来独立动作系统应该把哪些运动拆成不同控制通道、每个通道能在什么来源范围内活动，以及循环与反转点是否连续。

这一步仍是参考蒸馏层，不是最终动作系统。限位只是当前来源文件的证据包络，不是所有鸥类或所有鸟类的生物学常数。

## 不得误读

- 四组通道只驱动审计图和控制器重放，不修改来源鸟体；
- 来源限位不等于物种真实关节极限；
- 连续性审计不证明空气动力学正确；
- 左右不对称增益被限制在来源的 0–100%，不会放大来源缺陷；
- 原分离羽片、近似锁死的外翼扇面和源蒙皮缺陷不得进入未来羽毛母体；
- 滑翔、翱翔、转弯倾斜、起飞、着陆和逃逸仍等待用户文件；
- `visualAcceptance=false`；
- `productionReady=false`；
- 来源许可为 `CC-BY-NC-SA-4.0`，不得直接进入商业运行时。

## 下一道门

下一步只能在来源证据范围内建立**通道执行合同**：把翼根驱动、翼肘折叠、身体耦合和不对称残差转换成明确输入/输出接口，并验证跨循环连续性、参数裁剪和失败回退。展向扭转、外翼扇面、飞羽层和其他飞行姿态继续保持锁定。
