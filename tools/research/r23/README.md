# R23 未采用的像素重复性试验

这些脚本从身体项目根目录执行，仅做隔离诊断，不是产品入口或发布验收。报告保存在 `qa/fidelity-r23/`。

R22 自身的跨上下文对照也出现少量像素差异。原始输入、相机、材质均匀变量、上传字段和中间目标逐步核对后，抖动、提交刷新或等待试验仍未稳定消除差异，因而没有将这些试验的同步改动作为修复交付。某次零差异不能替代重复验证，更不能替代原版完整复刻验收。

生产实现保留原材质 GLSL 与原字段。正式入口和当前范围见 `tools/qa-source-r23.cjs`、`tools/check-release-r23.cjs`、`DELIVERY.json`。研究报告不得被提升为 sourceFidelityAccepted 或 visualAccepted。
