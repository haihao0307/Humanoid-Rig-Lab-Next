# 新人物源表面工作台 R001

## 当前目标

本阶段只完成用户提供 USDZ 人物的**源表面读取与检查入口**。短裤完整保留；删除短裤、补足被遮挡身体、骨架绑定、参数化蒸馏和服装试穿均进入后续阶段。

## 不允许偏离的规则

1. 不使用球、圆柱、胶囊或其他几何体随意拼装人物。
2. 不以截图、轮廓或主观比例重新猜测当前三维表面。
3. 首先读取 USDZ 内的 USDC 原始场景数据。
4. 保留并检查源 points、faceVertexCounts、faceVertexIndices、法线、UV、材质绑定和贴图引用。
5. 源文件身份由文件名、大小和 SHA-256 固定。
6. 后续参数化人物必须从这份可追踪表面证据中采样和蒸馏，不能把外部网格静默伪装成程序化成果。
7. 原始资产和后续生成结果分开保存。

## 网站使用

网页左侧是基于 Three.js 与纯 JavaScript USDC 解析器的源场景查看器。把原始 USDZ 文件拖入查看器，或在查看器内部选择文件。文件在浏览器本地读取，不会由本工作台上传到远程服务器。

加载完成后应检查：

- 人物整体比例是否和源文件一致；
- 短裤是否仍在且未被改写；
- 所有分件是否存在；
- 层级、网格、材质和纹理是否能被列出；
- 正面、侧面、背面和近景是否没有丢面或错误拼接；
- 控制台与解析状态是否没有失败项。

## 当前边界

R001 是源读取工作台，不是最终人物，也不等于已经完成表面参数化。只有在原始网格数据、分件关系与材质通道完整读取后，才进入后续的表面采样、函数拟合、骨架绑定和衣物接口阶段。
