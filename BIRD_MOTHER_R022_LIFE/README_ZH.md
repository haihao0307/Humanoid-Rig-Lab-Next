# Bird Mother R0.22P 海鸥函数生命工作台

## 本版解决的问题

- 不再依赖来源贴图维持表面信息，消除材质链路失败后退化为白膜的问题。
- 几何由体轴、超椭圆横截面、翼展/翼弦/弯度、羽片脊线和尾扇函数现场生成。
- 18 关节权重骨架驱动肩—肘—腕传导，并联动胸廓、头、尾和腿。
- 八种生命状态：站立观察、步行觅食、助跑起飞、巡航扑翼、逆风定点、滑翔盘旋、减速落地、理羽。
- 提供 WebGL2 主路径与 Canvas2D CPU 安全回退。
