# Bird Mother R0.22｜海鸥生命活动与表面曲线工作台

日期：2026-09-30

## 定位

本版从 R0.21 海鸥工作台继续，不覆盖旧分支。重点解决两件事：

1. 旧版看起来接近“白膜”的表面表现。
2. 只有局部摆动、缺少全身联动的机械动作。

## 本轮诊断

R0.21 并非没有来源贴图。包内仍保存 1024×1024 颜色图，但旧运行时在羽片函数读取 `shaftSpanSamples` 时中断，后续函数羽片和材质链没有完整执行；原颜色和灯光的灰白反差也偏低，因此视觉上接近白模。

R0.22 将来源贴图降为可调参与层，不再把贴图当作唯一表面信息。程序层始终保留：头腹暖白、背翼银灰、黑色初级飞羽、白色翼尖镜斑、黄色喙、粉灰腿足和羽片曲线。

## 程序化表面

- 按源组件语义划分身体、翼、尾、腿、喙和头部细节区域。
- 依据静止坐标、UV 和羽区函数生成羽片弧线、羽轴与微表面起伏。
- 顶点阶段沿法线加入小尺度函数位移；片元阶段增加羽片曲线明暗，不只是重新染色。
- 来源贴图、程序化羽区、羽片曲线和表面起伏可分别调节。
- 贴图失败时仍保留程序化分区，避免退回白模。

## 生命活动

工作台包含九种状态：静息、警戒观察、觅食步行、理羽、起飞、扑翼飞行、滑翔、着陆和长鸣姿态。

运行链：

`生命状态函数 → 关节目标 → 固定段长的肩/肘/腕/翼尖传导 → 头/躯干/尾/腿补偿 → GPU 蒙皮 → 函数表面着色与微位移`

九种状态不是九段外部动画文件，也不是机器学习训练结果，而是可调的程序化动作函数和约束组合。

## 已知限制

1. 20 关节骨架不能逐根驱动初级飞羽、次级飞羽和覆羽。
2. 当前没有独立下喙骨，长鸣只做头颈轮廓，不伪造张嘴。
3. 来源网格未完成物种级真实尺度校准，不能把当前翼展、腿长或质量当成生物测量数据。
4. 当前成年海鸥外观用于验证银灰背、黑翼尖和白镜斑的函数分区，源网格尚未完成物种级鉴定。
5. 来源许可为 CC-BY-NC-SA-4.0，不能直接作为商业运行时成品；商业生产需要以自有或兼容许可的函数重构资产替换。
6. 本版是表面函数和生命状态验证，不是最终 3A 羽毛、气动或肌肉解剖定稿。
