## 继承而不是重复发明

## 本轮确切新修复

旧客户端在已有 sample 尚未收到时调用 reset，会把随后的 sample 请求直接丢弃。可控重现中只发出一个 sample，复位前 steps=24 的数据仍被接收。R12.1 增加请求编号与命令版本：过期回复不应用；最多一个采样请求在途，重复采样合并为一个补采样请求；reset/step/kick/anchors/controls 等实际命令不合并、不跳过。重建后旧 generation 和重复/未知 request 均不能清除新的待接收状态。

只修改物理客户端/Worker 的快照传输协议。Cloth 类、实际物理步进、GLSL、棉纱几何、材质、灯光、采样、厚度、LOD 和针脚保留。原 R12 配方可显式兼容读取；R11 等物理语义不同的历史配方仍应在历史版本使用。修正 UI 仍声称残丝没有独立动力学的旧说明。
