# Denim R13 — 自碰撞、受力裂口和缝线张力的布样实验

## 实际生产代码
同一工作台、原牛仔材质及画布新增三种明确的布样实验模式；旧材质模式仍为默认。不是生成图片或预设动画，也不把旧静态破损预设说成完整动态撕裂。

自碰撞：布面三角形/边空间哈希，顶点—面和边—边厚度约束、位置摩擦，包含跨越符号保护。相同对折夹具可开关接触对照。只处理粗布面代理，不是每根棉纤维；邻接一环排除，跨越保护不是完整可靠CCD。

受力裂口：中央预设候选界面19组重合点，完整状态直接消除重复自由度、合并质量参与求解；载荷持续超过强度后才释放自由度。断裂不删除质量、不复位物理时间。只沿这一条预先选择的界面扩展，不是任意位置自适应重网格。中部较弱的强度场是声明的试验配置，不是实测。显示的纱线、曲线微层、远景载体都按同一物理界面分侧取样，不能由隐藏完整布面继续传力。

缝线张力：17个位置用两侧材料坐标加权根点建立只拉不推的线长约束，可调松量和热拆/接线。力回传布面；拆线同时删除实际约束与对应显示。三股上下走线读取同一根点及线长。没有模拟针刺过程、线结接触或工业锁式缝合的完整微观结构。

## 失败修正与边界
初始候选的局部焊接导致界面过度伸长，未发布。最终采用完整界面自由度消元、断裂后质量保持拆分；拉裂主方向采用全局约束PCG和有界增量，折叠/缝合使用多轮局部投影。默认拉裂、折叠、缝合用例的采样拉伸门槛15%；额外高界面强度不裂用例存在约23%瞬态拉伸，不属于此应变门槛，原始报告保留，不能宣称全部参数无条件稳定或准确。

新实验主方向顺应性是父输入的200倍；摩擦、强度、阻尼、线参数都是未实测工程输入，不把水洗颜色当物性，不宣称真实牛仔断裂力已标定。新增接触和裂口必然有CPU/GPU/图集成本，不是帧率升级。

原R12.1 Cloth类逐字不变，命令序号与过期采样保护保留。旧配方显式兼容；实验导出为报告和设置，不是完整可恢复逐帧快照。批量精确步进用于复现，每个240Hz子步都执行，不是实时性能证明。

## 验证与构建
首次hydrate.py只展开哈希锁定的本项目增量，生成所有规范可读JS/HTML/测试；CI在公网验证前将这些规范源提交入库。之后用build.py，不覆盖重跑迁移。SOURCE_LOCK逐一锁定候选源字节。

test-mechanics.cjs检查零载荷、质量/时间、强度对照、缝线传力/热拆线、松线不抗压、折叠接触、曲线分侧、非法输入。qa.py真正进入file://及固定公网页面，执行默认材质对照、三实验、近远镜头、暂停复位、自主步进、报告导出和390×844视口。未完成前不宣称新网页交付；截图只是内部证据。
