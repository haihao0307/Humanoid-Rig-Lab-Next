# Denim R14 — 先修厚度和连续弯曲，暂停撕裂

用户否定R13的折纸式中线折叠和齐整裂边，要求优先厚度/基础物理；人物整衣排除。父源码400e0d217c1b73015f2e052a0947556bb285c333，父固定网页82ab5421a14ea87734bf3e26b41f1d65d0a5e02e。只新增r14与专用CI，旧版、存档、main、其他工作台和根许可证不变。Draft，不合并、不强推。

## 根因与本轮实现
R13将两半布片的中线焊接，接合处缺少跨界抗弯，并固定整个左半片；右边缘目标翻过180度。这可用于接口断开试验，却不应当作自然整片牛仔折叠的已完成方案。布料可以有折痕，但该人工中线铰链不是厚度/材料弯曲求解的替代品。

R14的fold模式改为49×13连续网格，共637个唯一物质点，中线不复制、不拆分。只夹住左外边缘两列，另一外边缘通过有限刚度夹具移动；内部没有指定折线、目标圆弧或结果烘焙。面积积分质量、经纬伸长/剪切、重力、桌面支撑、摩擦、曲率与布面接触共同求解。原材质模式的Cloth类逐字保留，旧R13撕裂代码不作为新折叠求解器。

抗弯采用方向曲率二阶差分能量及耦合带状线性求解。另加厚度相关的局部转角限制，避免极端曲率集中在单网格边：默认半径目标=5×厚度，每个离散弯曲单元最大60度。它是明确的工程正则化，不是实测牛仔的压缩/纱线滑移定律，也不能保证残余误差为零。面内链约束与接触交替收敛，不能仅把有穿透的画面后处理成厚布。

布厚、面密度和抗弯输入分开。厚度影响实体纱截面及接触分离距离（标称厚度的1.04倍数值裕量）；默认材料族抗弯刚度按厚度平方缩放，是可替换假设，非所有织物通用关系。脚本可独立指定弯曲刚度。面密度可使用输入值或启用已有的按厚度估算开关。0.45/0.70/1.05毫米三个预设只作工程对照，未实物标定。

材质渲染读取同一整片位移场及导数，沿折叠方向使用连续Hermite插值，不再将经纬纱/微层在中线人为切开。保持旧纤维光学、噪声、原材质近远采样和命令采样顺序保护。折叠镜头垂直视场24度，棚景射线匹配；原材质模式36度与默认画面保留。

## 操作与范围
顶部进入整片厚度与折叠，可切薄/中/厚，调整边缘目标、松开夹持，侧看厚度，暂停/复位，导出报告。相机切换不重置物理；厚度/刚度更改重置，因为质量、曲率或几何改变。撕裂和缝合按钮不出现在新试验区，原R13固定页面仍保留。原破损材质预设可在返回原材质模式后使用，不能拿原静态破口冒充本轮自然撕裂成果。

## 门禁、成本和未完成
数值检查覆盖曲率线性残差、局部高曲率反作用、连续拓扑、质量、零载荷、厚度独立性、接触质量权重、自由悬垂刚度对照、三档折叠、夹持释放、采样布局与旧材质代码。真实file://及固定公网检查、字节摘要、原画面对照和截图以成功后的DELIVERY_RECEIPT.json为准。启动CI不等于交付完成。

本轮没有实现自然逐纱拉脱、针线力学深化、任意成衣拓扑、可靠全场景CCD或逐纤维自碰撞；接触仅连续粗布面顶点—三角面。桌面与边缘夹具是试验边界，不是隐瞒的“自由随便折”。前期局部角约束在小尺寸悬垂测试过软/过伸、纯二阶差分在低刚度出现集中折角，均被拒绝；最终模型增加了明确的高曲率保护。物性、半径保护、摩擦和夹具均需样布校准。

更多网格点/接触收敛有CPU成本。Node耗时和软件Chromium不是实机帧率，390×844是视口不是手机。报告的数组/显存账本不等于进程总内存。禁止将这一个固定折叠用例的通过外推成任意动作、任意设备或所有材料已达标。
