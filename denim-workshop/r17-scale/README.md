# DENIM R17 — 成衣真实尺度与中远景可读性

日期：2026-10-15。状态：独立牛仔裤装材质候选，等待用户视觉验收。它不是整套裁缝网站合入，也不是工业实物标定证书。

## 用户问题与纠正

用户指出现有服装网站中的牛仔纹理、纱线和针脚过小，稍微拉远就消失，并有模糊感。这里不能简单把所有纱线任意放大：现实牛仔纱线本来就是亚毫米尺度。真正需要解决的是三层表达同时成立：近景保留独立经纬纱；中景保留3×1组织形成的斜纹脊和竹节；远景保留靛蓝、磨白及缝线覆盖，不让高频变成灰糊、摩尔纹或彻底消失。

## 尺度基线

CottonWorks 的公开资料给出典型14盎司裤装牛仔约55–64根经纱/英寸、38–42根纬纱/英寸。本候选选择范围中值附近的60 ends/in与40 picks/in，对应中心距0.4233mm和0.6350mm；不是所有牛仔布的统一常数。

Coats 的牛仔裤缝制建议中多处采用每3cm 10–12针。本候选采用11针/3cm，即2.727mm针距。0.45mm面线直径是当前可调的几何/显示代理，不宣传为所有Tex规格的实测直径；物理直径与亚像素栅格支持宽度分开。

## 实现

页面是无贴图、无外部模型的自包含WebGL2牛仔裤样。裤腰、前后片、两条裤腿和厚度边由程序网格构建；材质坐标使用米制世界尺寸，不因纸样或人物UV缩放而改变织纹。

着色器从真实经纬中心距计算3×1经面斜纹。像素足迹通过`fwidth`连续决定表达：独立纱线不能被解析时，四纱循环的对角脊继续保留；更远时由低频竹节、靛蓝和磨白接管。没有全屏模糊或截图贴图。

腰头、门襟、前后袋、裤腿侧缝和裤脚使用同一条解析针脚函数。针距保持毫米值；当线径小于像素时，扩大的是栅格支持范围，同时按物理直径/支持宽度衰减覆盖能量，不把几何线径永久改粗。UI提供45%错误尺度对照，用于直接检查旧问题。

## 验收与限制

核心数值检查覆盖现实尺度、针距、亚像素覆盖边界与单文件依赖。浏览器检查覆盖整衣/中景/大腿/针脚微距、现实与错误缩放对照、组织/针脚分项、轻微成衣运动和390×844视口。

这是规则裤样上的材质验证，不是现有23款成衣、人物动作、纸样缝合和布料物理的全量回归。针脚未模拟工业锁式线迹的线结、张力和针孔；裤装几何不是生产纸样。中远景可读性是一种同源尺度重建，不能让肉眼在任意距离看见真实不可分辨的单根纱线。用户视觉批准、真实手机和消费显卡性能尚未完成。
