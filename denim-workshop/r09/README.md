## 新增真实运行能力

dynamics.js 使用 25×19（475）个节点、2632 个成对约束，模拟重力、惯性、风压、拉伸/剪切和距离式弯曲近似。固定 1/240 秒子步，每子步两轮约束迭代；长程上界约束缓解有限迭代造成的过伸长，不给自由点强制写入预录动画轨迹。风速归零仍保留速度，外力轻推之后有响应与衰减。

求解在内嵌 Blob Worker 中执行，与绘制帧率及画质档位分开。每次只请求最新快照；有在途请求时不堆积新的请求。475×3 位移通过 transferable buffer 传递；在 GPU 上通过一份位移及导数图集，统一驱动高密度经纬纱、毛羽、松散纱线、针脚和动态阴影。画质切换不关闭物理，渲染剔除不删除物理节点。窗口/视口隐藏时暂停本工作台；它不是一个已经接入全球时间的完整游戏世界。

新增“开启风吹 / 摆动”“动作锚点牵引”“轻推布面”“物理复位”和风速控制。动作锚点是附件输入测试，不是已经连接人物动作系统；setAnchorOffsets 提供 25 个锚点的米制偏移接口，setCollisionSpheres 提供最多16个球形代理的测试接口。原解析摆动单独标为对照，不能再称其为布料物理。

优化还合并了每顶点重复的形态函数及三角函数求值；浮点纹理支持线性过滤时采用硬件插值，否则使用手动插值回退。动态包围范围随实际位移扩张，不能借静态包围盒剔除已经摆入镜头的纤维。显式“节能预览”只降低内部像素数；XPBD 动态阴影仍按姿态快照更新。帧率上限不是一个把求解关闭的开关。

## 资源账与未测量项

本地 1000×780、DPR1 的保真静态状态，已跟踪 GPU 对象约182.52 MiB；这不是显卡总占用或整个浏览器内存。新物理位移/导数图集22800字节；求解器显式 TypedArray 合计180136字节。Worker 引擎、浏览器、驱动等额外开销不在此数组数值内。原 R08 的已跟踪账约246.58 MiB，原本地 R09 约182.50 MiB；图像尺寸、DPR、破损和远景过渡会改变分配。

动态外观现在比旧解析摆动承担更多真实计算，不能把新增物理与原静态速度直接比较后声称全面提速。软件 Chromium 的耗时不等于用户电脑上的 CPU/GPU 占用率或 FPS；未完成整衣、多人物、手机真机压力测试。最终实际 HTML 大小、当前资源账和浏览器状态以 BUILD_MANIFEST.json、DELIVERY_RECEIPT.json 为准。

  https://dev.epicgames.com/documentation/en-us/unreal-engine/panel-cloth-editor-overview

## 不能混淆的物理边界

这是布样级低密度代理，不是已完成的人物成衣系统。弯曲使用距离近似，物性未经实测标定。未实现自碰撞、连续碰撞检测、真实缝纫针穿刺或全局不穿模证明。球接触检查只覆盖代理节点，不能升级为全部可见纤维无穿透。破损布样目前仍用连续粗代理，破口纱桥/断丝跟随该场；不具备逐根断纱动力学与受力撕裂。

双面针脚有上下线路径及三股几何细节，但针孔没有实际拨开布料经纬纱，也没有线张力求解。小配方仅保存材料/外观参数，明确不包含全部网格和物理运行状态；不能把几百字节配方宣称为一件完整动态衣服的内存。

## 重建与复核

首次 python denim-workshop/r09/restore-source.py，再运行 finalize-source.py 和 build.py。传输段只用于将本轮本地源码无损转移到 GitHub：压缩包总摘要、逐段摘要、父文件摘要和目标文件摘要均检查；生成的规范 JS/HTML/Python 源码会正式提交。后续直接编辑规范源码，不重跑 restore-source.py。

node test-budget.cjs 检查共享点属性和缓存；test-layers.cjs、test-stability.cjs、test-cotton.cjs 保留父版数值回归。test-dynamics.cjs 检查四种布样形态、分段推进确定性、固定锚点、零风轻推及阻尼、运动锚点和代理球接触。数字 checks 是采样断言次数，不是独立场景数或真实度分数。

qa-publish.py 默认真实 file:// 导航，--url 为实际固定公网，--compare 为相同视口 R08 近景对照；--content 只用于受限本地开发，不能充当 file:// 或公网证据。测试包含实际开启风吹、继续摆动、换画质不停止物理、锚点牵引、暂停保持姿态、复位、针脚正背面、破口、远景、配方导出导入及手机尺寸布局。390×844为视口模拟，不是手机实测。
