# Denim R09 — 紧凑运行时与穿布针脚

## 当前任务与冻结基线

用户认可 R08 近景观感，要求不丢掉这项成果，优化文件体积、运行时内存和开启轻微摆动后的 CPU/GPU 开销，同时把黄色横缝线做成缝入布面的针脚。两条互不混淆的执行线：A 为资源/运行性能，B 为缝线结构。

冻结 R08 构建：`57e8c6c2ce61a1226da302ba3bb239fc5274ae61/denim-workshop/r08/index.html`，94,176 bytes，SHA-256 `6f9000811b7c3b3a4be2f31e21cea5cb42ccb4632478727d20b7fc49e8862acf`。继承分支头 `bf8353e5129e822404d2141a0b3a74ab2ba28783`。新分支 `fix/denim-r09-budget-stitches-20261011`。R01–R08 与其他工作台只读；不合并、不强推。

用户的本轮表态是对 R08 观感的认可，不是对未实现的物理、所有设备性能或影视级质量的批准。原轻微摆动是正弦着色器形变，不是风力积分、布料力学或自碰撞求解。

## 性能与大小要分开计量

文件体积、材料配方、CPU 保留数据、GPU 几何/纹理、渲染目标及驱动/浏览器内存是不同项目。不能拿一个很小的 HTML 文件证明运行时很省内存，也不能把 API 提交时间当作任务管理器的 CPU/GPU 占用率。

R08 已知同镜头基线：几何缓冲 120,032,840 B，其中展开后的纤维带与索引 112,871,136 B，约占几何 94%。离屏附件 111,965,672 B；四张同源材质捕获纹理及 mip 层约 22.37 MB；阴影深度纹理按 4 B/像素计约 4.19 MB。合计约 258.56 MB 已登记 GPU 资源，不是浏览器总内存。最终对照以同一浏览器同一视口的 `compare-qa.json` 为准。

### A1 紧凑存储，不删除 R08 的细纤维

原代表纤维默认 39,096 条及其位置、顺序、长度、父纱身份保留。每个曲线点原先复制两次左右带顶点，并存完整三角索引；现用一份 Float32 XYZ/半径、16-bit 八面体切线/寿命/父编号记录，通过顶点编号展开成带。记录 24 B/点；切线和寿命是有明确误差界的量化，不声称逐位无损。XYZ 仍为 Float32。

生成时以 4096 点小块直接进入类型数组，上传后释放中间块；不保留全部 JS 嵌套纤维点。旧的完整几何读取接口按需重新生成。主纱 YarnGraph 在运行时只保存生成参数/关系，省去未使用的密集中心线数组。小布片 4 织法×5 破损以旧/新 Float32 曲线摘要、数量、顺序逐项比较，默认全尺寸检查纤维数与编码预算。

### A2 减少无效绘制与 CPU 重复工作

主纱分块与纤维曲线做保守相机范围裁剪；保留布形与摆动余量，不把影子投射者按主相机裁掉。纤维按原顺序组成一个可见索引流，保持透明混合次序。相机不变时不重建可见表；摆动不重新生成/上传纤维几何。

同一纱截面的半径、噪声、中心等计算在着色器中提取为一次共享结果，再用于位置与法线。阴影用专用深度程序。真正缓存空 uniform 位置，避免每帧反复查询已被编译器消除的变量；深层自然纱审计移出逐帧循环；光源矩阵缓存，界面诊断最多约 4 Hz 更新。

原输出画布的额外多重采样关闭，但真正绘布的离屏 4×MSAA 保留。光照仍在线性空间合成后一次色调映射。异步 GPU timer 是可选功能，不等待未就绪结果；显示的是上一次完成的样本，不是实机利用率。

### A3 明确区分纯优化与质量/能耗取舍

`R08 采样规格` 档保留旧近景超采样标准，仅使用新存储、裁剪与共享计算。`节能保真` 默认档在纱线已经占多个像素时把超采样上限逐步降到 1.25，保持输出尺寸与 4×MSAA。它不是无损操作；同镜头像素差、实际画面和资源差分别记录，不能将少采样全部计为无损优化。

摆动上限提供 15/30/60 Hz，默认 30；这是上限不是保证帧率。节能档运动阴影按约 15 Hz 分桶失效更新，高精度档每次位移更新。暂停后冻结当前位置，页面隐藏时取消连续调度，静止时不持续刷新。降低运动频率会降低时间细腻度，不冒充同样流畅度下的免费性能。

### A4 极小材料配方与独立网页

`kaopu.denim_recipe@1.0` 只保存生成器版本、种子和参数；默认约 437 B，可导出、导入，并拒绝错误 schema/越界值。旧的完整参数/破口数据导出仍在。多件衣服应在同一运行时共享生成器，而不是复制整个工作台或为每件衣服保留显微布样。

独立 HTML 的引擎代码用确定性 gzip 内嵌、浏览器原生 DecompressionStream 解开。无 CDN、外置模型、网络贴图或 decoder 文件，不用 eval；GitHub 保留完整可读规范源码。需要支持 DecompressionStream 的现代浏览器。不支持时明确报错，不暗中载入旧页面。压缩网页不等于压缩运行时几何。

## B 黄色缝线

学习 301 锁式线迹的两线程关系，每一排分别有连续面线与底线；面线在每个针位进入布内绕过底线，再出布连接下一针。新增表面捻股截面、局部入针覆盖开口和接触变暗；正反面都可观察。默认两排共 64 针、66 针位，针距 2.94 mm、线径 0.14 mm；针距/线径可调，附正面针脚/底线观察按钮。

这是几何和材质结构，不是工业缝纫系统或布料受力求解。针孔为局部 fragment coverage，而非重新切开每根纱线的拓扑。穿线中心的有限样本不证明所有线径、布厚下都无自交；尚未验证缝线拉力、起皱、动态穿针或真实缝合。

## 原始资料及实际采用的内容

1. MDN WebGL best practices：避免阻塞查询、稳定 VAO、及时释放资源、按像素预算、批处理与渲染附件成本。本轮对应空 uniform 缓存、流式类型数组、裁剪批次、专用深度与明确的采样档位。
   https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/WebGL_best_practices
2. Khronos WebGL2 规范：整数纹理、顶点编号和固定 primitive restart。用于单点记录展开与一个有序可见纤维批次，不依赖 WebGPU 或外部库。
   https://registry.khronos.org/webgl/specs/2.0/
3. Khronos EXT_disjoint_timer_query_webgl2：计时结果可用性与 disjoint 检查。只报告支持时的异步样本，不捏造 GPU 百分比。
   https://registry.khronos.org/webgl/extensions/EXT_disjoint_timer_query_webgl2/
4. Coats Basic Stitch Types：301 面线/底线锁式关系；不是把 401 链式线迹混成锁式，也未宣称完成缝纫物理。
   https://www.coats.com/en-us/info-hub/Basic-stitch-types/
5. MDN DecompressionStream 与 visibilitychange：单文件内置解压和真实页面可见性调度。
   https://developer.mozilla.org/en-US/docs/Web/API/DecompressionStream
   https://developer.mozilla.org/en-US/docs/Web/API/Document/visibilitychange_event

## 重建、复核与成本边界

首次 `python denim-workshop/r09/bootstrap.py`，之后只修改规范源码并 `python denim-workshop/r09/build.py`。迁移只读冻结 R08，拒绝覆盖已有 R09 app.js。UI/比较两个 CI 工位必须构建相同字节，成功后才发布新固定提交。新的运行时代码已经编写，最终实际 file:// 与固定公网结果仍以 DELIVERY_RECEIPT.json 为准。

`node test-budget.cjs` 和 `node test-cotton.cjs` 验证结构/量化/连续性。`qa-budget.py --scope ui` 检查实际网页按钮、针脚、四织法、代表整理、配方往返、摆动不重建/上传、静止与可观察到的后台停绘。`--scope compare` 检查冻结 R08 同镜头画面，高精度对照的平均 RGB 误差门槛 <0.10/255；节能档记录误差且须 <5/255，并由实际画面复核。四种布形的可见裁剪与不裁剪结果在测试镜头下最大差 ≤1/255。

温热缓存下以 QA 专用 gl.finish 记录完成帧耗时与 API 提交耗时，生产循环不调用它。软件 Chromium 的时间不能转换成用户的显卡 FPS/利用率；记录减少的调用数和实际提交三角形，避免仅用一个时长猜原因。另做完整/破损两个场景各 8 帧亚像素移动，13×51 材料位置补丁比较，容差 max(R08×1.15,R08+0.12)，不是全画面绝对无闪烁证明。

额外资源包括紧凑纹理读取、可见索引及保守包围数据。裁剪不等于把所有不可见数据都从显存流出；工作台仍保留整块布样的紧凑点库。当前没有多件真实服装、复杂遮挡、统一布料求解器或显微细节缓存的集成压测。不能把约 437 B 的材质配方称为一整件衣服运行时仅占 437 B；也不能将显示器相关渲染缓冲机械地乘以服装件数或忽略几何/碰撞成本。
