## 本轮运行代码

`cloth-topology.js` 从同一个 Natural.contour 与实际保留的纱桥/尾丝构造版本化 `kaopu.cloth_structure@1`。面节点位于孔内时，不再具有质量、受风面积或碰撞响应；任何跨越孔洞的布片拉伸、剪切、两步弯曲连接均移除。面积用子格积分分配到存留节点，张力限长沿存留邻接图传播，不再保留跨孔的完整布片捷径。

可见双端纱桥和单端尾丝分别获得低分辨率 XPBD 链，有质量、惯性、风阻及弯曲近似。根部用存留布面权重绑定；焊接端点自由度被代入布面自由度，链张力反作用于布面，避免极小纤维质量与较大面节点质量导致的根部滑脱。全局面拉伸/实际纱桥弧长约束与链式三对角块求解组合；没有纱桥时使用较便宜的方向链求解。

物理位移用小型图集上传，密集纱线/毛羽不逐根重新生成。释放线使用独立链位移，布面使用排除孔内节点的覆盖加权插值。支持浮点线性采样时用硬件双线性；否则手工采样。相机、显示 LOD 和画质切换不重建/停止物理解算。修改破损结构、材质或形态则明确重置求解，不隐藏状态不兼容。

厚度、名义面密度、经向刚度、纬向刚度和弯曲倍率是真实求解输入。默认“按厚度估算质量”是明确的工程假设；取消后使用输入面密度。厚度对弯曲的立方缩放、所有刚度和阻尼目前未校准，不等同真实牛仔材料测试。颜色、水洗预设仍不是力学测量，也不宣称所有织法自动获得准确的本构参数。

原 R11 外观噪声、棉纱材质、采样、细节驻留阈值及针脚生成文件保持原字节。纱线和破口静态点位保留，只新增运行绑定数据。R12 配方加入 `mechanics.model=damage-xpbd@1`，旧版配方留在对应版本复现，不静默迁移物理含义。配方仍不是完整逐帧物理快照。

## 开发中实际修正的失败

初次局部约束试验中，小质量链端点造成明显的纱桥拉长和附着误差。直接提高迭代次数很昂贵；仅做链块求解仍有布面张力传播不足。最终采用端点代入、存留连接的块/全局求解，保留受力、质量和端点关系，不通过冻结运动或删除可见桥线换取稳定。未发布这些失败候选；数值门槛和失败边界保留于测试。当前 solver 仍为近似，不是无条件稳定或受力准确的证明。

## 验证方法

首次 `python denim-workshop/r12/derive.py` 从锁定 R11 生成规范源文件；生成之后直接编辑规范 JS、HTML 并用 build.py 重建，禁止覆盖式重跑迁移。SOURCE_LOCK.json 记录本地候选源摘要，CI 必须逐个核对。

`node denim-workshop/r12/test-structure.cjs` 检查完整/三种破损的点位保留、孔内零质量/受风面积、跨孔面约束移除、双端/单端绑定、零载荷不漂移、孔内与实布的球碰撞区别、3 秒求解、方向/厚度/面密度改变响应以及纱桥向布面传力。每 0.5 秒采样的面拉伸门槛为15%，链段长度误差门槛18%；数值通过不是实测材料精度认证。球测试只是选定空区的离散节点接触测试，不是完整穿透保证。

`qa-structure.py` 默认真实 file://；`--public <固定地址>` 验证实际公网页面。`--content` 仅是开发环境中的文档载入，不得称 file:// 或公网。静态近景对照事先门槛为平均通道差小于1/255、超过8/255的像素少于3%；不能用调高容差掩盖视觉退步。另测近远释放与复现、薄厚控件、破损物理、持续风吹/牵引跨 LOD、暂停/复位、针脚、导出导入与390×844视口。

## 性能与物理边界

新增物理并非免费。大破口会增加保留纱桥和尾丝的自由度，全局张力求解比原完整 475 点简化布片更昂贵。工作线程隔离的是主线程阻塞，不是消除 CPU 消耗。必须分别报告完整布样和破损布样的求解耗时、显式数组、图集与整页资源；Node 计时或软件 Chromium 不能冒充用户真实显卡 FPS。

仍未实现：布面/纱线自碰撞、连续碰撞检测、面级人物碰撞、受力生成新的裂口、纱线断裂演化、真实针孔和缝线张力、人物整衣接入、独立实例随机种子、局部虚拟几何分页、影视相机缓存与色彩输出。原针脚只是随布面运动的双面三股几何，没有在本轮变成力学缝合。新增链是代表纱线的低分辨率代理，不是每根棉纤维。
