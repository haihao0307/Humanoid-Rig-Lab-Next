# Fabric Fidelity R1

独立布料材质与风碰撞实验台。保留既有麻布和腈纶着色器，原始 Git blob 为 `72149bc1771b0d05c3f6186b839e439861bb8e20`。无 Adobe SBS/SBSAR 或 Adobe 导出贴图；不能称为 Adobe 材质一比一复现。

支持悬挂、迎风旗帜、球体落布、胶囊落布、台面垂坠、平展检视；风速/风向/阵风、拖拽、重力、约束、碰撞、原材质锁定、分屏比较、贴图导入、设置与截图导出。

物性均为演示参数；完整自碰撞和任意高速连续碰撞尚未实现。显示细分不替代真实物理分辨率。Height 导入当前只作通道检查。上传贴图不离开本机。

`chunks/*.b64` 是完整 HTML 的 gzip 分块。入口校验 SHA256 后解压并执行，不依赖第三方 JavaScript。可用 Python 的 base64/gzip 标准库合并恢复可编辑的独立 HTML。公开浏览器证据由同分支 Actions 工作流生成，不将 HTTP 200 或 DOM 加载当作渲染成功。
