# 独立服装模块

草裙作为第一件服装，从 `body/ProceduralGrassSkirt.js` 移到此目录。服装只消费已提交的人体骨架和同源蒙皮，输出自己的显示形变。每个人物持有独立实例，不创建人物队列，不修改动作目标、路线、交通预约或任务调度。此模块仍在视觉验证中，不能把接入完成写成“所有动作零穿模”或“大量 NPC 已达标”。

**默认使用原有骨骼驱动显示路径。候选布料求解明确关闭。** 调试时通过对应人物的 `compact.clothing.setSimulation(true)` 单独启用，`false` 恢复原路径；两个模式均由独立服装系统管理。候选在本轮真实浏览器的深蹲、坐下、起身检查中出现衣摆上翻、局部拉伸及穿入，已拒绝作为默认效果。隔离不是穿模修复完成，原路径也仍有已知交叉问题。

## 参考做法

- [Unreal Clothing Tool](https://dev.epicgames.com/documentation/unreal-engine/clothing-tool-in-unreal-engine)：把服装作为独立资产，以角色的碰撞体约束布料，使用最大运动距离和动画驱动控制偏离。适用于本项目的原则是腰部固定、衣摆放松，运动限制与材质参数分开。
- [NVIDIA PhysX Cloth 官方文档](https://nvidiagameworks.github.io/PhysX/3.3/PhysXGuide/Manual/Cloth.html)：用连接约束处理拉伸、剪切和弯曲；逐步插值身体碰撞体；以三角形内的虚拟采样点补足顶点碰撞。文档也明确区分连续碰撞、布料自碰撞及多件衣物之间的碰撞，增加粒子和求解频率有成本。
- [Unity Cloth 官方手册](https://docs.unity.com/en-us/engine/6000.7/manual/physics-section/physics-overview/class-cloth)：服装对明确配置的球/胶囊碰撞体作单向响应，可配置连续碰撞、虚拟粒子和休眠。不能假定穿上衣服就自动与整个场景或另一件衣服发生正确碰撞。

这里只采用公开的算法原则，自行编写项目内的简化实现。没有导入服装网格、贴图、第三方求解器或预制资产；当前实现也不是 Chaos/PhysX/Unity Cloth。

## 文件与接口

- `ClothingSystem.js`：每个人物的服装实例、更新、绘制、重置与释放。`add(id, garment)` 保持本人物内唯一 ID；身体时间和姿态不变时不重算。阴影和颜色绘制读取同一结果，绘制函数不推进布料。
- `GarmentClothSolver.js`：低分辨率环形求解网格，默认 32×13 共 416 个节点。保存相邻节点的距离、剪切和弯曲关系，以当前身体时间推进。腰部固定点、重力、阻尼、动画恢复和身体碰撞分开处理；三角形中心参与接触修正。
- `ProceduralGrassSkirt.js`：原有植物纤维、遮盖层和腰带的程序化生成及绘制。高分辨率显示网格从求解网格插值。腰部固定点复制附近现有皮肤的骨骼权重，读取同一 DQS/肌肉形变；不能只跟随骨盆，否则弯腰时腰腹会穿过腰带。

输入是本人物的 `human/sourceBind/world`、`agent.time`、身高比例及人体蒙皮调色板。输出是服装形变纹理、绘制资源和诊断；不回写人体骨架。`CompactSurfaceRenderer` 统一持有 `clothing`，并保留 `skirt` 引用作为旧诊断的兼容入口。替换体型/曲面时先构建新服装，全部上传成功后才释放旧服装；失败仅释放新资源。

当前衣物碰撞使用大腿、小腿、前臂及骨盆代理，属于工程包络，不是实际人体表面的精确碰撞证书。腰部绑定来自实际皮肤权重，但碰撞体仍需进一步拟合。

候选原型曾尝试沿外侧射线推出衣物，出现硬环状膨胀，已撤除；后续的连接求解保留为可复现试验，但不能靠继续增大碰撞半径来验收。接下来先拟合分段、渐变半径的腿部包络，解决近髋处蒙皮与刚性骨段之间的差异，并限制衣片翻转、拉伸；再补真正的扫掠碰撞和自碰撞。不得把失败的截图当作交付效果。

## 验收边界与后续

先验收站立、行走、转身、深蹲、坐下、起身、躺卧及动作切换，检查腰带、裆部、膝后、手腕经过衣摆的连续帧。必须同时记录衣物与身体的间隙、相邻节点拉伸、反面翻转和实际截图；不能只检查顶点。图片为真实 WebGL 检查证据，成果是可交互程序。

仍未完成通用的布料自碰撞、衣物层间碰撞、任意场景网格碰撞或完整连续碰撞。对采样点的投影不能保证所有三角形在所有时刻都不相交。多人下一步应测量服装单项耗时、总帧耗时和内存，再设置近/中/远求解预算、休眠与唤醒；不直接把所有 NPC 配成最高频率，也不依据单一 CPU 夹具宣称人数容量。
