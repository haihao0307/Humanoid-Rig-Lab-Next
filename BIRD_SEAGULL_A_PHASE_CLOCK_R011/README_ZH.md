# Bird Mother｜Seagull A 相位时钟与长周期稳定台 R0.11

R0.11 承接已经实际部署并通过桌面、手机浏览器验证的 R0.10 通道执行合同。它不制作新鸟、不重建羽毛，也不补造任何没有来源证据的飞行姿态；本版只解决同一段来源拍翼循环在不同采样率、暂停、恢复和长时间运行时如何保持同一个运动定义。

## 本版完成

- 唯一运动参数固定为 `phase01 ∈ [0,1)`；
- 来源周期固定为 `49 / 24 s`，即 49 个来源帧间隔；
- 采用 360 Hz 公共主时基，周期共 `17,640` 个整数相位刻度；
- 24、30、60、90、120 Hz 分别以 360、288、144、96、72 个相位刻度推进，因此切换采样率不会重定义动作；
- 建立 `CYCLE_ENTRY`、上下止点、最快上举、身体最低、最大翼展/不对称、最快下击以及 `F50_TO_F01` 边界事件；
- 建立时钟序列化、恢复、采样率切换和事件序号；
- 建立 1、10、100、1,000、10,000 周期漂移审计；
- 明确指出：24 Hz 和 120 Hz 每周期样本数为整数，30、60、90 Hz 不是。逐周期四舍五入样本数会确定性累计漂移，刷新率只能采样公共相位时钟；
- 来源鸟仍使用原网格、蒙皮和来源动画，R0.11 只驱动时间和 R0.10 通道评估。

## 边界

相位时钟解决的是工程确定性，不证明来源动作在生物学或空气动力学上正确。外翼扇面、展向扭转、初级飞羽展开、次级飞羽重叠以及滑翔、翱翔、转弯、起飞、着陆和逃逸仍保持锁定。
