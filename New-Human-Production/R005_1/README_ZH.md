# R005.1 首帧空白修复

R005 的人物数据、骨架和蒙皮已经生成成功，但渲染循环在第一帧调用了不存在的 `SkeletonHelper.update()`，异常发生在 `renderer.render()` 之前，因此网页界面显示“已就绪”，三维视口却完全空白。

R005.1 已改为 `SkeletonHelper.updateMatrixWorld(true)`，并增加首帧主动渲染、蒙皮网格禁用错误视锥裁剪以及可见运行错误提示。人物表面、轴向、骨架、蒙皮和动作算法未被替换。

## 当前动作

- 站立与轻微呼吸
- 原地行走
- 向前／向后行走
- 左转／右转
- 右手挥手
- 下蹲
- 坐下
- 起身
- 暂停、继续和停止

支持中文顺序指令，例如：

```text
向前走2米，然后向左转90度，然后挥手，然后坐下，等待2秒，然后起身
```

## 程序化程度

骨架、骨长层级、蒙皮权重、轴向归一化、动作、过渡、地面支撑修正和行为队列全部由程序运行生成。

但人物表面目前仍来自用户 USDZ 的完整采样网格数据，因此当前准确名称是：

> 数据采样驱动的程序化绑定人物

它还不是“不保留原始表面数据、只靠紧凑函数谱重建”的完全程序化人物。
