# 新人物 001 · 动作与行为测试 R005

## 执行分支

`work/human-character-surface-001-r005-motion-20260930`

## 本轮闭环

```text
原始 USDZ 表面（只读老师）
→ 完整表面采样
→ 自动规范轴向
→ 固定骨长骨架
→ 全顶点程序化蒙皮权重
→ desiredPose
→ 精确动画 / 物理跟随
→ finalPose
→ SkinnedMesh
→ 中文行为任务队列
```

统一坐标已经修正为：

- `+Y` 向上；
- `+Z` 人物正面与前进方向；
- `+X` 人物左侧；
- 左侧镜头位于 `+X`，右侧镜头位于 `−X`。

## 可测试动作

- 站立和轻微呼吸；
- 原地行走；
- 向前／向后行走；
- 左转／右转；
- 右手挥手；
- 下蹲；
- 坐下；
- 起身；
- 暂停、继续和停止。

支持顺序指令，例如：

`向前走2米，然后向左转90度，然后挥手，然后坐下，等待2秒，然后起身`

## 程序化程度

骨架、骨长层级、蒙皮权重、轴向归一化、动作、过渡、地面支撑修正和行为队列均由代码生成。

人物可见表面仍来自用户 USDZ 的完整采样数据，因此当前准确名称是：

> 数据采样驱动的程序化绑定人物

当前还不是只保存紧凑函数谱、完全不依赖原始网格数据的“完全程序化人物”。

## 边界

- 短裤继续保留并参与蒙皮；
