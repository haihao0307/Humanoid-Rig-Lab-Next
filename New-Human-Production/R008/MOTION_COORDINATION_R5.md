# R008 待机脚底稳定与全身跳跃协调

2026-10-01。本地入口：[R008-motion-5](http://127.0.0.1:8877/?version=R008-motion-5)。继续使用 WASD、Shift 与空格；默认 B 为“屈体越障”，A/B/C 均采用本轮全身协调增强。当前为可供用户动作挑选的候选版，公网未发布。

## 观察与根因

隐藏 Chrome 在修改前以 120 Hz 采样站立 10 秒和一轮默认跳跃。游戏闲置环顾将继承动画的根、骨盆、腿和脚动作一起混入；只去除水平根位移并不能去除下肢迈步和体重转移。原左右脚水平轴的峰峰位移约 10.6/10.5 cm 与 14.2/16.9 cm。脚趾也随之滑动。

原跳跃在归一化“离地”点仍保留约 55° 屈膝，离地后才继续伸展；臂角长期偏向后摆。固定低幅躯干和较浅收腿进一步削弱了全身蓄力/伸展的观感。默认实际骨骼测得蓄力下沉约 7.50 cm、准备期躯干倾斜约 15.87°、空中最大屈膝约 48.75°。

## 研究与使用边界

先阅读 [Epic Blend Masks / Blend Profiles 官方文档](https://dev.epicgames.com/documentation/en-us/unreal-engine/blend-masks-and-blend-profiles-in-unreal-engine)，采用按骨骼分层、上半身动作不影响下肢的原则。没有引入 Unreal 运行库或虚拟骨骼资产。

阅读 [Cefai 等，Scientific Reports，2024](https://www.nature.com/articles/s41598-024-70194-z) 的摘要和引言。该研究描述摆臂与近端至远端关节伸展的时序关系。本轮借鉴髋、膝、踝分段伸展和手臂先行的协调原则；所有游戏角度、时间、位移是项目自定参数，不视为论文的实测数值，也没有实现肌肉力、关节力矩或生物力学仿真。CMU 原稀疏曲线保留为左右差异的辅助数据，当前结果是程序化协调增强，不是未经调整的实采回放。

## 实施与所有者

- `SubjectRuntime.mjs`：只对游戏用的 `game_look_around` 克隆曲线应用骨骼掩码。根、骨盆、腿、脚和脚趾使用已认可的中性参考，上半身、手指和环顾继续播放。原四段单独检查动作及参数包未变。
- `JumpProfiles.mjs`：C2 阶段函数控制压缩、髋先伸展、膝随后伸展、踝/前足滚动、摆臂、空中收膝屈髋、落地再压缩与恢复。三方案分别保留双脚前跳、更深屈体与跑跳前后腿差异。来源辅助权重约 0.16–0.30，仅使用有限的双侧差值。
- `GameAnimator.mjs`：增加骨盆、三段脊柱、锁骨、颈头反向平衡及脚趾配合；承接当前 gait 的姿态和速度。脚掌滚动跨越离地阶段连续保留。空中 IK 目标的局部移动限制为 2.2 m/s，矫正角速度限制为 10.5 rad/s，避免接近直腿时的 IK 奇异点突变；地面真实脚接触不应用此空中限速。
- `CharacterController.mjs`：准备时间从 180 ms 改为 300 ms，使压缩与蹬伸在离地前具有可见时间。1.02 m 物理跳高、重力、走跑速度、碰撞、边缘容错和镜头规则未变。

第一次增强曾在离地时将脚掌俯仰突然复位，并使深屈腿的空中 IK 重新伸展过快。实际检查记录出现 0.230 rad / 8.33 ms 的单步转角。保持脚掌滚动的跨阶段连续性，提前渐进伸腿，再限制空中 IK 矫正速率后，三种方案的当前最大单步转角为约 0.11345 / 0.11887 / 0.11420 rad；首次落地步骤分别约 0.00362 / 0.00451 / 0.00896 rad。限速服务于实际连续性，不替代动作视觉评判。
