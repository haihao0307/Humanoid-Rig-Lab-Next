# 短裤：布块、缝合、曲度

用户明确要求以实际裁片与接缝构造服装，保留原版、自动按人物尺寸制版、降低腰口并设置松紧装置。本记录区分查到的方法、自己的程序表达与已通过的检查。目前仍未完成成衣，不能称为真实布料系统已验收。

## 实际服装参考

已阅读[Pattern Runway/Peppermint短裤缝制说明](https://peppermintmag.com/wp-content/uploads/2016/05/1103_SpringShorts_Instructions_PatternRunway.pdf)第5、6页，并检查示意图。该示例把对应前后片的侧缝、内缝连接成两条裤腿，再对齐两腿的裆缝；腰带短边形成环，长边接裤身，折回构成弹性带通道，插入独立弹性带并封口。这是一个实际款式的顺序，不是所有款式唯一合法的顺序。本项目含独立G裆补片，不直接复制其纸样、比例、缝份或无G的裆缝。

[Closet Core松紧腰头](https://blog.closetcorepatterns.com/elastic-waistband-finishes/)说明腰头通道、插入弹性带和防扭转定位。程序必须保留“布通道”和“弹性带”两个对象；腰头布长与弹性带自然长度不能混为一个restLength。腰头褶量来自收束关系，不能用材质贴图代替。

[Melly Sews裤装合体说明](https://mellysews.com/how-to-fit-pants-when-sewing-pants-fitting-issues/)展示裆部曲线深度与裆端延伸是不同调整，并以拉痕方向区分。不把所有裆部异常统称为裤子太窄。腹部与臀部也不能默认相同；裤身必须留下活动余量，不能以完全贴皮且完全无褶作为合体目标。

[GarmentCode作者论文](https://arxiv.org/html/2306.03642v2)及[作者裤装构件代码](https://github.com/maria-korosteleva/GarmentCode/blob/main/assets/garment_programs/pants.py)分别核对了Panel、Edge/Curve、Interface与Stitch的层次；裤腿外/内边和前后裆边是不同语义接口，裆曲线具有端点及切向控制。学习抽象与对应规则，不导入其资产、程序、样例数字或完整版型。

## 曲度的两种含义与程序关系

纸样边界曲率描述2D裁片轮廓。例如参数曲线c(t)=(u(t),v(t))的曲率为 |u'v''−v'u''| / (u'²+v'²)^(3/2)，切向必须非零；这不能直接替代整个3D布面的曲率。

布面3D弯曲描述缝好后相邻面法向的转动。已阅读[Discrete Shells](https://multires.caltech.edu/pubs/ds.pdf)第2页的膜与弯曲分开原则和边二面角公式。这里使用独立平片源长度、面积作为积分度量，布内自然二面角为0；接缝不是同一张未切开的平片内部边，不能默认为自然角0。

自己的最小关系式为：

1. 每片有独立米制材料域(UV)、经纬方向、边界曲线和对位标记。当前3D点X不定义材料rest。
2. F=∂X/∂(u,v)，C=FᵀF，拉伸与剪切由C相对源度量计算；保持既有5%检查，不靠缩放整片或平均远距离缝边通过。
3. 缝合是有向边界参数的对应X_a(s)=X_b(φ(s))。无抽褶普通缝核对逐区段源弧长；有抽褶必须显式记录布量与聚合关系，不能强改源边长。φ按标记及源弧长定义，不按当前XYZ最近点乱配。
4. 布内离散弯曲用 θ_e 与源参考θ0=0：E_b=1/2 Σ κ_e(ℓ_e/h_e)(θ_e−θ0)^2。h_e为源相邻三角高度平均的1/3，即(A1+A2)/(3ℓ_e)。κ输入单位N·m，能量J。接缝转动法则单独指定；当前仅提供明确自由转动形式，不能称为已校准真实针线。
5. 穿着形态由接缝、膜力、弯曲、弹性腰带、重力及身体/自接触共同求解。增加一个弯曲项不会自动修复错误的接缝方向、初始嵌入或不够的布量。

平片可以等距弯成圆柱等可展曲面，但不能无限制地无应变贴合任意双曲率人体表面。前后裆轮廓、拼缝、补片、适当抽褶/省道或材料允许的变形共同承担成形；不是为每个顶点指定一个“曲度数”就能制造合法裤子。

## 当前源模型的对应

|对象|当前身份|应承担的约束|
|---|---|---|
|前后主片|FL、FR、BL、BR|腰/臀/大腿尺寸与活动余量；各自源度量|
|裆补片|G|gusset-FL/FR/BL/BR四条有向边；裆空间与应力分布|
|裤腿|inseam-left/right、outseam-left/right|各自形成管状；不跨左右腿错缝|
|前后中缝|center-front/back|连接对应前/后片，不替代G边|
|左开口闭合件|side-opening-left|原源设计kind=closure、stage=5、initiallyActive=false；不得当作永久普通缝提前硬合|
|腰头|WFL/WFR/WBL/WBR、waist-*与waistband-*|腰头接裤身、腰环、布通道、独立弹性带|

上述19条包含一个闭合件，验收时要明确其开/合状态，不能用“19条全部永久硬焊”代替结构。当前实验保留未收敛缝边；还没有实现物理闭合件或真实腰头通道厚度。

自动适配必须从当前人物测得目标低腰环、前后腰弧、臀弧、裆深/前后裆长与大腿环，先调整源纸样，再保留本次源rest进行成形。换人物不是在已经变形的XYZ上统一缩放；A原版不因B制版修改。用户要求的腰口位置不能改成裤脚长度要求。

## 已落地的数学函数与验证界限

新增 `ShortsCurvatureModel.mjs`：四点铰链有符号二面角、解析角度梯度、源面积权重、弯曲能量梯度；布内平片与跨缝自由转动明确区分，退化铰链返回HOLD。`tools/test-shorts-curvature-model.mjs`核对平片零弯曲、有限差分梯度（最差误差约5.75e-14）、刚体不变性、按源尺度变化的曲率、接缝明确自由转动、退化拒绝。

该函数尚未接入全局穿着求解；当前离屏图仍是此前的未缝合HOLD结果。新增函数的测试不等于新服装图已出现、不等于材料已校准、不等于动作通过。形成系统当前也没有已校准的布料弯曲参数。必须在统一能量/梯度/矩阵和接触检查中接入，不能在主应变检查后私下改XYZ。

`evaluateShortsSourceCurvature`已接到源模型的1152条布内铰链，源边長/两侧三角面积来自原始UV，跨缝法则仍显式列为UNSPECIFIED，不暗中设平片休止角。相同源模型平铺时布内弯曲能量为0；在本次冻结实际截图的WORLD位置上，腰头WBR源边518:526二面角3.075684rad（约176.23°），近乎反折。证据在`qa/shorts-source-curvature-audit-20261004.json`；其单位刚度响应仅用于数学审计，不是亚麻的真实物性。这进一步说明5%拉伸通过不能证明形态干净。没有改变截图时的布面、身体或native时钟。

只读复核另确认：WFL源三角748在实际失败态的上界λ间隙只有3.607175e-6，局部C-Hessian较静止态放大约9.14e7倍。固定有限回溯到2^-20不能证明不存在更小可行下降；现有失败步没有CG真实残差及候选拒绝明细。下一轮应先补失败收据，并采用保持原严格域的fraction-to-boundary；不放宽5%、不继续盲加权重。局部Hessian比例不是全局条件数证书。

最终验收仍需：正确开合状态下的源接缝/裤子拓扑、腰头实际收束、原5%材料度量、身体与布面全表面接触/自交检查、当前人物多视角外形以及动作时的物理响应。这次没有完成这些验收。
