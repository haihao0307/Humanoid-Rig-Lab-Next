## 已确认的模型逻辑问题

1. 旧逐行映射使FL一条39.86mm源边变成81.08mm，比例2.034。它不应作为真实布片形态依据。
2. 原G中心到角点只有相应源长度约45%；初始参考被错误压缩。新的G采用既有u=0边的双半片刚体铰链；主片整片刚体定位，四条G接缝闭合，源度量保持单位。
3. 先把其余尚相距很远的布片硬平均，会破坏独立裁片的度量。新流程保持四条G接缝精确共享，只以有限静态缝合能量连接其余接缝。
4. 软缝罚权极大时，PCG残差不收敛。仅当全部源边间隙≤1e-7m、每源点质量平均位移实测≤1e-7m、无三角退化且源应变增量≤1e-4时，才消去已近重合的缝合变量。源质量每点计一次；多点链的最大位移不能从单条缝隙直接推断。
5. 旧穿着求解同时要求最大接触缺陷、接触平方和、腰头上限缺陷均不增加，且精确临时高度平面保持。最终 coarse9/fine1 的21个候选全部被该组合条件拒绝；旧记录没有逐条件分辨，不能断言是哪一个条件单独导致。主应变拒绝计数为0。新的恢复能量应统一接受方向，最终材料、位置、接触仍独立验收。
