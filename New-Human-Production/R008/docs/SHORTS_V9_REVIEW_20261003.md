# V9.4：实际截面、有向互补裁片与约束接触候选

状态：SOURCE_DEVELOPMENT_CHECKPOINT / HOLD。原版 A 保留；此文不声明短裤已经完成或适合生产穿着。

## 问题和实现

V8 从旧衣物包络推导的量体与新皮肤不一致。V9 对当前实际 WORLD 皮肤三角面取截面和矢状面交线，actor 平移/旋转除去、米制实际身高保留。未知被衣物覆盖皮肤依然是明示估计的裸胯补体，不是假称恢复的裸体。

`ShortsBodyTape.mjs` 保留严格查询：原生皮肤开放的截面必须 HOLD。在 actual bare minimum 附近发现原生大腿接口缺段；`guideSectionAtY` 只为初始服装摆放提供相邻真实闭合环的插值，并逐次记录两端来源/缺段 witness。它不是量体权威，也不改碰撞身体、UV、材料 rest 或质量。

`ShortsGarmentDraft.mjs` 新选项 `finalRiseBudget` 求解最终裁掉角点后的长度。设独立源纸样扩展量 q、剩余主片裆线 R(q)、裆片半宽 w/2 和割边 E(q)，求

`R(q) + sqrt(E(q)^2 - (w/2)^2) = L_skin + ease`。

程序先检查正高度和解析凸分支最小点，再在单调分支上二分求根；不是扫描穿着坐标，也不使用失败穿着 XYZ 重新烘焙 rest。关闭选项时旧纸样不变。最终源片为 9 片、553 个源点、848 面、19 接缝、451 自由缝合自由度。

`ShortsGarmentV9.mjs` 使用这些新量体标量和用户固定的低腰/裤脚平面重裁。保留独立松紧带：中线量体围度的 90% 为原长、EA=100N、有限伸长，绝不把收缩后 XYZ 当作 rest。

`ShortsSurfaceTransport.mjs` 保留有向 Darboux 标架的独立数学实现：u=aT+bR，v=bT-aR。固定世界X投影在内腿退化；局部标架虽正确，最近三角面运输仍会离开连续曲面 chart，产生有见证的30mm源边→81mm初始端点跳变。V9.1 已停用这个全局最近特征运输，不把局部公式通过当作曲面正确。

V9.1 初始映射把源外缝弧长归一化作为目标高度参数。该方法固定了端点，却在实际第5行偏离臀围平面5.394mm。V9.4区分通用材料坐标和本纸样明确以量体垂直深度编写的侧缝纵坐标：在backRaise=0且独立检查hip/hem端点一致后，使用该特定cut的纵深逆函数定位侧缝高度；不能泛化为任意UV长度都等于WORLD高度。内缝仍使用独立弧长端点定义。所有映射只是初态，不改source UV/rest/面积/质量。

V9.2 修正另一个确定的 chart 边界错误：旧内部曲面带有额外13～17mm径向松量，但 `c===0` 强行替换为没有相同松量的接缝点；内部极限与接缝不连续。原逐列Y选腰胯环或双腿环也会突然更换曲面chart。现在每片先固定腰下沿、臀围和裤脚三个参考曲线，按源外缝弧长分段loft；设参考行 Q(t)，共用中缝 C 和侧缝 S，使用 `X(t)=Q(t)+(1-t)*(C-Q(0))+t*(S-Q(1))` 做双边连续修正。额外松量按 `16*t^2*(1-t)^2` 在边界以零一阶导数归零（不保证完整曲面跨缝C1），边界位置由单独声明的共同曲线给出，不再覆写内部的非连续极限。主裤身腰边和腰头下缘使用同一曲线；quotient平均前直接检查原目标缝隙不得超过1e-10m。此转有限曲面的表达仍只是初态，不能升级为等距、接触或物理验收。

`ShortsInitialExteriorContour.mjs` 把闭合原生源多边形解释成非零winding平面集合，以交叉/接触/包含建立连通分量，选实际同腿thigh/calf轴所在分量。INITIAL专用360径向包络取相连所有源segments的最外union exit，逐ray保留triangle/barycentric、原loops、两两谓词、区间和填空长度。它不忽略小环、不声称精确union/裸皮测量；严格 `sectionAtY` 仍对MULTIPLE等原始异常HOLD。单/多环native初始pole统一骨轴，bare原测量保持原样。第七次冻结截面冷验证：两个proper交点、全部360 exits有源见证、一个非star-ray填8.9725微米，明确只是径向INITIAL近似；没有据此修身体或碰撞。

V9.4修正两个确定的调用/曲面问题：原`sector`从未收到`startPoint`，所以新腿部起角函数实际上没有启用；臀环到裤脚的XYZ弦也会穿入实际大腿。现按每行实际截面构造参考行，并传共享meridian。腿轴Z随高度变化，不能以dz正负拒绝真实共享点或钳成0；改用medial dx条件及互补有向弧。左前从atan2(dx,dz)递减到−π/2，左后递增到3π/2；右前递增到π/2，右后从同角+2π递减到π/2。共享起点/侧端点，弧长之和2π，内部不交叠；最终仍用双边transfinite修正，不声称等距或接触通过。

`ShortsClothRuntime.mjs` 可选择经纬/剪切有限 XPBD 膜模型。V9 工程参数是 2000/1200/300 N/m，尚无实测亚麻标定。仅片内共享源边使用平纸零角弯曲；跨缝自由转动，未假定缝线具有标定的弯曲角。原生动作没有被打开。

工作台采用最多 40 轮源度量/真实接触联合静态 authoring，真实接触无回退改善时停机。所有质量自由度保持正 inverse mass，source UV/rest/质量/19条pair恒定，原生时间/步数为零。一次真正的 2D 细分生成 1945 源点/3392 面/1751 自由度；渲染与审计使用同一个实际网格，不能拿显示法线代替形态或材料通过。

V9.2的实际35轮停止原因是罚项GN方向虽然减小总误差，却让当前最大接触穿入变差；有21个回溯步长全部被真实接触无回退检查拒绝。细分后又只是重采样，没有针对新增布点再次求解。V9.3引入独立mass-whitened静态可行方向投影：真实当前接触半空间、贴腰4～6mm范围、临时精确腰/裤脚平面与每DOF3mm信赖球共同参与；有界Dykstra/Hildreth投影未到数值可行时HOLD，不能把局部未收敛当成纸样无解。所有身体和材料验收仍查询真实状态，不用冻结平面取代最终碰撞。细分网格在相同独立二维rest上追加最多20轮真实接触求解。完整原生动作仍锁定。

V9.3实际粗15/细5轮因原1e−10m数值证书未通过停机，分别残差0.72nm/67.5nm；所有已接受步确实改善自己的最大应变和接触，不可误说已接受步加重穿插。V9.4只为可动半空间的内部投影目标增加固定1µm余量，外部原bound/1e−10证书、3mm球、高度plane、128cycle/250ms预算不变；nullspace消去行不tighten。即便内部未收敛，必须独立证明原约束才可使用方向。buffer目标可能排除零，因此理想原集合零可行投影的下降定理不适用于本次数值候选；实际analytic/FD和fresh gate仍决定接受。不宣称QP最优。

V9 向制造模块显式提供独立水平G纸片手持标架与新纸样来源。直接继承源模式的矢状G摆放，会使制造模块的“向上＋向外”方向不与割边正交，破坏其等距前提；这是初始化接口问题。新标架只是刚性手持初态，UV/rest/面积/质量不变，未将贴身后的G形态当作源纸样。新纸样不借用原A的提交哈希；实际源码哈希来自构建清单。

## 实际验证与失败边界

- 独立最终裆长/源裁剪：11/11；局部标架、弧长、互补腿chart、双边曲面及非法输入：17/17；原约束/内部余量、mass/plane/trust及有界下降方向：18/18。纯数学测试不代表人物视觉通过。
- 一次实际量体：8 个闭合原交线截面，74 triangle/barycentric witnesses，最大 WORLD 误差 2.38e-16m；这只验证量体。
- 当前参数 gzip SHA-256：`0f801bc60163a968aef8a647b2a9b472279236dc63d5b81d5c320654141333e2`。
- 独立 native CPU V9 在 upper-only source transport 的初始最大主应变约167.44%，21轮联合静态停机后约138.96%；采样接触仍有约22mm穿入，源材料5%和完整穿着没有通过。这不是浏览器结果；图形运行另行记录。
- 120轮源投影/接触实验和全腿曲面投影都拒绝，不能以循环更长宣布成功。`ShortsWearV9.mjs` 保留有界实验，不在用户工作台启动此失败路线。
- 第一次浏览器启动发现 native rebuild 新增解剖刷新后，旧 exact-string hook 没调用 `installShortsWorkbench`。构建脚本现要求恰好一个接入点并硬报缺失/歧义；第一次180秒超时证据保留，不能当作视觉验证。
- 后续三次独立浏览器分别暴露：腰臀截面已分为双腿、原生接口开放环与碎片环、接口下方主腿环及两个独立小环。严格皮肤查询继续保留原始图分量和三角面见证；没有过滤小环后伪称完整皮肤。新版启动仍需最终浏览器复核。
- 去掉身体、接触和时间步的纸样独立形成诊断：粗网格160轮后15.20%，完全相同二维裁片的一次细分80轮后9.17%；均未过5%。失败只记局部求解未找到可验收状态，不证明纸样无解。
- 后续实际源环分析确认内部小孔环与外轮廓完全内含、无交叉。初始外边界选择现按实际腿轴和逐环几何谓词定位外环，完整保留内孔数据与身体碰撞；严格量体仍不假称整个截面只有一环。
- V9 第六个实际浏览器包终于创建了工作台与真实细分布面，四视角和近景全部保存。但独立真实结果为134.03%主应变、40对自交、1368对估计补皮穿插，后腰上沿8.11mm距离；明确失败。它是后续V9.1修改的基线，不能说V9.1沿用了相同观测结果。
- V9.1 第七次浏览器在Y=0.622487m的原生腿环处构造HOLD；独立线段参数计算验证主环与小环有两个严格proper交点。未创建短裤，也未运行物理步。不能把该源环按内部孔洞删除，不能声称这一版的形态已经改善。
- V9.2 单次CPU native初态已成功构造：9片/553点/848面/19接缝/451自由度，全部接缝目标差仅2.22e-16m；最大主应变123.318%，仍未通过。CPU源是977244面测试fixture，不是最终浏览器1.57百万面。记录文件 `shorts-v9-initial-1791020181289.json`，没有静态迭代或原生物理步；不能与第六次浏览器134.03%作同状态改进比较。

- V9.4真实浏览器：initial145.705%→final143.853%；vertex signed minimum改善到−17.0991mm，bare913+native1000=1913交叉pairs，非共享DOF自交0。腰560采样max4.0527mm/min2.2550mm；180高度点误差≤2.22e−16m。粗9轮/细1轮均被fresh contact或initial-principal无回退门禁停止，已非投影残差早停。实际四视图仍有六角桶形腰胯、裆前波折和露肤，完整穿着HOLD，材料比V9.3更差。所有sourceUV/tri/mass/seams与V9.3逐值相同，0time/steps，A和检查模式切换保全。

- 对当前保存的 upper-only Darboux **初态**，FL `[58,67]` 是实际源边，长度30.448mm，映射后端点相距80.981mm。因此这两个固定初始位置不可能同时满足5%拉伸。证据覆盖3/553点，不能冒充最终浏览器状态或完整目标检查。全局轴旧实验的250mm跳变证据另存，明确属于已弃用方案。

这里使用的严格必要条件是 `|X(a)-X(b)| <= 1.05 * length_UV(P)`，其中P为源纸样边与零长度接缝组成的合法路径。图最短边路径给出内在测地距离的上界；不假称精确连续测地线。端点可以在有限柔度求解中移动，所以初态违反条件不等于自由布料不存在解。收缩后的端点弦长变短也不构成不相容证明。

## 后续停止条件

必须先修正已发现的初始局部映射矛盾并解决裆片/主片穿插，再判断穿着求解。长度预算闭合和局部标架正确仅是必要条件；当前没有数学证明纸样本身不相容。下一数学改动必须针对有 witness 的源三角面和接触约束；禁止继续扫描视觉参数、把 source rest 改成失败的当前 XYZ、去掉碰撞或降低5%材料阈值。实际布面、腰口和完整静态接触通过以后，才进行共享原生时钟上的物理动作测试。
