# R20：骨架支撑与全身组织变化

2026-10-03。用户要求审查清瘦体型，修正“缩小胸廓但手臂、手脚不协调”的问题，并使肌肉形态跟随肌肉量变化。当前入口：http://127.0.0.1:8877/?version=R008-body-tissue-20 。仍是采集参数驱动的重建与自创形变层，Candidate；不是完整解剖或生理模拟。

## 独立观察与修正

- 原 R19 未按胖瘦缩短关节，但横截面收缩在视觉上压小胸廓；躯干横向场进入肩部，手掌和脚部又被排除，导致比例失衡。
- 原腿中心线用固定 ±84 mm；当前绑定骨架的膝中心约 +137/−130 mm，踝中心约 +172/−165 mm。新层直接查询当前骨段，无需复制另一人物的坐标。
- 仅缩放半径和软化材质不能充分表达肌肉量。新层分别控制胸肌、肩峰周围肌腹、上臂、前臂、股部和小腿的纵向饱满度，肌肉较少时同时减弱表面起伏。
- 手掌、指部、脚背和足部软组织也参与变化，幅度低于腹部、大腿。足底接触高度独立保护。

## 研究与自主实现

[Stanford Virtual Human 项目](https://graphics.stanford.edu/projects/humanoid/)区分刚性骨架、肌肉、脂肪和表皮层；本轮采用分层原则，没有移植其有限元求解器或资产。[Blender Armature 文档](https://docs.blender.org/UATEST/manual/en/dev/modeling/modifiers/deform/armature.html)描述骨骼影响范围和权重驱动形变；本轮自行实现绑定段投影和八权重组织分区。以下尺度是对本人物的美术包络，不是人体骨骼扫描或医学测量。

## 函数所有者和变化范围

- `BodyTissue.mjs`：从原有 61 骨绑定矩阵生成骨段，按八个蒙皮权重形成躯干、肩臂、腿部、掌指/足部组织权重。手指采用自己的骨段；扭转骨使用对应主骨段。骨段投影在端点处限制范围，头部不进入四肢组织场。
- `BodyParameters.mjs`：CPU/GLSL 共用一个标量形变函数。躯干只改变美术支撑包络外的厚度；四肢按绑定段外距离变化，不改变绑定骨架、关节或身高参数。负向组织增益有独立上限，权重过渡混合位移。纵向样本保持原高度，避免清瘦肩部向锁骨挤压；脚部软垫可改变高度，但足底保持接触。
- `BodyBinding.mjs`：临时 GPU 组织字段、实时 uniform、八权重 CPU 表面查询、法线余子式及材质肌肉起伏。CPU 查询与 GPU 读取同一生成字段。
- `BodyWorkbench.mjs`：保留实时滑块、最新输入合并、紧凑配方存储，解释骨架与组织的区别。

| 区域 | 组织控制特点 | 支撑核尺度（米，美术值） |
| --- | --- | --- |
| 胸廓、骨盆、腰腹 | 胸肌和体脂独立；腰腹体脂更明显 | 横向 0.035–0.110；前后 0.025–0.069 |
| 上臂、肩部 | 肌腹响应大于关节/肌腱附近 | 0.014 起，肌腹增加约 0.007，肩部增加约 0.012 |
| 前臂 | 纵向肌腹响应较小，腕部保留支撑 | 约 0.014 |
| 大腿、小腿 | 股部和小腿肌腹分开，真实髋膝踝绑定 | 0.019 起，股部增加约 0.009 |
| 手掌、手指 | 掌部软垫与指部组织变化，保持骨段关系 | 0.0045 起，掌部增加约 0.008 |
| 脚背、足部 | 厚度变化较小，足底高度保护 | 0.0045 起，足部增加约 0.012 |
| 下脸、颈部 | 皮下饱满度与肌肉量小幅变化，眼眶独立保护 | 下颌/颈侧约 0.028/0.027 |

表中核是形变限幅依据，并非真实骨表面。手脚不是等比缩小；身高仍可整体缩放，这是有意的身高控制。

## 数据边界与弃用方案

只提交函数、关系、配方和诊断元数据，没有新增网格、贴图、外部模型或烘焙顶点。组织分区与锚点按现有权重重新生成，当前精度的临时字段占 22,611,596 字节，持久化字段数据为 **0**；实时调整不重算全部顶点或重建字段。

弃用整段横截面收缩、估算腿中心线、手脚完全固定，以及将不同区域系数直接加入非线性函数造成的叠加挤压。第一次新层检查发现极端清瘦肩部法线场反转，已在当前源码中以位移混合、负向限幅和纵向保护修正；一次眼眶微量污染以独立头部保护修正，不能把失败检查当成最终结果。

局部雅可比保持组织属性固定，与完整曲面含权重梯度的映射不同，不能宣称全局无自交、医学合理或最终美术验收。内部三角面诊断中的法线翻转也不能直接当成拓扑反转结论；本轮最终证据为上述字段检查、实际渲染及动作/接缝检查。原扫描细节、衣物折皱和骨盆被衣物遮挡区域仍来自参考重建；没有声称恢复未知的人体解剖。另一工作台的短裤与补体实现未修改。
