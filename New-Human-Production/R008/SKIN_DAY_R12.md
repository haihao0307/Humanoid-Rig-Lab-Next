# R12 肤色通道与海岛日晒

2026-10-02。当前生产为 `source/assembly.json` 选择的 R008。
入口：[肤色测试](http://127.0.0.1:8877/?version=R008-skin-12)。

## 实现与使用

左侧“肤色与海岛日晒”可调整基础肤色、冷暖、红润、细微变化、日晒程度及独立的粗糙度、油光、户外粗糙感。
首次进入使用“初到岛上 · 较浅”。可选择原始肤色、户外一周、长期日晒 30 天，或手动推进一天、重新到岛。
基础肤色控制采用线性颜色比例，保留已有表皮中的结构与细节；原始肤色和其默认参数可以恢复原有色素结果。

日晒使用有界指数积分，默认 48 有效日晒小时达到一半日晒程度。这是游戏美术参数，不是皮肤生理或 UV 剂量模型。
一天默认包含 6 有效户外小时，其余时段不新增日晒。一周及 30 天预设分别记录 7/30 天和 42/180 有效日晒小时。
自动预览默认关闭；打开后默认 60 实时秒对应一个游戏日。暂停游戏、原有动作检查、面部权重检查和后台标签页都停止自动累积。
手动改变日晒滑条覆盖当前外观程度，保留已记录的时间；选择阶段预设会切换到该阶段的配方及时间记录。

自动保存及导入/导出包含少量配方和进度。重建采样密度保持肤色设置。非法导入在验证完整配方后才提交，失败保留原状态。

## 游戏逻辑接口

```js
// 接入真正的岛屿时钟时，关闭用于工作台体验的自动预览。
HumanSkin.setAutomatic(false);
HumanSkin.preset('arrival'); // 新游戏时调用一次，读取存档后不要重复调用。

// 每次传入“这一步经过的游戏小时”，而非从开局以来的总时间。
// uv=0 表示夜晚，shade=1 表示完全遮阴，coveredFraction=1 表示完全遮盖。
HumanSkin.advance(gameSeconds / 3600, {
  uv: daylightIntensity,       // 0..4，相对游戏强度
  shade: shadeFraction,       // 0..1
  coveredFraction: coverage   // 0..1
});

HumanSkin.set({baseColor:'#e3c7af', sunExposure:.35});
const save = HumanSkin.export();
HumanSkin.restore(save);
```

`SkinAppearance.mjs` 拥有配方验证、线性色转换、独立通道和时间积分。
`SkinMaterial.mjs` 拥有 Three.js 材质接线、人物静止坐标上的连续颜色场和局部曝光权重。
`SkinWorkbench.mjs` 拥有 UI、存档和预览时钟；`app.mjs` 的实际游戏运行状态控制自动预览。

## 来源、审查与边界

改造本项目 `body/SkinAppearance.js` 的基础色、底调、红润与日晒控制，以及 `body/TissueShaders.js` 的色素和表面反射分离方法。
同时审查 `Human-Integration-Verified/body/SkinSurface.js` 和旧项目 `docs/face-knowledge` 中的失败记录。
旧身体坐标、衣领和袖口晒痕不适合当前赤膊人物；本轮按当前人物米制坐标重新写局部权重。
保留手掌、足底和腋下较弱的日晒响应；眼皮接入同一通道，眼球/眼白独立排除。

参考 [NVIDIA GPU Gems 3：皮肤渲染](https://developer.nvidia.com/gpugems/gpugems3/part-iii-rendering/chapter-14-advanced-techniques-realistic-real-time-skin) 的线性光照计算和色素/表面反射分离原则。
未移植旧项目的散射渲染层、毛孔几何或头部结构，也没有新增模型、来源图片或持久化顶点字段。
既有来源表皮仍由参数包重建；新增肤色变化由函数和标量参数实时计算，不能据此声称整个人物从零规则生成。

实际材质隔离视图发现：`tripo_part_1`、`tripo_part_2` 是裤身，`tripo_part_9` 是裤腰与抽绳。三者都排除肤色变化。
头部同一材质中混有皮肤、头发和眉毛，使用原始颜色与静止位置遮罩区分；混合边界仍属近景美术验收范围。
本轮只有统一日晒历史加局部权重。真实岛屿的天气、昼夜及遮挡需由游戏向上述接口提供；没有自动推断当前场景的 UV 或物理遮阴。
不模拟晒伤、晒后脱皮或长期休息退色。原有近景表面接缝和眼部简化问题沿用 R11 的限制记录。

## 验证

`node tools/skin-review.cjs` 在后台真实 Chrome 中检查阶段效果、实际像素、游戏时钟/暂停、导入导出、刷新恢复、采样重建及闭眼。
QA 临时截图和完整报告位于忽略目录 `qa/skin-r12/`；可提交的摘要与源码哈希在 `SKIN_REVIEW_REPORT.json`。
文件装配、角色控制和跳跃回归沿用项目检查命令。参数包字节数和 SHA256 保持 R11 的值。
所有数值与像素检查只覆盖所列场景，不能作为任意肤色和任意表情的美术质量保证。
