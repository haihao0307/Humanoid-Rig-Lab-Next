# CAT KAOPU V4.40 执行报告

## 本轮目标

在不改变 V4.32 中性整猫表面、不覆盖 V4.34 基础蒙皮、不破坏 V4.36 运动链和 V4.39 坐卧修形的前提下，开始建立第一层视觉表现：左右耳独立控制、眼球视线与程序化短毛方向场。

## 实际实现

### 独立左右耳

- 骨骼由 32 根扩展到 **34 根**，新增 `ear_L` 与 `ear_R`，均挂接在头骨下。
- 左耳重新分配 **128** 个顶点，右耳重新分配 **149** 个顶点；非耳区域权重保持原结果。
- 每顶点仍最多四骨影响，权重字节和严格等于 255，最大骨骼索引为 33。
- “耳眼追踪测试”“警觉观察”“左右观察”“嗅探”“行走”“转向”等动作会产生受限耳朵方向变化；也可以切换到手动模式分别控制左右耳。

### 程序化眼球

- 保留现有两个眼球表面，不读取外部贴图。
- 在片元着色器中生成琥珀色虹膜、竖向瞳孔与高光。
- 视线由 `gazeYaw / gazePitch` 实时驱动，可由动作自动控制，也可手动调节。
- 眼球、耳朵和头颈属于分离控制层，耳眼表现不会修改骨长或中性身体。

### 第一层程序化短毛方向场

- 以绑定空间位置和法线为输入，在头颈、躯干、四肢和尾巴上生成分区方向轴，再投影到表面切平面。
- 使用方向性高光、低幅微粗糙度与可视化调试色表达毛流。
- 不创建外部毛发模型，不读取纹理，不改变轮廓，也不用于遮挡关节折叠问题。

### 工作台与检查接口

新增：

- “眼球层”“耳骨层”“短毛方向”“毛流检查”开关；
- 自动/手动耳眼控制；
- 视线左右、视线上下、左右耳角度、短毛强度滑块；
- `__CAT_V440_*` 浏览器 QA 接口；
- V4.38、V4.39、V4.40 固定同机位回归截图。

## 自检中完成的二次调整

首次截图中，警觉动作使用约 −8° 的耳廓俯仰，近侧耳根出现轻微压扁感。根据实际截图将警觉耳廓俯仰收敛到 **−4.5°**，重新生成头部截图、浏览器 QA 和移动端截图。该调整没有修改耳骨绑定位置、基础权重或其他动作。

## 状态边界

V4.40 不是最终面部或皮毛版本：

- 没有眼睑与眨眼；
- 没有角膜厚度、泪膜与真实折射；
- 没有胡须；
- 没有几何轮廓毛；
- 没有花纹或毛色系统；
- 耳根在更大角度旋转下仍需要姿势修正；
- 坐姿后足、趴卧前后足和胸腹承重仍是工程近似。

当前状态：`visualAcceptance=false`，`productionReady=false`。
