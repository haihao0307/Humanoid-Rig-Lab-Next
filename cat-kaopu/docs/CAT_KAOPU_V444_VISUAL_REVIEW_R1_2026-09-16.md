# CAT KAOPU V4.44 双眼连续眶周载体视觉复核 R1

日期：2026-09-16  
证据批次：`cat-kaopu-v444-periorbital-qa-2`  
对应工作流：`Cat Kaopu V4.44 Continuous Periorbital`，run 2  
结论：`visualAcceptance=false`，`productionReady=false`

## 技术检查结果

1. WebGL2 页面、正面/三分之四/侧面近景和移动端截图正常生成。
2. 页面错误与控制台错误为空。
3. V4.40 `CATV440` 二进制载荷、34 骨 `RIG`、蒙皮权重、V4.39 姿势修形和 V4.36 运动链保持不变。
4. 默认眼部表现已经从 V4.42 的四片独立眼睑条带改为左右眼各一张连续环形眶周载体。
5. 连续载体共两片、1170 个顶点、2048 个三角形，由 `head` 骨驱动。
6. 眶周融合、闭眼褶皱、眼缘厚度和检查色控制均可运行。

## 与 V4.43 相比的有效改善

1. 上、下眼睑不再是内外眼角处断开的四片条带，内外眼角由同一环形拓扑连接。
2. 开眼、半闭和闭眼过程中没有重新出现黑色眼球月牙。
3. 完全闭眼时不再能清楚辨认出两块彼此独立的矩形条带端头。
4. 三分之四和侧面下，眼睑运动与眼眶连接的连续性高于 V4.42/V4.43。

## 仍未通过的视觉问题

1. 外环直接采样 V4.32 粗粒度头脸三角面，因而继承了明显的多边形折线和方形眼眶轮廓。
2. 开眼时，连续载体虽然拓扑正确，但仍可被看成覆盖在低分辨率眼眶上的独立环形补片。
3. 完全闭眼的闭合线仍偏直，眼睑上方的体积变化不足，尚未形成自然的猫眼睑弧面。
4. 眶周融合强度提高时，载体会放大粗头脸表面的角点，而不是生成更平滑的软组织过渡。
5. 当前问题已不再是“多片拓扑断裂”，而是“冻结载体采样分辨率不足和边界曲率不连续”。

## 逻辑纠正

把四片眼睑改成两片连续环网能够解决拓扑断裂，但不能自动提高冻结头脸的局部表面分辨率。继续扩大融合强度或增加更多环带，只会更忠实地复刻原有多边形眼眶，不能产生真实软组织曲率。

## 下一生产门

下一轮应建立 V4.45 局部平滑眼眶载体，而不是继续叠加覆盖层：

1. 保留 V4.44 双眼连续环形拓扑和动态睑裂。
2. 外边界不再直接逐点复制单个粗三角面，而是对局部头脸采样执行受限曲线拟合或移动最小二乘平滑。
3. 外圈最终位置仍必须回到冻结 V4.32 头脸，不得改变头部外轮廓。
4. 内圈继续由眼球和睑裂曲线控制，中间环带建立连续一阶法线和受限二阶曲率。
5. 闭眼曲线需要增加猫眼特有的上睑主导弧度，避免水平直线。
6. 必须增加更近的正面、三分之四和侧面眼部裁切证据。
7. 第三眼睑、胡须和轮廓短毛继续禁止进入。

因此 V4.44 证明了连续拓扑路线有效，但仍作为技术候选保留，不升级为视觉验收基线。
