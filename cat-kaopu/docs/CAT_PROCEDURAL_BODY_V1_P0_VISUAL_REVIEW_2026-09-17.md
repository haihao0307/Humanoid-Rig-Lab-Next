# CAT PROCEDURAL BODY V1 P0 视觉复核

日期：2026-09-17  
阶段：P0 参数内核与连续作者态  
状态：`visualAcceptance=false`，`stableTopology=false`，`bindAcceptance=false`，`motionAcceptance=false`，`productionReady=false`

## 本轮已证明

1. 整猫形态、骨架锚点、碰撞代理、灰虎斑毛色和受限个体差异均可以从同一份 CatDNA 确定性生成。
2. 最终运行时不读取外部猫模型，也不读取外部图像贴图。
3. CatDNA 具有版本、单位、坐标系、确定性哈希、参数范围和跨部位约束。
4. 四足接地、胸腰骨盆比例、骨架锚点和碰撞代理可以随参数同步更新。
5. 相同种子产生相同个体，不同种子产生受约束差异，为后续猫群和品种系统保留了正确入口。

## 当前不能通过的视觉问题

1. P0 仍是连续隐式作者态，不是最终稳定拓扑。局部表面存在采样和隐式混合产生的波动。
2. 头部仍偏长，口鼻与颅部关系尚未达到自然家猫比例；眼球与眼眶仍是功能占位。
3. 颈部、肩胛胸廓与前肢之间的连续体积还不够自然。
4. 前肢腕掌、后肢膝—飞节—跖部虽然已经参数化，但外表面仍偏管状。
5. 足掌只有基础体积，尚未形成趾端、掌垫和负重展开。
6. 尾根进入骨盆的连续性仍需根据权威测量校准。
7. 程序化虎斑已进入同一 CatDNA，但花纹方向、区域分布和远近稳定尚未视觉验收。
8. P0 初始短毛几何起伏过大，干扰了对身体轮廓的判断；已将默认起伏压到亚毫米级，并把参数上限限制在身体形态不会被掩盖的范围内。

## 因果判断

当前最重要的阻塞不是“缺少更多滑块”，而是默认 CatDNA 尚未由权威测量完成校准。继续凭主观截图随意调整参数，会重新回到此前反复出现的形态漂移。

外部参考的正确用途是：提取单位明确的骨链长度、关节锚点、身体截面和轮廓约束，再把这些测量写回我们自己的 CatDNA；外部网格不得成为运行时资产，也不得替代第一方程序化身体。

## 下一生产门 P1

1. 锁定至少一组许可和尺度明确的家猫解剖参考。
2. 统一参考坐标轴、单位和中性站立姿态。
3. 提取脊柱、胸廓、肩胛、骨盆、前后肢骨链、头颅、口鼻和尾根锚点。
4. 提取沿身体纵轴的连续宽度、深度和中心高度截面。
5. 将测量数据写入 CatDNA 校准记录，不把外部网格装入运行时。
6. 用固定六视图检查 Grey Tabby A 的头颈、躯干、四肢、足掌和尾根。
7. 只有六视图通过后，才进入稳定拓扑 Surface Carrier。

P0 是生产内核，不是已完成猫体；技术 QA 不能替代用户视觉验收。
