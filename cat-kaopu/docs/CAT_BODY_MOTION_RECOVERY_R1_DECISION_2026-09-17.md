# CAT BODY & MOTION RECOVERY R1 决策记录

日期：2026-09-17

下一母体：`cat_body_bind_v1`

## 结论

V4.39、V4.40、Phase 1 Gate A 和 Gate B 均不应继续作为生产身体母体叠加修补。Recovery R1 选择建立新的、明确版本化的整猫身体与绑定版本 `cat_body_bind_v1`。

这不是因为历史版本完全没有可复用内容，而是因为可复用内容分散在不同层：V4.15 提供较合理的解剖生成架构证据；V4.34/V4.39 留下蒙皮、接触和姿势修形经验；V4.40 留下动作和运行时接口；Gate A 留下简化碰撞代理。它们不能继续以旧 V4.32 表面为中心叠加成为生产猫体，必须重新统一生成、绑定和验证。

## 固定证据结论

Recovery R1 对以下候选使用同一固定视角与动作相位进行对比：

- V4.39 历史姿势修形基线；
- V4.40 冻结眼耳短毛基线；
- Phase 1 Gate A 单体 NPC；
- Phase 1 Gate B 躯干修正。

固定视图和动作证据显示：

1. V4.39、V4.40 和 Gate A 的整猫轮廓近似同一身体，未形成新的整猫形态。
2. V4.40 与 Gate A 的顶部固定视图在阈值比较中没有可辨识像素变化，其他固定视图变化也低于约 `0.03%`。
3. Gate A 与 Gate B 的固定视图变化约为 `0.11%–0.21%`，主要来自局部躯干场，头、颈、四肢、足掌和尾根没有完成统一重建。
4. V4.40 与 Gate A 的行走相位近似一致；Gate B 只改变局部表面，没有建立新的步态结构。
5. 测试动作中观察到边长最大拉伸约 `2.082×`、最小压缩约 `0.483×`，对应用户已经指出的关节附近破损、塌陷与不自然风险。
6. 现有身体仍为接近纯白的方向性短毛明暗层，没有形成环境 NPC 必需的毛色、斑纹、粗糙度及耳内、鼻头、眼周、掌垫区域材质。
7. 自动 QA 可以证明页面运行、数值有限、碰撞和接触没有直接崩溃，但不能证明整猫形态、蒙皮完整性和动作自然度通过。

## V4.15 的定位

V4.15 的历史记录显示它使用了更强的整猫结构生成逻辑：36 个解剖锚点、22 条主要骨段关系、51 条肌肉路径、纵向胸腹骨盆截面、内部肩胛锚点、连续耳根和单一闭合身体表皮；生成体量为 87,518 顶点、175,032 三角形，几何记录为单连通、无边界边、无非流形边。

但 V4.15 不能直接恢复为生产身体：

- 当时明确标记 `visualAcceptance=false`、`behaviorAcceptance=false`、`productionReady=false`；
- 面部平面、眼眶、胸腹层次、掌趾、皮下滑动和整体猫科气质仍有明显不足；
- 浏览器运行验收未完成；
- 当前 GitHub 分支没有保存可直接继续开发的完整 V4.15 源载荷。

因此只复用 V4.15 的结构原则，不把其结果伪装成已通过身体。

## `cat_body_bind_v1` 必须完成的内容

### 1. 连续整猫身体

一次性覆盖：

- 颅面、口鼻、额头与耳根；
- 短颈、肩胛胸廓肌肉吊带；
- 胸腔、腹壁、腰段和骨盆；
- 前肢肩—肘—腕掌—趾端；
- 后肢髋—膝—飞节—跖部—趾端；
- 尾根、荐骨和连续变细尾段；
- 一张连续、闭合、无破口的最终身体表面。

### 2. 新的版本化绑定

允许在证据证明必要时调整绑定局部位置、肩胛关系、关节中心、逆绑定矩阵和蒙皮权重，但必须建立新版本，不得在姿势或动画中用骨骼缩放修比例。

### 3. 蒙皮与姿势修形

肩、髋、肘、膝、飞节、颈根和尾根必须完成中性、常用屈曲、支撑相和摆动相应力测试；破口、翻面、体积塌陷和持续自相交均为硬失败。

### 4. 基础程序化材质

第一阶段不要求昂贵完整毛发，但必须加入：

- 基础毛色与灰色虎斑斑纹；
- 近、中、远距离一致的粗糙度和短毛方向；
- 耳内、鼻头、眼周和掌垫区域材质；
- 远景低闪烁与群体可承受的运行成本。

### 5. 核心动作

身体和绑定通过后，只生产：

- 中性站立；
- 轻微待机；
- 起步；
- 稳定行走；
- 减速停止；
- 左右转向。

每组动作按支撑开始、单脚支撑、摆动中段、落脚前、落脚和重心转移逐帧复核。生活活动、眼部细化、胡须、完整毛发、导航、猫群和品种扩展继续后置。

## 不再允许的捷径

- 继续在 V4.32 身体上叠加未经统一验证的几毫米 corrective；
- 用自动断言替代视觉验收；
- 用镜头、毛发或材质掩盖轮廓与蒙皮错误；
- 在姿势或动画中缩放骨骼；
- 单体未通过就复制猫群；
- 把历史结构记录称为已通过生产资产。
