# CAT KAOPU V4.45 MLS 眶周近景视觉复核 R1

日期：2026-09-16  
证据批次：`cat-kaopu-v445-mls-qa-2`  
对应工作流：`Cat Kaopu V4.45 MLS Periorbital`，run 2  
结论：`visualAcceptance=false`，`productionReady=false`

## 本轮不是单参数微调

V4.45 将 V4.44 的眶周生成链一次性替换为：

1. 每眼 96 段、14 个径向环的高分辨率连续拓扑。
2. 局部加权二次移动最小二乘曲面。
3. 周向周期低通，降低原粗三角眼眶的折线传播。
4. 外缘五次平滑回接冻结 V4.32 表面。
5. 上眼睑主导、下眼睑延迟的拱形闭合曲线。
6. 受限软组织体积与上眼睑几何褶皱。
7. 不透明 polygon-offset 皮肤绘制，避免透明补片暴露眼球或粗眼眶。

## 已确认有效

- WebGL2、正面、三分之四、侧面和移动端均正常运行。
- 页面错误与控制台错误为空。
- 开眼、半闭和完全闭眼之间存在稳定、可复验的几何差异。
- MLS 强度 0 与 1、闭合弧度 0 与 1 均产生独立变化。
- 未重新出现黑色眼球月牙或眼球穿出完全闭合眼睑的问题。
- 眶周连续拓扑、内外眼角和侧面头部轮廓保持稳定。
- `CATV440`、34 骨、RIG、蒙皮权重、V4.39 姿势修形与 V4.36 运动链均未改变。

## 仍未通过的视觉问题

1. 开眼睑裂仍偏横向和规则，真实猫眼的内外眼角高差、上睑弧和下睑支撑关系还不充分。
2. 完全闭眼虽然已经变成拱形目标，但近景中仍可看到两道偏平行的水平褶皱，尚未形成自然的一条主闭合缝。
3. 眶周补片本身比 V4.44 平滑，但它仍覆盖在低分辨率 V4.32 头脸上；眼眶外侧和鼻根附近仍可识别出载体边界。
4. 仅继续增加 MLS 强度、环带数量或闭合位移不会解决上述问题：这些参数只能平滑现有载体，不能补足冻结头脸在眉弓、鼻根和面颊之间缺失的连续曲率。

## 因果判断

V4.45 已经解决“逐点复制粗三角面”和“水平直线作为闭眼目标”两个底层问题，但剩余阻塞已经转移为局部头脸载体不足，而不是算法采样数量不足。

继续在当前环形补片上叠加小修属于低效路线。下一阶段应一次性重建一个更宽的局部眼区面部载体，覆盖眉弓、鼻根、外眼角和上面颊，再将睑裂、眼角、眼缘厚度、湿润缘和闭合褶皱统一参数化。该载体仍作为 Performance Deform 层存在，不写回 V4.32/CATV440，也不改变整猫轮廓。

因此 V4.45 保留为有效技术里程碑，但不升级为视觉验收基线。
