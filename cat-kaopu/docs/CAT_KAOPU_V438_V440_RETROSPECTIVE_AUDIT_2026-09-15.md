# CAT KAOPU V4.38—V4.40 前两版回顾审查

## 审查方法

在同一 Chromium WebGL2 环境、同一四分之三视角和相同动作时刻，重新截取：

- V4.38 坐姿保持、趴卧保持；
- V4.39 坐姿保持、趴卧保持；
- V4.40 坐姿保持、趴卧保持。

同时读取每版的边长倍率和地面穿透统计，并将 V4.39 与 V4.40 的输出顶点逐项比较。

## V4.38 结论

V4.38 已经清除了 V4.37 的明显穿地与极端塌陷，坐姿和趴卧都能读成完整动作。但趴卧仍存在少量极端变形：

- 坐姿：最小倍率 **0.6001**，P95 **1.0977**，最大 **1.4329**；
- 趴卧：最小倍率 **0.5011**，P95 **1.1981**，P99 **1.4340**，最大 **2.0777**；
- 低于地面 2 mm 的顶点：坐姿 0，趴卧 0。

V4.38 应继续保留为“穿地修复与第一轮姿势残差”回滚点，但不应作为最终坐卧表面。

## V4.39 结论

V4.39 对腋下、腹股沟、胸腹和尾根做了区域修形，并增加姿势目标法线。与 V4.38 相比：

- 坐姿最小倍率：0.6001 → **0.6255**；
- 坐姿最大倍率：1.4329 → **1.3439**；
- 趴卧最小倍率：0.5011 → **0.6515**；
- 趴卧 P99：1.4340 → **1.2675**；
- 趴卧最大倍率：2.0777 → **1.4641**。

V4.39 是明确的实质进步，尤其是趴卧极端值下降；但坐姿 P95 不是所有指标都单向改善，因此不能只挑最大值宣布完全通过。截图中后足与跗部仍然概括，趴卧胸腹与爪部接触仍是工程近似。

## V4.40 对前两版的回归结论

V4.40 的坐姿、趴卧变形统计与 V4.39 保持一致。逐顶点比较显示：

- 中性站立：全表面最大差 **0 m**；
- 坐姿：非耳区域最大差 **0 m**，耳区最大差约 **0.900 mm**；
- 趴卧：非耳区域最大差 **0 m**，耳区最大差约 **0.740 mm**；
- 行走：非耳区域最大差 **0 m**；
- 左转：非耳区域最大差 **0 m**。

耳区微小差异来自新增的耳骨权重，而不是 V4.39 坐卧修形被覆盖。V4.40 没有把眼睛、耳朵或短毛层用于掩盖 V4.38/V4.39 的几何问题。

## 当前保留与淘汰关系

- V4.38：保留为第一轮坐卧修正回滚点；
- V4.39：保留为当前坐卧几何与法线基线；
- V4.40：在 V4.39 上增加视觉表现层，暂不晋升为生产完成版。
