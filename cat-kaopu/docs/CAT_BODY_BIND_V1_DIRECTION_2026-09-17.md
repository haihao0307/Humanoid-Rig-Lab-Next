# CAT BODY BIND V1 生产方向

日期：2026-09-17  
分支：`codex/cat-body-bind-v1-20260917`

## 产品目标

这一分支不再修补 V4.32 冻结身体，也不继续叠加 Gate B/C/D corrective。目标是建立一个新的、明确版本化的整猫身体和绑定母体 `cat_body_bind_v1`，供第一阶段环境生物 NPC 使用。

第一阶段的优先级保持不变：

1. 整猫形态正确；
2. 绑定、蒙皮和常用关节变形不破裂；
3. 中性站立与核心运动自然；
4. 单体基础碰撞稳定；
5. 单体通过后再进入猫群、受限 DNA 和品种扩展。

## 为什么必须建立新母体

Recovery R1 固定证据显示，V4.39、V4.40 和 Gate A 仍使用同一 V4.32 中性表面；Gate B 只改动局部躯干。旧身体、旧动作和多层 corrective 继续叠加无法解决整体猫科轮廓、关节体积、足掌结构、材质和自然运动。

因此新版本允许重新生成身体表面、绑定局部位置、逆绑定矩阵、蒙皮权重和姿势修形，但所有变化必须版本化、可回滚；姿势和动画仍然禁止修改骨长或父子关系。

## 身体生成路线

### 作者态

采用连续隐式解剖场建立整猫基础：

- 纵向头、颈、胸腔、腹壁、腰段、骨盆截面；
- 内部肩胛与胸廓肌肉吊带关系；
- 前肢肩—肘—腕掌—趾端；
- 后肢髋—膝—飞节—跖部—趾端；
- 荐骨、尾根和连续尾段；
- 颅面、口鼻、下颌和连续耳根；
- 单一闭合身体表面。

V4.15 的解剖锚点、纵向截面、内部肩胛和筋膜过滤原则作为架构证据；其旧结果不作为视觉真值直接复制。

### 生产表面

作者态通过四视图后才冻结稳定拓扑，并建立：

- LOD0：近中景单体检查；
- LOD1：一般场景和小规模群体；
- LOD2：远景群体；
- 统一区域标签、关节邻域和材质坐标；
- 可重复生成的程序化二进制。

禁止在没有稳定拓扑前开始正式蒙皮和动作生产。

## 形态审核顺序

一次审核整猫，但修改仍按因果区域控制：

1. 头、口鼻、额头、耳根与短颈；
2. 颈根、肩胛、胸前与胸廓；
3. 胸腔、腹壁、腰段与骨盆；
4. 前肢与前掌；
5. 后肢、飞节与后掌；
6. 荐骨、尾根与尾段；
7. 正面、左右侧、顶部、前后四分之三整体节奏。

出现直筒躯干、柱状四肢、关节反向、足掌不着地、尾根脱节或头颈插接感，均不得进入绑定阶段。

## 绑定与蒙皮

新绑定优先保留已经有价值的稳定关节 ID，但不把旧绑定位置视为不可更改。必须检查：

- 颈根；
- 肩胛—肩—胸廓；
- 肘和腕；
- 髋和膝；
- 飞节与跖部；
- 尾根。

蒙皮完成后，以中性、常用屈曲、支撑相和摆动相执行应力测试。每个测试都要求：

- 无孔洞、翻面和长条伪影；
- 无明显体积塌陷；
- 无持续肢体穿插；
- 足掌保持完整；
- 表皮、骨架、碰撞和动作读取同一份 final pose。

## 基础材质同步进入身体阶段

环境 NPC 不需要立即制作昂贵的完整毛发，但身体阶段必须加入：

- 灰色虎斑基础毛色；
- 背部、腹部、四肢和尾部的区域色与斑纹；
- 粗糙度和短毛方向；
- 耳内、鼻头、眼周和掌垫材质；
- 中景可读、远景不闪烁的低成本表现。

不能再用纯白塑料体进行最终形态判断，因为材质会影响体积和边界判断。

## 动作生产边界

身体和绑定通过后，只重做：

- 中性站立；
- 轻微待机；
- 起步；
- 稳定行走；
- 减速停止；
- 左右转向。

每个动作按支撑开始、单脚支撑、摆动中段、落脚前、落脚和重心转移逐帧检查。动作运行顺序固定为：

`动作目标 → IK / 接触 → 关节限制 → 物理与碰撞 → final pose → Skin`

生活动作、近景眼部、胡须、完整毛发、导航和群体继续后置。

## 第一阶段最终门

只有同时满足以下条件才开放猫群：

- 整猫四视图经用户明确接受；
- 核心关节应力测试无破损；
- 核心动作自然且连续；
- 支撑脚无可见滑动；
- 基础程序化材质完成；
- 单体碰撞稳定；
- `visualAcceptance=true`、`bindAcceptance=true`、`motionAcceptance=true`。
