# CAT KAOPU V4.40 自检记录

## 已确认的有效进步

1. 眼球视线能够在左右阶段发生清楚变化，竖瞳保持在眼球表面，没有出现独立漂浮物。
2. 左右耳能够独立转向。`focus` 0→0.8 秒时，左耳顶点最大位移约 **4.608 mm**，右耳约 **2.408 mm**；非耳区域最大位移为 **0 mm**。
3. 中性站立与 V4.39 逐顶点完全一致。
4. 坐姿、趴卧、行走与转向中，非耳区域相对 V4.39 的最大位置差均为 **0 m**。
5. 短毛方向层开启/关闭只产生低幅表面明暗差；调试色显示头颈、躯干、四肢和尾巴方向场连续，轮廓没有变化。
6. 桌面与 390×844 移动端均完成真实 WebGL2 检查，页面和控制台错误为 0。

## 截图后主动修正的问题

警觉动作最初的耳朵俯仰幅度过大，近侧耳根视觉上略扁。已经把该动作的耳廓俯仰从约 −8° 收敛到 −4.5°，并重新截图与复验。其他动作和基础权重未变化。

## 仍未通过的内容

1. 眼睛目前只有程序化虹膜、竖瞳和高光；缺少眼睑、眨眼、角膜体积、湿润层和瞳孔对亮度的响应。
2. 耳朵是第一轮局部骨控。当前幅度可用，但大幅向后压耳、耳根折叠和耳廓软骨形变尚未建立。
3. 短毛层只是方向性着色与微粗糙度，不是几何毛发；近距离不会出现真实毛尖轮廓。
4. 暂无花纹、毛色、胡须、鼻头与口唇精细材质。
5. V4.39 遗留的坐姿跗部折叠、趴卧爪部和胸腹承重仍存在，不能用毛发掩盖。

## 逻辑边界

- “眼睛会转”不等于眼部系统完成；眼睑、角膜与视觉反射是独立问题。
- “短毛方向场存在”不等于已经生成真实毛发；当前没有增加轮廓或体积。
- “耳朵能独立动”不等于所有耳姿都可信；当前只开放低幅控制。
- 本轮没有通过改动 V4.32 中性轮廓来改善视觉，也没有让新表层反向修改骨架或动作。

## 下一门

下一阶段建议先完成眼睑/眨眼、受限耳根姿势修正与鼻口第一层材质，再建立短毛轮廓层和程序化毛色。必须继续保留“无表层遮错”检查：关闭眼睛/耳朵/短毛层后，坐卧和运动形体仍须单独成立。
