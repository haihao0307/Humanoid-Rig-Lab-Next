# CAT BODY BIND V1 R1 视觉复核

日期：2026-09-17  
证据批次：`cat-body-bind-v1-r1-5`  
结论：`visualAcceptance=false`，R1 不进入绑定阶段

## R1 已证明的内容

R1 已经从旧 V4.32 / CATV440 身体和 Gate corrective stack 中独立出来，能够在浏览器中从单一连续程序化场生成整猫作者态，并同步生成基础灰虎斑颜色。固定正面、左右侧、顶部、前后四分之三视图和参数重建均可运行。

这些结果只证明新身体生成链路可用，不代表形态正确。

## R1 明确未通过的形态问题

1. 头部整体过大、过圆，脑颅、面颅、口鼻和下颌关系仍接近卡通体块。
2. 眼球和鼻镜作为独立尺度结构过大且前突，干扰整猫轮廓判断。
3. 耳朵过高、过尖，耳根与颅顶连接仍不足。
4. 颈部和胸前体积过重，头颈—肩胛—胸廓过渡呈现块状堆叠。
5. 胸腹骨盆虽然来自连续场，但纵向截面仍有明显团块节奏，腰腹和背线缺乏自然连续曲率。
6. 后肢整体呈持续低伏和蹲姿，不符合第一阶段中性站立母体。
7. 前后足掌仍是简单椭球，趾行段落、腕掌和飞节—跖部关系不足。
8. 尾根进入骨盆的方式和尾段渐细仍不自然。
9. 隐式场分辨率与局部平滑不足，表面存在环状与波纹状起伏；程序化斑纹进一步放大了这些起伏。
10. 当前页面参数面板遮挡固定视图，不利于形态审批。

## R2 必须完成的修正

R2 不增加动作、绑定、导航或猫群，只重做作者态形态：

- 使用纵向截面表驱动胸腔、腹壁、腰段和骨盆，不再依赖多个大椭球堆叠；
- 降低并缩小头部，分开脑颅、面颅、口鼻和下颌；
- 缩小眼球和鼻镜，并在默认形态审核中隐藏这些尺度结构；
- 缩短耳高、扩大耳根并降低尖刺感；
- 提高中性站立高度，重新布置髋—膝—飞节—跖部关系；
- 减轻前肢柱状感，保持肩胛和胸廓之间的肌肉吊带关系；
- 重做尾根与荐骨连接；
- 对标量场执行受限平滑，减少 marching-cubes 波纹，但不得把关节和体积全部抹平；
- 固定截图默认隐藏参数面板，只保留干净形态证据。

R2 仍然是作者态候选；只有固定视图经用户接受后才允许冻结稳定拓扑并进入 `cat_body_bind_v1` 正式绑定。
