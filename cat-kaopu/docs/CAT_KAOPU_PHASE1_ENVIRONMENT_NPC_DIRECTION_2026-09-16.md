# CAT KAOPU 第一阶段：世界环境生物 NPC

日期：2026-09-16  
工作分支：`codex/cat-kaopu-phase1-environment-npc-20260916`

## 1. 产品定位

本阶段不是继续追求一只猫的全解剖复原，也不是先做复杂生活行为，而是建立可复用的世界环境生物 NPC 基础母体。

优先级固定为：

1. 形态正确、自然、轮廓可信。
2. 基础动作稳定、连续、脚底接触可信。
3. 单体碰撞、地面和障碍物关系可靠。
4. 生活行为只保留最小背景层。
5. 单体稳定后，再做群体、个体差异和同类动物扩展。

V4.46 双眼统一面部载体作为历史基线保留，但眼睑、角膜、第三眼睑、胡须和微观毛发不再是当前主生产门。

## 2. 当前方向纠偏

继续增加眼区局部环带、面数或完整解剖细节，对场景型 NPC 的边际收益已经低于修正整体体型和步态。当前必须重新开放中性猫体的形态生产线；V4.32 冻结体只作为可回滚基线，不再作为不可修改的最终形态。

群体系统不能提前建立在不稳定单体上。若单猫存在脚滑、转向不更新、步幅不匹配、躯干摆动错误或碰撞体错位，数量增加只会成倍放大错误。

## 3. 第一阶段工作范围

### 3.1 形态主线

必须用正面、侧面、顶部和三分之四固定视角审查：

- 头部体量、头颈连接和额头到背部坡度。
- 口鼻长度、颧弓和下颌体量。
- 胸腔、腹部、骨盆的前后连续关系。
- 肩胛、前肢、后肢真实关节位置与肢段比例。
- 足掌大小、落地面和趾向。
- 脊柱弧度、尾根位置、尾长与渐细关系。
- 站立时整体重心和四足承重关系。

本阶段不允许通过视角、毛发、颜色或局部眼部补片掩盖整体体型错误。

### 3.2 动作主线

第一阶段只把以下动作列为生产级目标：

- 中性站立与轻微呼吸。
- 起步。
- 稳定直行。
- 减速与停止。
- 左右转向并同步更新身体朝向。
- 简单观察动作，作为低频背景层。

坐、趴、舔爪、复杂生活序列保留为测试或第二优先级，不得占用主要开发时间。

动作必须由现有 34 骨架和固定骨长驱动。脚掌接触、支撑相、摆动相、骨盆位移、脊柱反向补偿、头颈稳定和尾巴惯性需要在同一周期中联动。

### 3.3 碰撞主线

第一阶段采用低开销混合方案，而不是逐三角形或全骨骼刚体碰撞：

- 躯干：椭球或胶囊体。
- 头部：球体或短胶囊体。
- 骨盆：椭球体。
- 足掌：接触点或小型盒体。
- 地面：高度与法线采样。
- 静态障碍：简化包围体。

单体阶段先验证地面、墙体和简单障碍物碰撞。群体阶段再增加个体之间的宽相检测、局部分离和绕行。

## 4. 个体差异策略

群体中的差异不能使用无约束随机缩放。后续实例 DNA 只允许在相关参数组内变化：

- 体长、胸深、骨盆宽和腿长保持生物学相关性。
- 头宽、口鼻长度和耳朵大小采用受限组合。
- 尾长、尾粗和尾摆幅联动。
- 步幅、步频和身体尺寸联动。
- 材质和花纹变化不得改变碰撞体与骨架真值。

第一阶段先建立一只可靠母体和参数接口，不急于批量制造外观随机但结构错误的个体。

## 5. 性能和现实约束

- 多 NPC 不适合每只都运行完整高精度 IK、全骨骼物理和近景眼部变形。
- 远景运行态需要共享网格、共享动作函数、实例参数和简化碰撞体。
- 物理碰撞必须基于代理体，而不是 SkinnedMesh 三角形。
- 群体避让需要空间索引；直接做所有个体两两检测会随数量平方增长。
- 形态差异必须限制在蒙皮和关节允许的范围内，否则会产生穿插、脚底漂移和关节反折。

## 6. 阶段验收门

第一阶段完成必须同时满足：

1. 固定正交视角下整体猫形可信，主要轮廓无明显结构错误。
2. 站立时四足着地、重心合理，腿部不扭曲。
3. 起步、直行、停止连续，无明显瞬移和脚底滑动。
4. 左右转向时根节点、胸腔、头部和运动方向一致。
5. 通过简单坡地或不平地面测试，足掌接触误差处于可接受范围。
6. 与墙体和简单障碍物碰撞时不穿透、不弹飞。
7. 单体运行稳定后，以 6–12 只作为群体技术门：不同形态参数、不同动作相位、无持续互相穿透。
8. 近景眼部和生活行为不足不得阻止第一阶段通过；整体形态、动作或碰撞错误必须阻止通过。

## 7. 执行顺序

1. 冻结 V4.46 为历史回滚点。
2. 对中性猫体做正面、侧面、顶部、三分之四形态审查。
3. 先修整体比例和关节位置，再修局部表面。
4. 重整起步、直行、停止和转向动作链。
5. 建立单体碰撞代理和静态障碍测试。
6. 固化实例 DNA 接口。
7. 最后进行 6–12 只群体技术验证。
8. 通过后提取通用四足环境 NPC 接口，扩展到其他相近动物。
