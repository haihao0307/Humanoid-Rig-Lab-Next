# CAT BODY BIND V1 R2 视觉复核

日期：2026-09-17  
证据批次：`cat-body-bind-v1-r2-8`  
结论：`visualAcceptance=false`，R2 不进入稳定拓扑与绑定

## R2 的有效改进

- 页面默认隐藏眼球和鼻镜尺度标志，整猫轮廓不再被过大的眼鼻子结构干扰。
- 头部、耳朵和口鼻相对 R1 缩小，颅面比例有所收敛。
- 胸腹骨盆改为参考纵向截面场，运行速度从 R1 约 `9.5 s` 降到 R2 约 `4.5 s`。
- 标量场增加一次受限平滑，生成表面保持单一连续对象。
- 固定视图、参数重建、移动端和可选骨架/眼鼻尺度标志均正常运行。

这些结果证明参考校准和作者态链路有效，但不等于形态通过。

## R2 仍然明显错误的部分

1. 中性姿势仍接近低伏或预备奔跑状态，后躯、膝和飞节长期压低，不能作为站立绑定母体。
2. 头颈仍偏厚，颈根—肩胛—胸廓连接有犬科或团块感。
3. 头部虽然缩小，但口鼻和面颅仍偏圆钝，耳朵在侧面存在感不足。
4. 前后肢过细，关节附近缺少受控体积，足掌仍接近简单胶囊/椭球。
5. 胸腹骨盆连续性优于 R1，但背线、腹线和后躯节奏仍不够自然。
6. 灰虎斑条纹对比过强，在固定灯光下产生类似表面沟槽或肋骨的错觉，妨碍几何判断。
7. 尾根与骨盆连接仍偏细，尾段曲线和渐细关系需要继续收敛。
8. 当前表面依然是作者态隐式网格，不具备稳定生产拓扑、蒙皮权重和关节应力验证。

## R3 修正目标

R3 只处理形态和表面可读性：

- 提高骨盆、腰段、胸廓和肩部，建立真正的四足中性站立；
- 重排髋—膝—飞节—跖部锚点，保持猫科趾行结构但不持续蹲伏；
- 进一步缩小颅面与耳高，细化脑颅、面颅、口鼻和下颌节奏；
- 减轻头颈和胸前团块，保留短颈与肩胛胸廓肌肉吊带；
- 适度增加四肢关节体积，同时控制足掌长度和宽度；
- 重新连接荐骨、尾根和尾段；
- 把虎斑材质降为低对比，增加独立的中性灰形态截图，避免材质误导几何判断；
- 继续禁止进入正式蒙皮、动作和猫群。
