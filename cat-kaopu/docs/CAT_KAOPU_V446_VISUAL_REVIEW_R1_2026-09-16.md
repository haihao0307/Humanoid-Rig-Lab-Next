# CAT KAOPU V4.46 双眼统一眼区载体视觉复核 R1

日期：2026-09-16  
证据批次：`cat-kaopu-v446-wide-eye-region-qa-6`  
对应工作流：`Cat Kaopu V4.46 Wide Eye Region`，run 6  
结论：`visualAcceptance=false`，`productionReady=false`

## 本轮完成的底层替换

V4.46 不再继续给 V4.45 的左右眼环形补片增加环带，而是建立一张覆盖眉弓、鼻根、双眼、内外眼角和上面颊的双眼统一面部载体。两条动态睑裂从同一曲面中切出，因此左右眼附近的软组织、鼻根连续和上面颊支撑位于同一变形场。

在初始证据中发现过三类实际缺陷：矩形载体外露、眼区内部缺片、载体与冻结头脸深度竞争。当前 R1 已完成以下修复：

1. 以解析面部域裁掉矩形工作网格的无效外围。
2. 对头脸射线未命中的眼眶内部使用多邻域加权重建，而不是删除内部顶点。
3. 用解析眶周壳替代粗眼眶凹槽的直接复制，并统一眶周法线。
4. 将闭合缝、湿润缘和眼缘响应限制在各自眼区，避免跨过鼻根。
5. 为表现载体增加受限物理深度和 raster depth bias，消除与冻结头脸的闪烁和破片。

## 已确认有效

- 默认画面不再出现矩形面部载体或侧向大平板。
- 载体内部不再出现大面积缺片和不规则深度裂缝。
- 眼球在完全闭眼时不再穿出。
- 开眼、半闭、完全闭眼具有稳定、可复验的几何变化。
- 正面、三分之四和侧面下，眉弓、鼻根、眼角和上面颊属于同一连续曲面。
- 关闭载体可回到 V4.45，开启载体不会改变整猫头部外轮廓。
- WebGL2、移动端、页面错误、控制台错误、参数极值和运动回归检查均通过。
- `CATV440`、34 骨、RIG、蒙皮权重、V4.39 姿势修形和 V4.36 运动链保持不变。

## 仍未通过的视觉问题

1. 开眼睑裂仍偏横向、规则和对称，真实猫眼内外眼角的高差、外眼角收束和上睑主导弧度不足。
2. 半闭状态主要表现为均匀压窄，尚未充分体现上眼睑滑动、下眼睑支撑和眼角固定之间的不同职责。
3. 完全闭眼已经只剩一条主缝，但缝线仍偏宽、偏淡，眼睑上方体积与下方支撑的差别不够明确。
4. 当前解析眶周壳成功消除了粗眼眶破片，但平滑量偏强，使眉弓、鼻根和上面颊局部趋于“面具化”；它需要恢复受控的解剖起伏，而不是再增加整体平滑。
5. V4.40 眼球仍是轻量球体，眼缘厚度、内外眼角组织和角膜前突关系仍只是近似。

## 因果判断

V4.46 已经解决“局部补片拓扑不连续”“内部缺片”“深度竞争”和“粗眼眶直接传播”四个底层问题。当前主要阻塞已经转为睑裂解剖目标不足，而不是网格分辨率不足。

继续增加顶点、扩大面部载体或提高平滑强度不会解决这些问题，反而会进一步抹平眉弓和面颊结构。下一阶段应固定 V4.46 的单一载体与深度策略，直接建立猫眼睑裂和眼角的解剖约束：内外眼角锚点、上/下眼睑不同闭合轨迹、闭合缝曲率、眼缘厚度和角膜前突关系。

## 下一生产门

下一轮直接进入 V4.47 眼睑裂解剖约束，不再增加覆盖层：

1. 固定 V4.46 单一双眼载体、解析面部域和深度分离。
2. 为左右眼建立独立内眼角、外眼角锚点及高差参数。
3. 上眼睑承担主要闭合行程，下眼睑只提供受限支撑与轻微上提。
4. 开眼轮廓需要具有猫眼外侧收束和非对称弧度，避免规则水平椭圆。
5. 完全闭眼只保留一条窄而连续的主缝，并建立上睑体积、下睑支撑和眼角固定。
6. 角膜与眼缘关系按近景检查，不通过放大虹膜或改变眼球位置掩盖错误。
7. 继续禁止第三眼睑、胡须和轮廓短毛进入本阶段。

因此 V4.46 是有效的结构里程碑，但不升级为视觉验收基线。
