# CAT KAOPU V4.43 眼眶软组织过渡层视觉复核 R1

日期：2026-09-16  
证据批次：`cat-kaopu-v443-orbital-qa-2`  
对应工作流：`Cat Kaopu V4.43 Orbital Soft Tissue`，run 2  
结论：`visualAcceptance=false`，`productionReady=false`

## 技术检查结果

1. WebGL2 页面、正面/三分之四/侧面近景和移动端截图均正常生成。
2. 页面错误与控制台错误均为空。
3. V4.40 `CATV440` 二进制载荷、34 骨 `RIG`、蒙皮权重、V4.39 姿势修形和 V4.36 运动链保持不变。
4. V4.42 四片几何眼睑继续存在；V4.43 新增四片由 `head` 骨驱动的眼眶过渡壳。
5. 眼眶过渡开关、强度、闭眼压缩和检查色均可运行，截图像素差异成立。

## 视觉复核结果

1. 开眼与半闭状态下，眼眶过渡层能够轻微降低眼睑外缘与眉弓、鼻根、面颊之间的明暗断层。
2. 完全闭眼时，眼球泄漏仍然没有重新出现。
3. 但开启和关闭眼眶过渡层的差异仍较弱，无法改变 V4.42 四片眼睑的主要轮廓读法。
4. 完全闭眼正面仍可辨认出横向盖板/塞片，三分之四视角仍可辨认出眼睑是叠加在粗粒度眼眶上的独立零件。
5. 检查色表明 V4.43 的四片过渡壳位于正确局部范围，但它们只是位于四片眼睑后方的第二层覆盖物，没有改变眼睑与眼角之间的拓扑关系。

## 逻辑纠正

“在眼睑后方再叠加一层软组织壳”并不必然产生连续软组织。V4.43 的运行断言通过，只能证明覆盖层存在，不能证明眼睑与眼眶已经成为一个连续结构。继续增加透明度、位移或颜色，会在同一错误结构上增加更多叠层，不能消除四片独立眼睑在内外眼角处的断开。

## 下一生产门

下一轮不再继续扩张 V4.43 的四片覆盖壳，而是建立 V4.44 双眼连续眶周载体：

1. 每只眼使用一张连续环形网格，而不是上、下眼睑和上、下过渡壳共四张独立条带。
2. 连续网格的内边界形成可变睑裂，外边界采样冻结头脸；内外眼角天然由同一拓扑连接。
3. 开眼、半闭和闭眼只移动连续网格的内边界与邻近环带，外边界保持在冻结头脸采样位置。
4. 旧 V4.42/V4.43 几何保留在历史基线中，但不作为 V4.44 默认渲染层。
5. 继续禁止修改 V4.32 中性整猫轮廓、`CATV440`、34 骨和蒙皮权重。
6. 继续禁止进入第三眼睑、胡须和轮廓毛发阶段。

因此 V4.43 作为受限实验保留，但不提升为视觉验收基线。
