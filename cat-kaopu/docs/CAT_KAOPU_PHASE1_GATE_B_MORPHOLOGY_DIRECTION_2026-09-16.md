# CAT KAOPU Phase 1 Gate B · 躯干形态修正方向

日期：2026-09-16  
生产分支：`codex/cat-kaopu-phase1-environment-npc-20260916`

## 1. 当前问题

Gate A 已经证明单体工作台、四足接触和简化碰撞代理能够稳定运行，但固定四视图仍显示出明显的整体形态缺口：

1. 躯干侧面偏长直筒，背线与腹线过度平行。
2. 顶部轮廓缺少胸腔、腰腹和骨盆之间的宽度节奏。
3. 胸腔下缘、腹线和后躯衔接缺少连续的软组织过渡。
4. 肩胛、胸前和颈根之间的坡度仍显突变。

直接增加猫的数量、颜色或局部随机缩放，不能修正这些母体问题。那会把“实例数量”错误地当作“单体质量”，并将同一缺陷复制到整个场景。

## 2. Gate B 目标

建立一层可回滚、可审计、低开销的绑定空间表面修正场，只处理：

- 胸腔横向体积；
- 腰腹收束；
- 骨盆连续性；
- 腹线提拉；
- 肩胛—胸腔—颈根过渡。

Gate B 不重新生成 CATV440 二进制载荷，不修改 34 骨父子关系、固定骨长、蒙皮权重、动作轨道、姿势修形和碰撞代理。

## 3. 解剖依据与使用边界

本轮参考正常家猫胸腔和腹部的横断面解剖、CT 对照和三维重建资料。资料用于确认胸腔、腹部和骨盆应作为相互连续但体量节奏不同的区域，而不是把躯干作为统一圆柱缩放。

这些资料不直接给出本项目网格每个顶点的唯一坐标，因此当前参数是受限形态假设，需要通过四视图视觉审批继续校准，不能被描述成精确解剖复原。

## 4. 技术结构

运行链路为：

`CATV440 中性表面 → Gate B 绑定空间区域场 → 原蒙皮矩阵 → 原姿势/接触求解 → 最终显示`

区域场同时实现于：

1. GPU 顶点着色器，用于实时渲染；
2. CPU 顶点路径，用于导出、采样和自动审计。

默认最大位移限制在约 9 mm，且保持身体纵向长度、地面最低点和眼区顶点不变。

## 5. 验收门

技术验收至少要求：

- CATV440 载荷哈希不变；
- RIG 数据和碰撞代理逐字一致；
- 四视图下修正开关产生可重复差异；
- 胸腔宽度增加、腰腹宽度收束、骨盆宽度基本保持；
- 三角形不翻转，边长变化处于有界范围；
- 行走、转向、足掌接触和墙体阻挡回归继续通过；
- 移动端无横向溢出。

Gate B 技术通过不等于整猫视觉通过。四肢段落、足掌、头部以及动作自然度仍需后续独立门处理。
