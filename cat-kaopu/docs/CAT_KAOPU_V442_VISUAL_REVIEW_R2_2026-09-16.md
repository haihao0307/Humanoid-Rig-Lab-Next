# CAT KAOPU V4.42 几何眼睑视觉复核 R2

日期：2026-09-16  
证据批次：`cat-kaopu-v442-bootstrap-qa-16`  
对应工作流：`Bootstrap Cat Kaopu V4.42 Geometric Eyelid`，run 16  
结论：`visualAcceptance=false`，`productionReady=false`

## 本轮实际变化

R2 在 V4.42 四片几何眼睑基础上继续完成：

1. 将可见睑裂限制在原眼球中心附近，避免使用几乎整个球面宽度。
2. 延长眼睑对眼球的几何遮挡范围，消除下眼睑后的黑色球面月牙。
3. 完全闭眼时同时保持上下眼睑位于眼球前方，并维持上眼睑在深度上的主导关系。
4. 将眼睑端部向内外眼角收束，避免几何片在眼角处保持完整矩形宽度。
5. 缩窄下眼睑向面颊的过渡带，并增强上眼睑的受限凸度。
6. 保留 V4.32 中性猫体、V4.40 `CATV440` 载荷、34 骨、蒙皮权重、V4.39 坐卧修形及 V4.36 运动接触。

## 已通过项目

- 开眼时虹膜和竖瞳位于受限睑裂内，没有重新扩大为整球暴露。
- 半闭眼与完全闭眼时不再出现明显黑色眼球月牙。
- `blink=1` 时眼球完全被遮挡。
- 正面、三分之四、左侧、厚度极值和移动端 WebGL2 截图均正常生成。
- 没有页面错误和控制台错误。
- 四片眼睑几何、34 骨、`CATV440` 载荷和运行依赖检查继续通过。

## 未通过项目

1. 完全闭眼的正面画面仍呈现横向“塞片/台阶”感，尚未形成自然的猫眼睑软组织体积。
2. 眼睑与眉弓、鼻根和面颊之间仍能辨认出独立覆盖层，尤其在三分之四视角下明显。
3. 当前 V4.32 头脸在眼球周围提供的是粗粒度、内凹且带明显多边形边界的眼眶载体。仅继续调节四片眼睑的曲线、颜色或法线，无法消除载体本身造成的凹槽和硬边。
4. 目前没有可随闭眼产生局部压缩与回弹的眼眶软组织层，因此闭眼虽然技术上完整，视觉上仍不像皮肤围绕眼球滑动。

## 因果判断

本轮剩余问题不再是“眼球漏出”或“眨眼数值不生效”。这两项已经解决。主要阻塞转移到了眼睑与冻结头脸载体的连接关系。

继续只修改眼睑片元颜色属于错误方向；继续单纯增加闭合位移也会把几何推成更明显的盖板。下一阶段必须增加一个受限的眼眶过渡/软组织修形层，让眼睑外缘与冻结头脸之间具有连续曲率，同时仍不得写回 `CATV440`。

## 下一生产门

进入 V4.43 之前必须保持以下边界：

1. 不建立第三眼睑。
2. 不进入胡须或轮廓短毛。
3. 不修改 V4.32 整猫中性轮廓和 V4.40 二进制载荷。
4. 先建立由 `head` 骨驱动、从冻结头脸表面采样的局部眼眶过渡壳或姿势修形场。
5. 新层必须提供正面、三分之四、侧面眼部近景，而不只提供整猫远景。
6. 只有开眼、半闭和完全闭眼在近景中都不再呈现独立塞片后，才允许把几何眼睑标记为视觉通过。

因此 V4.42 继续保留为技术候选，不升级为已验收基线。
