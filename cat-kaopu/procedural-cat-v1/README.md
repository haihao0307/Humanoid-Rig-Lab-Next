# CAT PROCEDURAL BODY V1 · P1 Authority Calibration

## 本阶段目标

P1 把许可明确的兽医形态测量转换为 CatDNA 约束，但最终猫体仍完全由我们自己的参数、公式、程序化几何和程序化材质生成。外部资料不进入运行时，不装载外部猫模型，不装载外部图像贴图。

## 事实边界

**已有可靠测量依据：**肩高、肱骨、桡骨、股骨、胫骨、髋骨、颅骨长度、颅部长度、鼻骨长度、颅宽和颅高。

**仍为候选表达：**体长、胸腰骨盆软组织截面、颈部体积、足掌尺寸、尾巴、站立关节角和灰虎斑外观。候选表达需要六视图审批，不能冒充测量真值。

## P1 相对 P0 的底层变化

- 默认肩高和四肢主要长骨进入文献均值附近；
- 头部由犬科式长口鼻改为短面、圆颅、双侧颊垫的猫科表达；
- 躯干由七个椭球串珠改为连续椭圆截面扫掠；
- 耳朵由两根胶囊改为三根耳根约束形成的程序化耳廓体；
- 肩胛、肘、膝、飞节和前后掌增加分段体积；
- 足端增加程序化趾端；
- 短毛几何起伏保持在低于形态尺度的范围；
- 所有变化继续由同一份 75 参数 CatDNA 驱动。
