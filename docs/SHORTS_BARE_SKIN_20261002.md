# 低腰短裤的底层覆盖修复

旧短裤的裤腰高于用户确认的新低腰口，裤身也穿过未通过的亚麻试穿面。原人物在旧裤下面没有独立腰胯和上腿皮肤；仅隐藏旧裤会留下洞。本次补造真实三维裸身区域，再在新版试穿视图替换旧裤显示。原版A文件不变，切到制造诊断或释放工作台时恢复原衣物显示。

`ShortsBarePelvis.mjs` 的所有者为服装集成；它从当前实际生成身体的截面标量、身高、骨骼关节和缺失区域范围形成估计解剖场，以共享格边的 marching tetrahedra 生成闭合面，并绑定现有 pelvis、spine 和两侧 thigh 骨骼。原裤的网格、UV、贴图和已变形顶点不作为补体源。坐标和蒙皮表只存在运行内存中。

这是作者补造的隐藏人体形状，不是精确恢复原来被遮住的皮肤。腰胯按原衣物截面内缩5毫米估计，两腿保留15毫米间隙。顶部寻找原生躯干完整360射线截面，实际支持标高约1.0552米，再向上重叠10毫米；下端在现有裸腿顶端重叠15毫米。当前补体有30,762点、61,520三角、单一闭合定向拓扑，构造与实际蒙皮WORLD位置差约3.6e-8米。拓扑和绑定通过不能替代身体接口、可见覆盖、自交或动作验收。

皮肤色素使用当前公开 `SkinAppearance` 参考标量；原生白色顶点只是贴图增益，不能误称已测肤色。粗糙度、色素与像素足迹过滤的微结构由公共 `SkinMaterial` 函数分别处理，没有复制皮肤贴图。上、下接口的外观需真实浏览器单独审查。

`ShortsSkinContactBody.mjs` 查询实际原生皮肤和新补体三角面。旧裤9/10/19仍留作原版与纸样量体依据，但在新版实际接触中明确排除；不把已替换的旧裤当成隐形第二条裤子。补体与原生表面的完整实体并集尚未认证。

接触求解修复同样独立：旧开放裤表面在约0.13微米的位移中把最近特征的符号翻转约32.88毫米，造成导数核对停止。现在每个临时调整回合固定该回合的真实接触平面作局部求解，接受前重新查询实际几何，并禁止真实接触残差变坏；5%布料应变、4毫米采样间隙、8毫米标高门限未放宽。新覆盖结果和完整物理验收分别记录。

方法来源： [Three.js SkinnedMesh](https://threejs.org/docs/pages/SkinnedMesh.html)、[Marching tetrahedra](https://paulbourke.net/geometry/polygonise/)、[Blender cloth collisions](https://docs.blender.org/manual/en/latest/physics/cloth/settings/collisions.html)。仅采用公开原理，场函数和参数由本项目编写。

实际v4浏览器构造得到30,804点、61,604三角、Euler2、单闭合分量与正体积0.0294429立方米；此数字和中立构造不同，应分别记录。原版A→B→A、原旧裤9/10/19的显示替换与恢复均通过，无浏览器错误。真实四视图仍发现补体穿出布片，因此v4覆盖不通过，不能把隐藏旧裤等同于完成覆盖。

接触性能已改为独立的原生皮肤BVH，并先查闭合补体、再以其最近距离作为原生查询严格上界。10个实际中立样本同时包含原生/补体各5个最近命中，有界合并结果与无限搜索的距离、位置、符号完全一致；此局部耗时不代表整页性能保证。

旧原生上腿开放边界的向下伪法线会把外部点误报为约90毫米负距离；最近组件的有符号距离不能自动当作整个实体并集的符号。新版默认覆盖路线改为当前量体截面初态，保留真实独立二维纸样、19接缝、451自由点、质量和布料材质；闭合补体的有界几何覆盖放置独立报告。不得将它称为低应变物理悬垂或开放动作。原版折叠方向转移模块保留为只读诊断，停止在每次加载时自动重复失败试穿。

v5只对补体的2,599个样本通过6毫米间隙，但前方及下视角的原生裸腿仍穿出；真实纸样应变161.31%，不能晋级。保留该失败。v6恢复原版折叠方向的初态，仅做明确标注的几何覆盖放置；实际量体腰头上下沿、中线和裤脚目标先统一到当前WORLD坐标，再保护这些高度。原生负距离若在该部件全部当前WORLD顶点的包围盒之外，明确纠正为外侧；闭合补体内侧证据不被更近的原生正距离遮掉。8个实际v4开放腿缘误判纠正、34个真正补体内点保持负号、80个原生最近外侧候选不变。该保守守护不是实体并集签名认证。

全静态布面交叉检查使用实际848个布料三角与现有原生皮肤、新补体三角，排除被替换旧裤；保守盒网格不漏大面，六条边与三角面测试并处理共面多边形交集。数值接触和相关退化均记录HOLD，浮点谓词不称精确算术；不运行物理步、不修改模型，不替代自碰撞、连续CCD或人体实体并集认证。

v6四视图的前腰与原生内腿露肤消失，2,599个实际补体+原生查询样本通过6毫米间隙，量体目标Y误差0、原版A不变。全静态三角检查另发现26段真实交线，集中在BL/BR后裆两片；用不同平面/Gram重心公式核对，平面残差约2.2e-16米，最短线段约0.12毫米，因此不是容差误报。此失败保留，不能把采样通过写成完整覆盖。原生源三角还有120个相关零面积退化，布料和补体零面积为0；退化保留并阻止完整实体/物理晋级。

最终v7实际覆盖检查：用当前原生皮肤和补体共同查询2,599个样本，有限1轮几何放置，原后裆26段交线降到0；独立全静态重查30,928个重叠候选对未发现交叉。腰头上下沿、中线、裤脚目标WORLD高度误差0，原版保全与切回通过。四方向未见此前皮肤岛；侧面射线受原生手臂遮挡，不能据此声称整个视角都有无遮挡证明。原生仍有120个相关零面积面，布料与補体无零面积面，完整实体认证仍HOLD。

明确限制：这是尺寸与表面覆盖预览，不是可用布料穿着。真实纸样最大主应变223.01%，仍超过原5%门限；弹力、完整自碰撞、连续CCD和动态未验收，原生步数与时间均0。没有用改写UV/质量或放宽门限宣布物理成功。源码可作为开发检查点上传，原公网A保留，新版未晋级公网完成版。
