# 程序化草裙 R1

每个人物曲面加载时，由 `body/ProceduralGrassSkirt.js` 自动生成适合个人腰胯尺寸的草裙。源码只保存生成方法与参数，不引入图片贴图、预制服装或烘焙顶点。

草裙由完整不透明底层、两圈错开的草叶和编织腰带组成。底层保持环形覆盖，裙摆额外向外展开，以容纳站姿大腿；每条草叶具有独立种子、长度和颜色差异。原始人物为干草色，复制体为橄榄绿色。草裙长度分别约 40.5 / 38.5 厘米，腰口从个人骨盆位置确定。

腰口绑定骨盆，下摆少量混合双侧大腿的变换，叶尖带有有界的程序化摆动。它是蒙皮服装近似，不是布料碰撞模拟；坐卧、极端步幅和复杂姿势仍需要另行验证。原场景 `TREE_D / WATER_A` 物理报错已在后续的 [持续任务 R2](NPC_PERSISTENT_TASKS_R2.md) 修复，实际行走 1 米已完成；这不代表服装全部动作姿势已验收。

每人增加 256 条草叶、12,032 个三角形及约 640.5 KiB 几何缓冲。正常画面增加一次绘制，启用阴影时阴影通道再增加一次。草裙使用人物自己的关节纹理，体型/品质替换时重新生成，失败时仅清理暂存资源，移除人物时释放资源。性能读数包含草裙三角形和缓冲。

已通过整包文件检查；后台实际渲染确认两人均穿着草裙。第一轮出现站姿大腿穿出，已增加裙摆空间并重拍。截图输出在项目目录外，项目仍保持函数与参数交付。
