# R20 按区域整理发流

2026-09-13。用户在两轮真实发型图片研究后要求开始调整系统。本轮修改 R18 新增的八个发型，原六款预设、默认选择及 R17 发根生长范围保留。研究照片只作观察参考，不加入项目资产。

## 修改依据和实现

自然发型可以整齐、光滑或有齐切发尾，也可以蓬松、有卷曲和散发。判定应看根部、发流、层次、分缝与收束是否连贯，不能把“多加随机噪声”当作自然。

- 短发使用连续的前、后发流面承载错位的外层发束。短背头的前区从发际向头顶梳起；刘海、中分和侧梳分别设置向前延伸和侧向偏转，侧面及颈后收短。这样减少多段引导相交造成的块状轮廓。
- 波波头从弯曲的分缝向两侧展开，随后下垂并在发尾内收。微卷款在同一结构上加入下半部的连续波动。提高侧面间距，避免当前参考头的耳尖穿出。
- 扎发沿头面直接汇到扎点。低马尾的颈后头发不再先向头顶绕行。马尾由三个彼此接近的下垂发束组成；丸子头使用盘绕中心线，末端收回扎点附近。
- 外层发束与细发采用相同的引导函数。短发和波波头先为实际发根找到邻近引导，再向发尾延伸。细发仍精确从原有根部开始；弧长重采样约束长发的分段长度。
- 降低新增发型的底层厚度，并根据底层实际修正后的半径给外层留出间距，减少相交形成的暗色补丁。曲线弯曲处增加纵向采样，横向发束数相应调整，总预算不增加。
- 材质沿各自发束切线计算主、次高光，降低发片边缘的整条暗沟，加强经过像素过滤的细部差异。发际边缘的不规则淡出限制在原有覆盖区内；原六款材质路径保持兼容。

## 验证边界

`node tools/test-hair-guides.mjs` 在合成参考头上检查 249 项根部绑定、有限坐标、低位汇合、下垂关系、底层间距和绕耳路径。真实参数头另用外部脚本检查 58 组预设、质量档、长度、密度和种子组合；包括所有 LOD 的内存与三角形预算、分段长度、颜色与几何独立性、R17 默认几何及生长区来源哈希。

按 `source/assembly.json` 装配入口后执行 `node tools/check-pure.mjs` 和 `tools/audit-files.py`。隐藏浏览器截图是单独的视觉观察，不代替文件检查，不操作桌面鼠标。图片保存在项目外的本轮 `hair-natural-r20` 审阅目录；保留修改前、迭代及最终截图以便比较。

每人几何仍限制在 432,000 / 1,296,000 / 3,456,000 B，另有固定共享 44 B；最多两次毛发绘制。没有新增照片纹理、预制网格或烘焙顶点资产，也没有逐帧重建几何。本轮不作为照片级真实、全姿态头发碰撞、发丝动力学或性能测量的验收。

## 本轮实际观察

八款前侧面/侧面及四组背面已在隐藏浏览器中查看。明显的块状交叉与局部穿插减少，原有颈后覆盖保留。近看仍有整片感，波波头上、下段的转折和发缘颗粒感仍可见；本轮是结构调整结果，不能据此宣称自然度已定稿。
