# 中性唇接触与下脸连续结构 R9

2026-09-15。本阶段承接 R8 口周与下巴连续结构，重点解决中性唇缝像永久黑槽、张口时上下唇自由边失去侧别并形成竖向条带、鼻小柱到人中的关系不足，以及中央下巴仍保留旧曲面的横向层次等问题。

## 已实施内容

- `body/FaceAnatomy.js` 升级为 `r13-neutral-oral-seal-lower-face`。
- 中性上下唇在视觉上保持接触；自由边只保留 0.001 mm 的次视觉侧别标记，用于让张口形变可靠区分上唇和下唇，不作为可见缝隙。
- 口腔内部成为独立绘制特征：中性闭口时隐藏，张口后才显示，避免以整条深色口腔表面冒充唇缝。
- 唇缝由有界、非均匀接触阴影表达，中央和口角权重不同，并随 `lipPart` 张口权重衰减。
- 唇部自由边使用局部横向低通表面，外缘仍精确返回原始皮肤附着面，减少张口时由源皮肤微梯度放大的列状条纹。
- 白唇缘幅度与影响宽度继续收敛，唇红边界采用渐进羽化；张口期间关闭外唇微沟槽，避免内返黏膜被错误解释成齿状条纹。
- 鼻小柱下方增加受限桥接体积和鼻下点凹区，人中嵴、中央人中沟与上唇峰形成连续纵向关系。
- 中央下脸增加第二个有界 Hermite 过渡床，重新分配颏唇沟、中央颏肌、成对颏肌翼和下巴基底体积，减轻旧曲面的横向分层。

## 不变量

本阶段属于 Performance Deform / 高级面部表现层。没有修改 Core Rig、父子层级、骨长、绑定姿势、人物比例或动作系统；身份中性脸与临时表情继续分层保存。所有新增形态仍由参数、连续函数和程序化几何产生，没有引入外部人脸模型、扫描网格或图片贴图。

## 边界

- 当前 `lipPart` 仍是唇部局部近似，不是真实颞下颌关节运动。
- 当前没有牙列、牙龈、舌头、唇齿接触和完整口腔组织系统。
- 眼白暴露、头颅低频形态、面颊与颈部连接仍限制整体真人感。
- 参数与浏览器检查通过不等于视觉验收；`visualAcceptance=false`、`productionReady=false`，等待用户审阅固定网页和截图。
