## 原函数皮纹

从冻结原版取回原有的附加噪波函数，连同已保留的 SkinGraphKernel 和原种子配方，在身体项目内完整重建四组 RGBA、各 12 级字段。包括原先只恢复 R 的凹陷字段的全部 GBA 通道，原始字节合计 178,956,960。Node 和实际浏览器工作线程的四组原始哈希均与原缓存相同。没有生成头部几何，也没有修改头部工程。

HTTP 字段作为可选的加速缓存。当前页先校验本地持久缓存，再校验下载的压缩及原始字节；缓存损坏、下载失败时由原函数重新生成四组字段。生成成功后再次校验，原子写入本地缓存。存储不可用不阻止载入。实际检查覆盖本地缓存复用、损坏的本地和 HTTP 缓存、函数重建后复用、存储不可用及配方不匹配拒绝。

完整三维原貌页另作了断开全部四组 HTTP 皮纹缓存的实测：原工作线程在约 38.8 秒内只生成一轮四组字段，随后进入原 GPU 材质、原几何、阴影和精细模式。实际刷新从已校验的本地缓存读取四组字段，没有再次下载或启动生成线程。该时间是本机单次检查结果，不是其他设备的时间保证。

## 来源分区与求交修正

离线编译改用齐次整数和精确射影谓词，避免浮点面积判定及域扩张影响极窄的原分区。所有原表面、法线、掌跖和肌理系数保持原字节；只重编译分区路由。sourcePackage 中的旧输入保存描述属于校准打包阶段；最终域路由的变化由 domainCompilation 和各档 sourceProgramSHA256 明确记录。

射线跨分区时按导数方向确定近、远侧，不再以可能舍入到分割点的区间中点判定方向。Float64 路径仅采用按机器精度计算的区间算术保护，不将它当作来源验收容差。旧状态及失败试验保留。

独立的离线原三角参照采用投影式无裂缝射线判定，避免朴素重心和在中线舍入为 1 所导致的参照误报。参照三角仅在离线测试中存在，不进入新运行时。

十档、四视角、641×826 的 21,178,640 条同机位射线中，命中覆盖差异为 0；最大距离差为 2.4868995751603507e-14 米，最大法线分量差为 1.308703145852519e-12。它们是限定采样下的数值结果，不是完整连续域或正式视觉验收证明。

另外以精确有理数核查十档全部 2,716,867 次分割：输入区域面积与两个输出区域面积之和严格相等，5,433,734 个非空子区域保持非负面积。证明程序输出的四组路由/函数数组哈希均与当前选用包相同。这只证明转为 Float64 决策线之前的分割面积守恒，不证明所有有限精度射线、零面积边界归属、分层遮挡、原法线或材质外观通过验收。离线参照三角未进入新运行时。

十档全部 184,160 个原非退化分区又作了完整区域的系数误差界核查。来源映射和存储映射均为仿射函数，其差在整个闭分区内受角点最大值约束；角点残差以精确有理数求值。全部分区的位置误差上界最高 2.7464e-16 米。原法线插值的凸包使用严格正的长度下界，个别分区改用精确约束二次最小值；归一化法线的向量误差上界最高 9.0929e-12，未留下无界分区。

同样核查了原静置材料坐标、干燥和掌跖五个字段：最高分量误差界依次约为 2.8441e-16、7.5475e-16、3.5755e-16、7.6632e-16 和 2.3486e-14（各字段原单位）。这些是存储系数在实数算术下的表示误差界；不包含有限精度射线求根、Float64 分区边界归属、首交竞争、原片元法线处理、非线性材质或纹理过滤。因此它比抽样覆盖更完整，但不能消除已记录的原生像素差异或代替正式验收。

## 标准模式的无损显存寻址

参数页标准模式直接读取原 Float32 砖块，以整数地址表定位实际字段，不再先展开完整密集 GPU 场。缺省砖块使用原先逐位验证的常量和轴字段；不拟合、不量化、不改变插值顺序。原人物 GPU 字段从 352,871,712 降至 258,899,608 字节。各体型的实际占用随字段变化。

生产 GPU 地址解码的 106,686,702 个 Float32 字检查没有不同字；包含字段、法线和单独标量读取。四状态 × 四视角 × 颜色/法线/深度的 48 幅整帧与保留的密集参考没有不同字节。

新路径的精细模式试验出现 2 个字节、最大 1 个 RGB 码值差异，因此没有把该路径用于精细模式。生产版精细模式保留原密集 Float32 GLSL。其正、侧面颜色/法线/深度六组比较没有不同字节。标准与精细切换只保留一个活动渲染器：实际检查纹理数为 12→6→12，事件和尺寸观察器不累积，相机、外观、完整状态不丢失。标准模式减少显存不等于所有设备、更高精度或所有操作都更快。

网页本体约 0.82 MB 与 1.68 MB。当前两页全部 82 个运行资产合计 198,754,116 压缩字节，其中四组可重建皮纹缓存约 90.44 MB。网页缩小不等于全部数据消失；原貌函数和阴影仍按状态读取，原人物及回退文件均保留。

## 隔离的骨架与软组织响应研究

`src/research/r24/BodySoftResponseR24.js` 将原始每项绑定贡献转入其实际原关节静置坐标，再使用来源绑定的参照姿态求值。参照仅固定总体脂肪、肌肉及原目录中 20 项有名身体脂肪/肌肉局部控制；身高、年龄、比例、身份、动作和其他变量继续取当前值。参照使用原人物的脂肪 0.66、肌肉 0.96 及原局部值，不把这个数值参照称为成人中性母体。没有删除原权重、替换为猜测骨架、生成连接面或修改头部贡献。

150 个数值组合和局部非对称检查通过 647 项断言。在所选软组织参考值处，默认来源输出逐位不变；离开参考值后是明确的有意改形候选，最大样本修正约 63.29 mm。所检查的原绑定支撑距离原先可变化约 30.70 mm，候选参照在这些软组织变量变化下保持不变。仿射恒等残差最大约 4.44e-16；其算术误差界只用于验证所写的矩阵规则，不是解剖、表面或视觉验收容差。

`tools/research/r24/build-soft-research.cjs` 可单独构建真实的直接求交研究页。它不被普通构建、BUILD.json 或预览入口选用；研究页禁用正式存档按钮和页面交接，不读取、消费或确认生产页等待交接的人物。实际生成的原默认场缓冲、尺寸和边界与当前参数页逐位相同。其他体型及 A/B 组合动作只作为研究输出，不替换原版。

内部三维检查仍能看到手指局部破碎/细小起伏、腋肘附近明显暗沟和未完成的胸肩体积表达。它继续使用未通过来源验收的旧隐式表面；候选表面法线、颈口、材料坐标、极端体型和连续组合动作均未完成验收。数值规则和能够绘制三维画面不代表外观已完成，因此 `displayReady`、`sourceFidelityAccepted`、`visualAccepted` 均为 false。候选保留供后续继续研究，默认版未采用。

真实研究页检查了原默认场逐位一致、完整头部输入保留、等待交接的人物不被消费、正式存档入口隐藏，以及三种动作/驱动、两组体型下的 48 个整身/半身视角；36 项技术断言通过。额外的 150 组离线局部诊断发现，部分体型最多有 9 个来源单元的候选法线相对当前来源转向超过 90°，最小点积约 -0.9994。此指标不是自交或拓扑翻转的证明，但明确提示局部形态仍有问题；相关单元、位置、参数、最小面积比和最大修正均已记录，没有通过删样本、平滑或填充把它们隐藏。

普通生产构建已从仅包含 Git 提交内容的独立目录重建，82 个运行资产及两个 HTML 均与当前选择的字节一致；不读取忽略的离线原模型，不依赖外部运行时下载。

## 连续参数页的来源缺陷定位

当前连续参数页的实际 GPU 首交另与原貌函数作了四状态、正侧背及半身共 16 组同机位比较，分辨率 481×641，共 4,933,136 条射线。记录到原貌独有命中 591、连续页额外命中 13,796；单条射线的最大首交距离差约 0.7353 米，包含近侧结构错误遮住远侧结构的情况，不能解读为软组织移动了这么远。每组最大值、像素、原来源单元和原绑定定位标签均保留；这些定位标签来自原默认绑定，不是 B 驱动的当前骨名或解剖分区。

在这四档的全部 37,012 个原表面样本处核查连续标量函数，最大绝对函数值约 0.004951；该函数不是已证明的距离场，所以这不是毫米误差。在首交差异最大的像素，显示命中点的函数值仍接近当前着色器的命中条件，而原来源表面点不必位于该零面上。这确认旧隐式表面本身仍有来源偏差，不能把所有问题归结为灯光、皮纹或三维显示故障。

因此保留原参数、原控制样本以及 GPU 字段逐位一致，仅分别说明对应的数据与传输没有改变；不说明连续渲染表面忠实复刻了原版。下一轮应先替换这个未验收表面，处理真实首交、手指腕部和足趾边界，再把骨架/软组织候选接入通过验收的表面。当前直接求交原貌页仍只覆盖十个固定原状态。

## 共享边界问题与精确整数函数核

四档的全部原顶点、唯一边中点和面内中心又分别沿三个方向作定向检查，共 664,044 条射线。与独立 Float64 原参照之间有 1,037 条覆盖差异；面内中心没有覆盖差异，问题集中在顶点和边界。这里出现的大首交差值也包含错过近层后命中远层的情况，不是整体形体位移。

对每档记录的 32 条覆盖例子和 10 条最大距离例子，另用精确有理数原参照复核。168 个记录案例中，当前浮点函数核有 126 个覆盖判断与精确原参照不同，另有 21 个命中选择了不同的原第一层；Float64 参照也有两个覆盖误判，因此没有把它当作数学真值。只修改闭区间分支及平行射线双侧遍历的候选未解决这些问题，定向覆盖差异反而增至 1,040，已保留并拒绝采用。

新的隔离原型保留精确整数域边界和有向平面系数，以 BigInt 有理数比较求交、闭区间和首交顺序，不加几何容差、不填洞、不改原表面。四档全部 168 个已记录案例的首交参数，均与独立精确原参照的分子/分母严格相同；实际浏览器与 Node 结果相同，输出 Float64 也与精确参照的舍入值相同。21 项技术断言通过。

研究函数数据单独保存为 `data/body-rational-domains-research-r24.json.gz`，最终覆盖十个固定状态，压缩字节与校验值见 qa/fidelity-r24/rational-domain-data.json，未计入生产页的 82 个运行资产。它没有原点表和面连接，只包含解析平面、域、决策及函数标识；仍明确保留来源分面分区，不是自主母体。提交后的独立目录可以只用这份数据及 `tools/research/r24/check-rational-bundle.cjs` 复核 420 个案例，无需原离线模型。

随后补齐十档共 1,660,110 条定向检查，记录到 2,552 条 Float64 覆盖差异。420 个记录案例经精确原参照复核，当前浮点函数核有 314 个覆盖差异及 51 个不同首层选择，Float64 参照自身有 6 个覆盖误判。十档整数函数核的 420 个记录案例均通过浏览器与 Node 的精确参数及 Float64 舍入检查，合计 51 项技术断言通过。

此核尚未接入三维显示、材质/法线字段和按需精确回退，也未证明所有连续边界射线。默认 R24 页面未采用这个原型；共享边界问题仍属于未完成事项。后续先完成有界浮点快速判定与整数精确回退及全档验收，再迁移连续来源表面，不能因 168 个案例通过宣布整个来源或母体完成。
