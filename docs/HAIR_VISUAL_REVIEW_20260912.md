## 观察结论

默认自然后梳、均衡毛发档、人体启动档，分别观察正面、侧面、后脑以及放大细节。

- 修正前：前额像梳齿，侧面呈大量规则平行细线；头皮间隙明显，轮廓贴头。低数量发束没有提供足够的基础覆盖。
- 修正后：头顶和前额覆盖更完整，整体轮廓稍有起伏。耳上、后脑仍有斑块状头皮缺口，发际线偏厚、过渡生硬，整体仍有头套感。
- 不能据此认定毛发已自然、照片级或视觉验收通过。宽度增加改善覆盖，也会加重块状感；后续应优先改善底层覆盖连续性、边界细发过渡和发束方向/高光层次，不能仅继续加宽。
- 面部和颈部另有可见棱面/接缝、眼部外观不自然。这些是当前整体画面的观察，不属于本次毛发修正的验证结论；身体界面也提示部分区域尚未满足目标精度。

## 本轮修正与诊断

`hair.mjs` 在相同生成数量中分配短底层覆盖、上层发束和少量细丝，底层约 65%、上层约 28%、细丝约 7%。上层增加径向起伏；宽片内部增加小幅头皮避让。`hair-rules-r2.mjs` 加入确定性的空间方向变化。`CompactHairRenderer.js` 区分底层色调和高光，并将屏幕尺寸 LOD 阈值改为 160 / 70 / 28 像素。

根点角度分箱显示符合蒙版的头顶、两侧与后脑都有根点。抽取默认全部 5,983 个根点，对照头皮径向场：根点半径差的中位数约 -0.0013 mm，1% / 99% 分位约 -0.047 / 0.073 mm，极值约 -0.098 / 0.163 mm。此诊断未显示整片漏种或明显径向场错位；结合加宽后的改善，显示覆盖不足是目前更有依据的解释。它不能证明局部密度均匀、有限宽度发片不穿插或连续碰撞安全。

## 本轮验证边界

- 实际默认生成：5,983 条显示发束、35,898 段，段数据 1,292,328 字节。配置上限仍为 6,000 条、1,296,000 字节，毛发仍一次实例化绘制。
- 实际执行九组生成输入：六个预设，以及微卷节省档/最长高密度、微卷精细档/最长、后梳低密度/最短。数据均为有限数，均在各自字节预算内；重复默认输入的缓冲 SHA-256 一致。该检查未在 GPU 上逐个查看其他五种预设。
- 最后一次后台页面的整体性能面板采样约 60 FPS、GPU 1.48 ms、渲染 CPU 0.43 ms、17 次绘制、几何缓冲 10.20 MB、曲面生成 4.45 s。这是该环境、该视角、该时刻的全场景读数；不是毛发专项基准、持续压力测试或跨设备保证。增加覆盖会增加片元重叠，降低 LOD 阈值也会增加部分距离的绘制量。
