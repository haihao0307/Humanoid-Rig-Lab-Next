# R18 发型扩展（2026-09-13）

后续：用户认为这一版不够自然，外层与材质已在 [R19 自然度修正](HAIR_NATURALNESS_R19.md) 中继续修改。本文件保留八款发型的初始范围与来源。

本轮在用户已认可的 R17 生长范围上新增八款发型，共 14 个选项（13 款有发造型及无头发）。原有六个选项、默认自然后梳、默认节省档以及未指定发型的角色种子选择保持兼容。新发型可用于任意角色，不按性别限制选择；本轮截图继续使用项目的 R2 参考头型。

| 预设 | 标识 | 造型方式 |
| --- | --- | --- |
| 前梳刘海 | `fringe` | 向前梳理，额前短刘海与错落发梢 |
| 立体短背头 | `quiff` | 额顶抬高，发流向后 |
| 中分帘式 | `curtains` | 两组向外分开的额前引导曲线 |
| 精灵短发 | `pixie` | 短侧发与不对称斜刘海 |
| 直发波波头 | `bob` | 脸侧及后方垂落，发尾内收 |
| 微卷波波头 | `wavy-bob` | 稍长的垂落段，发尾低幅波形 |
| 高丸子头 | `high-bun` | 贴头梳理至后上方，再绕成发髻 |
| 低马尾 | `ponytail` | 后方汇聚，再向下垂落并收细 |

在人物设置的“头发”页选择，菜单按短发、中长发、扎发及无头发分组。种子、颜色、密度、长度比例和开销档仍随角色配方保存。新增发型不会改变旧角色未指定预设时的随机选择结果。

## 实现与预算

`reconstruction/hair-styles.mjs` 负责引导曲线、等弧长重采样及运行时发型表面。发根继续由原来的拟合头部函数和 R17 区域规则产生。自由垂落段可以离开头皮；短发、波波头、扎发分别使用 8、10、16 段曲线。较多分段通过减少显示发束数量抵扣，未提高总预算。

发型表面并入原底层的索引缓冲，补充的法线也计入预算。GPU 仍最多两次毛发绘制，四级 LOD 共享顶点，运行期间不重新上传几何。颜色单独调整复用原缓冲。

| 档位 | 毛发几何上限 | 近景三角形上限 |
| --- | ---: | ---: |
| 节省 | 432,000 B | 24,000 |
| 均衡 | 1,296,000 B | 72,000 |
| 精细 | 3,456,000 B | 192,000 |

以上包括发型表面、所有 LOD 索引、法线和发束数据，渲染器另有固定 44 B 的共享四角及索引。显示发束不是人体真实发丝或毛囊数量。

## 验证与边界

- 文件装配、语法、输入来源锁、Worker 传输和共享缓冲预算由 `node tools/build-pure.mjs`、`node tools/check-pure.mjs` 检查，审计由 `tools/audit-files.py` 更新。
- 外部审阅脚本检查所有预设的三档生成、八款新发型的长度/密度/种子边界、默认造型及生长区文件与 R17 的哈希一致性、根部归属、曲线有限值和最大段长、全部 LOD 预算、种子重复和颜色独立性。
- 在隐藏浏览器内实际生成并切换八款发型，保存当前截图；波波头、微卷波波头、丸子头、马尾另有背面截图。通过明确的 `?hair-review=three-quarter#hair-preset=bob&hair-view=back` 审阅地址控制视角，无鼠标操作。
- 配方属于程序化展示造型；未进行真实发丝物理仿真、极限姿态的全身碰撞验收或各设备帧率基准。图像审阅与文件检查分开记录，代码中的 `visualAcceptance:false` 不因文件检查通过而改变。

本轮实际效果截图和生成检查记录位于工作区外的 `hair-styles-r18` 审阅目录，未将截图或烘焙模型作为人体资源提交。
