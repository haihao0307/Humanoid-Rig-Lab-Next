# 研究与老师：把资料转成可运行能力

返回 [总入口](../../WORKBENCH_BUILD_SYSTEM.md)。这是现有Reference First / Observe → Measure → Describe → Reconstruct → Compare → Distill的执行细化，不另建一套知识名词。

## 1. 收集顺序

先读用户已锁定对象与参考，再查已有仓库同类内核、失败记录及原总工作台；随后查原作者、官方代码、论文、官方示例和可靠实物资料。外部检索不使用中国网站来源。二手文章只能引导到一手来源，不能据摘要假称全文已读。

每项需求至少应有一种能判错的参考：轮廓有多角度，厚度有截面/测量，材质有不同光照与距离，动作有连续过程，物理有边界条件和可观测输出。缺项不一定阻塞全部，但必须影响对应主张与工位的状态。

优先补“当前实验需要但没有”的资料。没有必要每轮重新搜索整个行业，也不为凑老师数量重复收藏同一种宣传图。

## 2. 老师分工与准入

**视觉老师**提供质量目标；**结构老师**解释组成和关系；**算法老师**给出可执行方法；**动力学老师**解释输入、受力与稳定性；**工程老师**教会装配、性能、编辑、保存及部署。一个来源可承担多个角色，但必须分别证明。

筛选时先比较实际画面是否符合用户目标，再检查可学习性。记录六个维度，不用总分掩盖硬缺项：视觉水平、问题匹配、资料开放程度、复现成本、迁移难度、许可与维护风险。只有演示但视觉极好，可保留为标杆；不要把它作为当前可直接集成的算法来源。公开代码但效果低于目标，可用作工程老师，不能偷偷把它升级为视觉目标。

来源卡包含：sourceId、作者/机构、标题、URL、访问日期、版本或commit、读取层级、可取得的代码/数据/权重、许可范围、输入输出、环境要求、关联能力、成功/失败实验、剩余未知。代码许可、模型权重许可和素材许可分别核对；许可证不明时不再分发，不自行改成MIT/CC0。

## 3. 四种读取状态与四种实现关系

读取状态：METADATA_ONLY、CONTENT_READ、SOURCE_READ、EXECUTED。演示画面看过并不意味着SOURCE_READ；SOURCE_READ也不意味着EXECUTED。精确记录成功命令与设备，不把启动失败记成复现成功。

实现关系：REFERENCE_ONLY（仅参考）、DIRECT_REUSE（按许可直接复用）、ADAPTED_IMPLEMENTATION（适配实现）、INDEPENDENT_REIMPLEMENTATION（独立实现）。附exactReplication=true/false及差异。借思想重写不等于数学等价；代码重写也不自动证明免除上游权利要求。

不能取得老师时有三条诚实路线：保留其视觉目标并选择可运行的技术老师；只复现公开且信息足够的子能力；把该能力记作阻塞。禁止破解许可、绕付费、编造原理或假造源码出处。

## 4. 从观察形成Score

对象身份 → 主轴/基准坐标 → 部件图谱 → 共享边界/连接关系 → 多尺度曲面 → 材料分区 → 行为与接触 → 观测指标。

每条测量同时保存单位、坐标系、视角、标定方法和误差来源。图片中的像素比例不是天然毫米；配置值不是最终变形后的世界空间尺寸。推断和实测分开，缺深度时不得假装唯一三维解。

把共同规律放在上层能力，个体差异保存在配方。只保存必要数据，不为满足“纯代码”把测量证据删掉；也不把海量顶点数组换个文件扩展名叫成函数知识。

## 5. 教师实验的最小闭环

保留一份只读老师输入和可重现环境；跑原例；记录精确差异；只改变一个影响因素；验证原功能不退化；用新对象或新输入尝试迁移。变体测试必须留出没有用于调参的观察条件，避免只拟合一个截图。

每个提炼出的能力写一张简短能力卡：解决的问题、输入输出、公式/算法及来源、合法参数域、单位、边界条件、复杂度与内存、失败例、适配器、正负对照、当前验证范围。

迁移应删除老师身份依赖，不必强行删除合法的通用库。对程序化生产域，老师网格只作参考时必须退出运行时；对用户明确允许的扫描/贴图实验域，合法资产可保留，但必须承认对数据的依赖以及未验证的跨人物泛化。

## 6. 把研究优先级交给缺陷

优先研究会决定路线成败的问题：隐藏结构能否测量、浏览器能否承载求解、现有参数是否真有效、角色/材料坐标是否兼容、参考资产是否可合法使用。做一个能够否定方案的小实验，胜过先写几十页宏大架构。

研究结束必须留下可执行选择、证据和下一条生产命令。只有链接清单而没有“哪个能力学哪位老师、怎么迁移、如何验收”，研究未完成。反过来，资料不齐也不是无限研究的理由：允许在已授权范围内用明确未知状态开展互不依赖的工作。
