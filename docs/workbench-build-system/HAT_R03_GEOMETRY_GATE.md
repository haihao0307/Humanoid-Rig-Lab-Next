# R03帽子贴合的失败校正：显示成功不等于形态正确

2026-10-11。源于本轮实际开发和助手自查，不冒称用户已看过或否定了R03。

## 真实经过

用户接受R02的复刻外观作为继续调整的基础，随后要求量头贴合、针织包裹感和程序化品类母体。R03.0曾通过数字与浏览器运行检查，但取回真实图片后出现多个帽型尖刺、护耳帽异常放大。固定构建f531d067613feecf6a367788299870e05235b037因此被内部视觉审核拒绝，不作为交付或新的认可基线。R02仍保持只读。

## 可迁移的根因

一、测量对象与模型整体包围盒不同。帽口、帽冠、护耳片、系带、帽檐需有各自语义。开口截面可能缺一段，不能把没有交点解释成半径为零，再据此除法缩放。

二、三维模型不是一叠互不相关的二维截面。中心点随切片跳动、帽顶轴心被加上非零半径、突然改变拟合方向，都会产生尖刺和折返。拟合应保留角向/高度方向连续性，原网格保形与接触保护分开。

三、只有“有限数、无JS报错、canvas有像素”不够。标签和背景可以让空物体页面通过像素方差检查。必须联合核对可见世界尺寸、物体在相机中的占比、三维顶点/面、形变分布，以及真正的物体画面。检测到23米帽子必须失败，不能因它仍是有限数就通过。

四、程序化声明要具体：来源控制网再生、分区形变、解析生成、烘焙缓存是不同路径。控制点与UV仍来自作者时继续署名，不能因为运行时重新计算了顶点就宣称完全原创或极小公式。

## 本轮落实的检查

R03.1在生产层限制异常世界尺寸，并在回归中检查三种头形下的边长变化分布。针织帽使用实际源开口边界拟合佩戴坐标；护耳帽只用完整上部帽冠截面，系带不进入头围；空顶帽的投影环带候选明确标记，不冒称封闭截面。接触保护仍是静态径向采样，不是压力或连续三角形碰撞。

尺寸与边长门槛是针对该工作台的防错范围，不是服装物理标准；必须保留更严格的视觉审核、已知误差和用户审核。极小原始边可能仍有较大局部比值，不得用P99通过掩盖最大值和局部问题。

下一次规则修订要维护三个独立状态：机器运行通过、执行端视觉自查、用户接受范围。只在实际证据出现后更新对应状态，不用一份旧DELIVERY或多个成功测试数字代替最终画面检查。
