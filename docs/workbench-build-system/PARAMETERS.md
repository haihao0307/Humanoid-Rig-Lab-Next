# V1.1 参数掌握 → 有意义的变量 → 可复现预设

返回[总入口](../../WORKBENCH_BUILD_SYSTEM.md)。本册由执行端执行，用户不必逐项填写或手工调试。

## 一、围绕已复刻效果建立参数地图

先找到实际输入和默认值：UI、配置文件、节点、shader uniform、几何生成函数、求解器和隐藏条件。只读的导出信息、派生值和真正可写参数分开。给每项建立稳定ID以及它影响的部件/效果，不因页面里有滑块就判为掌握。

最小记录：参数ID、源码入口、类型、单位、默认值、启用条件、依赖、可测范围、预期可见效应、实测效应、异常与恢复结果。尚未探测的范围保持UNKNOWN，不虚构通用安全范围。

## 二、自己做受控实验

锁住复刻输入和观察条件；选择一个已启用参数，以低/默认/高等适用值进行单因素测试，观察真实几何、像素、行为或物理输出，再恢复原值核对。离散选项逐类测，不用连续插值冒充拓扑变化。检查错误值、缺依赖、停用条件和单位错误。

发现多个参数控制同一现象时，检验关键成对关系及极端组合，例如尺度与纹理密度、厚度与弯曲、眼裂与闭眼接触、裁片长度与缝边配对。外观效应与真实材料标定分开；颜色变化不自动改变力学。

参数多时主动排序：先最影响目标外观/功能的，再补低影响量。记录覆盖分母和未测组合；只测一个有效值不代表整个参数域都已认证。不使用一个任意“参数掌握百分比”掩盖重要未知。

## 三、把底层数字变成目标变量

底层参数是实现手段；用户变量表达实际意图，如“厚软/薄挺”“短款/长款”“轻度磨损/破洞”“圆润/骨感”。执行端明确高层意图映射到哪些底层量、什么条件下成立，必要时加入约束或拒绝不合理组合。

先证明变体可控，再添加带固定种子和分布的随机变化。结构类型、材质身份、物理条件之间不能无约束随机拼接。应优先形成少量明显不同且达到目标的高质量预设，再逐步扩充，不为数量做同质低质量副本。

## 四、每个预设必须能回来

保存参数全集、内核/老师/资产版本、依赖输入、种子、相机和必要初始条件；导入后重算并核对。显示预览应来自相同配方的真实生成或求解，缓存必须标来源版本，失效后不冒用。

换一个未用于调参的对象、尺寸或场景再验证；原样复刻成立不代表跨人物/跨材料成立。用户选效果，执行端负责重生成和约束，不用缩小人体或隐去结构迁就预设。

## 五、提炼时保留质量贡献

完整路径分成三份可追溯记录：老师原效果、冻结的网页复刻、自己的参数化/变体候选。接口、配方和局部内核可以逐步归一，不要求整套替换；合法依赖可以长期保留并注明来源。

每次替换一个内部模块都与冻结基线比较，细节/光学/交互掉级就回退和补学。最终“属于我们体系”的标准是能够解释、控制、变更、保存、迁移和维护，而非抹去老师名称或把第三方版权变成自己的。
