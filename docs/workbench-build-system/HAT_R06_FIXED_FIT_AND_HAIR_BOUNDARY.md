# 固定帽型—头部量配方法 R06

固定母型结构，不是固定所有人的号码；锁定可复现程序，不是锁死某个已拟合网格。

从来源生成 → 识别帽口/承托区 → 读取原人物/单位/基准 → 测实际皮肤截面 → 按类别量配 → 生成需要的内带或材料层 → 检查承托与整帽尺寸 → 对照来源 → 保存人物/母型哈希。

`cable`：真实开口、翻边及3.6mm默认材料内层；帽口承托，冠顶保留来源松量。
`fishing`：帽冠相连的真实内圈，不读取外饰带/外檐作帽围；檐长独立保留。
`flatcap`：来源浅内衬的来源射线对应重建，外观冠与前檐保留，1.2mm有限汗带承托；不以外帽形状直接贴皮。
`visor`：源前额带/后带分区沿各自高度适配，前檐剔出头围计算。
`patrol`：源帽口及其上承托条带，帽顶和前檐保留；不能使用旧错误平面把上头皮切入。
`chef`：实际源开口定位、褶裥冠保留，新增内汗带把支撑与膨大外冠区分。
`sherpa`：完整上帽体量配，布料内层2.8mm；护耳片与窄绳/顶部装饰分开，不能将绳索并入帽围或整体加厚。
`trilby/bowler/top`：来源内腔椭圆与全层共同变换，保持饰带和帽身层次；新增内汗带承托，冠顶空腔不是贴合误差。
`cloche`：来源完整30mm内腔截面，目标22mm工程佩戴圈；低檐保留。旧不完整截面不再冒充支撑圈。

新生成的五款汗带先寻找完整源内腔截面，必要的2mm步进向上定位及共同微量扩容都有实际诊断；内部条带下段按原头皮轮廓定尺寸，上段接近帽体内腔，默认1.2mm实体厚度。它是本项目新增构造，非实物测量或原作者纸样。

## 质量含义

结构参数不可被材质、换头、配方导入或异步旧请求意外改写。颜色/织纹可变，不能改变几何。没有来源开口、头部轮廓不完整或出界时明确拒绝，不能猜零半径、缩小人物、放宽成功标准或悄悄返回旧件。

实际支撑从三角面截出的内层/内带测，不把整顶帽子到头皮的中位距离叫帽口空隙。最近三角距离审计和浏览器数组哈希对应；哈希完全一致只证明重复性，不自动证明解剖定位和审美正确。

无发静态量配、物理戴入、毛发耦合、材料压力、用户视觉接受分别记账。每种新人物仍须有坐标基准、原头部哈希和适用范围；本轮未认证全部36人物或任意真实头型。

## 对平台框架的增补

当前用户将目标明确收敛为“先把帽子—头部量配做完”。因此不让长发进度阻塞尺寸程序，也不抢先实现不可靠长发占位。

真正固定一个母型，至少固定来源身份、内外结构、实际承托、坐标/单位、不可变尺寸规则、失败条件、输出记录与回归。类别不同可以使用不同内核，但输入身份和回归协议统一。

资料老师、来源控制网、自己的拟合代码和最终几何身份分开记录。来源控制网驱动并非完全独立解析重构；新汗带不是来源已有原件。错误版本保持历史，不把未通过样本改写为用户认可。

本目录只处理本轮帽子工作；不自动改写其他工作台或在后台运行。未来母本/执行者可显式引用该固定提交，不宣称全系统已经自动采用。


# 头发受压与戴帽子：延后实施的接入方向

用户要求先完成帽子和头部量配。长发还在其他工作台开发，本轮不做长发模拟，也不拿占位头发伪造效果。`hair-contract.mjs`及网页导出是接口约定、身份验证和后续步骤，不是已经工作的物理引擎。

## 不混淆三个问题

1. 本轮：给定无发头形及固定帽型，得到可重复的尺寸、内部承托和最终佩戴位置。
2. 后续：发根绑定原头皮，帽子沿给定轨迹移动，发束弯曲、滑移、相互排挤，帽子内壁与发束接触。柔软帽体可能与头发共同变形；定型帽先按刚性处理。
3. 再后续：人物动作、取下恢复、完整长发/辫子/扎发、摩擦与材料校准。

静态放得下，不证明从上方能够无碰撞戴入。头发受压通常涉及方向变化、弯曲和密度重排，不能用统一放大头模后再缩回代替；也不能缩短发丝段长、删除被夹头发或隐藏穿入点后宣称求解成功。

## 结构化输入

头部使用同一个人物ID、proportion revision、实际几何哈希、米制和已校准头部坐标系。发根需要原头皮三角形ID及重心坐标，保留根位置；发束提供静止曲线、段长、半径、质量、局部弯曲/扭转响应、密度或簇对应及来源版本。发型包络可用于宽阶段碰撞筛选，不能单独证明发束受压真实。

帽子输出实际内层/内汗带碰撞面、法向、材料厚度、支撑区域及母型版本。厚度不是头发预留空间，内部间隙也不是压强。柔软帽子的力学参数缺失时不得伪装成双向材料耦合；先限制为单向的刚性帽/导向束试验。

## 采用的技术老师与边界

NVIDIA，Gilles Daviet，Interactive Hair Simulation on the GPU using ADMM，SIGGRAPH 2023：
https://research.nvidia.com/labs/prl/admm_hair/
原研究采用带库仑摩擦的离散弹性杆和GPU局部—全局求解，并用弯扭、黏滑等实验检查。本项目借鉴“保留杆的弯扭/接触/摩擦、先验证再扩规模”的方向，没有移植该完整求解器或承诺同等速度。

SideFX官方Vellum Solver：
https://www.sidefx.com/docs/houdini/nodes/dop/vellumsolver.html
官方区分实际几何与约束几何，提供厚度、内外接触、摩擦和子步配置。这里采纳数据分层与碰撞子步原则，不声称浏览器已经运行Vellum，也不把官方默认值当作本项目实测毛发参数。

Stetson官方Fit Guide：
https://stetson.com/pages/fit-guide
它强调在实际佩戴位置量围，并区分合身与过紧。这里用于佩戴测量语义，不用于证明代码中的毫米留量、内部汗带厚度或舒适度。

## 第一项未来实验

一组短发导向束＋一个有完整内壁的定型帽。固定发根、保留段长，分时推进帽体，处理发丝—帽子、发丝—头皮、发丝—发丝接触和摩擦。记录最大穿入、长度误差、压缩前后分布、收敛与耗时，再取下帽子检查恢复。先通过单束及小簇的数值反例，再接短发全头。长发根本体、碰撞拓扑及披垂细节不在此轮搭建。

现实约束是实际发束和帽子内壁数据、头部坐标标定、材料/摩擦测量、穿戴轨迹、密集自碰撞成本及目标GPU预算。普通使用者仅给一个头围或照片不能立即得到可靠的真实压强与实物佩戴结果。


# R06 已观察到的适配边界

完整33组原头形/帽型必须保留。额外构造的窄长头形等比放大1.04后的钟形帽，增加帽冠内部检查后需要超过固定母型允许的10%共同径向调整。该组明确拒绝，不自动扩大帽冠、不偷偷回退旧模型，也不计为贴合成功。

99个测试输入对应98个拟合结果和1个明确拒绝。该比例仅是工程压力测试，不是新人物资料。安全上限没有为了使测试全绿而放宽。任何其他组拒绝或原33组失败仍使门禁失败。

此前发现窄长原头形的钟形帽上额部穿入：只检查汗带不充分。新增真实帽冠截面检查并以整个源帽组件共同变换保留饰带/帽檐层次；原失败数据不能用于称成功。
