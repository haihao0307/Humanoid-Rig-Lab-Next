## 外部一手资料与采用边界

1. Stetson官方量帽指南： https://stetson.com/pages/fit-guide ，https://blog.stetson.com/how-to-determine-your-hat-size/ 。量帽应围绕实际佩戴位置，不是取整颗头含耳朵的最大包围盒。本轮没有把现有头模未标注的眉骨、耳尖自动认作已检测到的解剖标志。
2. Stolen Stitches Taffy Twist： https://stolenstitches.com/products/taffy-twist-hat-pattern 。针织帽负松量依赖款式与材料；该模式参考不能推广为所有针织统一百分比。本轮0–18%为明确可调的工程探索范围，默认值未经实物拉伸标定。
3. Knit Darling Rosendale： https://www.knitdarling.com/patterns/rosendale-slouchy-hat 。紧贴帽口和上部垂坠留量可以共存；“贴合”不能变成所有帽冠都必须吸附头皮。高顶/礼帽的顶部内腔同样不能一概视为错误。
4. Cornell Yarn Cloth： https://www.cs.cornell.edu/projects/YarnCloth/ ；Stanford YarnSim： https://graphics.stanford.edu/projects/yarnsim/ 。真实针织响应涉及纱线、弯曲和接触，本轮只吸收原长与拉伸状态应分开的概念。程序纹理是过滤后的着色器浮雕，不是这些纱线求解器的复刻。
5. Bridson、Fedkiw、Anderson的布料碰撞研究： https://www.graphics.stanford.edu/papers/cloth-sig02/ 。布料厚度与运动碰撞需要明确处理。本轮径向截面外推是静态采样保护，不能冒称连续碰撞或压力/舒适度。

本轮只用非中国网站的一手来源；资料链接不是视觉或物理通过的证据。

## 实现与可复现的数据链路

来源控制网/拓扑/UV → 浏览器Catmull-Clark程序再生 → 帽冠/帽檐/帽带/后倾等分区参数 → 实际头形三角网截面 → 分类适配 → 静态外推保护 → 显示与独立诊断。

头形保持原顶点和原尺寸。佩戴圈从当前坐标Y=12mm工程候选开始，可以显示并调整；不是自动眉骨/耳尖识别。记录截面软尺周长、表面环长、宽深、前后冠弧、左右冠弧。耳朵、鼻尖、冠弧、帽带圈不能随意混为同一尺寸。

针织帽按实际头部从帽口到顶部的轮廓包裹；松冠预设保留受控上部留量。机织帽、定型礼帽、空顶帽和褶裥厨师帽分别处理承托圈及帽冠，不把全部区域缩成头皮形状。毛发留量只是显式几何占位，不是已生成或已压缩的头发。

负松量只改变未拉伸帽口原长与所需伸长记录；它不把已佩戴帽子的几何缩进头皮。未进行材质试片标定，不能根据该值推断压力、安全或舒适度。

## “程序化”必须分级说清楚

本轮所有11款运行时网格从署名来源控制网和拓扑重新生成，新增分区形变和配方；资源包不放烘焙的最终帽子显示网格。控制点、原UV和保真贴图仍来自作者，其权利归属没有变化。

这属于“来源控制网驱动的可再生参数母体”，不是摆放一个已定型网格后只加全局缩放，也不是已经完成完全独立、低维纯解析函数的重构。某些来源控制网仍然很密，不假称所有款式都已压成极小公式。

保真材质默认不改；可切程序毛呢、斜纹、针织浮雕并调整毫米尺度、颜色和起伏。程序材质暂不宣称与原贴图同等级，更不宣称影视级纱线几何。

## 框架新增门槛

参数输出需区分原型、原长、佩戴后形态与物理响应；每项声明其有效品类，不适用的控制禁用。不能用只改变界面数字的滑块冒称真实几何变化。用户认可只覆盖当时可见范围，不能从R02外观认可推导R03贴合合格。

从真实用户反馈提取可迁移规则；例如头围不能用含耳朵包围盒代替、负松量不能造成穿头、贴合不能抹掉帽类特征、控制网/解析函数/烘焙网格必须分开说明。某款帽子的坐标、高度和校准常量只留在该母体配方。

机器验收包含原型再生误差、头形不变、全11款×3头形的有限值与采样、原版对照、实际参数响应、文件导出/导入、材质编译、桌面与手机视口、file://零核心网络和固定HTTPS。测试数字仍不是人工美感或连续碰撞通过。
