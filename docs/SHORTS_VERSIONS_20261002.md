# 短裤双版本开发记录

原版 A 是用户认可外形的 R24 静态版本；保留原文件的 SHA256 和固定网址，不重新生成或覆盖。新版 B 单独使用当前 R008 人物的实际生成几何量体，目标为按用户确认的原版小臂中段降低腰口（原身高的 3.46933%，当前人物约 62.43 mm）、裤脚不变、38 mm 亚麻腰头布套与独立有限弹力带。

**当前状态：开发源码，穿着与布料动作尚未通过。不能作为完成版或生产版发布。**

历史候选曾验证原版 / 新版 / 原版离线切换、新纸样面积与质量、19 条真实接缝和四个制造阶段终态。这些证据只对应当时冻结的源码与人体；最新腰口修正版不能继承历史通过状态。最新制造过程仍在腰头阶段 HOLD；折叠制造终态也不能代表已穿着或动作通过。

根因审查确认了两处初始化错误：裤脚纸样约 863 mm，却被旧目标压到约 544 mm 的腿围；主片腰向与横向混用，使侧腰落到错误侧。`ShortsBoundaryTargets.mjs` 已独立生成逐边等长、包围实际腿部截面的裤脚外环。`ShortsExteriorFrames.mjs` 是独立裁片外部支持面初态；它不代表已闭合的裤子，也不代表穿着或物理动作验收。旧失败记录与原制造路径保留。

GitHub 开发分支仅保存生成源码、关系、参数接口、检查脚本和状态说明。没有提交历史 HTML 构建、烘焙布料顶点、截图、预制模型或贴图。原版固定文件通过 `ShortsVersions.mjs` 中的 URL 与 SHA256 识别；构建双版本时获取或传入原文件并核对字节。

在仓库根目录安装运行时代码并构建内部候选：

```sh
cd New-Human-Production/R008
npm run runtime
npm run entry
npm run standalone
node tools/build-shorts-comparison.mjs
```

最后一条命令需要联网获取固定原版。也可以传入原版本地 HTML、候选 HTML 和输出 HTML 三个路径；生成后单体双版本文件不依赖核心网络资源。候选仍会显示未通过状态并禁用布料动作，不会自动发布。

源纸样检查：`node tools/probe-shorts-draft.mjs`。仓库根目录的 `node tools/probe-shorts-boundary-targets.cjs` 检查裤脚目标；`node New-Human-Production/R008/tools/probe-shorts-exterior.mjs` 检查独立裁片初态。这些几何检查不能替代完整穿着、身体 / 自碰撞、弹力带和人物动作验收。

本轮另修复了实际最近面 / 边 / 顶点的接触方向查询，避免远处点被错误单面法线判为内部。当前人体 1,401 个独立外部裁片查询通过，真实表面内侧仍触发接触；完整人体实体拓扑和连续碰撞尚未验收。

`ShortsWearingHinges.mjs` 已增加真实 11 条源接缝、491 个自由度的连通裤身临时调整路径。单次构造松开后纸样应变约 4.71%，但衣口最大目标偏差约 62 mm、最近特征负距离约 37 mm，因此仍 HOLD。它没有改变纸样、质量或材料参考，没有关闭最后腰头，也没有运行布料动作。目标场自身不满足纸样度量，不能据此断言纸样必然不适合人体。

后续必须完成连通裤身的连续低应变外部放置，再关闭最后腰头，执行真实站立、走路、跑步、跳跃和停止后的布料检查。通过独立验收后才晋级并更新公开测试网站。

2026-10-02 腰口位置修正版（v3）：用户明确降低腰口，裤脚长度保留。ShortsWaistFit.mjs 以原版32个真实W.upper边点平均高度和原版小臂中点的同坐标标高确定下降比例，再按当前真实生成身高自动换算；不会取不同姿势的新人物手臂来改变版型目标。BodyAdapter 的裆部量体轴固定到原衣物参考中线，避免降低腰口同时移动裆底和裤脚。实际最新GameAnimator中立人物检查通过：下移62.433毫米、38毫米腰头、全裤脚顶点最大移动0米、原人物骨骼姿态不变。

接缝光照修复：Runtime 在实际已缝合的quotient拓扑上计算一致的面积加权法线，再回填源UV顶点；独立未缝布片不合并，位置/纸样/质量/材质与物理状态保持不变。它只修接缝明暗断线，不代表低分辨率轮廓、褶皱或布料悬垂已完成。

新版工作台明确分开“量体版型位置预览”和“真实纸样缝合检查”。前者显示新腰口及固定裤脚的源参数生成位置，尚不满足纸样应变，禁止当成已穿成布料；后者保留真实缝合制造终态。两种模式均禁用未通过的动作，不把静态纹理当物理。单次有界静态试穿仍失败（最大布料主应变约52.53%；实验量体轴随后已修正，该试验不证明修正版）。原版文件仍字节不变。

最新双版本入口会在原版加载后只读提取其实际运行态折叠方向，原版字节、时间和物理状态不变。`ShortsAcceptedSeedTransfer.mjs` 通过极分解去掉原版伸缩，用新版独立二维纸样的长度恢复19条实际接缝、451个自由点的连通初态；临时坐标不写入源码，也不作为新布料静止形状。`ShortsWearingMetric.mjs` 再做最多40次整体静态调整，保留5%应变、4毫米采样间隙、8毫米标高门限；它不执行布料物理时间步。

唯一实际中立人物实验结果：初态应变45.94%，最终34.59%，采样人体间隙残差5.60毫米，裤脚最大标高误差9.38毫米，第25次独立导数检查停止。状态仍 HOLD，不能继续盲目增加迭代或开放动作。原版方向帮助构造初态，但新旧纸样对应方向仍不完全可积分，尚不能据此判断新版纸样本身不可穿。

新版初次打开只启动有界试穿调整，耗时制造诊断由“查看布料缝合检查”手动启动；不会每次加载自动重复失败的完整制造过程。测试入口：[本机双版本工作台](http://127.0.0.1:8883/qa/shorts-two-versions-20261002/index.html)。此为内部候选，不能替代公开完成版。

历史v3限制（本轮已替换显示与接触）：当时R008原裤下面缺少独立裸身腰胯和上大腿，保留原裤作碰撞外包络与对照。因此新低腰口上方可见旧黑色腰头；这是源人体覆盖缺失，不能通过隐藏网格或换肤色冒充已修复。松紧边和布料求解通道已保留，物理悬垂、完整三角接触、自碰撞和站走跑跳验收仍未通过。

最新真实浏览器 A→B→A 检查与中立人物实验独立：临时参考成功只读转移，451个自由点，无核心网络请求或浏览器错误，候选动作守卫通过。实际浏览器姿态下静态调整8次后HOLD，耗时3.82秒，应变38.07%，采样间隙残差9.86毫米，标高误差26.31毫米；制造腰头终态应变5.1966%仍不通过。此结果不继承中立实验数字，完整验收为失败。原版文件SHA256保持2b9158f76cd75aef5605be86bd7092c406d333467ce116eca130f166580635da。

最终v7实际覆盖检查：用当前原生皮肤和补体共同查询2,599个样本，有限1轮几何放置，原后裆26段交线降到0；独立全静态重查30,928个重叠候选对未发现交叉。腰头上下沿、中线、裤脚目标WORLD高度误差0，原版保全与切回通过。四方向未见此前皮肤岛；侧面射线受原生手臂遮挡，不能据此声称整个视角都有无遮挡证明。原生仍有120个相关零面积面，布料与補体无零面积面，完整实体认证仍HOLD。
