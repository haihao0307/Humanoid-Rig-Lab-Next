# R20 连续实施记录：身体结构、动作与局部函数

## 实际实现

- `BodyAnatomyR20.js`：胸廓、锁骨、胸腹、肩胛、背腰、骨盆、臀部以及上臂/前臂/大腿/小腿的外表结构函数。使用支撑坐标和长骨方向定位，体脂在几何上减弱肌肉起伏。新增有限的肩带、屈髋和屈肘软组织响应；这是外形估计，不是内部解剖测量。
- `BodyArticulationR20.js`：将双四元数的刚性修正与原有完整仿射贡献混合，保留原关节条件下的每项贡献与非刚性残差。旧档案不自动启用。法线及材料坐标也随修正变换。
- `BodyDigitsR20.js`：连续掌体、鱼际、指节和指腹，腕部桥接、掌背细脊与掌纹、指甲表面。尺寸和端点由当前来源数据校准，动作由当前支撑定位。对原采样拟合的替换限定在局部，不宣称整只手的来源已经独立。
- `BodyFeetR20.js`：跟部、足弓、前掌、脚趾及腕踝式连续桥接，保留脚趾弯曲与两套驱动。局部形状函数由项目编写，尺寸/绑定仍有来源。
- `BodyRayR20.js`：直接求隐式函数交点；乳头与脐部等小尺度结构改变实际零面。GL_POINTS承担屏幕采样，不生成身体三角面。材料和噪波由函数生成，没有图片皮肤或外部模型。
- `BodyImplicitAppR20.js`：统一体型操作、五组动作入口、三种观察光与人物原光、平移和近距离缩放。完整人物保留当前头部状态；载入与接口恢复共用同一条路径，保存本页的观察光设置。

## 实施过程中发现并继续修正

1. 单纯增大结构幅度仍会被宽拟合与平滑压掉。尝试更小拟合核与短差分后出现块状采样波纹，未保留该组合；改为较宽几何差分与单独的小尺度表面导数。
2. 第一版连续手指直接切回旧掌体，出现厚指根与掌部裂隙。随后引入连续掌体、限制不合理的指根/末节半径比，并减薄掌体。
3. 左右掌坐标的叉积会在镜像下反向，导致指甲与掌侧不一致；显式加入左右手方向约定，做镜像函数检查。
4. 原局部场沿手足平均方向切换，在踝部会由盒边界主导并产生环状接痕；当前改为沿前臂/小腿方向进行有限宽度过渡。
5. 校准档从旧基线建立时可能覆盖后来由头部板块更新的状态；本版显式保留当前头部组合、GNM、面部动作、头颈姿态与表情，并保留当前身体驱动。

## 接触、尺寸与颈口的继续修正

新增 `BodyLocalCompositionR20` 在局部覆盖时保护邻近其他身体表面；`BodyContactFieldR20` 按静止参考邻域分别拟合接触处的场并取并集，避免把靠近的手臂与躯干错误平均成碎裂缝；`BodyInteriorR20` 用保守的闭合内部支撑补足肢体内部符号，仍不把动画定位点当作测得的内部骨骼。`BodyNeckClosureR20` 只在身体侧颈部参考域对当前边界拟合封口平面，不裁切抬高的手臂，不修改头部状态。

小年龄试运行发现固定成人尺寸下限和固定世界精度不成立，已让手足范围、拟合核、体素间距与求交步长随支撑尺度变化。最新边界例包括年龄轴0、较高偏瘦档、手臂靠近躯干和MHR手足缩放/弯曲。输入和结果保存在edge-cases.json；不把这四例说成全范围认证。

页面把动作系统切换放到常用入口；计算时显示当前更新区域。已提交给后台的压缩数据及巨大的内联脚本不再持续留在主线程。构建先写完整临时文件再原子替换，避免工作页读到写了一半的版本。
