# 函数、变量与噪波：当前身体如何构成

母体是同一组数值函数：形态系数混合、关节变换、每个影响的完整加权、隐式表面重建和表面求交。个体变量沿用原来的身体参数与动作状态；全套人物变量也随档案保留，头部变量由另一板块使用。内部另有拟合/校准系数，它们是几何表达所需的变量，不能与少数用户滑杆混为一谈。

身体形状表达为标量函数`F(x,y,z;变量)=0`。当前由参数函数计算9253个有方向的身体采样，再建立连续插值的标量系数场。此处采样不是多边形顶点：没有邻接面、三角连接或模型绘制指令。手和脚使用四个额外的局部系数场，避免全身统一精度吞掉指趾间隙。

数值场是函数的系数缓存，修改个体变量后重新求值；人物档案只存变量，不存逐帧表面网格。它不是导入的皮肤贴图。肤色变化、毛孔感、粗糙度与薄油膜由材质函数及噪波处理。当前噪波材料尚未完整复现旧平台所有外观通道，不能宣称整体皮肤已等价。

R05额外缓存三个参考坐标通道：以完整加权变换的局部逆映射，将当前表面位置关联回同一个身体母体的参考位置。噪波使用这个参考坐标，不直接使用运动后的世界位置。该通道依然是数值函数系数，不是颜色图片或三角面。当前已用整体平移做独立检查，完整弯曲和非刚性变形的材质对应仍需继续核对。

显示端沿像素视线寻找函数零点，由函数差分求法线，再计算照明。为了执行片元函数，屏幕只使用`GL_POINTS`覆盖像素；没有生成角色三角面，也没有全屏三角形、面索引或人物顶点缓冲。新的交付不载入Three.js、外部模型或图片资产。

R08将几何梯度与着色方向进一步分开：躯干用有方向采样计算平滑方向函数，并缓存方向系数；表面求交仍用同一个标量函数。这个方向场不改变几何，也不生成多边形。手足仍使用局部梯度。具体近似与限制见NORMAL-FIELD-R08.md，不能将受光更平顺等同为拟合精度提高。

本阶段R15保留原核，使用正则最小二乘求校正系数；局部场及法线尺度以关节方向的连续权重过渡。显示越过函数零点后做区间细化，并减小停止阈值。实际像素交点与函数表面已分别核对；它与函数对原身体的拟合误差是两件事。详见CONTINUITY-AND-RAY-R15.md。

当前标量场只是局部拟合的近似距离，不是经过全局Lipschitz证明的精确SDF。步进、局部场切换、关节接触和薄小结构需要实际视图检查；不能用“采用隐式函数”代替视觉验收。

`data/body-function-program.json`保存数值系数、字段和关系。结构审查排除了`faces`、`triangles`、`quads`等连接表；数组中仍有采样索引、骨骼索引和加权对应关系，这些用于函数运算，不用于构造多边形。所有源于原模型的数值继续标为来源推导，不能改称来源已清除。

原模型的三角连接只在单独的旧版参照环境中，用于抽取独立表面检查点；不会进入新的函数身体交付。检查点没有参与当前标量场生成，因此不能用训练点误差替代这些留出点的表面误差。
