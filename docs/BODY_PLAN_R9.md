# R9：175 cm 比例、臀腿与足部

这轮根据用户提供的侧面图调整：保留小腿肌肉分区，增加整体厚度；重新组织脚跟、足弓、跖骨和脚趾比例；缩短髋到踝的骨架长度，并重做臀腿衔接。新增角色外形与任务预设，作为后续复制不同 NPC 的数据入口。

本轮代理只检查文件内容，没有启动页面、实例化人体、运行姿态、编译 GPU 着色器或生成修改后的截图。文件检查结果不代表外形和动作已经验收。

## 比例依据与设计值

175 cm 是用户指定的角色基准。AIST 1997–98 青年男性样本的身高均值为 1705.8 mm、足长 253.2 mm、足宽 101.6 mm、小腿围 356.0 mm；这是特定年代和样本的数据，用于参考比例，不能称为全亚洲人群的平均值。[AIST 原始统计表，第 1 页](https://www.airc.aist.go.jp/dhrt/97-98_Statistics.pdf)

| 项目 | R8 参数 | R9 设计 |
| --- | ---: | ---: |
| 站立目标身高 | 1750 mm | 1750 mm |
| 髋至膝关节段长 | 440 mm | 412 mm |
| 膝至踝关节段长 | 425 mm | 404 mm |
| 站立髋关节高度，由参数计算 | 938.11 mm | 889.15 mm |
| 足长名义值 | 272 mm | 260 mm |
| 足宽名义值 | 96 mm | 104 mm |
| 小腿最大围度目标 | 没有统一目标 | 370 mm |
| 大腿上段最大围度目标 | 没有统一目标 | 552 mm |

关节中心段长、外部测量标志和骨网格的完整长度是不同量。表中 R9 围度是构造目标；最终细分皮肤的尺寸、姿态后的围度与接触情况仍须实测。

髋到踝共缩短 49 mm。`adultPresetSpec` 将对应的约 48.96 mm 站立高度差分配到腰胸段：从髋上 65 mm 开始平滑增加，在原 T1 高度处完成。颈椎与头部整体平移，颈部局部长度保留；`HEAD_ROOT_Y` 继续由总身高求得。胸廓、肩部开口、背部包络和蒙皮区域使用同一坐标换算，避免各自保留旧高度。

## 骨架、肌肉与皮肤

股骨既有的前弓和侧向骨干偏置保留，站立膝屈仍为 5°。大腿皮肤使用股骨、髌骨的采样包络，再叠加前侧股四头肌、后侧股二头肌长头／半膜肌／半腱肌和内侧大收肌／长收肌的体积。骨骼形态及肌群关系参考 [Dartmouth 第 12 章](https://humananatomy.host.dartmouth.edu/BHA/public_html/part_3/chapter_12.html)和[第 15 章](https://humananatomy.host.dartmouth.edu/BHA/public_html/part_3/chapter_15.html)。

小腿保留腓肠肌内外侧头、比目鱼肌、胫骨前肌和腓骨肌群的走向与纵向分布。增加连续的深层体积，用截面周长约束整体粗细，再用同一厚度数据生成皮肤和肌肉片。围度拟合在关节附近淡出，保留膝、踝的骨性支撑；若可用的缩放范围不能达到目标，结构报告会记录误差。

臀大肌的骨盆段与向大腿延伸的体积共同参与覆盖。臀腿开口仍共享原来的边界索引，连接曲线使用新大腿表面的切线。臀中肌位于更深的外侧层；这些层次参考 [Dartmouth 第 14 章](https://humananatomy.host.dartmouth.edu/BHA/public_html/part_3/chapter_14.html)。本版只细分主要体积，尚未逐一表示全部深层小肌、韧带或肌腱受力。

足部重新设计了跟骨后段、距骨、舟骨、楔骨、骰骨及五条跖骨射线。跟垫边界收至踝后约 67 mm，跖骨头向前重新排列，缩短外露脚趾所占比例；默认趾骨下压角从 R8 的 14–29° 改为 4–10°。每足仍是 7 块跗骨、5 块跖骨和 14 块趾骨，拇趾两节、其余三节。

足底保留内侧较高、外侧较低的纵弓及跟垫、前掌垫。足背与足底对骨包络分别留出设计余量，并以平滑包覆替代逐点硬顶出；骨突仍需在页面中核对。足弓的结构关系参考 [Dartmouth 第 17 章](https://humananatomy.host.dartmouth.edu/BHA/public_html/part_3/chapter_17.html)。当前足弓是静态构造，未实现韧带张力、足内在肌四层细分或受力塌陷。

## 用户检查入口

打开当前 `index.html`，进入 **臀腿与足部**。查看范围可选 **脚与小腿／臀腿／全身比例**，方向可选正面、内外侧、背面、俯视和斜侧；灰模、肤色、骨骼、硬基底、支撑体和肌肉图层沿用同一个人物。

先核对全身髋、膝高度，再查看臀下缘到后侧大腿的连接、小腿内外侧厚度、跟垫与足弓、趾根与趾尖比例。姿态按钮用于进一步查看膝、踝和脚趾的连接。**保存当前视图** 导出 PNG；**导出结构检查报告** 保存骨包络残差、围度构造目标与估计、肌肉片异常、趾甲投影缺失及当前关节信息。

## 可变角色与预先分配的任务

**体型参数** 提供小腿体积、大腿体积、臀部体积和软组织厚度。修改后点击 **应用体型**。**角色预设** 可以按种子选择有界的体型、肩部、颈部及肤色变化，并导出为 `jarvis/character_preset@1` JSON。同一种子与同一基准得到相同参数。

预设保存外形、身份、种子和任务文本；示例见 `examples/characters/`。当前预设固定使用 175 cm 的 R9 骨架。手部独立尺寸、人脸身份、服装、发型及任意身高尚未纳入这个预设格式。

导入预设会修改当前人物，任务可由 **返回场景并执行任务** 启动。供后续场景装载器使用的 `window.__CHARACTER_PRESET__` 必须在人物运行源码之前设置；若其中 `task.startOnSpawn` 为真，代码会在场景与 Agent 准备好后提交任务。任务对象在实际场景中解析，解析失败会记录原因，不会伪造目标。

人物子页提供以下接口：

```js
const preset = HumanLab.character.sample(17);
preset.task = { command: '挥手', startOnSpawn: true };
await HumanLab.character.apply(preset);
HumanLab.character.startTask();
const saved = HumanLab.character.export();
```

本轮没有增加批量 NPC 运行器。下一阶段可以按“骨架版本＋体型参数”复用构造结果，给每个角色独立的姿态、动作队列和运行状态，再补充距离分级与批量渲染。当前单角色的骨基底已经在形体重建间缓存，普通动作只更新已有姿态和渲染数据；大量角色的初始化耗时、显存与帧率尚未测量。

检查脚本为 `tools/verify-body-plan-r9.mjs`，结果保存到 `tests/body-plan-r9/file-qa.json`；最终数量以该报告为准。检查只处理文本、JSON、源码语法、参数算术、哈希和压缩载荷，不导入人体模块。R8 和更早报告保留为历史，不能用来证明 R9 的外观或动作效果。

本轮修改前保存了 45 个文件，随后在改动两份 README 前补充备份。清单位于 `backups/body-plan-r9-20260908/hashes.json` 和 `additional-hashes.json`。

两侧大腿、小腿、足部径向网格合计 77,952 字节，围度缩放系数 1,168 字节；这些只是指定数组的容量，不含骨副本、采样数据、皮肤、28 个下肢肌肉片、趾甲与 GPU 缓冲。体积守恒、完整三角形碰撞、足底接触和运动状态下的趾甲贴合未验证。
