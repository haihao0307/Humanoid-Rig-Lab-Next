# R23 骨性框架与主要运动肌群

2026-10-04：本轮交付两种可切换的真实三维展示，不改写 R22 的体型生成或升级其极端体型验收状态。

本机入口：`http://127.0.0.1:8877/?version=R008-motion-anatomy-23&anatomy=framework` 与 `anatomy=muscles`。同一工作台通过两个按钮切换；支持拖动旋转、滚轮缩放、表面比例对照、肌群/拮抗对选择、动作播放与相对绑定姿势角度滑块。进入解剖展示暂停角色控制，退出恢复原人物可见性与检查状态。

## 证据、模型与可复用边界

- **观测**：现有61骨骼绑定的父子关系、逆绑定矩阵、关节位置、骨段长度和当前来源的坐标架。R008 原表面没有自身骨骼，本绑定继承并适配于此前人物，不声称由外表面独立恢复了真实内部骨骼。
- **估计**：长骨宽度、胸廓肋骨、骨盆、肩胛、颅骨、腕足结构的几何表达；24类左右共48个主要运动肌肉/肌群的路径、附着、肌腹和肌腱。此为功能性示意，未复刻全部206块骨骼或全部肌肉。胸廓表达10对示意肋弧，不是完整12对解剖复刻。
- **NotObserved**：真实骨表面、个体肌肉附着、纤维架构、内部肌肉边界、肌肉生理激活、力量、肌腱刚度和神经控制。
- 新人物按 `AnatomyAnalysis` 重建语义、轴与身高后，再拟合路径；骨架缺失或歧义明确拒绝。数学测试覆盖缩放、旋转、平移的新来源，但不把通过测试称作所有物种/年龄/畸形或所有角色的自动解剖验收。

| 文件 | 责任 | 持久化 |
| --- | --- | --- |

| tools/test-motor-anatomy.mjs | 语义/尺度变换、拮抗、截面体积代理、退化输入测试 | 数学测试 |
| tools/motor-anatomy-review.cjs | 当前人物实际渲染和真实 DOM 事件验证 | QA 程序；截图在忽略目录 |

骨局部锚点：`a_local = inverse(B_bind) * a_bind`；当前人物坐标：`a_now = inverse(actor_now) * B_now * a_local`。每个路径点属于明确骨段，不能把所有端点刚性绑在同一块骨上，也不能只把静态线路随人物整体平移。

曲线路径按36段采样，肌腹截面使用连续轮廓，中段膨大、端段为较细肌腱。设剖面权重为 `w(t)`、当前加权弧长为 `I = integral(w² ds)`，半径比例 `s = sqrt(I_rest / I_now)`，截面体积代理 `V_proxy = pi * R0² * s² * I_now` 保持不变。它是显示模型的截面积分近似，不等于弯曲管道真实封闭网格体积，也不是人体生理上严格常体积的证明。

颜色阈值：路径比小于0.98呈红橙（缩短）、大于1.02呈蓝（拉长），其余为中性红；选中肌群为黄。颜色来自运动几何，不是 EMG、激活或受力。屈肘/屈膝展示为孤立关节运动，可能抬离地面，不承担站立接触求解。行走/跑步使用现有人物的动作曲线。

肩外展示例使用绑定姿势相对角度，不声称求解完整肩胛肱骨节律。当前没有 OpenSim 式球体/椭球绕行求解、肌肉间碰撞、筋膜滑移、真实力矩和肌肉力驱动运动。存在肌群重叠，宽肌采用简化肌束，不能直接用该展示宣称 R22 胖瘦表面已由真实肌肉内部解剖驱动。原外表面、原参数包和原体型算法未被替换。

## 方法来源与本轮修正

- [OpenSim Muscle Editor](https://opensimconfluence.atlassian.net/wiki/spaces/OpenSim/pages/53090145/Muscle%20Editor)：明确固定点的所属局部骨框架以及路径、via点、moving点和wrap点的区别。本轮实施骨局部固定点和估计路径，没有移植其模型或宣称实现wrap/力学。
- [Wilhelms / Van Gelder, Anatomically Based Modeling](https://graphics.stanford.edu/courses/cs448-01-spring/papers/wilhelms.pdf)：参照骨架/肌肉/表皮分层以及变形截面、长度与宽度变化思路；文章指出常体积只是近似，端部和弯曲截面会影响实际体积。本轮自创加权弧长截面代理。
- 第一次实际画面检查发现肋笼偏低：人物 `spine_03` 位于约1.297m，颈约1.515m，名字“chest”不能当胸廓上缘。已改用当前颈/肩带地标拟合胸廓上缘，同时上移胸大肌/三角肌后束的估计起点。不能恢复为按骨名猜内部器官位置的方法。
- 本轮只读取方法，没有引入外部人体网格、贴图或预制模型。观察与估计的边界持续写入工作台和接口报告。
