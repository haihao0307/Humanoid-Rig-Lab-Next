# R26 同一反推方法，保留不同人物的数据差异

2026-10-04。用户要求统一的是处理过程：不同人物采用同一套方法，输出应保留该人物的结构差异。固定方法不等于固定人物尺寸，更不等于将所有外形差异直接当作骨骼或肌肉差异。

[骨架展示](http://127.0.0.1:8877/?version=R008-method-26&anatomy=framework)、[同数据肌群展示](http://127.0.0.1:8877/?version=R008-method-26&anatomy=muscles)、[表面与原绑定对照](http://127.0.0.1:8877/?version=R008-method-26&anatomy=inverse)现由同一份结果生成。工作台仍保留原游戏绑定，动作演示使用该绑定的运动学。候选骨架与肌肉估计未升级为力量驱动动力学。

## 固定方法与个体数据的界线

`HumanInverseMethod.mjs`固定`human/surface-musculoskeletal-inverse@1`：六个阶段、采样/截面质量、端点求解规则、局部表面约束、肌群显示比例、成人组成条件及证据规则。配置深冻结。`HumanInverseSystem.mjs`是统一入口，禁止来源适配器覆盖这些参数。`HumanBodySpecies.mjs`保留全体支持成人共用的肌肉/SAT分配、增长与年龄先验。方法版本变更后必须对所有测试来源执行同样流程，不能以“只适合这个人物”为理由单独调数字。

| 固定、所有人物共用 | 每个人物单独计算/输入 |
| --- | --- |
| 角色语义、分段与求解次序 | 自己的来源表面、初始骨架或语义标志、坐标架 |
| 截面拟合、拒绝规则与关节合并 | 自己的左右中心、截面轴、有效覆盖与残差 |
| 组织预算公式、肌群关系和约束 | 自己的截面代理体积、路径长度、局部空间 |
| 缺失数据与不确定性的表达 | 哪些部位有观测、哪些部位只剩先验 |
| 同一身份骨架保持规则 | 不同身份允许不同骨性比例；同身份组成变化另处理 |

新来源的适配器只允许`sourceId/materialRegions/evidence/protectedRegions/interpretation`。其中`materialRegions`仅把该来源的外部部件对应到统一语义，如`upperarm_l/torso/clothing`，不得塞入半径或缩放系数。当前R008专属文件只做此对应。新模型不能沿用R008部件号，也不能改变通用人体公式来迁就自己的模型。

## 六阶段计算

1. **语义与坐标架**：使用该来源自己的无歧义分析结果。单位与左右/前后、父子关系须明确；原绑定只作初值。当前仍需要初始人形骨架或人工语义标志，不是任意无骨架网格自动复原内部解剖。
2. **参考表面约束**：同一采样与稳健椭圆截面规则，排除衣物。保留原表面生成器，不将输入人物改造成平均模型。截面只是数据摘要，不能声称无损表达全部表面细节；完整外形仍由原参数场保存。
3. **骨架候选**：按R25局部端点和共享关节规则求解，保留人物自己的长度、轴向和左右差异；未知处保留先验及状态，不填成“精确数据”。同一身份只建一次参考骨架。
4. **独立组织预算**：对每个有效截面`A=πab`，沿段长以分箱厚度累加观测覆盖部分的代理体积。支持核、肌肉和SAT分别分配，不以围度增加等同肌肉增加。
5. **主要运动肌群**：48个共同语义的肌群，以候选关节拟合路径；按所属区预算及共同路径份额分配尺寸，并在有局部观测的地方约束到皮肤包络以内。未观测的臀部、髂腰肌及不完整大腿保留明确的先验状态。
6. **校验与导出**：记录骨段误差状态、外表面残差、组织先验、附着估计、输入完整性；导出关节、截面参数、组织预算和肌肉路径关系，不导出扫描顶点数组。

## 组织与路径数学

物种分区的共同图形先验为`c=coreFraction`、`s=satFraction`。截面中`support=A*c²`，`muscle=A*((1-s)²-c²)`，`fat=A*(1-(1-s)²)`，三者之和严格等于该观测截面面积。它是外形空间分配，**支持核不是实测骨体积，肌肉/SAT分配不是真实组织分割**。肌肉、脂肪、皮肤外形之间存在不可唯一分离的情况，必须记录先验与未知项。

该人物每个主肌群的共同路径先验份额为`priorVolume/sum(regionPriorVolumes)`；可用区域的肌肉代理预算中55%用于主肌群可视化，余量代表未显示组织。55%是共用图形选择，不是医学比例。肌腹截面采用已有`bellyProfile(t)`，体积代理`V=πr²∫bellyProfile² ds`；目标预算给出`r=sqrt(V/(πW))`。渲染器按实际曲线的积分重新换算半径，使实际显示近似体积与该预算一致。

局部附着点只在有近邻截面时约束，保留沿骨段的位置并限制法平面上的偏移。表面包络留出肌腹半径；半径上限或数据缺口会产生未表示预算，必须记录，不能撑破人物或把皮肤点叫做真正骨附着。

同一身份的组成状态使用`human/reference-composition@1`，只包含`fatness/muscle/age`，不绑定R008模型名称或身高范围。身高和肢体比例属于输入身份；骨架参考数据深冻结。脂肪变化只走脂肪预算；肌肉量与年龄条件走肌肉预算。状态变化不重新反推骨架、不改写参考肌肉量。该接口目前为数据层；原体型着色器仍使用R22成人组成系统，本轮没有宣称已重写全部体型或解决R22极端造型问题。

## 可复用性与真实精度

“不同形体原封不动保留”落实为：原表面参数生成器不变；个体关节/截面/左右差异不被固定身高模板覆盖；同一方法生成相应尺寸与路径。**不能据此外推成真实内部结构无损恢复**。单一表面无法区分每种肌肉/脂肪组合，也无法测得骨径和真实附着点；此处使用共同先验，并非训练得到的完整解剖回归器。

当前数学测试覆盖支持的成人比例、局部厚度差异、刚性变换、缩放、材料重排和网格密度；不代表儿童发育、病理畸形、任意衣物、任意网格或非人类物种自动验收。面对这些输入仍按相同的证据/求解流程处理，但需要条件规则扩展或明确拒绝，不能偷偷放宽当前人物的阈值。

## 方法来源与未采用路线

- [SKEL研究](https://skel.is.tue.mpg.de/)说明共同模型空间可以结合个体数据拟合骨架。这里学习共同方法与个体参数分离；没有使用其模型、学习参数或网格。
- [Inside Humans原论文](https://www.frontiersin.org/journals/virtual-reality/articles/10.3389/frvir.2021.694244/full)用于理解皮肤约束、内部结构先验和信息不足的区别。当前并未实现其体积/力学求解。
- R23肌肉展示只用身高比例决定尺寸，不足以保留同身高人物的局部宽度差异；已让生产展示从统一反推结果接入骨架、预算和路径。R25中心求解及不完整截面拒绝规则保持一致。
- 拒绝“给每个人物单独调肌肉倍率/骨径”的做法，也拒绝“变胖就同比放大骨头”“外表面增厚就全增加肌肉”。这些都违背共用规则与组成分离。
