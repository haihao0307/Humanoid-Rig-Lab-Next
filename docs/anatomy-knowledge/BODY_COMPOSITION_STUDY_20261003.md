## 先纠正结论

R21 有骨段统计、肌肉名称目录、表面滤波和保护规则，但还没有由独立肌肉与脂肪组织量生成全身体型的模型。现有四个滑块仍主要驱动原表面的经验位移场。骨长不变、接缝为零、衰减函数单调，只说明这些工程性质成立，不能证明人体形态合理。

尤其不能把“看见了肌肉目录”说成“每块肌肉已经参与体型计算”。本轮检索调用关系：`muscleWeight` 用于工作台显示；`muscleState` 没有生产形变调用；`BodyParameters` 仍按固定高度与粗区域变形。

## 必须分开的变量

1. **身份骨架**：同一成人的静态骨段长度、胸廓/骨盆支撑和头骨比例。改变体脂/肌肉不应缩短骨段；姿态仍可以改变骨架位置。不同人物的骨性比例本来可以不同。当前支持包络是作者估计，不能把皮肤半径分位数当真骨轮廓。
2. **肌肉组织量**：各肌群的体积、纵向肌腹分布、截面方向、附着与绕行。减肌肉主要减少软组织，骨头不会一起缩小。增加肌肉也不是均匀放大整条手臂。
3. **脂肪组织量与分布**：皮下脂肪、腹内脂肪等独立描述。全身联动不等于每个部位使用相同膨胀比例；脸、颈、躯干、上臂、前臂、臀腿、手足都需各自响应与边界。
4. **姿态与激活**：肌肉组织量是较长期的体型变量；一瞬间收缩主要改变肌肉形状、力与姿态，不是瞬间长出更多肌肉。肩胛、肘窝、腹股沟等需要局部姿态修正与接触。
5. **皮肤状态与外观**：皮肤包络、松弛、表层细节、色素和光照分别处理。增脂后的肌腹可见程度依赖局部覆盖和形状；不应统一抹掉全身纹理，也不应让所有肌纹在所有胖瘦状态下同样鲜明。
6. **年龄先验**：可以影响区域组织分布、肌肉量先验、质量与皮肤状态，但不能把年龄直接视为每个人必然减去同一肌肉量。活动/训练与个体差异尚未观测，须明确默认假设。18岁也不能仅因为小于32岁就一律被扣肌肉。

“同一个肌肉滑块、不同年龄外形不同”可以保留为产品语义：滑块表示同龄条件下的相对肌肉水平，再通过年龄先验得到组织量；UI必须显示其为相对水平，而不能冒充实际肌肉质量。若用户选择绝对体积模式，年龄不能悄悄重写该体积。两种语义不能混用。

## 可实现的数学路线（作者方案，尚未验证）

### A. 规范空间中的紧凑人体描述

持久化 `identity + composition + pose + skin`，以及关系、来源、校准量和置信状态。运行时采样为临时字段，不保存新顶点数组。骨架局部框架只作为定位，必须补充胸廓、骨盆、头部支撑和表皮特征点。统一身高缩放是首版明确的造型约定，不代表不同身高者真实体格都按同一比例变化。

### B. 先给组织体积，再求形状

每个肌群 i 的目标体积 `V_m,i > 0`，各脂肪区域 j 的目标体积 `V_f,j >= 0`。先使用相对基准体积，基准未测得时标为作者校准；不在 UI 显示伪造的 kg 或体脂率。存在可信密度和组织量后才能由质量换算体积。肌肉百分比与体脂百分比不能各自随意变化而忽略共同分母。

区域脂肪分配 `q_j >= 0, sum(q_j)=1, V_f,j=q_j*V_f`。可用归一化正函数保证预算，区域权重的数值必须校准，不能因 softmax 保证正值就认为分布正确。SAT 与腹内造型量分开；后者先视为腹部包络参数，不能声称精确恢复器官。

沿肌肉路径的弧长 s，定义椭圆截面半轴 `a_i(s), b_i(s)`，有 `V_m,i≈integral pi*a_i*b_i ds`。如果两半轴同倍率 k，体积随 k²变化，而不是随 k变化。固定姿态下可求 `k=sqrt(V_target/V_current)`，但弯曲、重叠与肌腱区域需另行计量，不能把该近似直接推广为全身精确体积。

肌腹、肌腱与骨性保护分别建场；屈肌/伸肌截面不同。姿态变化的常体积近似与长期增肌的目标体积变化属于两套计算。

### C. 从组织包络求皮肤，而非对已有肌肉模板加同一位移

先产生骨性支撑与肌肉/其他软组织包络，再求局部皮下层及皮肤。小厚度可暂用 `V_SAT≈integral t(u)dA`；这是薄层近似，大厚度必须重算实际层体积。凸起、凹槽、皮肤锚定、重力与接触会使外形不同于等距偏移；需要正则化与局部约束。

候选校准目标：`E = w_measure*E_measure + w_volume*E_volume + w_support*E_support + w_smooth*E_smooth + w_contact*E_contact`。分别约束围度/宽深、组织量预算、骨性支撑、局部连续性及接触。各项使用统一或归一化量纲；不是任意拼接数值。仅最小化 silhouette 不保证组织正确。规范空间与拓扑邻域应避免靠近的手臂和躯干、双腿之间发生空间滤波串扰。

肌肉外形可见性从局部覆盖与姿态计算。原颜色中已有肌肉阴影时，不能假装仅改法线就解决；需区分反照率与烘焙明暗，无法唯一分离的部分记录不确定性。微观皮肤、肤色、伤疤保留独立通道。

### D. 形状与姿态耦合

体型求解结果须参与局部姿态修正：肩外展、肘屈、髋屈、膝屈的组织压缩/膨出，以及大体型的肢体接触。单纯沿用原瘦体型蒙皮再加体积会穿透或失真。实时版先采用少量作者函数和局部近似，复杂求解放到参数变化时；完整有限元不是本工作台首版承诺。

## 独立算例：检验单位与体积关系

本轮用 Node 计算一个人工圆柱横截面；**不是该人物测量，也不是人体正确性测试**。骨圆半径15mm，肌肉等效面积为 `pi*(35mm)^2`，脂肪环厚5mm，长度固定。外半径 `r = sqrt(r_bone² + A_m/pi) + t`。

| 肌肉体积相对基准 | 骨半径 | 外半径 | 围度 |
| --- | --- | --- | --- |
| 0.5 | 15mm | 33.940mm | 213.249mm |
| 1.0 | 15mm | 43.079mm | 270.672mm |
| 2.0 | 15mm | 56.720mm | 356.385mm |

肌肉减半不需要缩骨；肌肉加倍也不等于手臂半径加倍。固定内层时，5mm与20mm脂肪环面积分别约1274.823mm²和6041.768mm²，厚度与体积并非线性。半径增长10%意味着圆面积增长21%。薄层1m²面积上加1cm厚度约为10L，说明“大一点”的位移必须有量纲与预算。这些是几何反例，只检验计算逻辑，不能确定真人组织分布。

## 下一轮实施顺序与拒绝条件

1. 先做当前人物的参数语义和量尺：静态骨段/保护尺寸、各区域围度/截面、基准外形；真实观测与估计分别标注。不能直接标成完整解剖。
2. 做上臂最小验证区：固定骨支撑，分开屈/伸肌与脂肪壳，同时对照低脂低肌、低脂高肌、高脂低肌、高脂高肌。验证组织预算与轮廓，不先全身推广未校准函数。
3. 扩展躯干、肩背、臀腿、前臂、脸颈及手足，各有分布、末端保护和接触；不是统一倍率。新增人物重新校准局部量尺与未知区域。
4. 接入年龄条件与姿态，比较同一骨架下的变化。肌肉量、质量、力量不混称；绝对/相对语义透明。
5. 用户实际检查全身正/侧/背与屈伸动作，再形成视觉验收。文档、纯函数测试或局部算例均不能代替这一项。

必须拒绝的捷径：继续把参数扩大3倍当机制完善；全身统一模糊；把八权重改名肌肉权重；增加更多肌肉目录条目却不驱动形变；根据单表面宣布精确恢复内部组织；用 R21 老截图证明本轮已修复。

后续需要记录的检查量：骨长与支持不被组成缩放；组织量预算误差；各区域响应的有限差分；围度/截面与目标差；肌纹可见性对局部覆盖的响应；边界与材质连续；局部自交和动作接触；眼睑/足底/伤疤的独立检查。容差随首个校准样例制定，本文不提前伪造验收阈值。
