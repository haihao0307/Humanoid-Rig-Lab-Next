## 证据必须分层

| 项目 | 当前实际数据 | 允许推导 | 不能声称测得 |
| --- | --- | --- | --- |
| 骨架 | 输入模型的绑定关节、父子关系、逆绑定矩阵 | 骨段长度、局部轴、左右与父子语义 | 真正骨表面、关节软骨、完整解剖骨架 |
| 表面 | 参数场重建表面、八权重、材质函数 | 骨段周围表面半径分位数、组织影响区 | 精确皮下脂肪厚度、内部组织边界 |
| 肌肉 | 表面外形与绑定骨段 | 主要肌肉/肌群的估计路线、作用、拮抗关系 | 每块肌肉的真实附着点、纤维、体积和力量 |
| 被衣物覆盖身体 | 衣物外形 | 独立标注的造型估计 | 隐藏裸体的精确恢复 |

绑定骨架是动画输入观测，不是完整人体骨骼扫描。当前肌肉目录覆盖主要体表肌肉与肌群关系，包含深层作用参考；不是全部人体肌肉的精确重建。路线显示必须写明“估计”。单个外表面不足以确定内部组织；未知字段保留 `NotObserved`。

当前 R008 原表面来源没有自带骨骼/动画，工作台使用此前继承并适配的61骨骼绑定。这里分析的是该工作台的实际绑定关系与当前表面包络，不能声称从外表面独立恢复了人物真实内部骨骼；新人物的原生骨架或重新拟合骨架需要单独记录来源。

## 必须保持的结构关系

1. **骨架支撑**：同一成人、同一身份与身高，胖瘦/肌肉不缩短肱骨、股骨等，不以软组织缩放改变静态绑定关节。姿态仍可移动/旋转骨架；不同身份可有不同骨性比例。年龄不是统一缩骨系数，当前18–75岁范围的年龄组织先验需单独校准。胸廓与骨盆应有保护包络；当前包络是造型支撑估计，不是真骨轮廓。身高整体尺度是当前造型约定。
2. **肌肉**：肌腹增加体积，肌腱与骨附着附近变化较小。肩臂、躯干、髋腿、掌足联动，不能仅改变躯干。年龄可以修正肌腹饱满度；滑块数值与年龄修正后的有效值分别记录。
3. **脂肪**：外覆组织增厚不仅改变围度，也遮蔽肌腹沟槽、肌腱刻度和肌肉阴影。高肌肉与高脂肪可以同时存在，但不应保留同等锐利腹肌分隔。体积与刻度不能用同一个标量代替。
4. **表皮**：肌肉几厘米尺度的起伏与微米级肤质是不同频段。色素、凹凸、粗糙度/油光、散射、伤疤独立。增加脂肪不能把毛孔、伤疤或日晒颜色一起抹除。
5. **关节/末端**：腕踝、掌指、足趾有骨性支撑；组织变化小于肌腹，但不能完全不变。保留足底接触与眼眶/眼睑贴合。衣物应独立适配身体，不作为肌肉采样。
6. **运动**：骨架运动后蒙皮传递位移；肌肉长度与半径可用近似体积关系联动。估计路线不是运动学求解器，不能凭路线图声称动作已自然或力量已正确。

## 数学模型、来源与适用边界

- 骨段投影：`t=clamp(dot(p-a,b-a)/|b-a|²,0,1)`。根据本人物绑定骨段生成局部组织锚点，所有八个影响权重均参与。不能凭旧人物固定坐标猜新模型中心线。
- 表面包络：按骨段纵向分箱，统计半径 r25/r55/r85。统计量来自外表面，可能受到衣物/不完整表面影响，绝不能把 r25 称作骨半径。保护核是明示的造型系数。
- 肌肉影响：紧支持 Wendland 核 `w(r)=(1-r)^4(4r+1)`，超出支持半径为零。不同肌群可重叠，权重不是肌肉解剖分割概率。
- 收缩近似：圆柱体积近似 `R=R0*sqrt(L0/L)`，来自常体积肌肉造型思想。真实羽状肌、肌腱和动力学不由这个简式确定。当前提供可复用计算函数，尚未作为所有运动的肌肉动力学。
- 脂肪遮蔽：造型传递函数 `T(d,λ)=exp[-0.5*(2πd/λ)²]`，`d` 为估计厚度，`λ` 为肌肉刻度尺度。它借用扩散/低通的频率关系，不是医学拟合或测得的脂肪厚度。当前 1.8m 参考人物 d 最大25mm、λ60mm；微观肤质不由这个函数驱动。
- 曲面处理：法线相容的局部邻域平滑，只填补局部凹槽，限制最大14mm，保护重要区域。不同法线/组织区限制串扰；目前不是完整拓扑扩散、有限元或严格体积保持求解。
- 原表面明暗：在线性空间按当前表面位置分离细/粗亮度，减弱肌肉尺度明暗；保留原色度及高频差。跨分块共享临时字段，不逐 UV 部件独立模糊。原颜色中的光照与色素不能唯一分离，因此这是有保护遮罩的启发式，不冒充真实反照率恢复。复杂伤痕必须专门检查。

参考只用于方法，自创函数实现，没有引入外部人体或皮肤资产：

- [Baran / Popović, Automatic Rigging and Animation (2007)](https://dspace.mit.edu/entities/publication/02216671-1424-4552-a2d3-74cec29e2062)：通用骨架嵌入与蒙皮；不等于由皮肤恢复精确内部解剖。
- [Wilhelms, Anatomically Based Modeling](https://graphics.stanford.edu/courses/cs448-01-spring/papers/wilhelms.pdf)：骨架、肌肉、皮肤的层次与近似常体积造型。
- [Desbrun et al., Implicit Fairing](https://graphics.stanford.edu/courses/cs164-10-spring/Handouts/ImplicitFairing.pdf)：尺度相关曲面扩散与体积约束思想；当前局部滤波不声称完整实现该求解器。
- [OpenSim Muscle Editor](https://opensimconfluence.atlassian.net/wiki/spaces/OpenSim/pages/53090145/Muscle%20Editor)：附着点、路径点、绕行需在局部骨框架中明确记录，不能凭表面断言。
- [Interactive Modelling of Volumetric Musculoskeletal Anatomy (2021)](https://arxiv.org/abs/2106.05161)：肌肉体积组织仍依赖作者给定曲线/约束；是当前估计证据边界的依据。

## 可复用接入步骤

1. 校验单位、绑定姿态、逆绑定矩阵、父子图、所有八权重及归一化；禁止骨架循环和重复名称。
2. 识别骨架语义；支持当前命名与 Mixamo 类别名，陌生命名使用显式映射。缺失/歧义返回 `needs-review`，阻止自动变形。
3. 从当前头/骨盆/肩臂建立局部坐标与身高；测量左右骨长、比例、表面横截面。重新生成区域锚点，保留不对称。
4. 按骨段建立肌肉关系模板，标注作用、拮抗、估计来源和未观测字段；作者校准真实附着资料后才能提升证据等级。
5. 校准胸廓/骨盆支撑、肌腹、脂肪分布、面部和保护区，再生成临时组织字段。当前 R008 体型包络、伤疤保护、面部与游戏动画仍有本人物专用校准；分析器的复用不代表任意模型已可自动完成整套运动与体型适配。
6. 对照参考/轻瘦/高肌肉/高脂肪/老年与动作；检查关节不变、边界闭合、眼睑贴合、骨段外组织、肌肉起伏及衣物。

`window.HumanAnatomy.analyze(input,{mapping,frontHint})` 是通用分析入口；`export()` 导出紧凑当前分析报告，只有骨段、关系、统计、证据和规则，不保存新表面网格。

## 已失败的方法，后续不得重复

- R19 瘦型缩小胸廓，且手臂中心线硬编码：骨性结构被错误压小。
- R20 八权重、关节固定和局部雅可比通过，但高脂肪仍有锐利腹肌：只改体积与切线法线，遗漏几何沟槽和原表面明暗。**测试通过不等于体型外观正确。**
- 只扩大已有支持核、不区分肌肉脂肪：不能建立组织关系。
- 旧人物坐标直接套新人物；把估计肌肉附着称为解析出的真实肌肉；把绑定线称为完整内部骨骼：均不允许。
- R21 初次局部滤波把每个采样格的法线直接赋给顶点，出现块状光照；改成连续插值，跨原边界同步临时字段。初版55mm邻域仍保留腹部横向肌腹，改为90mm邻域与更宽亮度频段再检查。不能把“沟槽填补量大于零”当作肌肉已正确遮蔽。
- 材质数组序号不是材质名称末尾数字。R21 初版把两者混用，错误排除了部分皮肤并影响裤子；现按实际名称识别保护材料，并检查每个原始保护材质所有顶点的遮蔽权重均为零。这也是将既有 R12 经验变成自动检查的具体规则。
- 胸廓/骨盆的保护包络适用于减少组织，不能直接作为增脂的轮廓分段。R21 实际渲染发现沿这些支持段增加脂肪会形成规则横向台阶；正脂肪改用连续宽包络，负组织仍保留原骨性保护。
- 对每个部件的 UV 贴图分别模糊亮度，会在部件边界形成补丁，即使顶点接缝为零也不代表材质连续。改为共享表面空间亮度频段；已弃用新增 UV 低通贴图。
- 合成法线的顺序也属于通道契约：先衰减肌肉尺度原法线，后添加程序化微观肤质；伤疤区域须排除脂肪法线遮蔽。只保持微观滑块值不变，并不能保证最后着色保留了它的效果。
