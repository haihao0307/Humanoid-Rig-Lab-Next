# R25 由当前人物表面反推候选骨架

2026-10-04。用户最新要求是依据已有模型的表面与整体比例反推骨架。它取代R24“等待内部数据”的执行路线，同时保留真实内部不可唯一确定的事实边界。

[本机交互入口](http://127.0.0.1:8877/?version=R008-inverse-25&anatomy=inverse)：第三个按钮“根据当前表面反推骨架”。可旋转、缩放、选择骨段、开关表面截面/原绑定/半透明人物，导出紧凑参数。金色为候选中心线与关节，青色为继承的原绑定，绿色为通过质量检查的外表面椭圆截面，红色为观测不足或关节需要复核。圆柱仅是4mm可视化笔画，不是推断出的骨径。

## 数据与职责

| 层 | 来源与事实 | 约束 |
| --- | --- | --- |
| 外表面 | 当前参数生成器的`skinRest`参考形体与材质分区 | 运行时读入，结果不保存采样顶点 |
| 原绑定 | 继承并适配的61节点、角色语义、坐标架和初始方向 | 初值，不是同一人物内部扫描；本轮不改写游戏绑定 |
| 表面分区 | R008当前来源的31个`tripo_part_N`部件，按名字解析 | 材质数组顺序不可当作部件ID；衣物1/2/9排除 |
| 候选骨架 | 每段的外表面拟合轴、靠近端点的中心偏移、共享关节位置 | 明示估计；不能把皮肤轴直接等同于骨轴 |
| 未观测 | 骨面、骨径、髋部与近端大腿、逐指内部骨中心、肌肉真实附着 | 保留NotObserved，不以裤子外形补成裸体实测 |

`SurfaceSkeletonFit.mjs`负责通用求解与证据状态；`R008InverseCalibration.mjs`只负责当前来源外部部件语义；`SurfaceSkeletonDisplay.mjs`生成显示几何与参数导出；`MotionAnatomyWorkbench.mjs`负责视图、选择与恢复。核心没有现有人物坐标；换人物需重新建立无歧义角色/坐标架和表面语义适配器，不能直接照搬R008部件编号。当前需要初始人形骨架或人工语义标志，尚不支持任意无骨架网格完全自动解剖。

为避免脂肪变化反过来改变同一成人的骨长，求解只用来源参考体型。进入反推视图临时恢复参考脂肪/肌肉/年龄并锁住体型控件；退出恢复此前配方。身高的场景整体尺度单独保留。不能对每次胖瘦变化重新求骨架。眼球/眼睑独立层不参与此骨架拟合；头部轮廓包含头发和五官，不能称为颅骨外表面。

## 计算模型与单位

坐标以当前来源规范化米制参考架处理。骨段初始为`a→b`，`t=dot(p-a,b-a)/|b-a|²`，法平面轴为`u,v`。最多180000均匀步长外表面样本；每骨段12个纵向分箱。分箱是薄带近似，不是真正三角形与零厚度平面的交线。

每截面求`q(x,y)=Ax²+Bxy+Cy²+Dx+Ey=1`。24个角度箱平衡不同网格密度，四次IRLS抑制离群点；截面中心由二次型求解，特征值给出椭圆半轴和方向。少于24点、少于15/24角度覆盖、非正定椭圆、异常长宽比、残差过大的截面不作为端点依据。拟合后还须按新中心重新检查角覆盖，并限制轴长不能超过观测投影跨度的1.35倍，防止部分表面被外推成过长完整椭圆。RMS/95分位为皮肤与椭圆的近似径向差，不是骨骼位置误差或医学置信区间。

端点只使用距该端点0.30段长内的有效截面；至少两个局部截面及四个总有效截面、足够纵向跨度才允许估计。线性局部回归的偏移限制为`min(0.04H,0.20L)`。共享关节对相邻骨段候选按局部观测数量合并，记录候选分歧；分歧超过0.006H或触及先验边界标记需复核。手掌截面混合多指，禁止据此移动中指根节点。大腿近端受衣物遮挡保留先验，不强行镜像另一侧补齐。

这些阈值是项目自创的数值保护选择，不是文献证明的个体解剖精度。组织内骨头可能偏离表面中心。当前主要利用截面修正横向中心，纵向关节位置仍受原绑定初值限制；完整骨面、胸廓/骨盆内部轮廓、真实肌肉附着和动画重新绑定均未完成。

## 学习来源与采用范围

- [Pinocchio原论文](https://people.csail.mit.edu/ibaran/papers/2007-SIGGRAPH-Pinocchio.pdf)：学习模板语义、表面约束与连续优化的组合思路。其目标为自动绑定，不能把绑定成功当作内部解剖测量。这里未复制论文代码或模型。
- [SKEL研究项目](https://skel.is.tue.mpg.de/)：学习把骨架运动学语义与外表面约束分开，以及按对象重新拟合的路线。未使用SKEL/SMPL模型、训练参数或骨网格；本求解不是SKEL复现。
- [Inside Humans原论文](https://www.frontiersin.org/journals/virtual-reality/articles/10.3389/frvir.2021.694244/full)：学习以皮肤约束和骨架先验联合拟合的做法，并记录外表面对骨长度/骨径的信息差异。内部骨径不能只由外表面唯一恢复。当前椭圆近似没有实现该论文的体积/力学求解。

## 失败方法与纠正

1. R23按原绑定比例生成框架不足以回答“从当前表面反推”；保留其运动展示，但不能把它叫作反推结果。
2. 第一版用整段中心回归外推关节，会将不对称肌腹的偏移带到端点。已改为仅端点附近的观测，并加入“仅中段肌腹偏移不移动端点”的测试。
3. 肩颈过渡和多指截面不满足规则椭圆假设。仅看原中心角覆盖不够，侧面QA发现颈后伸出的椭圆；补上拟合中心角覆盖与观测跨度后已拒绝该外推。已拒绝高残差截面，禁止掌部截面移动中指根；有效截面和关节分歧在报告显示。
4. 体型滑块会改变当前显示表面，但来源骨架求解应固定参考身份。已加入临时参考体型与退出恢复；不把不同脂肪形态拟合成不同成人骨长。
5. 服务进程保留旧路由会导致新增模块404。只重启经`/health`核实的本机人物预览服务，使用隐藏窗口，不接管用户鼠标。
