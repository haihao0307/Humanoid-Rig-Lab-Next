# 面部结构细化 R7

2026-09-13。延续自然人脸研究，本轮修改眼睑、鼻底与唇部的生成结构。参数是当前 R2 头部的外观设计，不是测量数据或生理标定值。

## 实现

- 眼裂由上下不同的弧度、两侧不同的弧峰构造，增加上睑折痕随闭合展开的变化。接触余量为 0.28 mm；光学层的中性前移由 2.5 mm 改为 1.8 mm，闭眼回收量由 1.2 mm 改为 1.0 mm。CPU 中性法线与 GPU 变形法线都使用显示网格相邻采样。眼白的基础反射颜色适度降低。闭眼实拍后进一步收窄眼角支点的影响区域，将支点高于接触曲面的上限从 6 mm 降到 2.5 mm，避免大范围抬起闭合睑面。闭合线中部进一步下移，保留平缓的眼角切线。
- 鼻底的参数纵坐标与实际纵坐标分离，使鼻孔所在区域能够回折。回折主要分布于两侧，鼻小柱另有较小的下垂参数；鼻尖下方截面收窄，鼻翼具有独立的局部体积。
- 鼻孔在曲面的参数域裁切，内壁共用裁切边缘，向实际三维开口法线的反方向延伸 5 mm。取消旧的正面椭圆片元裁切，避免鼻底回折后被再次挖掉。
- 上下唇增加连续的唇红弧面、向口内返回的唇面及有深度的口腔入口；闭口线与唇峰的形状同步用于表面着色。界面说明同步更新，仍明确没有下颌关节、牙齿和舌头。
- 保留原有 22 项表情通道、头部绑定与身高缩放。配方保存函数参数及少量结构说明，临时网格和截图不进入人物配方。

## 验证方法

- 眼睑参数检查覆盖中性、眯眼、睁大与闭合等组合，比较 CPU/GPU 标量公式、接触关系、固定眼角、外缘连接、法线和面片方向。
- 面部参数检查使用平面及倾斜平面作为独立输入，检查三维面片朝向、鼻腔深度、鼻孔整圈边缘逐段吻合、内唇与口腔深度，以及输入保留和缩放绑定。不能再假定鼻底或口内的所有面片都朝向正前方。
- 实际渲染与表情检查的最终记录、构建校验值及截图位于仓库外的 face-anatomy-r7/runtime-verification.json。文件检查与实际渲染分别记录。最终实拍覆盖中性、两侧斜视、轻微仰视、半闭眼、双眼闭合、单眼闭合、50% 与 100% 微笑、惊讶、鼓颊抿嘴、皱眉；近看档已实际完成计算。最终加载的面部和眼部脚本文本与工作区一致，控制台没有捕获到错误或警告。

## 依据与限制

研究重点是眼球与眼睑的包裹关系、鼻底的立体返回、唇部体积，而非只增加网格密度。参考 Disney 的 [眼睑运动方法](https://media.disneyanimation.com/uploads/production/publication_asset/66/asset/realisticEyeMotion.pdf)、[眼球结构与采集研究](https://la.disneyresearch.com/publication/high-quality-capture-of-eyes/)、[眨眼研究](https://la.disneyresearch.com/wp-content/uploads/Modeling-and-Animating-Eye-Blinks-Paper.pdf)，以及 [Digital Emily](https://vgl.ict.usc.edu/Research/DigitalEmily/) 对面部形状、外观和表情分别采集的工作。这里只借鉴结构和检查方法，没有导入扫描模型、贴图或这些项目的角色资产。

尚未实现物理软组织、独立眼球注视、完整角膜折射或自然眨眼时序。闭眼时的眼眶体积和眼角阴影仍不够自然，源头部的面颊、下颌和部分眼眶折痕仍可能显露；高强度组合也不能由有限参数检查证明完全没有自交。现有唇部拉开控制仍不等于可信的下颌张口，口腔入口的几何深度不代表完整张口功能。此轮仍是程序化近似，不能称为照片级真实人脸。
