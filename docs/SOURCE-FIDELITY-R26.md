## 一帧几何缓存及按需边界输入

保留最后一次完成的精确求交工作缓冲，用于相同人物、程序、机位和实际画布尺寸下的原皮肤、法线与结构观察切换。缓存保留原世界位置、法线及材质坐标输入，所有材质重新求值，不缓存旧照片，不降低精度。人物/程序变更清空缓存；不同机位或尺寸不使用不匹配结果；上下文/页面重建使用新实例。

只保留一帧，世界位置/法线/材质三个 Float32 RGBA 输入共每像素 48 字节，上限 128 MiB。超过上限回到原求解路径。这里有明确的额外 CPU 常驻成本，不能沿用 R25“没有额外整帧 CPU 缓存”的结论。它不等于全部 GPU 或场景内存已压缩。相同机位的原材质刷新继续直接复用 GPU 输入。

切换原貌页中的体型时，显式头颈包也更新到对应的原记录，避免把上一体型的边界带回工作页。十份参考输入从主 HTML 移为按需 gzip 字节包，默认显示不读取它们；压缩与原始 SHA-256、来源和完整包指纹全部核对，最多保留两份。失败发生在更新显示前，保留上一人物。它们只是原头侧边界输入，不生成头部表面。

## 连续字段的操作历史修正

原貌状态跳过隐式字段后，原代码可能尚未初始化基准协方差法线；首次编辑时误用当前编辑结果作为参照，而直接载入编辑档案使用原人物参照。R26 在读取初始档案前固定原基准所需输入，等真正计算连续字段时才准备邻域与基准法线。已匹配原貌状态继续跳过这部分工作。

字段缓存绑定程序、颈部算子、质量、完整状态及当前边界。只对已证明等价的零值写法共用字段；返回的原始人物状态仍按用户输入保存。新的字段语义有独立版本标识，缓存不把旧结果当成新计算。

独立浏览器上下文分别检查 A 系统体重编辑、B 系统动作编辑与直接读档；实际工作线程的全部 30 份字段/法线缓冲逐字节一致。同一会话的等价零值档案命中现有缓存，原始存档写法不丢失。这修复操作历史依赖，不能证明连续零面已经与原表面相同。

## 收尾前继续定位的结果

原版身体基线在正、侧、背三个机位各重复两次显示，颜色与三个中间目标均一致。这项原版自对照只覆盖该基线，不外推所有状态。函数显示在没有原型钩子、遮罩绘制或中间层探针的条件下，背面仍可重现首次/重绘差异，因此不能把它归咎于截图或检查工具。

另用只读帧缓冲逐字节读取显卡上实际的世界位置、法线、材质坐标、原函数法线系数、材质坐标系数和掌侧系数。三个机位各三次读回中，六组输入、机位和交点帧均一致；背面颜色仍发生变化。这个结果排除了本次测量范围内这些几何输入在两次显示间变化的解释，没有证明所有着色纹理或后端行为的根因。

显式高精度顶点采样、去除材质辅助像素丢弃并用透明混合、使用原生 LEQUAL 深度状态、声明位置及深度输出不变性，均未消除首次/重绘差异，全部隔离保存。透明混合试验还改变了少量舍入结果，不能采用。四份完整 HTML 的冻结快照、对应实际报告及恢复到新研究目录的工具一并保留。首次独立探针初始化超时也保留，没有把该失败记录当成通过。

独立物理射线对照的当前完成范围与位置、法线、材质坐标最大差异记录于 `qa/fidelity-r26/original-functions-native-rays.json`。它读取离线原表面的独立 BVH，产品核只接收现有数学函数包；既不把原三角表接回运行页，也不以物理射线结果替代原生像素和连续状态验收。旧验证环境的全分辨率尝试因预计超时而中止，保留中止记录；固定等距列对照另存于 `original-functions-rays.json`。随后定位到验证环境的额外开销，同一源码在 1025 条控制射线上逐字段一致，才改用常规执行环境复跑全分辨率。检查程序的局部计时不是网页性能结论。
