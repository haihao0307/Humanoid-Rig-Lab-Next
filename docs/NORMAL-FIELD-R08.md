# R08：形状与着色法线分开

R05的隐式零点拟合在独立点上约有毫米量级偏差。直接对该近似场求细尺度梯度，会把局部拟合起伏放大成不自然的碎块阴影；这在半身和全身距离均能看到。增加表面噪波不能解决这个问题。

R07只扩大梯度求值尺度，并减少偏平的环境填充，改进有限。R08沿用R05的形状函数和零点校正，不改体型或动作算子；另外计算平滑的着色方向函数。

在主标量场的相同采样位置，用当前身体的有方向采样和相同的距离、方向权重对法线求加权平均并归一化。结果缓存为额外的四通道数值系数场。它没有多边形连接，也不保存图片颜色。直接求交找到表面后，着色方向由85%的该方向场与15%的宽尺度隐式梯度混合。手足局部区域保留其细尺度梯度，以保留指趾间隙和小结构。

这种方法属于着色法线近似，不是新的几何误差消除。它不能提高独立表面点的拟合精度，也不是几何曲率、物理组织或严格SDF的证明。参考法线和采样仍源于原身体，来源必须保留。局部区域切换处的法线连续性、姿势极端变化和皮肤材料仍需审核。
