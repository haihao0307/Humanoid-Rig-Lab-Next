# 肩胸、腋窝两层结构 R4

2026-09-08。当前交付为源码与构建文件；本轮只检查文件，没有运行人物、操作浏览器或拍摄新截图。

## 先明确正确的结构关系

肩部的支撑关系是胸廓—锁骨—肩胛骨—肱骨。锁骨在前方撑开肩带；肩胛骨位于后侧，肩峰和关节盂支撑肩部外侧；肱骨头在关节盂附近旋转。肩胛骨和锁骨需要随关节整体移动，因此“硬”指各构件的局部形状不被动作拉扯，不代表锁在世界坐标里。[OpenStax 肩带结构](https://openstax.org/books/anatomy-and-physiology-2e/pages/8-1-the-pectoral-girdle)

外层三角肌包覆肩峰至近端肱骨，胸大肌形成前侧向上臂汇聚的扇面；腋窝前后襞是跨越胸壁和上臂的软组织过渡。正确的抬臂轮廓应留下腋窝凹陷，肋部不能被整体拖成两片鼓起的翼状体。[OpenStax 肩带与上肢肌肉](https://openstax.org/books/anatomy-and-physiology-2e/pages/11-5-muscles-of-the-pectoral-girdle-and-upper-limbs)

已查看项目中保存的 MakeHuman 官方 CC0 基础人体参考图 `tests/shoulder-arm-r2-screenshots/reference-makehuman.jpg`。它用于观察胸侧、肩帽和上臂的连续轮廓，不作为所有体型的标准；没有把参考模型导入人物。

将骨骼与外部软组织分层也是已有建模研究的做法；这里采用适合当前程序模型的支撑约束近似，没有实现论文中的完整材料或动力学求解。[Inside Humans 分层解剖建模研究](https://www.frontiersin.org/journals/virtual-reality/articles/10.3389/frvir.2021.694244/full)

## 实现

| 部分 | 数据与行为 |
| --- | --- |
| 硬基底 | 独立复制胸骨、胸椎、肋骨、锁骨、肩胛骨、肱骨几何；每件只用所属骨骼的刚性矩阵。没有蒙皮权重或肌肉变形数据。 |
| 支撑体 | 固定的胸廓包络和近端肱骨椭球，给软层提供附着参考。它们是工程近似体，不是医学分割结果，也不是新增肌肉。 |
| 软层 | 保留同一份连续表皮、肌肉和筋膜；用基底外的静止厚度组织局部外壳，再写入附着点、所属骨骼和变形限额。 |
| 活动 | 先计算关节蒙皮、肌肉起伏和呼吸，再限制软层相对基底的法向压缩与切向滑移。两种材质（肤色、灰模）使用同一套变形。 |
| 腋窝 | 胸廓和肱骨附着之间保留自由过渡带。约束强度在更换所属骨骼前降至零，避免硬切换接缝。 |

`body/ShoulderLayers.js` 是新层的独立可读源码，完整嵌入 `body_runtime.js`。

构建次序为：读取骨架的静止绑定数据 → 创建或复用硬基底 → 构建软组织曲面 → 建立局部附着属性。硬基底缓存键包含静止关节图、绑定位置/旋转、身高、骨几何和中性结构规格，排除动作、肌肉激活、时间、肤色以及软层形体参数。动作更新不重建也不写入基底顶点。调整肩部软层参数后，即使重新创建组织对象，也复用同一份硬基底。

取消组织构造器中根据软层胸廓参数改写骨几何的调用。肩部抬臂权重现在从胸廓外缘向上臂过渡，替换 R3 从身体中部开始的大范围横向权重扩散。

在完全附着区，胸侧软层额外法向位移渐近限制为 4 mm、切向滑移为 8 mm；上臂对应为 6 mm 和 14 mm。压缩也受静止厚度的 45% 上限约束。这些是当前作者设定的工程参数，不是人体组织材料常数。上胸和肩带附近的约束更弱，保留肩胛、锁骨活动需要的滑移。过渡区按权重混合，不能把完全附着区的限额当成整个肩部的统一位移上限。

初始软壳只在有效外侧附着区域调整厚度。落在支撑体内部、或距离过小的顶点会计入 `unsupportedVertices` 并跳过约束，以便暴露绑定问题。报告同时给出附着数量和静止厚度范围。本轮没有执行模型，因此这些数值尚未实测。

增加两个四分量浮点属性 `structureAnchor`、`structureData`，每个主表皮顶点增加 32 字节；没有导入网格或图片。实际显存占用还包括渲染器批次与查看模式的缓存，需打开页面后评估。

稀疏地面支撑采样也接入同一套肩部混合与约束公式，避免只改显示、保留旧肩部采样位置。这些采样仍省略微小呼吸和肌肉表面位移，不是完整接触求解器。

## 你打开页面后的检查顺序

在“肩膀与上臂”工作台选择：

1. **硬基底**：正、侧、背面检查锁骨、肩胛骨、肱骨头和胸廓关系；切换垂臂、侧抬、前伸，观察各构件只整体移动，形状不拉长。
2. **支撑体**：检查胸廓包络与近端肱骨支撑范围。这是内部约束近似体，不能据此判断外观是否自然。
3. **灰模 / 肤色**：观察三角肌包覆、胸侧轮廓、腋窝凹陷以及前后襞的连续性。
4. 改变软层形体参数后再回到硬基底，确认基底轮廓一致；最后播放连续活动，检查过渡带有无折叠、穿插或突然移动。

可以通过组织报告读取 `localLayers.foundation` 与 `localLayers.soft`。硬基底和支撑体视图都使用当前人物，未另建展示用角色。
