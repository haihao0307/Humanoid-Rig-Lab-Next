# 皮肤假疤线修正 R2

2026-09-12。用户在授权多肤色、多视角截图后，要求重点处理看起来不对的“痣疤”。本轮先联网调研，再修改源码；使用独立无界面浏览器检查实际画面，没有操作用户鼠标。

本次定位到的是表面生成产生的假斑纹和接缝。当前皮肤配方没有独立的痣或疤痕层；本轮没有添加随机斑点，也没有用贴图盖住缺陷。

## 原因与修正

1. **部分高度曲面三角形朝向错误。** 原生成器用第一个顶点的局部导数法线决定三角形朝向。边界修正或粗采样处，局部导数可能与整个三角形的弦面法线相反，导致相邻面翻转。现在使用来源图表的高度轴与向外符号定向。材质保留正常的正反面处理。
2. **新连接点缺少法线。** 实际近看档检查发现 3817 个参与绘制的连接点没有来源法线，沿用了占位的正 Z 方向。该方向在后颈会选择错误的法线场方向，形成一串亮色针脚。关闭毛孔和色差噪声仍能看到该线。现在新增边节点从相邻有效来源法线按边参数插值并归一化；最终参与绘制的缺失法线点数为 0，后颈亮线在实际截图中消失。诊断新增 `inheritedBoundaryNormals` 和 `missingSourceNormals`。
3. **递归细分消耗顺序不合理。** 原先先深入最早的三角形，可能耗尽当前图表的额度，使后面误差很大的面保持粗糙。现在先评估该图表全部初始面，再按归一化误差从大到小处理，并在取出任务时重新检查共享边。身体皮肤也检查法线插值误差。没有提高总细分额度、位置误差目标或内存保护上限。

上述更改位于 `reconstruction/mesher.mjs`、`reconstruction/topology.mjs`。`body/CompactWorkbench.js` 更新生成版本标识，入口仍通过 `tools/build-pure.mjs` 装配。肤色、油光、散射、微表面配方及原始系数包未因这次修正而改变。

## 实际复查结果

同一角色、同一材质参数和固定光照下，已重新拍摄浅、中、深肤色的正面、45° 斜侧、90° 侧面和背面，共 12 张原图，另有面部及胸部近景。正面颈胸的深色细线减少，后颈的亮色针脚消失，脸部和肩部更平顺。

## 验证与依据

`node tools/test-skin-surface.mjs` 验证晚出现的大误差优先得到处理、确定性排序、后颈新增节点继承背向法线，以及两个真实来源图表的朝向和有限误差。`node tools/test-trim-conformity.mjs` 继续验证先前的退化裁剪回归。这两个显式运行检查与只读源码的文件审计分开。

`tools/check-startup.mjs`、`tools/check-surface-continuity.mjs` 增加了对应文件约束。`node tools/check-pure.mjs` 仍只检查文件，不运行人体或 GPU，不会因此将全局状态改为视觉验收通过。

调研参考：

- [CGAL Polygon Mesh Processing](https://doc.cgal.org/latest/Polygon_mesh_processing/index.html)：区分面方向、法线、组合拓扑与几何缺陷；本轮据此分别定位朝向、连接和采样，没有引入 CGAL 依赖。
- [Three.js DecalGeometry](https://threejs.org/docs/pages/DecalGeometry.html)：贴花可增加局部细节，但转角会产生投影畸变；本次确认不是已有贴花层故障，未用贴花掩盖接缝。
- [美国皮肤科学会：疤痕概述](https://www.aad.org/public/diseases/a-z/scars-overview)：真实疤痕的颜色和表面状态会不同；仅用于辨别外观设计与异常几何，不作为本模型的生理标定。
