# 身体晒痕 R8

2026-09-12。用户要求身体也有晒黑痕迹，避免面颈与前臂变深、胸背和腿部完全一致的外观。

## 当前行为

沿用 `jarvis/skin_appearance@2` 的日晒加深、户外粗糙感及生成种子，不增加配方字段。基础肤色、四档户外经历与已有角色导入方式保持兼容。

- 胸腹和背部带较浅的累积晒色，肩部略明显。
- 胸前领口呈下凹过渡，后颈领口较高；袖口以下的手臂更深。
- 腿部加入短裤和鞋袜遮挡形成的深浅分界。
- 边界至少有 24 mm 的完整平滑过渡区，并随屏幕像素覆盖范围拓宽；既有种子与低频变化只让位置发生小幅偏移。
- 日晒加深控制色素变化，户外粗糙感控制相同部位的光泽与微起伏。两者均为 0 时关闭这些效果，旧版无日晒配方不会留下固定色斑。

这是多次穿着、日晒形成的场景艺术配方，不读取当前衣物，也不是实时紫外线照射、衣物透光率或当地居民肤色的测量模型。默认使用常见领口、短袖、短裤和鞋袜的累计遮挡关系；尚未提供服装类型切换。

## 实现与开销

`body/TissueShaders.js` 的 `skinBodyExposure` 使用 R2 固定来源坐标，因此晒痕附着于皮肤，不依赖当前光照、相机或动画姿态。与面颈和前臂遮罩取最大值后，进入既有色素、粗糙度、油光和微起伏通道，避免重叠区域反复加深。

复用原有三次噪声求值；无新增贴图、纹理采样、顶点/索引、uniform、绘制通道或生成请求。新增成本是片元中的平滑遮罩算术，GPU 耗时未测量，不能称为零开销。工作区同时发生的体型和网格改动不计作本次材质增量。

## 修改前调研

- [WHO：紫外线对皮肤的作用](https://www.who.int/news-room/questions-and-answers/item/radiation-the-known-health-effects-of-ultraviolet-radiation)：紫外线会影响现有色素和黑色素生成。用于区分晒色与另行控制的表面状态，不据此推算日晒剂量。
- [WHO：衣物与紫外线遮挡](https://www.who.int/news-room/questions-and-answers/item/radiation-protecting-against-skin-cancer)：覆盖范围和面料影响暴露。这里将遮挡差异简化为软边界，具体位置、强度和衣物组合属于艺术设定。
- [PBRT：纹理采样与抗锯齿](https://pbr-book.org/4ed/Textures_and_Materials/Texture_Sampling_and_Antialiasing)：纹理需要考虑像素覆盖区域。身体晒痕沿用现有来源坐标导数，给遮挡边缘设置最小软化宽度。
