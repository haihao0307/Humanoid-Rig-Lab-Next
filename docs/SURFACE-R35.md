# R35 身体体表功能

当前人物由参考、已有数据和多轮迭代形成。R35 在既有函数表面上接入和调整皮肤，不要求重新进行原数据表面分析；来源记录仍保留，身体显示继续采用函数求交，未生成人物三角面。

## 已接入的范围

- 固定预设人物和目前受支持的 A 骨架连续体型、局部调整及姿势使用同一套既有身体皮肤着色、区域色彩、毛孔和细纹数据。动态身体以实时求交得到的表面位置、法线和局部坐标驱动皮肤，而不是只显示单一肤色。
- 工作台把 22 项皮肤调节分为「肤色与色斑」「表面质感与细节」「散射与细绒毛」：包括明度、冷暖、红润、色斑、粗糙度、油光、毛孔、细纹、微纹理、区域变化及皮肤柔光。微细纹理在近距离更容易观察。
- 可调形体或姿势变化、以及方向光变化时，按当前函数表面重新计算两盏方向光的阴影；固定预设改变灯光方向时也会更新阴影。皮肤柔光沿用已有的屏幕空间扩散，不是完整物理体积散射。
- 皮肤参数与完整人物档案一起保存、载入；身体皮肤调整不覆盖头部档案。仅修改皮肤参数时，复用已计算的身体表面与阴影，避免重复计算形状。
- 继承 R33 的轮廓采样及转动中边缘处理。无窗口浏览器实测了皮肤滑块的画面变化、近景微细节、体型和姿势衔接、灯光和阴影、保存载入、图形环境恢复以及旋转前后轮廓。检查记录在 `qa/skin-r35/`，没有生成交付截图。

## 尚未完成

- 皮肤覆盖范围受身体功能约束：年龄和性别连续变化、部分旧档身体改形、B 骨架屈曲等尚未接通，因此不能声称这些状态下的皮肤已完成；姿势结构观察仍不是完整皮肤显示。
- 按钮当前切换静态姿势，真正连续动作播放及更多动作组合仍待接入。独立头部、附件和整个平台的联动仍待完成。
- 现有扩散是屏幕空间效果，细绒毛为光泽响应，并非独立绒毛几何；没有实现完整体积散射。显存、加载和阴影更新表现只在当前测试环境检查，其他设备与场景仍需实际验证。
- 实际三维效果及不同体型、动作组合仍需用户观察；功能测试不能代替视觉验收。
