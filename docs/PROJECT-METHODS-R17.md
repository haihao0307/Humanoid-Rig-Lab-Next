## 表达层次

后续母体的目标形式为：

`F(x; v) = F_support(x; v) + Σ a_k(v) φ_k(x) + N_surface(x; seed(v))`。

`F_support`承载身体结构和体积；`φ_k`是有明确区域、尺度和衔接条件的确定性形态函数；`a_k`是个体变量。`N_surface`负责不规则表面，不能用随机噪波代替骨盆、肩胛、关节位置和轮廓。当前R17尚未将全部旧形态场替换成这个新母体，不以该公式冒充实现完成。

皮肤层可由稳定的多频噪波、定向细沟核、稀疏毛孔核、区域色素和绒毛曲线核表达。远处无法解析的微细节需要转换为受控的统计反射响应，不能一律抹平，也不能放大高频噪点来制造细节。区域边界和动作后的材质坐标必须保持稳定。

## 按优先级推进

1. **已实施的无损整理**：重复系数只存一次，统一操作，保留全部原变量与旧档案；同相机核对全身、半身和动作。
2. **形体与变形**：中性、瘦、胖、肌肉型及关节动作，先处理腕部和手部、肩胸连接、骨盆与下肢体积。普通灯光只作观察条件，不为一盏灯重塑人物。
3. **确定性母体分区替换**：逐区建立项目自编函数、身体比例与局部控制。每次记录新变量如何确定、真实修改和未通过项；将旧来源校准与新增数据明确分开。
4. **参数维度压缩**：测量多状态响应的相关性、依赖与误差，再做局部低秩或稀疏残差；保留未被基底覆盖的独立调整。仅有同名、相关或中性零响应不足以删维。
5. **表面程序补齐**：保留肤色分区，按身体区域配置噪波与绒毛响应；在半身、全身及另一场景核对。无需逐光源保存一套肤色。
6. **头部与总平台整合**：共同坐标、颈口函数、附着和完整存档。只在真实替换、视觉回归与接口验收之后变更组件自主状态。

每步保存函数版本、数据哈希、操作增量、实际截图、已测范围和失败。公开操作界面使用项目自己的参数名称；内部来源证据保持真实，不通过改名或迭代次数判断原始来源已经消失。
