# 皮肤材质细化 R4

2026-09-12。按用户“保证开销的前提下，对皮肤进一步地进行细化调整”的要求，在已有皮肤材质中实现区域光泽、局部血色与分尺度微表面。沿用此前授予的离屏截图权限，补充了相同网格上的实际画面对照与 GPU 计时；没有操作桌面鼠标。

## 改动与控制

- 额头、鼻部、两侧面颊、外耳使用参考姿态坐标中的平滑椭球权重。额鼻保留较集中的反光，面颊及身体略偏哑光。区域仅用于受控的 R2 人体。
- 红润控制在面颊与耳部更明显，低频色素变化仍受原有“肤色细微变化”控制。所有颜色调整采用乘法，保留浅、中、深基础肤色之间的差异。
- 新增中等尺度的浅起伏，原有细尺度噪声改为浅凹毛孔。两者共用一次表面梯度计算，并联动局部粗糙度与轻微的凹处高光遮蔽；毛孔不向底色绘制黑点。
- 按像素覆盖范围淡出细节，将无法分辨的毛孔转成小幅平均粗糙度；面积拉伸继续调节起伏幅度。噪声坐标旋转减少明显的轴向排列，梯度有幅度上限。
- 仍使用已有七项控制及 `jarvis/skin_appearance@1` 配方，没有新增持久化字段。控制提示同步更新。

实现位于 `body/TissueShaders.js`，面板提示位于 `body/SkinAppearance.js`。本轮没有修改人物几何生成、绑定、行为或毛发逻辑。保留现有双层 GGX 和局部包裹光散射近似。

## 开销边界

| 项目 | 本轮变化 |
| --- | --- |
| 皮肤噪声求值 | 每个皮肤片元 2 次变为 3 次；没有迭代采样循环 |
| 贴图、材质缓冲、几何缓冲 | 无新增 |
| uniform / varying | 无新增 |
| 主绘制及阴影通道 | 无新增 |
| 改肤色、油光、微细节 | 继续更新已有材质参数，不重建几何 |

区域权重是当前参考人体的艺术配方，不是测量得到的生理分布。未来更换参考人体或源坐标时，需要同步调整区域位置。高光与油脂程度不由肤色深浅推断。

## 实际性能对照

环境：Windows、Chrome 无界面运行、WebGL2 / ANGLE D3D11、RTX 4070 Ti SUPER。使用同一个活动档网格与头发、固定姿态、相同镜头/基础色/光照，仅替换新旧片元程序。每种程序先预热 20 次；随后按 AB/BA 交替顺序收集各 30 个 GPU 查询，每个查询包含 4 次重复绘制，结果除以 4。查询期间暂停内置计时钩子，结束后恢复。使用 `EXT_disjoint_timer_query_webgl2`，未检测到 disjoint 或 GL 错误。

| 画面 | 修改前 GPU 中位数 | 修改后 GPU 中位数 | 中位增量 | 修改前 / 后 P95 |
| --- | ---: | ---: | ---: | ---: |
| 700 × 820 面部近景 | 0.1395 ms | 0.1494 ms | +0.0099 ms | 0.2417 / 0.2340 ms |
| 700 × 820 上半身 | 0.1277 ms | 0.1324 ms | +0.0046 ms | 0.2501 / 0.2122 ms |
| 1920 × 1080 面部近景 | 0.1737 ms | 0.1911 ms | +0.0174 ms | 0.2596 / 0.3226 ms |
| 1920 × 1080 全身，启用阴影 | 0.2289 ms | 0.2356 ms | +0.0068 ms | 0.3153 / 0.3384 ms |

这些是隔离场景中的重复绘制 GPU 时间，不是完整网页帧耗时或游戏 FPS。CPU 提交中位数约为 0.13–0.15 ms，浏览器时钟粒度和后台负载不适合用来断言细小差异。各画面的 GPU 中位数增幅约为 3%–10%，绝对增量较小；不能据此保证所有手机和集显上的成本。P95 有波动，不据此声称帧稳定性改善。

同网格 A/B 中，身体保持 316,326 个三角形、11,146,449 字节几何 GPU 缓冲；主绘制均为 16 次，开启阴影时额外 15 次阴影绘制。测试先保存原材质程序，再装到当前同一个网格上比较，避免不同生成批次的几何变化混入材质收益。

## 画面与验证范围

## 调研依据与取舍

修改前核对了 [Epic Digital Humans](https://dev.epicgames.com/documentation/en-us/unreal-engine/digital-humans?application_version=4.27) 的区域粗糙度、双层高光、法线到粗糙度和凹处高光处理思路，以及 [USC Skin Microstructure Deformation](https://vgl.ict.usc.edu/Research/SkinStretch/) 对皮肤微结构与拉伸下反光变化的研究。本轮选择是在当前渲染器中的低成本艺术近似，没有复现测量模型或引入扫描贴图。完整调研与后续散射选项见 [R3 调研](SKIN_MATERIAL_RESEARCH_R3.md)。
