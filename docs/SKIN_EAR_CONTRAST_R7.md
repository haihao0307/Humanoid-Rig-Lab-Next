# 耳部遮挡修正与日晒对比 R7

2026-09-12。针对日晒档位区别偏弱，以及耳朵看起来缺了一块的问题，先核对材质、法线与遮挡方法，再通过已授权的离屏截图定位。

## 耳部原因与处理

单独显示 `FJ2811` 外耳时，耳甲腔、耳屏和内侧曲面存在；叠加头部 skin 分块后，头部侧面覆盖了这些结构，留下 C 形外耳轮和一小块像悬空的耳屏。原始分块截图保存在交付目录的 `ear-only.png`、`head-only.png`；这两张是定位证据，不是最终整体效果。

`body/CompactWorkbench.js` 新增 `compactClearEar`。只对头部 skin 分块生效，在参考坐标 y=1.484–1.529 m、z=0.072–0.108 m 内，沿左右方向最多内收 8 mm。椭圆范围外位移与梯度平滑归零；横向使用平滑门控，雅可比行列式大于 0.73。法线使用对应的逆转置变换。耳朵分块没有被移动或删除；收窄下边界以保留耳垂下方连接，耳道后方仍由头部遮挡。

这属于参考头部显示形状的局部修正，不改变拟合参数包，也没有建立新的扫描误差证明。颜色与阴影共用修正后的顶点程序；规范化参考坐标先写入 R，再进行修正，肤色纹理不随修正滑动。身高缩放和原有关节变换继续在后续应用。

`reconstruction/mesher.mjs` 为与耳根区域相交的 31 个侧头曲面片提供局部采样额度。只有这些片内与耳根范围重叠的三角形使用 2 mm 边长目标，close 档为 1.5 mm。额外细分预算为 preview 1400、close 4000、其他档 2400，全部计入组总预算和既有全局保护。未提高全身质量档，也未动五官、手部和面部表情的既有额度。

目标边长在额度用完时不保证全域达到；当前耳廓的源曲面折面仍可见。此修复消除了主要的头部覆盖问题，不能视为耳部全部拓扑和真实感已经验收。

## 日晒区别

四档预设及基础肤色参数不变。日晒对线性颜色的衰减系数从 `(0.22, 0.30, 0.37)` 调整为 `(0.55, 0.66, 0.74)`，全强度下各颜色通道仍保持正值；户外粗糙度增加系数从 0.07 调为 0.11，油光减弱系数从 0.18 调为 0.30，已有中尺度起伏的增强系数从 0.45 调为 0.75。

这些是艺术控制，不是当地人口测色值或 UV 剂量。仍可分别调整基础肤色与日晒经历；色素加深仍为连续乘法，不添加黑点或新的斑块纹理。既有三次噪声求值、两个高光分量和绘制通道均未增加。

## 方法来源

- [PBRT：法线的变换](https://www.pbr-book.org/3ed-2018/Geometry_and_Transformations/Applying_Transformations)：位置改变后应使用逆转置处理法线，避免表面方向失配。本轮对局部凹入使用解析雅可比。
- [PBRT：三角网格](https://www.pbr-book.org/3ed-2018/Shapes/Triangle_Meshes)：区分几何面方向与插值着色方向，避免把所有外观缺陷都当作颜色问题。
- [Epic：Digital Humans](https://dev.epicgames.com/documentation/en-us/unreal-engine/digital-humans?application_version=4.27)：耳部散射应局部控制。此处先处理已定位的遮挡；没有用更强散射或发红掩盖缺失的内部结构，也未增加屏幕空间散射通道。
