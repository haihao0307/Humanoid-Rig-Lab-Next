# 轻量支撑余量反馈 R25

日期：2026-09-15。开发分支：`feature/human-motion-workbench-adjustment-v1`。本轮承接 R23 的方向力量反馈与 R24 的坐起准备、连续步态相位和连续转身，增加一个不修改 Motion-Lab R2.2 锁定源码的轻量支撑反馈适配层。

## 目标

当前人物仍是运动学角色，不能把本轮描述为完整人体动力学。本轮只使用已经提交的脚锚、根节点运动、物体质量和上一固定步的实测物体加速度，生成幅度受限的身体补偿：

1. 腰椎和胸椎的轻微前后、左右反向倾斜；
2. 双脚同时支撑时最多 8 mm 横向、10 mm 前后骨盆回中；
3. 支撑余量较小时最多约 12% 的空手步速收缩，持物时最多约 18%；
4. 诊断中报告支撑脚数量、近似支撑余量、风险、倾斜量、骨盆偏移和速度系数。

该层不修改骨长、父子关系、动作来源、物体刚体求解或锁定的 `motion/vendor/*`。坐、躺、起身支撑转换期间自动退出；手掌受物体约束时只施加很小的躯干反倾，不移动骨盆。

## 计算边界

支撑区域是由当前接触脚位置加保守脚掌半长、半宽形成的二维代理；重心是身体根节点与持物位置按质量加权的近似；没有使用真实身体段惯量、足底压力、地面反作用力、ZMP、捕获点或跌倒求解。因此：

- `calibrated=false`
- `fullDynamics=false`
- `visualAcceptance=false`
- `productionReady=false`

此层的意义是让现有运动学动作开始对支撑和负载方向产生连续、可观测的小幅反馈，而不是宣称完成真实生物力学。

## A/B 测试

默认启用 R25。预览网址追加 `?balanceOff=1` 可关闭该层，便于比较同一条行走、转身和搬运动作。

建议测试：

1. 连续直线行走后急停；
2. 90°、180°转身；
3. 搬运轻箱与较重箱后转向；
4. 推动物体遇到阻力；
5. 坐下、起身，确认支撑转换没有被本层干扰。

重点观察躯干是否只产生小幅连续补偿、双脚是否仍固定、动作是否没有整体慢放感。肩腋表面折叠不属于本轮范围。
