# 局部体型与人物形式 P2

状态：源码已接入，Candidate；仅文件验证，未运行人物生成器、网页、动作或 GPU。P0/P1 的身高方案继续保留，本轮增加局部体型，不把外形解释为体重、肌力或健康状态。

## 使用入口

人物设置 → 体型与身高。先起身站稳，选择起始体型或调整滑杆，最后点击“应用体型”。提供参考、修长腿型、紧凑、宽肩、纤细、丰满六种起始体型；角色定义列表也加入这些配方，可保存、导入以及生成独立 NPC。

选择体型保留待应用的身高；选择较矮、参考、较高保留七项局部参数。滑杆在点击应用之前只编辑配方。应用期间禁用本面板控件，沿用整体角色暂存、校验和替换事务；失败保留原人物。原有 NPC 生成、行为和物理任务的并行改动已保留。

| 参数 | 范围 / 中性值 | 作用 |
| --- | --- | --- |
| statureScale | 0.94–1.06 / 1 | 整体身高缩放 |
| legProportion | −1–1 / 0 | 腿身比例；通过中部纵向位移改变骨盆和腿长，头顶及足底区域不随这项移动 |
| shoulderWidth | −1–1 / 0 | 肩部外移或内收，手臂链随肩部移动 |
| hipWidth | −1–1 / 0 | 骨盆及邻近区域横向宽度 |
| waistWidth | −1–1 / 0 | 腰部横向宽度 |
| torsoDepth | −1–1 / 0 | 胸腹前后厚度 |
| armFullness | −1–1 / 0 | 上臂、前臂轴周围的局部丰满度 |
| legFullness | −1–1 / 0 | 大腿、小腿轴周围的局部丰满度 |

这些是当前参考人体附近的设计范围，没有人口统计或医学含义。参考源高度为 1.7194712 m；身高范围约为 161.6–182.3 cm。体型不会自动修改力量、体重、性别、疲劳或生理状态。

## 函数、参数和关系

`reconstruction/shape-contract.mjs` 定义 `jarvis/human_shape@2`、`r2-regional-shape-r2` 和全部八项参数，拒绝非有限值、越界、未知字段及混合版本。旧 `human_shape@1` 仅身高配方迁移时把七项新参数置零；角色配方升级为 `character_preset@6`，接受 @3/@4/@5 的旧角色。导出保存函数引用、参数、关系和来源，不保存生成顶点。

`reconstruction/shape-deform.mjs` 提供页面与 worker 共用的 F。页面组装器直接嵌入同一源码并把它计入生成器哈希。几何身份包含原始来源哈希、生成器哈希、完整体型版本及所有参数的精确数值；人物名称、任务和显示舍入不参与几何身份。相同身高但不同肩宽等参数会触发身体重建，不能误用旧身体或毛发。

F 顺序组合：肢体径向平滑场 → 腰宽 → 胸腹厚度 → 腿身比例 → 骨盆宽度 → 肩宽 → 整体身高。每个局部场使用平滑过渡和明确的有限支撑；轴向场、管状场都带解析雅可比，并检查局部行列式。法线使用逆转置，不把位置位移直接加到法线上。算法适用于当前锁定参考的约定范围，不是对任意人体输入的证明。

腿部管状场根据参考臂手节点及末端限制外半径，保留 1 cm 距离；这只声明参考节点保护，未认证整个手部网格。T1 及以上保持 F(p)=statureScale·p；现有面部控制、耳部控制和毛发根的作用范围均在这一区域。毛发沿头部局部坐标缩放，发梢不逐点调用身体的局部场。

`body/CharacterShape.js` 复制源骨架，然后对每个静止节点和末端使用 F。源骨架、拟合系数和动作内核保持原样；球面拟合仍是来源证据，没有重新拟合。运行时姿态继续使用刚体双四元数，不在姿态阶段拉伸骨骼。

Worker 在 canonical 空间生成曲面、执行现有静态腋窝分离和绑定，再用 F 处理个人位置与法线。保留 canonical 属性供材质和面部控制使用；个人位置保存为绝对 Float32。每个显示顶点增加 12 字节参考坐标，计入资源报告。皮肤拉伸使用个人静止三角形面积，避免把体型变化误当作动作拉伸。支撑探针从全部个人皮肤顶点重新挑选，按个人关节坐标中的 26 个方向覆盖极值。

## 动作与物理尺寸

`bodyMetrics` 同时提供个人和中性参考的肩宽、髋宽、臂长、肩高、站立骨盆高度、低蹲高度、掌部接触点及身体各部分代理半径。推演、接近、携带、坐躺、IK 和物理代理消费个人尺寸；坐躺净空用个人骨架解析源动作帧并缓存，任务执行继续消费同一份推演结果。

代理半径是显式的设计余量，变瘦保留参考净空，变宽增加余量。它们不是从完整曲面测量得到的碰撞包络，不能宣称不会穿插。变化后仍需动作及视觉验收，不能将参考动作精度直接转移为个人曲面精度。

## 精度与未完成范围

参考的插值、边界及法线误差限定在 canonical 坐标空间。仅整体缩放时可按尺度推导参考长度误差；有局部体型时 `derivedErrors=null`，个人插值、边界及法线误差明确未测。个人 Float32 再编码舍入单独报告，不覆盖全部变换误差，也不继承完整位置证书。

本轮没有制作脸型身份系统、年龄/性别模型、真实肌肉脂肪分布或人格系统。现有面部微控与表情继续工作于保留的头部参考空间。以上“接入”是源码关系描述，不是本轮运行结果。

## 调研依据

- [SMPL 官方项目](https://smpl.is.tuebingen.mpg.de/)，用于区分静止体型、姿态以及关节依赖的建模思路；本实现没有导入 SMPL 模型或学习系数。
- [Dual Quaternion Skinning 官方研究页](https://users.cs.utah.edu/~ladislav/dq/index.html)及其论文，支撑保留刚体姿态变换、在静止体型阶段处理形状的决定。
- 当前项目锁定的 R2 来源、原有 DNA 来源与 P0/P1 方案继续可追溯；新增的设计参数不构成独立观测。
