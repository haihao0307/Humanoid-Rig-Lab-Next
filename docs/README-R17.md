# 身体函数重构 R17

当前入口：[人物身体_R17_精简参数与无损加载](delivery/人物身体_R17_精简参数与无损加载.html)。图文自审：[测试与自审](delivery/身体重构_测试与自审.html)。本板块只做身体，头部由其他板块处理。R08和R15保持可回退；最终哈希及功能检查以DELIVERY.json为准。

最新整体探查：[R17整体探查与后续路线](delivery/身体_R17_整体探查与后续路线.html)，新增8组状态/16张正常距离实拍，产品未改。发现进入体型为高肌肉定制档、体量变量与绑定支撑耦合及中间场数据偏重等问题；下一修改范围限定躯干结构与体量响应校准，见docs/BODY-AUDIT-AND-ROUTE-R17.md与AUDIT-R17.json。

表示方式遵循用户硬约束：**函数构成母体，变量定义个体，噪波处理表面；不生成身体三角面。** 新运行时不加载原来的网格模型或面连接，不引入Three.js、外部代码或皮肤图片，不构造人物顶点/面索引缓冲。显示直接寻找隐式函数表面；屏幕绘制只调用点图元，没有全屏三角形。

原R15保持不变，当前版本没有迁移到总工作台。校准系数和权重仍源于原系统，不能称所有数据已经自主。

## 当前核对结果

- 1916项原参数目录随程序与存档保留；后台保留965项身体控制，界面按当前驱动显示有效项，头部变量保留在档案中。
- 主界面集中为8个常用身体变量与一个应用按钮，详细身体控制折叠保留。统一入口`bodyControlR17.apply`支持批量修改，34对左右局部参数可联动，单侧自由度保留；相同值不重新求解，无效批次不会部分写入。
- 数据包合并734个字节相同的数组副本，2256个逻辑数组保留为1522个唯一数组，包大小117.4MB降至59.9MB。数值位模式、完整元数据树和计算语义不变；不是裁剪体型维度。
- 原身体算子的1213项输入、2426个单项取值比较通过；它不等于所有组合和整个范围均已视觉验收。
- 独立运行时的中性、胖瘦、肌肉、性别形态、手臂动作及另一骨架响应，与参照计算结果核对通过。
- 真实保存、载入、连续载入同一文件和旧R15档案载入通过。身体变动没有清除头部变量。
- 6000个独立目标表面点的近似投影检查：均方根约0.968mm，95分位约1.976mm，最大约4.933mm。不是全局Hausdorff距离或严格最近点证明，仍非一比一。
- 显示交点另行通过实际GPU深度回读核对，最大函数残差约0.08mm；这是像素相对函数的误差，不能称为人体还原精度。
- 材质参考坐标随身体移动：40点整体平移与30°转身检查通过；噪波编辑不触发身体形体重建。大关节弯曲后的全部材质坐标尚需继续审核。
- 实际GL绘制检查没有三角图元、人物面索引或远程请求。自启浏览器在检查后关闭。

具体哈希和最终结果以`BUILD.json`、`DELIVERY.json`及对应QA报告为准。截图用于运行证据；可操作的真实三维页面是交付本体。

## 自审与后续

当前已经摆脱了“只重写函数但仍显示旧三角网格”的路线。R08分离形状求交与着色法线；本阶段改为沿关节方向平滑过渡，采用保留原核的正则最小二乘，取消系数硬截断，并修复越过零点后直接接受交点的问题。详见docs/CONTINUITY-AND-RAY-R15.md。

这些改进主要在表示稳定性、接合与显示准确度。整体肤质改善有限，弯腕局部亮线和过强褶皱仍未根治；部分隐式表面仍有数毫米误差。短距离阴影和延后腕部法线切换的试验没有通过视觉自审，未采用。不能用强噪点或局部柔化掩盖形体误差。

用户最新优先级：身体整体比例、体积和动作质量 → 残余腕部、手足及更多动作/接触 → 自主母体和校准数据分区替换 → 与头部模块的数学边界连接及总平台整合。暂不针对某套灯光重调肤色/粗糙度。所有步骤继续保留来源、真实迭代、正常距离截图和未通过项。参数整理与项目库方法详见docs/PARAMETERS-AND-COMPACT-R17.md和docs/PROJECT-METHODS-R17.md。

构建：`node tools/build.cjs`。参数映射检查：`node tools/test-controls-r17.cjs`。实际新旧函数、像素、操作与存档检查：`node tools/qa-compact-r17.cjs`。交付完整性与结构检查：`node tools/finalize-compact-r17.cjs`。旧版检查脚本和被取代的网格比较阶段继续归档；不要调用`qa/legacy-comparison/build-legacy.cjs`构建新平台。
