# 本次阶段：接合、稳定拟合与实际交点

本阶段由用户在R08交付后明确要求“继续做下一步”启动。只改身体，不修改旧R15或头部板块，不改变原身体参数算子、骨架、权重或人物存档合同。函数、变量、噪波和零人物三角面的限制保持不变。

## 1. 用关节方向控制局部精度

R08以手足局部方盒的边界控制粗细场切换，着色方向也有独立的硬切换。新的过渡仍用原方盒限定外部支持，但实际权重取决于当前关节原点和手/足采样中心形成的方向。沿该方向以五次平滑函数 `t³(6t²−15t+10)` 在前臂/小腿与手足间过渡。

手部区间为关节前35mm到关节后15mm，足部为前45mm到后15mm；原点与方向随动作重新计算。几何标量、材质参考坐标和法线尺度使用同一个过渡。方盒外缘仍保留8mm衰减和45mm支持余量，避免重新出现悬浮指尖。

这不是完整解剖模型，也不保证接触或极端动作无自交。正常距离弯腕图仍有局部亮线/褶皱过强，不能把这次改进写成所有接缝已经消除。

## 2. 保留原核，替换截断求解

R06曾同时更换核与求解器，手指显示破碎，未采用。本阶段保持R05的方向筛选、带宽和行归一化核 `A`，改为求解：

`min_b ||A b + g||² + λ ||b||²`

采用稀疏预条件共轭梯度求解 `AᵀA + λI`。全身λ=0.04，局部λ=0.002；不再将单个系数夹到±25mm。固定正则项约束求解；这不意味着数据、参数邻域切换或所有形状都已全局光滑。

中性体型的最大系数为全身约19.02mm、局部约16.11mm，原先两者均触及25mm。不同体型单独记录：女性形态的局部最大系数约42.46mm，数值探查定位在骨盆样本3020，并非手足样本；不能把中性体型数字当作整个范围的上界。诊断见qa/fit-region-probe-r12.json，实际状态与收敛记录以当前交付生命周期报告caseFits为准。

6000个独立目标点的近似投影：R08均方根0.944mm、95分位1.954mm、最大4.912mm；新拟合约0.968mm、1.976mm、4.933mm。小幅增加约0.024mm，换取受正则约束的求解。训练约束残差、系数求解误差和最终表面误差不是同一个指标。

## 3. 核对实际显示交点

旧步进器在函数值变负后直接接受当前位置，且正值停止阈值较宽。新显示保留前一个正值位置，对越过零点的区间做10轮二分；手足区域限制最大步长，停止阈值从全身0.8mm/局部0.3mm缩小到0.08mm/0.03mm。

独立检查将实际GPU求交深度编码为RGB24回读，再用CPU标量插值器核对交点。三种正常距离画面中，R12最大内部偏离曾达约1.12mm；R15回读的最大绝对残差约0.0802mm，未再发现超过0.1mm的内部偏离。报告见qa/ray-hits-r12与qa/ray-hits-r15。

**0.08mm是像素交点相对当前函数表面的误差，不是相对原人体表面的一比一还原精度。** 当前函数仍有约毫米量级拟合误差，也没有全局最近交点、Hausdorff或精确SDF证明。

## 4. 本次未采用的方案

- R10：弱正则的全身系数仍接近39mm，未选为默认。
- R11：局部求解在迭代上限处略高于预设残差目标；R12提高上限，保留原始记录。
- R13：加入近处遮挡和短距离阴影后，正常距离产生硬边与色块，已拒绝。最终版本沿用R08的灯光和材质函数。
- R14：越界交点得到修正，但正值停止阈值仍偏宽；R15进一步缩小阈值。
- R16：延后腕部着色法线切换，正常距离没有消除亮带，未采用。初次R16法线诊断仍用了旧混合规则，已标为不能用于该方案的法线验证；实际截图保留。没有将该诊断当作通过证据。
- 近距腕部图、去镜面与仅环境光图只用于定位问题，不能代替半身、全身验收，也没有把诊断用的超范围参数保存为产品默认。

## 后续优先级

1. 全身与半身下的区域肤色、表面粗糙度/油膜和受光层次；当前整体仍平、细节仍弱，不能称视觉完成。
2. 增加姿态与接触检查，分辨源形体的腕部褶皱与隐式表示误差，继续处理残余亮线。
3. 与头部模块通过共同静止空间和颈口函数连接。当前仅保留接口，没有擅自修改另一板块。
4. 独立来源的母体、变化场、权重与校准数据替换；现有系数仍保留来源关系。
