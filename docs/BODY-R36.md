# R36 身体体型、骨架与旧档

本版以当前迭代的人物身体和 R35 皮肤为基础，继续直接求交函数表面。来源系数和已有分区信息仍被使用；这不是已完成的独立母体，也不代表整体视觉已验收。

## 本次接入

- 工作页「身体统一调整」增加年龄、性别连续滑条，也可直接输入数值，与胖瘦、肌肉、身高、比例、胸部及已有局部参数一起应用。性别形态为 0～1；年龄形态为 -1/3～1，表示从婴幼儿到老年的模型参数，并非实际岁数。头部档案不会被改写。
- B 骨架的身体姿态已进入当前连续身体，支持现有的屈髋屈膝等姿势和允许的身体关节分量；默认开启的姿态修正参与计算。A 骨架动作保留，切换驱动不清除另一套动作。B 的头部动作及不同身份参数仍受现有兼容范围限制。
- 已恢复 R18 躯干、R19 肩背结构、R20 躯干和四肢体积以及关节修正。真实 R20 人物档案可载入并保存，头部及其他档案字段保留；这些改形只在档案启用时应用。
- 年龄、性别、B 骨架及已接入的旧档改形使用当前皮肤、动态阴影和屏幕空间柔光。数据按所需形态和驱动延迟载入，首次切换仍可能需要等待。

## 检查范围

- 在无窗口浏览器中检查了工作页滑条、婴幼儿/青年/成年/老年样本、性别混合、B 骨架屈曲、年龄性别与 B 屈曲组合、真实 R20 旧档、旧档与 B 屈曲组合，以及保存和恢复。B 屈曲姿势下也检查了转动中和停止后的轮廓处理。
- 对现有 B 评估器与旧档体积、关节改形做了离线数值核对。B 的姿态修正使用来源派生的响应函数，其中原始数值相加时的舍入无法完全重现；这项核对不等同于人物整体视觉验收。
- 检查使用当前测试环境和有限组合，不代表所有年龄、身形、极端动作、设备或头部组合都已验证。

## 尚未完成

- 旧档专用手指、脚部局部隐式细节尚未接入当前函数表面；旧档的特殊法线变换也未逐项恢复，当前法线随更新后的身体重新计算。档案中的相关设置仍保留。
- 动作按钮是静态姿势，连续播放、更多复杂动作和极端体型下的自然变形仍待完成。
- 头部独立项目、附件跟随及整个人物平台的联动仍待完成；不同设备性能和完整物理体积散射也未完成。
- 当前身体、皮肤和动作的最终外观仍需结合实际三维页面及用户反馈调整。
