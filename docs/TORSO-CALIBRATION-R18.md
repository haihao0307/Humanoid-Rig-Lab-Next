# R18 躯干结构与体量响应校准

## 本轮范围与判断

从R17整体探查的第一优先级开始，建立明确的校准档、分离软组织体量和动画支撑，并在限定躯干范围加入项目自编的大体积函数。R17交付和全部旧参数键保留，旧档不自动启用新响应。头部、共享R15、毛孔、衣服和总平台没有加入本轮。

这是校准和局部结构的实施版本。身体自然度、肩腋连接、手足及完整动作仍未达到最终视觉验收；本轮检查通过不等于整体人体已经完成。

## 基准档与兼容

- 默认进入成人校准档：年龄形态轴0.5、体重0.5、肌肉0.35，身体局部增强归零，原身高、比例、性别形态与基础混合保留。年龄轴0.5是项目中的校准约定，未经实际年龄换算，不能当作人体统计标准。
- 校准偏瘦为体重0.28；丰满为体重0.86、肌肉0.15；校准肌肉为肌肉0.9。它们是同一套支撑规则下的固定测试点，不宣称覆盖所有组合。
- 头部所属变量、头部局部项和两套驱动中需要保留的头部状态不清空。当前原档MHR身份和动作向量本来均为零；没有通过清空身份来伪造中性档。
- “R17原人物”恢复原始状态，包括总体肌肉0.96和原局部增强。读取旧档时没有`bodyCalibration.enabled`，继续执行旧响应。新档将校准模式、结构强度、原人物状态和已完成迭代一起保存。
- `BodyControlR17`仍负责965项身体入口和34对左右联动；新校准规则未删除原控制维度。

## 支撑和体量的分离

`BodyShapeR18`的表面形态仍用当前全量形态系数计算；动画参考头点和方向单独使用支撑参考求值。支撑参考固定总体weight=0.5、muscle=0.35、cupsize=0.5、firmness=0.5，并去掉fat、muscle、volume、tone、pregnant、navel、nipple、breast、bulge、circ类别的身体局部体量项。头颈所属项保留。

height、proportions、性别形态、年龄形态、显式局部尺度和位置仍可以改变支撑。此处所称支撑是现有动画绑定参考，**不是从影像恢复或测量的真实内部骨骼**。原骨架名称、参考数据和权重仍保留来源。

规则只在新校准模式启用。两个驱动共用同一个形态求值对象，因而A驱动和B驱动的目标绑定都获得同一份支撑参考，而没有只修显示层或只锁四条被测肢段。

## 局部结构函数、坐标和量级

`BodyTorsoR18`使用米制、Z向上的共同静止空间。以左右髋关节中点为原点，髋中点至neck01的高度作为纵向尺度，upperarm01.L的横向位置作为肩带尺度。当前成人校准档对应高度约0.51688m、半肩带尺度约0.17719m。这是本人物绑定的测量值，不推广为所有人体常数。

纵向坐标u由该高度归一化，横向a为距中线距离除以半肩带尺度。函数分别控制胸前宽体积、胸廓侧向支撑、腰部收束、肩胛后侧宽体积、腰背转折和骨盆后侧体积。幅度为毫米级并随当前支撑尺度缩放；不是靠噪波刻肌肉。

每个分量使用高斯宽函数。纵向u低于-0.42、高于1，以及横向a大于1.02的区域完全为零；边界使用五次平滑过渡，避免硬切。胸廓和腰部的形体定义受肌肉轴调节，高体重降低这些结构分量，骨盆保持宽缓体积。程序不提供真实肌肉分束、筋膜或内脏的恢复声明。

位移先加到共同静止空间每个完整影响贡献，再按原权重和当前皮肤矩阵运输。这样两套驱动及躯干转动中的修正都随身体走；没有用屏幕空间补丁。独立数值检查重新蒙皮完整影响包，验证其与实际纠正后采样相符。

该层是项目自编的局部结构修正，底下仍依赖原形态场、采样、法线和绑定数据。不是整套自主母体替换完成。

## 几何和着色的分离

界面提供当前表面、仅几何法线着色、几何法线方向三种观察模式。仅几何模式保留灯光和表面参数，只替换法线来源；法线方向模式显示几何梯度方向。这里的几何法线来自当前隐式标量函数的差分，不是原网格法线。

第一候选的躯干仍使用85%参考方向混合，宽面结构受抑制。最终候选仅在校准躯干使用平滑区域权重，将参考方向混合降至40%；区域依据材质静止坐标选取，避免跟随相机改变。原人物模式、手足局部求交及灯光、肤色、粗糙度配置保持原规则。

没有通过更强噪波或单独调灯补形体。参考方向、差分间距与结构函数仍需在后续逐层研究，不能断言某一个平滑参数是全部缺陷的唯一原因。

## 函数所有权

| 文件 | 负责的内容 |
| --- | --- |
| `BodyCalibrationR18.js` | 成人/极端校准档、头部保留边界、软组织和支撑参数分类 |
| `BodyShapeR18.js` | 在R01完整表面算子上分离动画参考求值；原算子约定保留 |
| `BodyTorsoR18.js` | 自编躯干宽体积函数、有限支持、完整影响运输和校准报告 |
| `BodyImplicitWorkerR18.js` | 原始参照法线初始化、双驱动求值和隐式场构建 |
| `BodyRayR18.js` | 隐式求交、校准躯干法线混合、结构诊断模式；仍只绘制点图元 |
| `BodyImplicitAppR18.js` | 校准/原人物切换、真实迭代、完整存档及重复载入 |

## 失败、修正和防止重复

1. 第一次数值脚本把B驱动中的类型化矩阵当成普通嵌套数组，扁平化后相减得到NaN。改为逐矩阵明确转换为数组；没有放宽数值阈值。另一次局部变量测试误删了头部局部项，改为只增补被测身体局部项。
2. 最早一次浏览器辅助脚本直接读取尚未定义的错误标记，导致辅助脚本失败；改为显式读取window属性。此项是检查工具错误。
3. 第一候选完整运行期间继续进行了法线与存档改进，其最终源码哈希检查失败。该轮因此不能作为最终通过证据，已保存在`qa/calibration-r18-trial1/`。最终候选重新构建并完整复测，运行时文件冻结后再验收。
4. 第一候选宽面结构仍受参考方向抑制，未把它当作最终视觉完成。降低的混合量仅用于校准躯干，并保留原人物和几何诊断对照。

## 可重复验证和下一步

`node tools/test-calibration-r18.cjs`检查两套驱动的旧档数值一致、总体和局部软组织不动支撑、身高/比例仍有效、有限支持和完整影响包。`node tools/test-controls-r17.cjs`核对原控制映射。`node tools/qa-calibration-r18.cjs`离屏运行正常距离多体型/动作、真实保存/重复载入、R17原人物画布对照及实际零三角面绘制。最终哈希和截图以`BUILD-R18.json`及`qa/calibration-r18/browser.json`为准。

第一优先级的支撑分离和校准入口已落地；整体自然度的最终条件尚未通过。下一轮应继续核对胸廓肩带、腰腹和骨盆的宽面结构，特别是背面与肩腋过渡；等这层稳定后再进入第二优先级的关节、手足和动作。不要把本轮有限样本的通过外推为所有体型、所有动作或全部自主来源已完成。
