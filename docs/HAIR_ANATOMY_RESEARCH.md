# 头发与人体的关系：研究及现有实现复核

2026-09-09。本次只查阅资料和阅读代码，未修改运行时代码、未运行应用。本文将文献事实、建模推论和待验证原因分开；不是对现有头发的验收。

## 1. 从皮肤到整头发型

毛囊是皮肤中的组织结构，包含毛球、毛母质及根鞘等；毛干是其产生的角化纤维。出皮口只是可见毛干与皮肤相接的位置，不能把整个毛囊等同于贴在头表面的一个点。外观模拟可以省略内部组织网格，但必须保留可靠的附着位置和出皮方向。[组织学说明](https://www.ncbi.nlm.nih.gov/books/NBK532929/)

毛囊单位描述相邻毛囊的组织分组。一个单位可以包含多根终毛；它与梳理后肉眼看到的一束头发不是同一尺度。密度至少要区分毛干数/cm²与毛囊单位数/cm²，不能直接互换。现用印度男性研究将二者分开测量，且没有提供头顶部的独立采样结果。[原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC11753574/)

毛囊形态与毛干本征弯曲有关，离体培养研究也观察到产生的毛干保留弯曲特征。因此，发丝形状不能仅由头皮法线或绕头球面的走向决定。[Thibaut 等，2005](https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1365-2133.2005.06521.x)

对应到本项目，应分别表示：

| 层次 | 决定的内容 | 不能拿它替代的内容 |
| --- | --- | --- |
| 有头发生长的皮肤区域 | 根点能出现在哪里、发际线边界 | 整个人体的碰撞范围 |
| 毛囊与局部坐标系 | 根点、出皮角度、局部生长方向、直径 | 整根头发的最终路径 |
| 毛干 | 长度、自然曲率、弯曲和扭转响应 | 头皮上连续的一层硬壳 |
| 梳理与剪裁 | 分缝、刘海、层次、发束、剪裁长度 | 人群毛囊统计或性别常数 |
| 接触与运动 | 与耳、颈、肩及其他发丝接触后的运动 | 从头中心向外推所有点 |
| 成像 | 毛丝遮挡、方向性高光、透射与阴影 | 生物学密度本身 |

## 2. 毛干与身体怎样相连、怎样避让

建模推论：毛干根部应绑定在有头发生长的皮肤三角形上，用三角形身份和重心坐标随皮肤运动。出皮方向应在该点的局部坐标系内表达。皮肤内部的毛根属于正常解剖结构；需要防止穿入肉体的是外部毛干，不能把二者混为一谈。

外部毛干是一条有长度、粗细和弯曲特性的空间曲线。弹性杆研究把中心线、弯曲、扭转及伸长约束分别处理。这说明“改变节点位置但不控制长度”的修正不足以表示头发。[Discrete Elastic Rods](https://www.cs.columbia.edu/cg/rods/index.html)

本项目的工程要求应是：根部不漂移，外部曲线保持设定长度和连续性；接触时在局部表面附近弯曲、滑动或停留，不能瞬间被推到远处。耳后和颈肩的几何不是以头中心为原点的单值球面。碰撞对象可以包含身体多个部位，而根点只能从头皮生长区域选取。长发接触肩部时，肩部还必须随躯干运动，不能固定在头部坐标系中。

引导发丝的碰撞安全也不能直接代表插值生成的所有毛发安全。已有实时头发研究专门处理引导发丝插值后的穿插与摩擦；这属于需要单独解决的问题。[作者论文，搜索索引可读，全文抓取因文件大小受限](https://www.cs.columbia.edu/~cxz/publications/hair_collision.pdf)

## 3. 为什么图中的效果仍像硬壳

真实纤维的受光与纤维轴向有关。Marschner 等对单根毛发的测量研究显示多重高光和轴向旋转相关的散射变化。增加黑色覆盖率无法替代这些特征。[原始测量与模型](https://www.cs.cornell.edu/~srm/publications/SG03-hair-abstract.html)

对于本项目，首先要有合理的空间毛干路径、层次和轮廓，再处理材质。覆盖网格和发片可以是性能近似，但必须近似正确的毛发体积；它们的三角形数量和贴图密度不等于真实毛囊结构。

## 4. 对照当前代码的具体发现

以下为文件阅读可确认的问题；它们对截图的贡献仍需后续几何数据或画面验证。

1. **生长表面和碰撞集合混用。** `HairFollicles.js` 49、66 行向包含头皮和耳部的 `scalp.collider` 查询最远交点，作为根点和面积采样。代码没有要求命中的三角形属于头皮生长区。加耳朵作为障碍，可能同时改变根点归属，这是结构错误。
2. **碰撞修正没有保长。** `HairCollision.js` 53–65 行先径向投影，再抬升或截短；`HairFollicles.js` 89–96 行接受修正点，却没有重新约束相邻段长度。`lengthM` 只参与前面的路径参数化，不能保证输出曲线仍具有该长度。异常拉长与此机制相符，但尚未逐根复现截图长线。
3. **外部毛干仍依附球面路径。** `HairFollicles.js` 84–89 行用方向向量沿头部径向参数化推进，再加抬升量。这个方式限制了自由空间曲线，不能表达自然离开头皮、垂落和绕过耳部的普遍情况。
4. **连续底层仍主导外形。** `ProceduralHair.js` 55–70 行建立绕头连续网格，再铺满毛发覆盖。加入真实直径和毛囊统计，并没有自动消除连续壳面的轮廓与受光特征。
5. **动态系统只是整体摆动近似。** 三个弹簧坐标不能分别表达各发束的长度、弯曲、重力响应与接触。它可以作为远景近似，不能宣称完成了毛干力学。
6. **文献数据来源还需更细标记。** 当前 `vertex.unitProbabilities` 是额部与枕部数字的平均，原印度研究没有采样 vertex。应明确记录为插值假设。不同人群研究的密度、直径和单位比例也不能称为当前人物的测量结果。

## 5. 后续实现应满足的顺序和证据

先分离头皮生长域与身体碰撞域，明确根点归属和局部方向；再建立具有固定剪裁长度的空间曲线，并处理局部接触；最后从这些曲线生成可承受的显示近似。女性发型应在同样的结构基础上独立梳理，不能只延长男性参数。

重新做头发前，应能在文件中明确每个字段的单位、来源和作用。后续生成数据需要能回答：每个根点属于哪块头皮；总弧长与指定长度差多少；身体修正前后位移多少；是否有非有限点、异常长段和折返；根点是否在运动中漂移；插值和远景简化是否重新造成穿插。

最后还必须检查发际线、发旋、耳后、后颈与颈肩的实际外观。当前用户要求只验证文件内容，故本次没有执行这些运行时检查，也不将研究结论或静态检查当作视觉通过。
