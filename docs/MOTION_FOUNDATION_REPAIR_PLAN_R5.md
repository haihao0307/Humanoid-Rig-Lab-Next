# 人体动作基础修正计划 R5

2026-09-13。按用户“开始计划、修改”执行。先完成单人基础和动作连接验证，再确认双人持续负载；不把任务计数或静态文件检查代替近景动作验收。后台浏览器不操作桌面鼠标。面部、毛发的并行工作保留。

1. **建立可比较基线。** 捕获同一源码集合，在相同人物、相同相机中观察来源站姿、45° 抬臂、90° 抬臂及挥手。分别关闭肌腹、肩部 LBS 混合、参考腋窝抬升；临时几何法线只用于区分轮廓折叠和着色误差，不直接当作修复。
2. **修正骨架与蒙皮不一致。** 除已修腕部，检查骨盆至大腿、脊柱及肩带的父变换是否把绑定子关节映到已提交子关节。保持来源骨长和手脚接触；固定的动作实验室文件不改动。
3. **依据对照选择肩腋修正。** 保留有证据的改动，撤回造成静止形体压缩或扩大折痕的配置。避免移动骨骼来补偿错误曲面；不通过关闭碰撞、加大误差阈值或单独改法线掩盖几何问题。
4. **验证动作与开销。** 覆盖单人站姿、抬臂、挥手、步行、动作交接及两种体型，再执行双人实时循环。保留脚锚、连接误差、运行错误、CPU/GPU 和帧间隔记录。截图和临时显示数据存项目外。
5. **装配交付。** 执行相关数值回归、源码装配和全量文件检查；附本轮实际近景，逐项说明已解决与未通过的内容。

执行状态与结果在本文件后续记录。此计划不宣称目前全部人体曲面、物理或全部长任务已合格。
