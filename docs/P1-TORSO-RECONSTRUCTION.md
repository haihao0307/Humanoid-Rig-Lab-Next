# P1 躯干基准、校准与支撑研究

固定路线仍是 [P1～P5](../BODY-ROADMAP.json)，当前在 **P1 / P1.1**；所有主任务均未验收。此记录区分实际工作、证据和未解决问题，不定义新的全局优先级。

## P1.1：原数据基准

- 进入时的原人物是已调整人物，体重为 0.66、肌肉为 0.96，不能称为中性成人。对照还包括肌肉和体重均为 0.5、清除身体局部控制的校准候选；其余人物条件按该档原始记录保持。
- 离线原版与 R29 来源函数在相同的 321×481 画布、机位和灯光下，对这两组各检查正、侧、背全身及半身，见 [matched-native-baselines.json](../qa/p1-torso/matched-native-baselines.json)。R30 来源页继承相同形体和材质实现。原版几何只在隔离对照中使用；它不是运行时人物三角网格。
- 全画面仍有少量轮廓覆盖和局部颜色差异。原人物正面 RGB 单通道最大差为 23，其他七个视图也有各自差异；这些数值是观察结果，不是验收限值。挑选出的差异见证点在原始几何射线与函数首交的离线对照中没有命中分歧；这不证明所有像素、机位和形态一致。
- 原人物正面肩缘的一个像素，原版着色输入和函数页取到不同的深度与法线。像素内部附近存在另一处原表面；投影量化实验可解释这一处现象，但尚不能唯一确定 GPU 的覆盖规则，也不能解释所有剩余差异。证据见 [shader-input-probe-1.json](../qa/p1-torso/shader-input-probe-1.json)、[pixel-footprint-witness.json](../qa/p1-torso/pixel-footprint-witness.json) 和 [raster-coverage-hypotheses.json](../qa/p1-torso/raster-coverage-hypotheses.json)。深度探针使用半精度帧缓冲，不能当成完整精度测量。
- 将原着色输入的部分计算顺序移到分区极值点的尝试未改善八个视图中的全画面最大色差，部分结果变差；该候选没有选用，见 [vertex-order-decision.json](../qa/p1-torso/vertex-order-decision.json)。不能由此断言其他显示差异的原因。

必须继续核对胸肩、腰腹、骨盆的表面位置、法线、边界、首交和正常距离外观，包括更多条件及局部近景。现有数据没有用户批准的验收容差，不能自行设定或放宽；本区原数据与视觉均未验收，也未开始将有意改形混入母体。

## P1.2：可回退校准

R30 工作页把校准前完整人物状态和校准状态一同保存在完整人物档案中。进入比较时只改变既定的体重、肌肉与身体局部控制，保留年龄、性别、身高、比例、姿态、驱动、头部和未知字段；可恢复进入校准前的人物。

目前只有已接通原轮廓函数的组合允许进入校准；未接通的组合（包括当前 B 驱动校准）明确拒绝并保留原人物。该档是对照候选，不是已验收中性母体，尚未解除原骨架与软组织的耦合。实际工作页切换、错误回退、冲突字段和完整档案往返见 [calibration-session-browser.json](../qa/p1-torso/calibration-session-browser.json)。

从已显示的原轮廓状态调整到未接入的参数组合时，工作页现在保留原人物并提示原因，不再自动切到旧的简化研究表面；用户仍可主动选择连续研究候选，已有研究档案也保留载入能力。这个保护不代表任意连续体型已经完成原数据复刻。

## P1.3：支撑与软组织

第一次把所有体型直接套用同一绑定使原静止形体产生明显位移，已拒绝并保留结果，见 [shared-support-first-probe.json](../qa/p1-torso/shared-support-first-probe.json)。后续候选保留各体型原静止形体，仅把参考人物的相对支撑动作复合到目标状态。参考是原人物本身，并非已确立的成人中性骨架；绑定参照点也不是实测骨长。

四个同一人物严格体型的静止位置与法线在已测函数域极值上逐位保持；参考人物自己的动作也逐位保持。中等躯干和手臂动作的实际函数画面已在四个视角检查，但这不等于极端动作或视觉验收。证据见 [relative-support-probe.json](../qa/p1-torso/relative-support-probe.json) 和 [locked-preview-browser.json](../qa/p1-torso/locked-preview-browser.json)。

独立[支撑动作三维研究页](../delivery/身体_P1_参考支撑隔离研究.html)可以切换原支撑与参考支撑；它不替换工作页人物，不提供存档导入导出。仍需支持任意体型的原表面、更多形态与动作组合、完整人物档案、B 驱动和原数据及视觉验收，才能考虑进入主工作页。

新增的 A 驱动连续支撑函数把原人物的关节系数单独提取成约 438 KB 的压缩程序，不包含人物顶点、面连接或蒙皮点数组。在同一原人物的六组胖瘦/肌肉值、静止和一组躯干/手臂动作下，修正运算顺序后，与原版计算的 104 个关节矩阵及参数系数逐位一致；参考支撑复合后的参照位置仍有最大约 `4.45e-16 m` 的数值差。此前未修正候选保留在 [continuous-support-before-arithmetic.json](../qa/p1-torso/continuous-support-before-arithmetic.json)。这些是所测样本的结果，不是容差或全参数范围验收；其中位置是绑定参照而非实测解剖骨长。程序和检查见 [BodySupportRigP1.js](../src/research/p1/BodySupportRigP1.js)、[continuous-support-native.json](../qa/p1-torso/continuous-support-native.json)。它尚未接到连续身体表面和完整人物存档，未证明整体骨软分离完成。

保持其他人物条件不变，在胖瘦和肌肉各取五个值时，原绑定参照的肩部横向间距相对于原人物约变化 −0.97%～+2.20%，骨盆参照间距约变化 −5.94%～+1.39%，躯干两个参照点的距离约变化 −7.61%～+8.24%。这是来源派生关节函数的离散扫描，数值不代表人体实测骨长，也不能推广为全部人物；它指出软组织控制和原支撑关系确有耦合，见 [support-coupling-sweep.json](../qa/p1-torso/support-coupling-sweep.json)。

为判断连续体型能否忠实保留原始计算，在颈部流程之前对三组非模板胖瘦/肌肉值做了离线对照。此前参数掩码的运算分组与原版不同，造成每组 34～38 个系数分量不同；旋转归一化和乘法分组也与原版不同。保留原运算顺序后，这三组的参数系数、静止坐标、Float32 位置、静止绑定矩阵和蒙皮矩阵均逐位一致；此前及分步结果一并保留在 [continuous-shape-source-feasibility.json](../qa/p1-torso/continuous-shape-source-feasibility.json)。另用原版捕获的六组静止样本复核上述计算，结果同样逐位一致，见 [continuous-shape-six-samples.json](../qa/p1-torso/continuous-shape-six-samples.json)。旋转函数另对 131 个确定性矩阵与原助手函数逐位对照，见 [proper-rotation-source-order.json](../qa/p1-torso/proper-rotation-source-order.json)。

修正已用于 R30 保留的连续研究计算，未替换固定原轮廓。六组静止算术相同不代表全部体型、头颈流程、表面分层、首交或视觉已经一致，更不意味着来源派生的研究计算已成为自主母体；原始点表只在隔离对照中检查，没有作为本轮新增数据交付。

## 保留边界

本轮无头部项目修改，无人物三角面生成；R29 来源分区和派生系数仍保留，因此自主母体没有完成。P1.4 的体量调整、P2 的连接与变形、P3 的逐区母体替换、P4 的局部计算与肌理、P5 的头身及平台整合均未完成。检查和候选不代替这些任务的通过条件。
