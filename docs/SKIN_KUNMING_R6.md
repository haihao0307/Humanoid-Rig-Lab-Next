# 昆明场景皮肤 R6

2026-09-12。在 R5 的十二种东亚基础肤色上，增加独立的日晒经历与户外表面状态。默认采用中等中性基础肤色、适度日晒；肤色深浅和底调仍可自由选择。这是场景艺术配方，没有将昆明居民视为一种固定肤色，也没有代表性本地测色数据支撑这些具体数值。

## 研究依据与取舍

- [WHO：紫外线与环境因素](https://www.who.int/news-room/questions-and-answers/item/radiation-ultraviolet-(uv))指出海拔、季节、太阳高度和云层均会影响紫外线暴露。昆明场景的日晒经历因此按个体户外生活独立设置，不由气温或身份自动推断。
- [WHO：紫外线对皮肤的影响](https://www.who.int/news-room/questions-and-answers/item/radiation-the-known-health-effects-of-ultraviolet-radiation)介绍了色素加深及长期皮肤老化。本轮取其中的肤色加深、表面更哑光和浅起伏作为可控的视觉线索；粗糙度数值是美术选择，并非医学量度。
- [昆明地表太阳辐射变化研究](https://www.progressingeography.com/EN/abstract/article/1007-6301/46637)提供本地季节性辐射背景。其观测为太阳总辐射，不能直接当作紫外线指数，更不能据此换算居民肤色。

## 行为与数据

人物设置 → 皮肤与肤色保留十二色选择，并新增四档日晒经历。色卡只改基础肤色、底调和红润；日晒预设只改以下两个参数。

| 日晒经历 | sunExposure 日晒加深 | weathering 户外粗糙感 |
| --- | ---: | ---: |
| 较少日晒 | 0.08 | 0.04 |
| 日常户外（默认） | 0.32 | 0.16 |
| 经常户外 | 0.60 | 0.28 |
| 长期户外痕迹 | 0.78 | 0.52 |

两项控制均为 0–1 的相对艺术参数。生成的东亚场景人物按现有种子追加这两项差异，不改变 R5 的基础肤色随机序列；通用范围生成默认将两项归零。内置居民沿用已有种子采样入口。基础肤色没有被烘焙为新色卡，仍保存在 baseColor。

皮肤配方升级为 `jarvis/skin_appearance@2`。显式 `@1` 配方迁移时将两项新参数设为零，旧版线性 skinColor 也保持原外观。未知版本、非有限或越界参数仍被拒绝。`@1` 不允许夹带新字段，导出统一使用 `@2`。角色体型和表情配方由各自模块继续保存。

## 材质与开销范围

使用现有规范化参考身体坐标 R，面部和颈部采用宽渐变，前臂与手部使用连续权重。它近似轻便短袖的既往暴露分布，不读取当前衣物遮挡，也不累计实时 UV 剂量。身体模型改变比例时仍使用原参考空间；参考解剖布局改变时应更新这些区域。

色素通过各颜色通道相乘柔和加深；户外粗糙感小幅提高粗糙度和现有中尺度起伏，并减弱油光。沿用当前细节噪声形成很弱的大范围不均匀，不添加黑色痣点、灼伤红斑或新的疤痕纹理。

- 新增一个 `vec2` uniform，即两个浮点参数和对应上传。
- 噪声调用仍为三次，GGX 高光仍为两个分量。
- 无新增纹理、几何缓冲、采样循环或绘制通道；调整不触发人物重建。
- 像素着色增加了连续区域权重与颜色/粗糙度运算，因此不能宣称零计算开销。
- 本轮未进行 GPU 计时；自动审批拒绝了超出已有截图例外的运行时参数验证。R4 的性能数字不代表 R6 的新增耗时。
