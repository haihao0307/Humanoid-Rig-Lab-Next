# R21 发束层次与细发覆盖

2026-09-13，接续用户要求继续调整 R20 的整片感。本轮保留 R17 生长区、八款造型走向及原六款默认预设，修改外层组织、发尾覆盖和材质。

## 修改

- 内层保持密实，外层变窄、错开起止长度并有不同的抬升高度。密集的内部体积与较松的外层分别处理，避免所有发片全透明后露出头皮、耳朵或背景。
- 外层使用按种子确定的细发中心线、宽度和发梢位置计算覆盖，发丝之间可以露出下一层。横向偏转、细丝颜色与高光变化沿发流连续；无法在当前像素尺度分辨的细节转为平均覆盖，不使用时间抖动。
- 内层只在发尾逐渐稀疏，外层的稀疏程度更高。每片原有的三分量数据同时编码层次和稳定 ID，不增加顶点属性缓冲或绘制次数。
- 独立细发略微抬离同一引导面，减少整条埋在不透明表面下的问题。抬升以根部为零，根部位置保持不变。
- 波波头顶部弧面与下垂段之间使用位置、切线同时连续的三次插值，去掉原先沿整个头围形成的硬转折。
- 新增波波头连接处切线连续性的回归检查。保留低马尾绕耳、颈后直接汇合、实际底层间距与根部绑定检查。

代码继续以函数、参数和程序化着色器表达；没有加入照片贴图、预制网格或烘焙顶点资产。外层发束数、所有 LOD 索引和内存预算不增加；最多仍为两次毛发绘制。本轮没有进行 FPS 或显卡总内存测量。

## 本轮查阅

- [Epic Digital Humans：Hair Shading](https://dev.epicgames.com/documentation/en-us/unreal-engine/digital-humans?application_version=4.27)：发丝方向决定各向异性高光，主、次高光分别反映光源与毛发颜色；同一片统一高光不足以表现单根发丝的变化。
- [SideFX：Generating hair cards for games](https://www.sidefx.com/docs/houdini/fur/haircards.html)：发片分组、弯曲和根梢控制。仅参考结构原则，未导入其资产。

## 验证与观察

`node tools/test-hair-guides.mjs` 包含 339 项断言，其中 90 项检查两种波波头、三档长度、五个横向位置和三个连接位置的切线连续性。外部脚本检查 58 组预设、质量、种子、长度和密度组合的有限值、根部范围、分段长度及每个 LOD 的字节/三角形上限，并确认 R17 默认几何与生长区来源哈希不变。

文件装配及检查使用 `node tools/build-pure.mjs`、`node tools/check-pure.mjs` 和 `tools/audit-files.py`。隐藏浏览器中的实景截图单独保存于项目外 `hair-natural-r21` 目录，不能用文件通过代替视觉判断。第一轮遮罩出现过度透光，随后将密实内层与稀疏外层分开处理；这次过程截图不作为最终效果。

最终八款主视图与四款后视图均已重新截图。波波头中段的横向明暗接缝不再明显，发尾的大缺口已收紧，刘海与短发末端呈现细丝密度过渡；耳上、后脑和颈后覆盖保持连续。整体轮廓仍偏规整，盘发和马尾的主体仍有成片感，本轮结果不等同于照片级自然度或生产验收。

339 项引导断言、58 组参数检查、107 项毛发文件契约均通过；完整装配一致性检查及 Python 文件审计也通过。发型截图来自本轮最终毛发源码。工作区同时存在其他人体功能修改，前后图用于观察头发变化，不作为其他部位的对照结论。
