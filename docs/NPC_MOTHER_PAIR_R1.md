# 母体双人初始场景

页面初始化保留原始人物，并从同一个 `reconstructed-r2@1` 函数母体生成第二人。新增配方存于 `control/NPCPopulation.js` 的 `npcMotherVariant`，不是预制模型或烘焙网格。

复制体的身高比例为 0.95，腿身比例 -0.35，肩宽 0.70，骨盆宽度 0.35，腰宽 0.65，胸腹厚度 0.55，手臂丰满度 0.75，腿部丰满度 0.65。肤色为暖棕色，发型为深棕微卷短发。两个实例分别生成个人曲面、骨架和控制状态；本次没有实现共享网格缓存或 GPU 实例化。

优先将复制体放在原始人物右侧 1.05 米处，沿用既有碰撞和站位检查。启动后显示双人镜头，原始人物仍为当前人物。在“NPC 生成与多人控制”中可以切换当前人物；“查看全体”可恢复多人镜头。性能面板初始折叠，启动诊断在连接成功且场景实际绘制后自动收起。

2026-09-12 使用后台无头浏览器运行实际工作台，未操作桌面鼠标。确认两个人物及毛发加载成功、个人身体/控制器/曲面对象彼此独立、共享同一场景、可以切换到复制体并切回。已直接捕获当前画面。整包文件检查与 Python 文件审计通过。

当时另发现场景碰撞报错 `TREE_D / WATER_A`，导致共享物理步进暂停两人的动作。2026-09-13 后续修正了水壶的初始重叠位置，并在实际双人场景完成“向前走1米”（水平位移 1 米）；持续任务的实现与验证范围见 [持续任务 R2](NPC_PERSISTENT_TASKS_R2.md)。多人性能仍未完成专项验收。
