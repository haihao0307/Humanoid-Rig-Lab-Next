## 本轮实际检查

- 无窗口浏览器访问当前工作台，检查默认皮肤、一次姿势、胖瘦/肌肉/肩宽组合、拒绝不支持的年龄与性别变化、B 骨架与存档往返；检查记录在 [capabilities.json](../qa/platform-r34/capabilities.json)。默认粗糙度调整实测影响了画面，动态姿势中皮肤控件仍不可用。
- 受支持的两组姿势在相同相机下，以五个视角比较 R33 与 R34 的身体深度和轮廓；受测像素一致。范围只覆盖这两组姿势与这些视角，见 [pose-depth-comparison.json](../qa/platform-r34/pose-depth-comparison.json)。
- 使用既有 R20 人物档案检查载入及保存，确认旧功能标记得到保留，但当前页面不应用这些改形，见 [legacy-r20.json](../qa/platform-r34/legacy-r20.json)。
- 用真实界面按钮及 JSON 下载、载入检查常用操作，见 [ui-roundtrip.json](../qa/platform-r34/ui-roundtrip.json)。这些检查不代替用户对人物实际外观、所有参数及动作自然度的判断。

## 路线精简原则

只保留能影响身体外观、可调性、动作、保存、性能及整合的任务。原数据的历史记录仍保留，但不继续将原数据表面分析、一比一对照、来源独立逐区重写或单独的中性校准作为平台使用前置条件。性能优化以实际卡顿、加载和目标设备为依据。原来的 P1～P5 编号继续使用，具体顺序以 [工作路线](../EXECUTION-ROUTE.md) 为准。
