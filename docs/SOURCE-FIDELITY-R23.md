# R23 身体表面、人物衔接与加载

本轮从 2026-10-24 09:00:50 UTC 开始，硬停止 12:00:50 UTC。只处理身体，原 R15 与独立头部项目保持只读。交付以可操作的三维网页为主，不制作截图画廊。

## 已实现

- 原貌页接回原有的身体肤色层次、毛孔细纹、关节与掌跖色差、颈部浅细褶四项控制，保留原范围及原材质公式。只更新材质时直接复用当前精确表面，不重新计算形体。完整人物文件保存这些值及未显示的头部、附加字段。
- 原貌函数按当前状态读取，51 个压缩字段保持原字节，最多缓存两个已解码状态。原貌页网页本体由约 62 MB 降至约 0.7 MB；数据改为按需读取，未删去函数或降低精度。
- 完整参数页将原 44,950,878 字节压缩包直接交给工作线程读取，避免两份巨大 base64 字符串。网页本体由约 61 MB 降至约 1.6 MB。解压前后均校验哈希，保留 2256 个逻辑数组、1522 个共享数组及全部原控制。
- 两页通过当前标签的临时记录传递完整人物和相机，接收成功后才移除记录。参数页直接建立当前状态的第一份函数场，不先建立一次临时默认场。基准邻域和法线的原计算仍保留。两套驱动的字段与 R22 先进入默认状态、再载入同一人物的结果逐位比较。
- 原貌页仍只接受九个已记录的体型/动作状态；不支持的连续状态留在参数页，可另开原版对照。显示校验采用原貌页自己的原始人物合同，查看用相机记录不会被误当作形体或材质差异，记录本身仍原样保存。
- 精确求交工作线程分段让出消息处理，取消过时计算，保留最新相机和程序版本。实际调度检查使用生产工作线程及人工加重的求交器，不把调度检查当作几何复刻证据。
- 原貌页在真实 WebGL 中断后暂存完整人物并重建画面，恢复相机、身体表面和人物。短时间重复中断时停止自动重载，提供恢复和下载暂存人物。参数页计算数据校验失败时，同样保留可下载的待载入档案。
- 将原项目的皮纹函数及种子配方收进身体项目。三个完整 RGBA 皮纹场的 12 级字段，以及凹陷遮蔽的 R 通道，均可由函数重建并与原缓存逐字节相同。凹陷缓存的头部附加 GBA 通道仍保留原缓存，不声称已重新生成；未改头部项目。

网页本体缩小不等于模型数据消失或总 GPU 内存同比下降。皮肤与固定状态阴影仍使用原数值缓存；连续参数页仍使用原 R22 密集 GPU 函数场，未采用被拒绝的 GPU 间接分页。

## 原阴影与像素对照

已恢复原版的正常更新时序。依次回放九个记录状态时，18 幅缓存与原版读回哈希一致。强制重建会改变原版当时使用的阴影矩阵，不能与该历史快照混称同一观察条件。不同操作历史及任意连续状态的动态阴影仍未完成。

跨上下文的逐字节像素一致性仍有局部差异，R22 自身的重复对照也出现差异。抖动和提交同步试验未稳定解决，未作为已通过修复。R23 保留原材质 GLSL、原函数系数及原显示状态，不为追平像素而改形、平滑、加厚或放宽误差范围。最大值和失败继续保留，不能仅用均方值宣布验收。

当前有效报告、对应构建哈希、继承证据及未通过项，以 DELIVERY.json 为准。原模型只在隔离参照中使用，未混入新显示运行时。

最终固定版本的运行检查包括：45 项原貌运行检查、17 项人物与画面恢复检查、20 项计算字节包检查、22 项人物往返检查，以及 91 项实际 HTTP 入口与数据检查。A 抬臂、B 屈髋膝直接初始化的函数字段均与 R22 载入同一人物的结果逐位相同。这只能证明相应的原工作页数值行为保留。

原版身体对照采用实际绘制拦截，在保留全部原阴影投射物的同时，阻止头部、头发及附件进入身体颜色对照。九状态正侧背面 27 组及身体表面控制 42 组均完成，无非身体对象实际绘制。九状态对照仍有最高 129 个 RGB 码值的局部差异，内部区域最高 97，覆盖差异最高 7 像素；身体表面控制对照最高 19。完整最大值、坐标及线性中间层继续保存，未判定外观验收通过。独立上下文颜色重复性也未通过逐字节一致性。

已从提交的 Git 文件独立导出并重建：没有离线原模型、旧大型中间缓存或未提交运行文件，两份网页哈希及全部 74 个运行数据文件一致。原貌工作线程中断的失败对照和早期未采用试验也保留，不会被后续通过的运行检查覆盖。
