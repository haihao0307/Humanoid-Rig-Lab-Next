## 改动前的问题

旧控制器每次抬脚固定 0.42 秒、固定抬高 6.2 厘米、固定向前落脚 14.5 厘米。前脚落下后可立即抬起另一脚，没有独立的双脚承重间隔。导航从静止直接进入指定速度，在终点直接归零。骨盆几乎不随步态旋转，手臂主要依赖脚前后距离的单个信号。手动停止还会直接清除摆动脚状态，可能留下半空中的脚。

## 当前动作结构

1. **站立**：保留呼吸，加入很小的骨盆姿态与颈部变化；脚部目标保持固定。它不是随机摇晃或主动换脚站立。
2. **起步**：先向即将支撑的一侧转移身体，0.16 秒准备后逐步增加路线速度。原地转身不会因为“移动中”标志而启动大幅摆臂。
3. **行走**：按当前速度预测落脚位置；每只脚依次经历脚尖离地、摆动、脚跟落地、全脚掌支撑。落脚后保留双脚支撑时间，再交接给另一条腿。
4. **全身配合**：骨盆小幅偏航和侧倾，腰胸椎反向补偿；侧向转移跟随支撑腿，中期支撑有小幅升高。对侧摆臂有时间滞后，肘部不再保持同一个弯曲量。
5. **转向**：继续沿既有避障路线移动，支撑腿与身体的相对偏航过大时先等调整步；不直接旋转固定在地面的支撑脚。
6. **到达与停步**：提前降低路线速度，完成当前落脚并调整双脚站位后才报告步行完成。手动“停下”仍立即停止路线位移，但保留当前脚的落地过程；“暂停”仍冻结当前姿态。下一项站立动作等待双脚站稳再开始。

抓握、搬运、推物、坐躺和手势仍沿用已有控制权。手掌目标存在时不叠加本轮骨盆与身体平移装饰，避免破坏抓握；腿部经过同一个接触调度器和原有 IK、关节约束。没有修改骨架长度、人体形态、皮肤、材质、语音或场景规划。

## 初始工程参数

| 参数 | 数值与含义 |
| --- | --- |
| 路线速度 | 保留普通慢走 0.50 m/s、搬运 0.43 m/s；不是用加速播放掩盖僵硬 |
| 速度 | 响应时间 0.20 s；加速上限 0.8 m/s²，减速上限 1.1 m/s²；距路点剩余距离参与减速 |
| 一次脚部运动 | 0.46 → 0.36 s，随实际速度变化；包含起始和末尾各 12% 的脚底滚动 |
| 两脚平放交接 | 每次落脚后等待 0.15 → 0.09 s；两个脚底滚动阶段还提供部分接触，不应把本值直接当作完整支撑相比例 |
| 抬脚高度 | 2.4 → 5.0 cm，短小调整步进一步降低；脚底旋转带来的踝部上移另算 |
| 脚掌角度 | 离地 +0.18 rad、落地 −0.12 rad；绕保守的脚底边缘代理旋转，保持代理触地点 |
| 落脚约束 | 前向预测不超过 31 cm，落脚相对骨盆水平距离不超过 34 cm；不按上一次足位限制步幅，避免长距离行走累计拖脚 |
| 骨盆与身体 | 偏航最大约 1.8°，侧倾约 1.0°，侧移 9 mm，中期支撑起伏 6 mm；根据速度淡入 |
| 手臂 | 对侧摆动系数 0.30 rad，保留原骨架自然外展与掌心朝向；手势和抓握优先 |

脚底接触是运动学近似，使用保守边缘代理，不是当前皮肤网格的精确接触流形。没有实现趾关节主动蹬伸、足底力、摩擦、质心动力学、楼梯、跑步或视频自动提取动作。当前步行速度较慢，不宜将此参数直接用于正常快走和跑步。

## 文件入口与复核

- `body/NaturalLocomotion.js`：可读的接触调度、导航缓动和姿态信号。
- `body_runtime.js`：当前生效源码，`Human.pose` 接收 `locomotion` 信号，仍统一求解全身。
- `tools/sync-natural-locomotion-r1.mjs`：把可读模块同步进当前源码。
- `tools/sync-body-runtime.mjs`：同步现有身体页面与主工作台压缩载荷。
- `tools/verify-natural-locomotion-r1.mjs`：只解析源码、核对模块和解压文件；不执行人体、动作循环、浏览器或服务器。
- `backups/natural-locomotion-r1-20260908/`：此次改动前的源码与交付页面。

后续修改依次运行两个同步脚本，再运行文件复核脚本。`tests/natural-locomotion-r1-files.json` 是本轮文件复核结果；不能用它宣称动作运行或视觉验收通过。旧截图目录与独立肩部预览快照不属于本轮动作验收。

下一轮真人对照应先覆盖直走、短距离起停、90°/180°转向、走后敬礼、携物步行这几个样本，重点看支撑脚是否滑动、膝盖是否突跳、脚底是否穿地、起停是否有明显顿挫。之后才扩展正常速度步行、原地换重心和坐下起身，并按许可选取少量动捕样本进行相位归一化与骨架重定向。本轮没有运行这些动作或宣称其视觉结果。
