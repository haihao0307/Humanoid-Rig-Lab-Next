# R16 头皮种植范围与解剖分区

本版本的耳上避让过宽、耳后与后颈过高，已被用户否定并由 `HAIR_SCALP_COVERAGE_R17.md` 修正。下文是历史记录，不能作为当前范围依据。

2026-09-12。用户指出 R15 像一圈锅盖，要求重新研究中国人的头发分布并界定范围。本轮针对当前成年男性参考头型调整种植范围和分区疏密，并实际检查正面、侧面及后脑。

## 调研依据与适用范围

- [Bao 等，Study on Hair Distribution in Healthy Males for Hair Restoration Design，2018](https://pubmed.ncbi.nlm.nih.gov/30277939/)：研究 1,000 名无头发疾病的中国年轻男性。摘要报告平直发际线 48.7%、平直并中央突出 27.9%、圆弧 9.8%、圆弧并中央突出 13.7%；前缘和颞部以单根毛囊单位为主的比例不同。这支持形态多样性、分区和前缘细化，不能推出所有中国人共有一条标准曲线。
- [Tsai 等，The distribution of follicular units in the Chinese scalp，2002](https://pubmed.ncbi.nlm.nih.gov/12081679/)：调查实际毛囊单位与每单位发丝数量。这里的显示发束是低成本几何近似，不能将它的根点数量称为实测毛囊数量。
- [Hair Transplant Practice Guidelines，2021，Male hairline design / Temporal triangle](https://pmc.ncbi.nlm.nih.gov/articles/PMC8611706/)：区分额中、额颞角、颞三角和前缘过渡，并强调个体化及微观、宏观不规则。本文仅借鉴解剖与视觉组织，不采用移植密度作为正常头皮密度。

下面的坐标和相对权重由当前 R2 头型标定，是建模参数，不是上述研究提供的三维扫描坐标或人群平均测量。不同年龄、性别和头型仍需独立标定。

## 重新界定的范围

| 部位 | 当前规则 |
| --- | --- |
| 前额中央与侧额 | 中段较平直，向两侧轻微变化；边缘用细丝与疏密过渡 |
| 额颞角 | 独立的轻微退让，保留额角与颞区之间的转折 |
| 颞角与颞下区 | 单独设置向前的颞角与其下方的小幅退让，避免一条斜线直接切到耳朵 |
| 鬓角 | 耳前窄区向下延伸，长度缩短，边缘逐渐稀疏 |
| 耳上与耳后 | 耳上留空，沿耳廓上方转折，再向耳后与枕部衔接 |
| 枕部与后颈 | 向下收窄，左右与中线分别控制，保留轻微中线退让与渐稀的短发 |
| 头顶内部 | 连续覆盖；相对采样权重高于边缘，接近顶区时平滑恢复正常长度 |

各区连续连接，边界由 16 个解剖控制点决定。`reconstruction/hair-zones.mjs` 是唯一范围定义：方位角从前额中线向左、右各自展开，以分段平滑插值计算边界、相对根点权重、发束长度和过渡宽度。种子加入有限的左右差异与微小不规则。

移除了原来的 `1.96 - 0.83 * front` 圆弧公式和 `1.495 m` 统一截断。候选根点允许向下搜索到 `1.46 m`，实际是否生成由解剖边界决定，前额、耳区、颈部不会因为放宽搜索范围而自动长发。

## 生成与显示的一致性

根点采样、发束区域长度和底层几何均使用同一分区定义。底层网格直接沿各方位的真实边界生成，最外圈随额角、鬓角和后颈转折；不再生成一张大圆帽再用另一套片元公式裁切。

底层增加三个 Float32 属性：边界过渡坐标与两项程序化纤维坐标。它们包含在原 GPU 总字节预算中，并随 Worker 结果转移。片元直接使用预计算的过渡属性，删除了原来的耳区与圆帽角度计算，没有新增纹理、绘制通道或逐帧几何上传。

节省档将周向采样从 64 提至 96，以描述较窄的颞角和鬓角；相应减少显示发束，仍受原预算约束。原有径向避让补偿、共享头关节绑定和距离 LOD 保留。

## 当前预算和验证

- 默认节省档实际为 **2,554 条显示发束、430,752 字节、最近景 23,408 个三角形**，加 44 字节共享角点及索引。总几何上限仍为 **432,000 字节 / 24,000 个三角形**，最多 **2 次绘制**。
- 均衡档默认种子实际 5,407 条显示发束、1,292,616 字节、70,932 个三角形，上限仍为 1,296,000 字节 / 72,000 个三角形；精细档上限不变。
- 16 组实际生成覆盖所有预设、多档位、长度及密度边界、改种子和单独改色。数值与索引有效，全部根点在分区范围内，所有可绘制 LOD 均不超预算；相同输入可重复，不同种子改变分布，改色不改变几何。
- 9 个独立区域探针检查了额内、额外、额角退让、颞角、鬓角、耳区、枕部、后颈和颈外；16 个控制点的衔接连续性检查通过。
- 当前默认档已实际查看正、侧、后方。第一轮发现鬓角过尖和额角过硬，第二轮已缩短鬓角、柔化额角。当前仍是较紧实的程序化短发，没有声称摄影级真实或跨人群通用。
- 没有新增最终版本 GPU 连续耗时结论。静止页面暂停刷新，旧 R15 的帧率采样不能代表此版本。浏览器日志仍有先前出现过的 `MutationObserver.observe` 类型错误，未定位来源；本轮毛发可显示，未观察到毛发着色器编译报错。
