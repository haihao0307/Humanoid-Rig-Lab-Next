## 本轮发现与修正

R27 的 52 项形变不是任意脸型完备基。首轮真实参考拟合同时撞到眼宽、眉长、下颌/下巴边界，且末尾统一安全限幅会削弱已拟合结果。不能只增加滑块范围并声称解决。

1. 新增独立的 `foreheadHeight`，共 53 项参数、43 项可由正面观测求解，10 项深度参数保持未知。额部场从眉间上方平滑开启，向颅顶的延伸平滑饱和为平移，避免无限拉长毛发。旧 `upperFaceLength` 保留原含义。
2. 眼区的局部支持拓宽，眼宽左右场在中线分开；眉长以内眉为起点向外延伸，左右支持分离，眼线以下关闭，防止两眉在鼻根相加或用眉长移动眼中心。下巴支持覆盖对应的下颌前部，而不是只动中央很小的一块。
3. CPU 与 GLSL 从同一描述生成，包含上述遮罩解析梯度；表面、眼球、眼睑仍共用身份映射。眼球是有界表面近似，不声称恢复真实球体或内部眼眶。
4. 拟合器 `bounded-regularized-landmark-fit@2` 同时优化可见点误差、参数正则与代表性真实头部/眼球样本上的雅可比/伸长软约束；候选回溯使用同一采样可行域。最终应用仍检查全部头脸样本。拟合初值取实际有效参数；初值不在拟合安全域时只收缩可拟合参数，保留深度输入。采样检查不能证明全局无自交。
5. 程序化虹膜采用身份映射在眼中心的切平面度量补偿，避免扩大眼眶时将虹膜色素同步拉成椭圆。瞳孔与虹膜半径分别保存；它们不代替眼球几何恢复。网站可切换参考眼部比例，基准比较恢复原半径。
6. 新链接自动载入同一参考、配方与原图；页面显示可检查的照片点、模型/目标数值及每区像素位置误差，支持重新拟合、手动调整、基准切换和导出。没有依赖后台浏览器独有的 localStorage 才能看到结果。

## 实际结果与尚未覆盖的外观

78 点加权位置 RMS 从 **0.099939 → 0.035163**，约下降 64.8%；换算到原图眼距尺度约 **7.90 → 2.78 px**。这是位置误差，不是身份相似度。最终 40 次迭代、全头实际安全比例 1、最小采样雅可比约 0.48105，最大实际位移约 20.45 mm。

| 比较量（眼中心距 = 1） | 当前模型 | 照片目标 |
| --- | ---: | ---: |
| 颧部宽 | 1.942 | 1.949 |
| 下颌宽 | 1.278 | 1.265 |
| 鼻翼宽 | 0.477 | 0.468 |
| 口宽 | 0.763 | 0.759 |
| 人物左眼裂宽 | 0.406 | 0.471 |

实际后台截图显示轮廓、鼻翼和口宽有所接近，但眼裂、眉长、额部与细部表面仍有差异，**没有完成身份外观验收**。来源人物的伤痕、色素、胡须、唇缝接触、毛发形体与光照保留；原毛发的折叠在新比例下仍可见，不能把接缝数值或低点误差称作外观已无缺陷。单张正面照片不能恢复侧面深度、真实毫米、遮挡部位或内部骨骼/肌肉。

本轮交付可用于判断“照片记录 → 比例参数 → 真正三维变化”的路线，尚不能称作完整目标人脸。下一轮应先复核模型与照片的眉/唇语义标志点，增加可独立控制的眼裂形状与唇接触结构，再以同一固定镜头检查；发型/健康肤质属于独立外观层，不能靠几何数字误差代替。

## 函数所有者与证据

`FaceIdentityModel.mjs` 拥有形变描述、饱和额部与左右遮罩；`FaceIdentityBinding.mjs` 拥有实际外表面、雅可比采样和眼部共享映射；`FaceReferenceFit.mjs` 拥有约束拟合与分区残差；`ProceduralEyes.mjs` 拥有虹膜切平面色素尺度；`FaceIdentityWorkbench.mjs` 拥有会话读写、参考图/标点、比较和导出；`server.cjs` 拥有固定参考输入路由。身体、服装与反推骨架方法没有为这张脸改阈值。

`tools/test-face-identity.mjs` 检查 53 项描述、82 个模型点、27 项量尺、额部/眉部过渡梯度、中线与对侧保护及合成拟合。`tools/validate-reference-r28.cjs` 验证新的浏览器会话自动载入真实目标、图片尺寸、基准恢复、侧视/闭眼、实际接缝、CPU/GPU 映射/法线与数据导出；证据及当时源码哈希写在 `qa/face-reference-r28/validation.json`。PNG 仅为内部 QA，不是用户创作成果。文件装配/门禁使用 `node tools/build-pure.mjs`、`node tools/check-pure.mjs`。

最终后台检查无页面/控制台错误；基准切换后恢复的全部位置数值差为 0，原接缝组最大差为 0。CPU/GPU 135 点位置最大差约 0.0000614 mm、法线向量最大差约 1.36e-6；身份与虹膜数据在表情/重置后保留。上述仅验证实现一致和有限状态，不能代替外观验收。加载及新会话照片显示仍使用实际异步完成条件。

弃用：只放宽数值而保留窄影响区；双侧眉长在中线相加；只在拟合结束后统一限幅；将点误差换算成“相似度百分比”；以单图推断深度或健康肤色。
