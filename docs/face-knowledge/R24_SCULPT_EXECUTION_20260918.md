## HeadSculpt：数值错误与艺术失败分别处理

新增 `body/HeadSculpt.js` 为三对宽支持域平面算子，覆盖颧上面、颊侧面与下颌后侧面；移动真实三维点并通过 Jacobian 更新法线，进入身份映射之前与面皮、原头侧面和附着毛发共用。它解决的是形体所有权，不是自动生成正确美观。

1. **单步初版折叠。** 总强度 .64/.48/.52；CPU 677,520 点中 50 个 determinant 非正，最小 −.0510238816。GPU 128,100 个点/法线组合也遇到 50 个折叠输入位置；最大法线与真实逆转置误差约 1.99947。解析导数本身与差分吻合，保护区没有位移，因此不能把失败解释成测试误差。证据 `head-sculpt-cpu-initial.json`、`head-sculpt-gpu-initial.json` 保留。
2. **八步积分修正。** 每步强度为 `1-(1-totalStrength)^(1/8)`，总目标强度不降。整条路径留在平核内才验证原解析总收缩；进入衰减区者验证沿平面法向移动、距离单调减小与逐步重放一致。CPU 同样 677,520 点无非正值，最小 .190445124；GPU 128,100 组合最小 .190724340，最大位置误差 .000000579 m、法线误差 .000118483。30,000 镜像检查及身体/眼心/中央鼻唇保护检查通过；不是所有连续空间的无折叠证明。证据 `head-sculpt-cpu-integration.json`、`head-sculpt-gpu-integration.json`。
3. **A 仍然视觉失败。** 八步积分没有消除错误的平面目标：颧上区域向外顶成横向厚板，侧面和灰模暴露宽台阶。数值稳定只让错误造型稳定地产生，不能因此保留 A。
4. **B 依据源截面重定平面。** 颧上 anchor 改为 `[.045,1.495,.168]`、normal `[.72,.12,.684]`；颊侧改为 `[.045,1.477,.164]`、`[.80,-.13,.586]`；下颌 anchor `[.055,1.455,.147]`，支持中心 x=.054、x 半径 .022，减少前腮外推。强度仍 .64/.48/.52。CPU 677,520 点无折叠，最小 .1872，见 `head-sculpt-cpu-b.json`。B 三图厚板显著减轻，但颧肩和颌底仍像人工凸台。
5. **C 再调整艺术强度。** 保留 B 平面，强度改为 .36/.35/.32。CPU 677,520 点和 GPU 128,100 组合均无采样折叠，最小 determinant .416；最大 CPU/GPU 位置误差 .000000599 m，法线误差 .000078117；保护域位移零。见 `head-sculpt-cpu-c.json`、`head-sculpt-gpu-c.json`。这是对 B 仍过硬的候选修正，不是靠降低强度绕过初版负 Jacobian；折叠问题已先通过积分解决。C 实拍已完成，执行者的观察与拒绝原因另列下文。
