## 结论与语义边界

当前 **不能覆盖全部脸型或全部脸部数据**。57 个局部权重场中 8 个眼睑/眼角区受保护，49 个可编辑区提供 147 项 XYZ 请求位移。区域重叠、归一化、眼周保护和全局安全限幅使这些数值不是 147 项独立的五官比例。单轴请求 ±3 mm 也不是各点保证达到 ±3 mm；实际位移必须查看报告。

彩色图显示最大权重归属，不是互不相交的组织切块。分区峰值、全体面部样本上的均值和 >1% 点数说明影响范围，不能解释成眼距、鼻宽、嘴宽或解剖组织体积。区域中心是当前人物美术校准用的场中心，不能称为实际检测出的眼角、鼻翼、唇角或下颌测量标志。

| 特征 | 当前可做 | 缺口 |
| --- | --- | --- |
| 额头、鼻梁/尖/翼、颧颊、唇周、下巴表面 | 局部近似微调，镜像或独立左右参数 | 语义尺寸目标、联动约束和目标误差 |
| 三庭、五眼、全脸宽高、上下脸长度 | 可间接影响部分表面 | 实际共享测量标志、全局比例变量；不能强制所有目标都符合相同比例 |
| 眼距、眼裂宽高、内外眼角倾斜、眼球位置、眼皮形态 | 眨眼和视线是表情通道 | 当前无身份形态参数；眼部保护区不能用皮肤平移替代 |
| 鼻宽高、口宽、唇厚、颧宽、下颌宽 | 局部位移可近似部分变化 | 缺少独立尺寸和结构联动，不能保证组合比例 |
| 眉毛、眉密度、发际线、耳、后脑/完整头颅 | 部分邻近皮肤可动 | 未形成完整独立身份控制 |
| 下颌骨位置、牙列、口腔结构 | 当前表面不能观测内部 | 未完整建模；NotObserved 不能伪装成恢复 |
| 毛孔、肤色、皱纹、色素、粗糙度 | 由独立表皮/材质通道负责 | 不属于 XYZ 脸型位移数据 |

`ProceduralEyes.mjs` 的 `identityCalibration` 暴露运行时中性构造值：眼中心间距 68.0 mm、眼裂宽 23.6 mm、高 5.6 mm、眼球半径 12.5 mm。它们是构造参数，不是用户图片测量，不是眼睛可编辑功能已完成的声明。

之后参考图比较需依次补齐：真实共享标志及比例测量 → 全局头脸比例 → 眼球/眼眶/眼睑联动 → 鼻唇下颌结构控制 → 固定镜头下的目标比例误差。三庭五眼可作为描述和比较方式，不能把所有目标脸强制成一张“标准脸”。正面图适合正面投影比例，但不能唯一恢复侧面深度、遮挡和内部结构。

方法研究只用于原则，不导入外部头、网格、贴图或参数资产：[FLAME 原论文](https://download.is.tue.mpg.de/flame/flame_paper.pdf) 区分身份形状、姿态与表情；[CVPRW 2023 单图三维重建论文](https://openaccess.thecvf.com/content/CVPR2023W/GCV/html/Yu_Unsupervised_Style-Based_Explicit_3D_Face_Reconstruction_From_Single_Image_CVPRW_2023_paper.html) 说明单图深度歧义。有限形变基与正面观察不构成任意脸型覆盖保证。

## 加载实现与进度含义

`LoadingProgress.js` 在模块图加载之前启动，显示进度条、当前阶段、数据量/域数量和耗时。百分比是阶段加权完成度，不是剩余时间预测；计时器不推动百分比。超过 30 秒没有新进度时提示可能仍在计算或等待，不能断言卡死。失败显示原因和重新加载按钮。

`SubjectLoadingWorker.mjs` / `SubjectLoading.mjs` 在后台读取参数、解压、解码、生成曲面。读取阶段按实际流字节数/Content-Length 更新；生成阶段按 681 个曲面域的实际完成数更新。`surface-generator.mjs` 只添加进度回调，不更改采样规则。TypedArray 缓冲区通过 transfer 交给主线程；不可克隆的 chart functions 由原参数在主线程重新编译。

`SubjectRuntime.mjs` 以同一个步骤生成器驱动同步 `createSubject` 与异步 `createSubjectAsync`；首轮构建在几何、面部、骨架、各材质、眼部、表皮及体型阶段之间让出事件循环。`app.mjs` / `shorts-app.mjs` 接入此流程；首帧 shader 编译和渲染完成后才显示 100% 并关闭遮罩。单个主线程阶段仍可能暂时占用 CPU，进度值不能冒充每毫秒都有可中断的工作。

`server.cjs` 返回参数实际 Content-Length，并只开放明确运行时入口和其可达相对 JS/MJS 依赖。内部检查曾发现同时新增的运行时模块未在静态白名单中，导致启动失败；改为可达依赖收集，避免新增依赖继续留下无提示加载状态。保留本机端口 8879，不停止其他工作台。

研究依据：[Worker 与可转移对象](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Transferable_objects)、[ReadableStream.getReader](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream/getReader)。未引入人物资产。
