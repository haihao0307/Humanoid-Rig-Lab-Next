# 当前 R008 的皮肤知识记录

骨架、肌肉、脂肪与表皮的持续规则已汇总到 [人体知识体系](../anatomy-knowledge/README.md)。R20 高脂肪仍保留腹肌刻度的用户反馈说明此前正常关节、接缝和法线诊断未覆盖体型外观。后续修改必须区分骨性支撑、肌腹、脂肪厚度、几何沟槽、原表面明暗和微观肤质；运行时 AnatomyContract 与接入分析门禁共同执行，不能仅保存在聊天中。

R20 审查确认，R19 的横截面收缩会在视觉上压小胸廓，而估算的腿中心线与当前髋膝踝不一致。现从实际绑定骨段及八个蒙皮权重生成独立的软组织分区/锚点，骨架只随身高改变。瘦型减少骨段外组织，胸廓/骨盆保留美术支撑包络；肌肉量改变肩、胸、上臂、前臂、股部、小腿肌腹及法线起伏，掌指/足部组织幅度较小。眼眶和足底接触保护必须独立。组织配方不得混入采样网格；临时 GPU 字段可从原权重重新生成。权重过渡要混合各区域的完整位移，不能将控制数值直接塞入非线性函数叠加收缩；颈部遮罩不能进入肩臂。QA 中冻结组织属性的局部雅可比只是法线场诊断，不是全局无自交证明。所有者、米制包络、弃用方案及实际检查见 [R20 骨架与组织记录](../../New-Human-Production/R008/BODY_TISSUE_R20.md)。

服装集成新增的估计裸身腰胯/上腿补体由 `ShortsBarePelvis.mjs` 独立拥有，原人物头脸、原皮肤与旧裤几何不改。生成来源、米制尺度、骨骼绑定、共享皮肤通道和真实覆盖验收范围见 [低腰服装补体记录](../SHORTS_BARE_SKIN_20261002.md)。原生白色顶点仅是纹理增益，不作为肤色测量；不得将估计补体称为被遮挡原人体的精确恢复。

R19 将全身形变移到 GPU uniform，并从同一个纯标量函数生成 CPU/GLSL，避免实时拖动重算全部顶点。下脸变化应保护嘴唇中央和眼眶，不可整段等比加宽；当前眼眶锚点体型位移为零，闭眼遮挡沿用真实几何。年龄通过自创美术包络修正四肢/躯干肌肉饱满度，基础滑块值保持独立，不能称为生理测量。扩大体型时必须使用当前肩肘腕中心线、限制腿部场进入手部，并区分运行诊断的 513 点抽样与 QA 的完整表面遍历。此前放大旧核、错误固定手臂深度和整段嘴周变形已弃用；来源、函数所有者、尺度、实际检查与截图见 [R19 实时体型记录](../../New-Human-Production/R008/BODY_LIVE_R19.md)。

R18 成人体型/年龄叠加保持采集参考坐标及眼周保护，见 [体型和跳跃记录](../../New-Human-Production/R008/BODY_PARAMETERS_R18.md)。身高同时调整骨架、表面和碰撞；胖瘦/肌肉用同一连续场影响皮肤和衣物，并以余子式变换法线。眼皮外圈以上不改变轮廓，年龄细纹走独立材质高度函数（额纹/眼角基准约 100/65 µm），色素、粗糙度与灰发分开。年龄 18–75 是成人美术参数，不能作为医学测量或完整人体种群模型。灰发应保留源亮度，弃用统一亮灰覆盖的白漆效果；局部支持必须平滑穿过中线且保留两腿间隙，相反胖瘦/肌肉组合也须检验。来源系数不变、体型数组只缓存于内存；QA 记录来源哈希和实测关节角度，不能只靠角度曲线宣称跳跃自然。

R17 增加局部曲面细分与独立的材质细节配方，见 [表面精度记录](../../New-Human-Production/R008/SURFACE_DETAIL_R17.md)。默认身体/头部目标 8/4 mm，微纹理默认最大绝对高度 2.8 µm；按像素足迹过滤，不混入色素通道。原采集曲面及 Haar 材质系数不变，新增纹理为自创微结构，不冒充重新采样毛孔或恢复丢失形体。必须区分“采集参数驱动的重建”与“从零解剖规则生成”。四档闭合、35 µm 眼皮贴合、闭眼遮挡和实际 GPU 像素变化检查均留有证据；细分提高运行内存与首次生成耗时。实现所有者、尺度、来源、拒绝方案及性能边界均记录于 R17 文档。

R14 按用户反馈移除新增程序化切口，保留原伤疤愈合；[自由观察与自然眼白记录](../../New-Human-Production/R008/VIEW_EYES_R14.md) 保存实现所有者、材质尺度、研究来源及实际后台 QA。眼白从较强清漆改为温暖灰白、柔和反光，眼眶坐标控制眼睑接触渐变。未改变眼球几何、眼皮锚点或虹膜直径。镜头支持暂停和近景下自由旋转、平移、缩放；人物移动只平移用户所选镜头。

R15 用户仰视截图揭示 R14 正面检查没有覆盖的结构问题：固定眼眶切口与被裁掉的球体留下空隙，邻近顶点估算和平滑深度也不能保证贴合。现改用真实三角面重心绑定、逐点位置/UV/法线查询、宽覆盖区和完整球体，并共享头部材质通道。拒绝仅调暗眼白、扩大切口及大块平滑补丁作为修复。详见 [R15 眼周衔接记录](../../New-Human-Production/R008/EYE_SOCKET_R15.md)，之后眼周 QA 必须加入仰视、侧视、闭眼遮挡与不同采样密度。

R16 身体的分块接缝来自独立部件 ID、边界拟合偏差及细分丢点，不能当作皮肤色素消除。生成器统一边界位置、八权重与采样，现场补齐剩余窄缝；原傷疤愈合改变几何后须同步接缝组。补面的 UV 优先保留真实边界值，不能对极小参数域外推到另一片皮肤。去贴图检查必须保留生产八权重蒙皮；普通四权重替换材质会产生假损坏。详细尺度、弃用方案、原始参数不变证据和实际 QA 见 [R16 身体接缝记录](../../New-Human-Production/R008/BODY_SEAMS_R16.md)。

- 伤疤补全分离色素、法线/粗糙度和局部曲面；运行时稀疏采样不能作为隐藏健康皮肤的精确恢复。单纯褪色和大块平滑替换已分别因残痕与色块问题弃用。
- 色素变化与粗糙度/油光分开。基础色在**线性颜色空间**按比例调整，保留原始参数重建出的表皮细节。
- 旧 R2 的坐标与衣领/袖口函数不能直接套用；当前是赤膊、赤脚人物，使用当前静止坐标形成曝光权重。
- 材质名称不能凭“身体高度”猜测：R12 的腰部材质隔离图证明 `tripo_part_9` 是裤腰/抽绳，已和两侧裤身一并排除。首次像素对照发现了这项误染，修正后重复验证。
- 原头部材质同时包含皮肤和毛发，需要颜色及空间遮罩；眼皮另行生成但共享肤色状态，眼白独立。
- 日晒时间积分独立于渲染帧数；48 有效小时达到一半程度是自主游戏设定，不是医学测量。
- UI 自动预览是演示时钟；真实游戏需显式传入昼夜、天气和遮阴。自动预览与实际时钟不可同时推进同一状态。
