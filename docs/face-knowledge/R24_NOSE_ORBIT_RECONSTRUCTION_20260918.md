## 实际整合

1. `nose.bridgeSections` 分别定义鼻根、骨段、中部软骨的前面半宽与本体半宽；`compactNasalBridgeDepth(..., y)` 继续保留远端 cheek 值和切线，31 mm 只承担接脸范围。鼻尖过渡段可更宽，骨/软骨段收窄；没有把整个鼻子等比压缩。
2. 鼻尖 centreline 与成双横截面重配，翼所在站和孔所在站保持不同深度；y<1.478 的控制点数值保留。注意全局 C2 guide 的导数仍有联动，这不是宣称整片人中几何完全不受鼻形影响。
3. 孔轮廓在共同切孔参数域加入轻微弯曲、内外侧宽度差和斜向；开口长短轴没有简单缩小。裁孔、角参数恢复及内部墙使用同一映射，避免形状和边缘脱节。
4. 孔内增加真实回卷：半径先在孔缘之后扩展，再向深处收拢。鼻翼侧和前上方的扩展大于小柱侧，形成三维遮覆。C2 hook 在共同外缘的位置与切线为零，角向 roof 使用 positive-sin³；外缘仍与面皮共边。前庭皮肤增加至两排，深腔 10.5 mm。未改变材质颜色来假造深度。

目前深处鼻道仍以原孔轴为方向的简化腔体；外部鼻表面仍基于高度场，并非完整鼻软骨/皮肤体积仿真。新增的是孔缘后方真实的回卷与内部扩张，不能据此声称已还原所有鼻组织。
