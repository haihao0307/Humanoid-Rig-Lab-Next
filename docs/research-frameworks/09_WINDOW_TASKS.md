# 09 · 给新窗口的可复制任务指令

这些是后续用户选择某一任务时可直接提交的指令。本次建立档案不触发它们执行。RF02—RF07各自从P0开始；已有同任务成果时先恢复，不重复创建。

## 通用开头（每个任务都必须附带）

```text
仓库：haihao0307/Humanoid-Rig-Lab-Next。
先直接读取本档案所在分支或固定提交的RESEARCH_FRAMEWORKS_START_HERE.md、docs/research-frameworks/README.md、00_CONTEXT_AND_BOUNDARIES.md、08_DEPENDENCIES_AND_ACCEPTANCE.md，以及选定专项文件。
本档案的原始参考基线为e7df669b97a13ca79ff9b780ea21d20da7acd1d0，不代表你接手时所有原工作台仍停在该版本。先实时核对目标工作台README、BUILD_MANIFEST、TASK_STATE、源码、分支、PR与活动运行；缺项记录未知。检查是否已有窗口做同一任务。
保持人物、姿势、材质、物理和窗口状态分层。只做人/服装/裁片/布料/鞋及局部交互，不扩展建筑、飞机、地形、动物、植被或完整大世界。谱和自有程序化生成器仍为权威。
先写任务锚点、允许改动路径、假设、预先冻结的验收与反例，然后做一个最小实验；不要仅提交计划后停止。若权限或必要证据不足，完成独立可做的核查，明确阻碍，不编造数据。
只在独立分支工作，保持Draft；不合并、不强推、不改写历史、不覆盖其他活动分支。实验读生产时只读；新后端在候选中，不自动替换旧版。测试通过不等于用户视觉或物性/制造认证。
网页实现必须固定公网HTTPS、核对实际渲染/交互/版本；不能用图片、ZIP、localhost代替。交付受阻写“交付未完成”并保留任务状态。文档或离线实验则如实说明没有新网页，不伪造网页交付。
保存TASK_STATE、来源版本、差异、失败与下一步。独立解释是否值得推进，而不是为了证明新框架好而换测试。
```

## RF02-P0 · 资产与材料只读清单

```text
只接续RF02-P0。专项：02_ASSET_MATERIAL_INTERCHANGE.md。
先读S3材料快照/合同与S2.1共同协议，记录二者真实差异，不能只统一字段名。核对R17.2牛仔当前有效源以及被采用的宿主绑定声明。
第一轮做一个牛仔材料与宿主绑定的无损清单：稳定ID、源commit/摘要、材料轴与米制尺度、针脚显示语义、光学/力学分层、版本兼容条件和UNKNOWN。数据不足保持未知，不借其他版本填成同一运行时。
实现独立只读导出→重载→逐字段核对，加入错误版本、缺依赖、循环引用、单位错与unsupported字段反例。生产renderer、材质、几何、灯光、物理不改。
不要第一轮引入完整USD SDK或替换所有shader。完成后给出往返丢失、被拦下的错误组合、原工作台不变证据及成本；再判断是否有必要做一个MaterialX/OpenPBR子集转换实验。
```

## RF03-P0 · 可辨识的小参数逆向求解

```text
只接续RF03-P0。专项：03_EVIDENCE_INVERSE_SOLVING.md。
先读Ceres/GTSAM一手资料，仅选择一个后端。先做自有生成器的已知真值合成夹具，两组明确相机观测，少数参数，固定噪声/seed与离群点。不要第一轮拟合整个人脸或所有材质参数。
建立观测、因子、参数锁与单位归一化；输出候选、每因子残差、退化/辨识性与不确定性方法。没有尺度证据不能输出真人绝对毫米。
测试已知真值恢复、离群点、错误单位/镜像、缺视角、导数小例子、取消和过期结果拒绝。普通姿势不能改骨长/比例。候选applyAuthorized=false，由原工作台事务接受。
报告与基线相比解决了什么，合成夹具与真实验证分开。证据不足时不强行生成可信数值，列出需要新增的最小观察。
```

## RF04-P0 · 牛仔材料空间与连续足迹诊断

```text
只接续RF04-P0。专项：04_MATERIAL_SCALE_SPACE.md。
先恢复R17.2已验证源码与实际有效分支，核对材料坐标和shader装配，不覆盖原构建。读S3声明，记住视觉与物理版本尚未绑定。
第一轮先实现只读足迹诊断和固定相机轨迹基线；锁定尺度、材质、灯光、曝光、几何、物理、分辨率。确认问题再在独立候选中只改一个连续滤波/覆盖环节。
不做固定距离分档LOD、整件高低模/纯色替换，不放大真实纱线去假造可读性，不新增动作缓存。
对照近景、整裤、掠射角、推拉运动与窄屏，检查时序闪烁、材质身份、方向/覆盖和CPU/GPU成本。拒绝用更大像素方差或全局模糊单独证明成功。
只做牛仔；毛衣、皮革、皮肤后续独立验收。保留失败候选和同条件实际网页证据。
```

## RF05-P0 · 一个可解释的抓取条件检查

```text
只接续RF05-P0。专项：05_SEMANTICS_AFFORDANCE.md。
读取当前真实人物动作/手部能力、布片/衣服身份与抓点/接触接口，不能沿用旧R编号冒称最新版。学习BDDL目标谓词方法，不搬整个BEHAVIOR环境或外部资产。
第一轮只做“该人物现在能否抓住指定布片”的只读条件检查：部件锚点、版本、可达候选、手部占用、物理能力、缺失证据。TRUE/FALSE/UNKNOWN与RF01五态显式映射。
测试过远、旧锚点、双人占用、被夹住、缺接触接口、取消和换版本。不能因为动画播完就判成功，不能用父子挂接假装物理。
只有底层已有真实抓取且用户授权后，才接一个提起放回闭环；否则输出BLOCKED和责任工作台。保存状态转换、失败恢复和假成功对照证据。
```
