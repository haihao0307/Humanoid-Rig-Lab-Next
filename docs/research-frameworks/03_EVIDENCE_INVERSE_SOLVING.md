# RF03 · 因子图 + Ceres / GTSAM证据驱动逆向求解

原排名第3。当前状态：设计存档，尚未在本轮部署求解器。目标不是让优化器猜出所有人体或材质参数，而是让每次参数调整都有观测、约束和不确定性记录。

## 1. 项目痛点与价值假设

人物比例、头型、鞋楦适配和布料形态经常靠目测反复调。一个正面看似改善的参数可能破坏侧面；一张照片可能把光照误差变成唇色，也可能把相机透视误差变成人体比例。

本框架尝试把多个观察条件放进同一求解问题，并说明哪些参数由证据支持、哪些来自先验、哪些无法辨识。它应减少互相矛盾的人工补丁，而不是给错误模型贴上“数学最优”的标签。

## 2. 老师的范围

因子图把变量和局部关系分开组织；GTSAM展示用测量因子、噪声模型与先验构造估计问题。Ceres提供带参数边界、鲁棒损失和导数的非线性最小二乘工具。二者可作为不同实现选择，不要求把两套引擎同时装进浏览器。[S06][S07]

协方差与秩亏诊断有适用假设；观测尺度、参数可辨识性、模型误差不应被一个低残差数值掩盖。[S08]

## 3. 具体接入链路（设计）

EvidenceSet → Observation → 参数块与因子 → SolverCandidate → 独立校验 → 人工确认 → 原工作台事务提交。

每项Observation保留原资产引用、标注来源、相机/单位、观测值、误差模型、遮挡状态和允许用途。原照片不进入公共数据包。每项Factor保留变量引用、残差定义、归一化、权重依据、适用条件和源引用。

参数块应区分：相机、比例、姿势、材料光学、材料力学和显示参数。同一个实验只开放必要的一小组。普通姿势实验锁住骨长、父子关系与proportionRevision；比例实验只能输出新比例候选，再交原有比例事务处理。

建议的目标形式是：E(theta)=Σ rho_i(||L_i r_i(theta)||²)+先验项，其中L_i用于按观测误差尺度归一化。毫米残差、像素残差和角度残差不能不加解释地直接相加。rho与权重是实验设计，不是自动证明可信。[S06]

## 4. 哪些问题不能靠优化器补足

单张图片在尺度、深度、遮挡与相机之间可存在多解。缺少尺度标尺时不能声称绝对毫米已恢复；正面图不能独立确定全部头后部形状。材质颜色和灯光共同变化时，优化可能把错误曝光吸收到albedo里。

Ceres的参数上下界不等于任意接触不穿透硬约束已经实现。碰撞、拓扑和关节限制应由正确参数化、已有约束层或候选后验证保证。把巨大罚权加进去也不自动等于严格满足。

先验可帮助选解，但必须标成先验影响；不能把模型偏好说成个人真实生理特征。病态问题应返回UNIDENTIFIABLE或UNKNOWN并请求更有信息的观察，而不是输出看似精确的十位小数。

## 5. 首轮最小实验RF03-P0

先用自有生成器产生一个带已知尺寸的小型合成标定对象，生成两组已知相机的观测，注入可重复的小噪声和少量离群标点。只求一个长度、一个局部宽度等少数参数；锁住其他变量。合成数据是测试夹具，不是真实人体测量证据。

用一个求解器离线或在独立Worker里复现：已知真值恢复、离群点鲁棒性、错误单位拒绝、缺一视角时的不确定性增加。不要第一轮就拟合整个高维人脸，也不先做可微皮肤渲染。

第二阶段才选一个用户有权使用、带充分标定的真实部位例子，例如已有头部多视角或鞋履内部尺寸。训练/拟合视角与留出验证视角分开，不能在同一套标点上自证。

## 6. 拟议输出

SolverCandidate包含sourceRevision、parameterPatch、fixedParameterIds、residualsByFactor、outlierFlags、observability、uncertaintyMethod、solverVersion、seed、stopReason、validationRefs和applyAuthorized=false。

不得把协方差估计直接当校准后的概率。记录计算假设、是否近似、是否秩亏、边界是否激活；无法估计时返回null与原因。新输入导致版本过期时，候选保留为stale，不能覆盖最新人物。

## 7. 验收、收益与失败门

合成夹具按预先冻结的噪声与尺度设置恢复容差，实际数值在运行前登记。检查导数与有限差分的小问题对照、重复运行一致性、错误单位/镜像反例、离群点影响、退化观测检测、取消任务和旧版本拒绝。

真实例子要比较留出视角误差、人工修正次数、时间和是否破坏已认可形态。更低训练残差但更差留出结果属于失败。全部“优化成功”仍不等于用户视觉接受。

## 8. 成本、约束与退出路线

主要成本是观测收集与标注、相机/单位标定、构建有意义残差、导数调试、非凸初值和稀疏线性代数。普通人不能靠安装Ceres立即获得可靠的人体重建。C++引擎移入WASM/Worker的包体、依赖、线程和内存限制须单独试验；离线老师可先跑通，不强制浏览器首发。

当证据不足、需要越权修改比例、模型反复收敛到不合理解或比较数据没有区分能力时，停止自动晋级。保留原参数与人工入口，候选永不自动写回生产。
