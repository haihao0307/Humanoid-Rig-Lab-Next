# R10 表皮连接与权重连续性

2026-09-11。用户报告敬礼等姿态中肩腋连接处出现大块薄片、腕部与骨盆存在开裂，并要求从底层解决。此次更改针对源码中可确认的连接和绑定缺陷。只验证文件内容，未执行人体生成函数、权重求解器、人物动作、网页或 GPU；不把源码推断当作实际效果验收。

## 源码原因与处理

| 原因 | R10 的处理 |
| --- | --- |
| 每个曲面独立递归细分，一侧增加的边节点不会传到另一侧，形成 T 形连接 | `CanonicalTopology` 记录全局边细分树，所有分区采样结束后将细分传播到每个相邻三角形 |
| 多边形三角化可能省略共线裁剪节点 | 恢复原有裁剪节点，再做曲面采样；各精度保留同一条源裁剪折线 |
| 接口只合并源曲线初始参数点，遗漏曲面自适应细分的点 | 接口两侧合并实际细分后的参数集合，传播到稳定后连接；小腿径向图表端部也继承裁剪节点 |
| 同一个位置按不同绘制分块的包围盒独立量化 | 同一全局顶点先生成同一个 Float32 坐标，后续分块逐值复制，不再按分块量化位置 |
| 连接带、身体和肢体分别按各自语义区域计算权重 | 接口成对点共享一个绑定根；先按整个人体建立权重场，再把同一行编码复制到绘制分块 |
| 四权重和 8 位量化会增加权重截断与离散变化 | 八权重、16 位整数编码，整数和严格为 65535；渲染与地面支撑采样使用相同八项数据 |

几何顶点和绑定根是两层身份：几何上本来重合的点共享顶点 ID；接口两侧本来相距很近的点保留各自原位置，只共享绑定根。全局位置匹配容差为 1 nm，范围限于同一表皮；独立五官材质仍保持分离。

如果两个端点采用完全相同的归一化双四元数变换 `D`，在实数算术中有 `D(pA)-D(pB)=R(pA-pB)`。因此同一接口横向配对的原始宽度不会因两套不同权重而膨胀；共享几何位置的各次绘制也不会因不同编码或权重而分离。浮点运算仍有有限精度，接口纵向和其他软组织形变仍需实际姿态检查。

## 权重场

保留原有同源骨轴和语义区域作为初始权重。接口绑定根合并成员的区域与位置用于求权重，原始表皮位置不随该合并改变。

从语义分区相邻边和接口根出发，沿三角形边构建 60 mm 的距离带。仅在这个带内使用正权重的邻接扩散，保留初始权重约束，带外固定初始权重；骨盆中线仍固定到骨盆，避免左右股骨把中线拉开。每轮保留最大的八项并重新归一化，最多 48 轮，停止阈值为最大单项变化 `2e-5`。这是稀疏近似解，参数不是实测人体标定值。

本实现没有体积有限元网格、没有完整双调和优化，也没有测量肌肉、皮肤压缩或滑移。它不能标为完整 BBW 或软组织仿真。

## 研究依据

[CGAL Polygon Mesh Processing](https://doc.cgal.org/5.1/Polygon_mesh_processing/index.html) 区分几何形状、共享边、三角化和组合拓扑修复。此处据此将连接关系放到绘制分块之前，不引入 CGAL 运行依赖。

[Jacobson 的自动蒙皮课程](https://www.skinning.org/automatic-methods-compressed.pdf) 讨论平滑、局部、非负和归一化权重；[原作者 BBW 项目](https://igl.ethz.ch/projects/bbw/) 使用有界变分优化。R10 采用表面邻接与正权重约束这一方向，但实际实现的是带初始场约束的近似图扩散。

[Kavan 的双四元数蒙皮说明](https://users.cs.utah.edu/~ladislav/dq/index.html) 列出了短路径翻转等限制。单独使用 DQS 不能替代拓扑连接和共享权重，本轮保留既有 DQS 变换与动作核心。

## 文件验证及运行诊断

`tools/check-surface-continuity.mjs` 只解析源码和系数包 JSON 头：核对接口引用与正反向区间、共享拓扑先于编码的顺序、身份的跨线程传递、权重根的共用、GPU 属性步长和 CPU 八权重一致性。总检查还会核对七个曲面系数包及八个 Motion-Lab 核心文件的来源哈希。

用户启动时，`HumanLab.compact.report.topology` 会报告开边、边关联数异常、方向不一致及未配对的声明接口边数量。`closedEdgeIncidence` 只代表这些边计数满足条件；未执行顶点邻域或自相交检查，`fullClosedManifold` 保持 false。无法匹配的径向边或无法稳定的接口传播会明确报错。

`HumanLab.compact.report.binding` 会报告求解迭代数、最大权重变化、是否收敛、最大截断比例和量化误差。重复绘制的顶点若坐标不一致，或绑定根损坏，会报错。代码中的运行统计仅在启动后产生，本轮没有观测到这些统计值，也没有声称接口数量检查已经在生成表面上通过。

所有拓扑、坐标和权重仅在内存中生成，项目仍只保存函数、参数、关系和来源。此次全局连接阶段及八权重增加了临时内存、绑定计算和 GPU 属性成本；实际性能未测。导出配方已记录新方法，保持 Candidate 和未运行验收状态。
