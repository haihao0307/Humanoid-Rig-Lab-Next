# 人体连接、活动与分离规则 R1

日期：2026-09-12。状态：Candidate。规则初版完成文件内容审查后，用户已另行授权实际生成并以 A-pose／T-pose 观察人体；运行证据和结论另见 [人体姿态观察记录 R2](ANATOMICAL_POSE_REVIEW_R2.md)。本文说明规则机制，不作为完整模型的视觉验收结论；完整模型的 `visualAcceptance` 仍为 `false`。适用于当前 Human-Workbench 的 R2 来源曲面、128 个控制节点和 14 个来源分区。

## 规则的含义

身体按“相对骨段稳定区、关节过渡区、相互分离区”处理。稳定是相对所属骨段稳定，仍继承骨架和人物的整体运动，不是把顶点固定在世界坐标中。关节过渡是连续皮肤上的权重分区，不把肩、肘、膝等正常连接切成独立零件。

手臂可以贴住胸侧，双腿和手指也可以接触；接触不应建立永久拓扑连接或共同蒙皮身份。因此没有要求所有姿态都保持固定空气缝隙。本版不增加自碰撞或软组织接触求解器。

## 全身分区规则

| 部位 | 相对稳定的归属 | 允许的连接与过渡 | 应隔离的影响 |
| --- | --- | --- | --- |
| 头颅、脸、耳及面部独立部件 | 头节点；没有新增下颌或表情自由度 | 颈根附近可连接相邻颈椎 | 肩、胸、手的骨骼不能因靠近而控制脸 |
| 颈部 | 相邻颈椎 | 头—颈—上胸保持来源连接 | 不向整个上肢传播权重 |
| 胸、背、腰 | 高度所在的相邻脊柱节点 | 椎段间连续过渡；胸背随躯干转动 | 肘、腕、手不能牵拉胸腹 |
| 锁骨、肩带、肩根、腋窝近端 | SC、AC 与上臂根部控制链 | 仅肩根局部允许躯干／肩带与上臂连接；肩部皮肤连续 | 不允许沿上臂内侧一直连接到肋侧和腹部 |
| 上臂中段 | 同侧 upperArm | 肩根与肘附近有过渡 | 胸腹、另一只手臂、腿 |
| 肘 | 同侧 upperArm—forearm | 有限的肘部过渡带 | 腕、手或躯干的远距离影响 |
| 前臂 | 同侧 forearm、radiusRotation | 保留前臂旋转链；肘与腕局部过渡 | 胸侧与另一条手臂 |
| 腕、掌与指根 | 同侧 hand、掌骨及近节指骨 | 腕到掌连续；掌部和指蹼允许多射线过渡 | 对侧手、腿、躯干 |
| 远端手指 | 选定指射线的相邻指骨 | 同一根手指的关节连续弯曲 | 其他手指的指骨，不按欧氏距离混合所有手指 |
| 骨盆中央、耻骨区 | hips | 骨盆整体随根节点运动；外侧进入同侧髋根 | 不平均左右股骨旋转来拉开骨盆中线 |
| 髋、大腿 | 同侧 femur；髋根允许 hips | 骨盆—大腿保留来源连接；权重过渡只在髋根局部 | 另一侧股骨、另一条腿 |
| 膝 | 同侧 femur—tibia | 膝周有限过渡；不增加新运动角度限制 | 对侧腿、足部远距离牵拉大腿 |
| 小腿 | 同侧 tibia | 膝、踝附近过渡 | 对侧小腿、手和躯干 |
| 踝、足与趾根 | 同侧 foot、midfoot、跖骨及近节趾骨 | 踝到足连续；前足保留局部过渡 | 对侧脚和上肢 |
| 远端脚趾 | 选定趾射线的相邻趾骨 | 同一根脚趾关节连接 | 其他脚趾的骨骼 |

“指射线／趾射线”是从掌骨／跖骨延伸到该指／趾末端的骨链。当前来源只给整手／整足的粗分区，远端射线由绑定姿态下的指骨段距离估计，并包含末节指／趾骨节点到来源 `tipM` 的终端骨段，避免遗漏末端而选到邻近射线。它不是人工逐指分区的替代品，也不是来源解剖标注。

## 可执行规则与接入

权威实现为 [anatomy-rules.mjs](../reconstruction/anatomy-rules.mjs)，版本 `r2/anatomical-constraints@1`。它只保存函数、关节关系和参数，不保存网格或逐顶点结果。

1. `effectiveMask` 保留源分区，并修正混合骨盆分区的侧别。来源值 `72 = pelvis | left_lower_limb` 的曲面延伸到右侧骨盆；右侧去掉左腿位，远离左髋且低于髋部的左大腿使用左腿归属。不会修改锁定的来源系数包。
2. `canShare` 约束不同分区的重合点焊接、来源接口三角带，以及接口变形根的传递合并。未声明为相邻的区域不能共享身份。手臂与肩带／躯干的连接还必须位于局部肩根范围。同一来源分区内部的原有连通关系保留。
3. `resolve` 从同源关节位置确定允许骨骼、局部衰减和相对稳定区。上臂、大腿等中段限制到本骨段；前臂保留旋转链；关节附近允许相邻段。
4. `buildCompactBinding` 在生成初始权重前解析归属，先过滤指趾候选，再裁剪与归一化。每一轮接缝权重扩散重新投影到该点的完整 `anatomicalSupport` 允许集合；合法但初始权重为零的骨骼仍可进入后续过渡，邻居不能引入集合外的骨骼。稳定单骨段行由 `ownership.allowed.size===1` 判断并固定，不能仅因初始权重恰好只有一项非零就固定。扩散仅处理有邻边、未固定且处于接缝带或肩部过渡区的行。
5. 肩部初始权重使用从来源肩部接口出发、沿已连接皮肤边累计的有符号曲面距离，建立躯干与同侧上肢之间的共同连续权重场。肩部支持集合保留同侧合法肩臂链，并允许当前脊柱行的局部相邻行相接，不引入另一条手臂、头或指趾。外缘再平滑回到原有合法权重，避免直接切换粗分区权重。
6. 同一合法接口仍共用一行八项权重；编码总和仍精确为 65535。主页面装配和 Worker 使用同一个规则源文件。每次人物重建自动应用，无需新开关。
7. R6 将头／颈／躯干共同使用的 `cranialWeight` 接到先验归一化之后。原先头分区在距头关节约 65 mm 的球壳两侧突然切换允许关节，造成歪头时下颌变形断层；现由连续颅底场将颈椎权重平滑混入头部。刚性头壳保持单头关节绑定，接缝仍共用权重，脸部补片与底层头壳使用同一头部姿态。此场只在生成时求解，运行时仍使用原有八项蒙皮数据。

R2 另保留 [toe-separation.mjs](../reconstruction/toe-separation.mjs) 的脚趾函数修正：按同源趾根与末端参考点定义连续的趾间回缩，保留趾根和趾尖，以变形误差驱动局部加密。规范位置打包时统一修正位置与法线，再由修正后的曲面建立绑定距离图和权重；不修改锁定的来源系数包。这是针对来源前足连皮的工程形状修正，不是逐趾解剖重建或通用自碰撞。

`CanonicalTopology` 的无参考参数入口只保留给原有通用拓扑工具；工作台生成入口明确加载 `rig-reference.json`，创建带规则的拓扑实例。传给规则的点采用解剖绑定坐标：X 向人体右侧、Y 向上、Z 向前，单位米。拓扑的原始来源坐标在入口反射 X 一次；蒙皮已有的反射结果直接使用，避免左右翻转两次。

## 参数和已有来源连接

`ANATOMY_BANDS` 集中保存参数：肩根外边界半径为上臂长度的 0.70，髋根权重外边界半径为大腿长度的 0.28，肘／膝／腕／踝的轴向过渡半宽比例为 0.12。R6 头颈场使用 C7→头关节轴，颈核心半径为该轴长度的 0.30，核心外的颅壳高度修正斜率为 1.40；C2→头关节高度用于平滑头部权重，C5→C4 的平滑下边界防止影响肩部。这些是工程适配参数，不是实测解剖标定。肩／髋衰减核心参考同源球拟合半径的 1.5 倍。指趾远端从指根轴向比例大于 1.12 起选定单根射线，同指骨之间保留局部过渡。

肩部连续权重场另用曲面距离过渡宽度：上侧为 100 mm，下侧腋窝附近为 60 mm，随高度平滑变化；各自最外侧的 20 mm 用于淡出到原有合法权重。这是沿已连接边累计的离散曲面距离，不是空间中任意接近的手臂与胸侧之间的距离，也不是要求皮肤间留出同样宽度的空气间隙。

这些是可调的工程初值，不是论文给出的生理阈值，也不是实测皮肤滑移范围。颈、髋等已有来源裁剪接口仍按相邻关系连接，不用未经标定的蒙皮半径切断正常皮肤。肩根半径与权重支持参数本身不移动来源曲面。实验性的肩腋几何修正均未保留：绑定态扇区改形、按权重回缩并混合 DQS/LBS、姿态空间统一极坐标回缩，在实际 A-pose／T-pose 中仍产生折叠或三角交叉，已移除相关模块。数值上正的局部 Jacobian 不能替代实际三角网格的姿态验收；观察证据与失败范围见 R2。

文件元数据中已有 163 条接口带，包括颈部、左右腕、左右足踝和骨盆。检查来源接口不等于执行新规则后确认它们全部通过。被规则拒绝的接口整条跳过，并记录 ID；不会先生成一半连接。传递合并出现不合法组合时抛出错误，工作台沿用原有重建失败处理。

## 可观察字段及局限

生成报告的 `topology` 中增加 `anatomyRules`、`rejectedAnatomicalWelds`、`rejectedAnatomicalInterfaces` 和 `rejectedInterfaceIds`。拒绝接口可能留下开边，应结合已有 `openSkinEdges` 等字段处理，不能把“拒绝连接”视为完整拓扑修复。

`binding` 中增加 `anatomyRules`、`stableNodes`、`rejectedInfluenceMass`、`ownershipFallbacks` 和 `perIterationOwnershipProjection`。其中拒绝质量是多轮累计的无量纲原始权重，不是百分比；回退次数表示原先候选全被过滤后，在合法集合里选最近关节的次数。回退可避免空权重，其分布需要结合运行记录检查。`shoulderPrior` 记录曲面距离方法、上下侧过渡宽度、外缘淡出宽度、接口种子数和过渡节点数。`selfCollisionImplemented=false` 明确区分权重规则与碰撞求解。

这套归属规则能限制错误焊接和跨区权重扩散；不能自动拆掉同一源曲面内部已经存在的几何桥、对穿或错误形状。不同手指在同一粗分区内的原有拓扑也没有按逐指标签重新切开。来源肩腋融合带仍待修复，当前没有保留实验性的肩腋回缩或混合蒙皮。脚趾函数修正的保留不代表腋窝或全身粘连已解决。未改变关节中心、烘焙新模型或添加碰撞间隙，也未更改现有动作角度或时间驱动。

初版的文件审查与后续获授权的实际姿态观察是不同证据。实际肩部连续性、腋下分离、手指姿态、开边变化及性能应按 R2 中记录的源文件版本、姿态与结果解读；不能把某个姿态的观察推广为所有动作都已通过。规则依然是 Candidate，完整模型的 `visualAcceptance=false`，本文不作人体粘连已消除的验收结论。

文件验证入口仍为 `node tools/build-pure.mjs` 和 `node tools/check-pure.mjs`，用于装配、源码解析、依赖及参数核对。规则文件检查中的 `ruleFunctionsExecuted=false` 描述该检查器不执行规则函数，不代表后续授权运行从未发生。检查数量、运行数据与视觉证据以对应版本的记录为准。

## 调研来源与取舍

- [OpenStax：Synovial Joints](https://openstax.org/books/anatomy-and-physiology/pages/9-4-synovial-joints)：关节活动类别的基础说明；用于区分肩髋、肘和腕等运动关系，不用于推导皮肤权重数值。
- [Blender 4.4：Armature Deform Parent](https://docs.blender.org/manual/it/4.4/animation/armatures/skinning/parenting.html)：自动权重在复杂骨架和重叠区域可能产生非预期影响，需要调整归属。
- [Three.js：SkinnedMesh](https://threejs.org/docs/pages/SkinnedMesh.html)：骨骼索引和权重决定顶点受哪些骨骼影响。本项目沿用自己的八项权重和 DQS 管线，不改为 Three.js 默认蒙皮。
- [SIGGRAPH Skinning Course](https://www.skinning.org/)：蒙皮包含静止模型、骨架及权重场；本实现是带归属约束的近似正权重扩散，不宣称实现有界双调和求解或真实软组织力学。

来源先于本轮代码修改查阅；工程规则由本项目结合现有分区编写。外部资料不能作为本项目效果已验证的证据。
