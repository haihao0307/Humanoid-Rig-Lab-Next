# R10：参照三维嘴部模型重新构筑

2026-09-14。针对用户要求“这个嘴，去找模型参考，重新进行构筑”，重新设计嘴部曲面。后台浏览器操作；没有使用桌面鼠标。

## 实际看过的模型

1. [Human Mouth Reference — Velicsek Artistic Anatomy](https://sketchfab.com/3d-models/human-mouth-reference-916a3bee8ee84702a77070f7cbb6906c)。在作者的 Sketchfab 查看器中实际看到了灰色三维嘴部，并旋转到另一侧观察。网页标注约 13.3k 三角形、6.7k 顶点。这是艺术解剖参考，不是人体测量数据。
2. [Free 3D Head Model — Ten24 / 3D Scan Store](https://www.3dscanstore.com/blog/Free-3D-Head-Model)。查看其 [ZBrush 无贴图近景](https://www.3dscanstore.com/image//data/01%203D%20Head%20Models/Free/Zbrush-CU.jpg)，能直接观察唇面、口角、唇纹和皮肤过渡。该模型样本并不是当前人物身份或通用比例标准。

观察：上唇向闭合缘内收，下唇有宽的弧面；闭合处有立体返回而不是一条平面线；唇面在口角凹入周围组织。无贴图参考还能看出，皮肤与唇红处的结构变化独立于颜色。

只将观察转化成自写函数和少量设计参数。没有下载或提交参考网格、图片贴图、烘焙顶点、扫描数据；没有复制这两个模型的几何资产。

## 本轮构筑方法

- 将原来上下唇共用的起伏公式替换为各自的截面控制曲线。
- 外轮廓、闭合线、上唇和下唇外缘分别由少量手工控制点描述。几何生成和 shader 遮罩使用相同的数据及插值切线。
- 使用保形三次插值，控制峰值和转折，避免插值额外鼓包。
- 闭合缘在 y / z 两个方向同时转弯；接触处切线朝向返回面。内唇采用椭圆弧返回口腔，法线由实际曲面计算。
- 唇红外部保留皮肤支撑曲面，并增加口角局部凹陷。首个候选渲染仍有外缘凹槽，随后提高外缘支撑来处理它。
- 嘴部保持头部绑定和现有表情通道；本轮不改变眼鼻、动作系统、人物生成样例与肤色材质。

口宽约 51 mm，截面参数是作者设计值，没有把参考图片里的像素比例冒充毫米测量。网格在运行时由函数生成；几何参数随人物配方保存，参考来源记录在本文。

## 验证

已进行三轮实际预览，包含无唇色的素模正面与侧面。第二候选仍显示下唇下半部偏斜面、闭合线偏直，未接受为交付结果；第三候选继续拓宽下唇正面弧面并调整中央唇珠与闭合线，同时扩大口角唇色的渐隐区。

第三候选在 balanced 档完成中性正面、约 37 度侧面、灰模、半张嘴、最大唇部拉开、微笑、鼓颊抿嘴和整脸检查。所检查画面未观察到新增穿孔或翻面；张嘴时可看到向内返回的唇面。这是有限视角人工观察，不是所有表情组合的无碰撞证明。已还原 22 项表情通道为 0。

当前仍为 Candidate：下唇下方的阴影和唇红边界偏整齐，整个头部尚有其他五官与皮肤的合成感；不能称为真人扫描级效果。没有完整下颌关节、牙齿和舌头，最大拉开只验证既有近似通道。

浏览器读取的 FaceAnatomy.js 与磁盘源码逐字一致，档位 balanced 且生成已结束。日志仍有一条未带源码定位的 MutationObserver.observe 参数错误；本轮记录它，没有将其声称为已修复。没有捕获到 GLSL 编译错误。

已通过文件装配检查，以及 61,171 项面部几何参数检查。新检查包括内收深度界限、曲面外缘切线、自由缘转弯、三角形法线方向和张嘴连续性。最初在口角极薄位置发现两个法线方向问题，已通过改变轮廓端点切线修复，保留了该检查。

旧 R9 检查把近似单调的上唇深度当作要求，不能支持此次观察到的内收。现有检查允许有限的内收，并继续限制深槽；不是取消几何方向或连贯性检查。
