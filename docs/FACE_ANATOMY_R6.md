# 鼻部主曲面、唇缘与眼睑复查 R6

2026-09-13。根据 R5 和本轮实际渲染中仍存在的块状鼻部、厚唇缘、眼眶亮带及闭眼鼓起继续修正。检查使用独立无界面 Chrome，没有操作桌面鼠标。

## 保留的调整

- 鼻部由九个纵向控制截面构造主轮廓，截面的深度与宽度平滑插值，再过渡到现有人物的两侧脸部。鼻尖、鼻翼与鼻小柱共用这一曲面；鼻腔从更新后的鼻底向内生成，保留封底。此处是针对当前 R2 头部的形态设计参数，不是扫描或测量数据。
- 面部平滑半径改为 4.5 mm，适度修正眼眶及眼下体积。嘴唇减小厚度和前突，闭口线更平缓，唇峰起伏减弱。唇部采用皮肤的基础着色和表面参数，再让红色沿唇缘衰减，降低独立贴片和硬边感。
- 眼部的各光学层与接触曲面整体前移 2.5 mm，减小眼球前缘与下眼眶皮肤的深度差。闭眼后段具有最多 1.2 mm 的共同回收量；左右眼独立读取闭合状态。该回收量是外观校正，不是经过验证的生理运动模型。
- 眼睑曲线约束允许向眼球方向回收，接触下限阻止其进入光学表面；保留向前过冲限制与外缘连接。修正了旧单调限制将闭眼中段撑平、到边缘再突然转向的问题。CPU 构造、GPU 表情和阴影仍使用对应曲线。
- 参数继续进入人物配方，生成的顶点、鼻腔和眉毛不写入配方。原有表情通道、角色缩放与头部绑定继续使用。

## 验证

- `node tools/check-eye-anatomy.mjs --parameter-fixtures`：包含各状态 CPU/GPU 标量公式对应、闭合线、眼角固定、外缘切线、几何方向，以及新增的闭眼中段回收和眼球共同位移回归检查。
- `node tools/check-face-anatomy.mjs --parameter-fixtures`：检查拓扑、绑定、身高缩放、唇部方向和鼻腔深度。鼻腔基准改为更新后的鼻底曲面，另用倾斜原始面验证进入方向。
- `node tools/build-pure.mjs`、`node tools/check-pure.mjs` 与 `tools/audit-files.py`：装配、源码契约及文件校验。
- 实际程序在近看档检查中性、微笑、皱眉、惊讶、低落、单侧微笑、鼓腮、双眼闭合和单眼闭合，另检查侧面及眼鼻嘴局部。最终运行状态与源码校验值记录在 `runtime-verification.json`。

## 仍存在的限制

鼻部块面、唇缘硬边和眼睑亮带有所减轻，但闭眼仍有体积感，眼角及面颊、下颌仍能看到源曲面的折痕。当前没有眼球注视运动与动态细纹，也不是完整面部软组织模拟。合成参数检查和有限表情实拍不证明任意组合都没有自交，整体仍未达到照片级真实。
