# 亚麻短裤两裤筒装配 R2 方案

分支：`fix/shorts-two-leg-assembly-r2-20260919`

基线：上一轮诊断分支 `fix/shorts-separated-legs-20260919` 的提交 `c26df618bc61330a890ee75016957bfe70f0dacc`。

状态：**计划已冻结，尚未取得成衣视觉验收；`visualAcceptance=false`。**

## 1. 这次重做的问题定义

目标不是在画面中把两块相交布面简单推开，而是从原始二维裁片生成一条具有以下真实拓扑和装配关系的短裤：

- 一个连续腰口；
- 两个彼此独立、方向正确、面积为正的裤脚口；
- 左前片与左后片形成左裤筒；
- 右前片与右后片形成右裤筒；
- 左右裤筒只通过前裆、后裆和独立裆补片连接；
- 裤腿之间保留真实开口，不存在跨腿盖面、隐藏补片或着色器假分缝；
- 原布坐标、经纬方向、质量、裁片身份和真实接缝关系保持可审计。

上一轮已经证明：二维接缝名称正确，不等于三维装配路径正确。右裤片仍可能绕到左腿，裆补片的左右剪口也可能落到身体同一侧。因此，这轮从“裁片身份—有向接缝—装配阶段—接触门禁”四层一起重做。

## 2. 必须先纠正的错误思路

### 2.1 错误：已经有两个裤脚拓扑环，所以成衣一定是两个裤筒

拓扑环只说明最终连接表中存在两个边界环，不能证明模拟过程中没有把右裤片从左腿一侧绕过去，也不能证明裆补片的左右剪口保持正确的空间次序。

### 2.2 错误：提高迭代次数或刚度可以修好装配错误

更强的求解只会更用力地收敛到当前约束允许的状态。如果送料方向、初始工作区或缝制次序错误，增加迭代可能得到更大的应变和更稳定的错误穿插。

### 2.3 错误：某一保存帧的离散面交会为零，就可以判定通过

单帧零交会不能证明步间没有穿越，也不能证明裤筒方向、裆部送料、身体接触和后续动作正确。必须同时检查连续碰撞、布厚、应变、接缝闭合、左右归属、裤脚环及动作恢复。

## 3. 小妈学习结果转成的工程规则

这轮吸收以下可复用原则：

1. 二维材料域、三维装配态和动态穿着态必须分开，不让动态补丁反过来污染纸样。
2. 接缝不是“两个总长度相等的数组”，而是有方向的材料边界关系，必须保存端点、剪口、弧长参数、方向、局部送料比、所属阶段和释放条件。
3. `PanelRegistry`、`BoundaryRegistry`、`SeamGraph` 和 `AssemblyStageGraph` 分开管理。
4. 身体碰撞读取最终人物姿势；不能读取动画或 IK 前的旧身体位置。
5. 发现新穿越、左右归属翻转、裤脚环塌陷或应变越界时，回退到上一个通过状态，不能继续从坏状态累积。
6. 源裁片、材质批次、装配状态和验收证据分别保存；未知参数不默认为零。
7. 通过源码测试、静态成衣、动作穿着和移动端性能四道独立门禁；一项通过不能替代另一项。

## 4. 外部方法蒸馏后的核心改动

参考程序化服装系统中的裤装装配关系：每一侧先由前片和后片沿外侧缝、内侧缝形成一个独立裤筒；左右裤筒形成后，再通过前裆和后裆连接。身体分区也必须区分 `left_leg`、`right_leg` 和躯干，而不是把两腿合并成一个统一碰撞目标。

因此本项目改为以下顺序：

1. 左裤筒：`FL + BL`，闭合 `outseam-left` 与 `inseam-left`。
2. 右裤筒：`FR + BR`，闭合 `outseam-right` 与 `inseam-right`。
3. 独立验证两个裤筒的方向、裤口环、身体归属和无穿插。
4. 激活前裆和后裆，逐段连接左右裤筒。
5. 最后按四个剪口顺序安装独立裆补片 `G`。
6. 下身装配稳定后，再连接腰头和左侧开口。
7. 进入准静态松弛；通过后才允许动态动作。

与旧路线相比，裆补片不再与四块散开的主裤片同时争夺空间，前后裆也不会在两个裤筒尚未形成时提前把左右材料拉成一团。

## 6. 身体相对的初始摆放与工作区

不能再使用世界 X 轴的简单左右半空间，因为人物可能旋转、移动或采用不同骨盆姿势。

新的局部坐标来自人物最终姿势中的：

- 骨盆中心；
- 左右髋中心形成的人体横轴；
- 骨盆—胸腔形成的上轴；
- 两者叉乘形成前轴。

放置规则：

1. `FL/BL` 围绕真实左大腿的外侧、前侧和后侧建立初始刚性平面。
2. `FR/BR` 对称地围绕真实右大腿。
3. 前片在身体前侧，后片在身体后侧；不能只根据左右腿分区而忽略前后。
4. `G` 起初位于裆部下方的独立工作区，左右剪口分别朝向左右裤筒，前后剪口分别朝向前后裆。
5. 临时工作区约束只阻止错误越侧和翻面，不提供最终裤形，也不修改原布长度。
6. 对应真实针脚稳定闭合后，工作区约束逐组撤除；成衣阶段不得残留永久裤腿锚点。

## 7. 裤筒先行的装配工序

### 7.1 左裤筒

- 保持右裤片和裆补片为独立、无缝线作用的材料。
- 左前、左后先对齐外侧剪口，再对齐内侧剪口。
- 缝线从稳定剪口向两端逐段推进，禁止整条边在一帧瞬间收拢。
- 每完成一小段，运行材料、身体和布—布接触检查。
- 左裤筒完成后，必须得到一条方向一致、非自交的裤脚边界环。

### 7.2 右裤筒

- 完全使用同一工序和阈值，不复制左腿最终顶点。
- 右裤筒必须由自己原始的 `FR/BR` 材料求解出来。
- 左右结果以镜像关系作诊断，但不强制镜像位置。

### 7.3 双裤筒中间门禁

两条裤筒同时满足以下条件才进入裆部：

- 两个裤脚环均存在、互不共享边、投影面积为正；
- 左裤片主要对应左腿，右裤片主要对应右腿；
- 两个裤脚环的中心分别位于人体矢状面的左右两侧；
- 两裤筒之间没有严格三角交会；
- 内侧缝、外侧缝真实闭合；
- 临时工作区没有强迫材料越过身体或产生超限应变。

## 8. 裆部与补片工序

1. 先连接前裆，保持后裆和 `G` 关闭。
2. 前裆稳定后连接后裆，持续检查两个裤筒没有互换或反套。
3. `G` 的四条边不同时启动；按前左、前右、后左、后右剪口关系分批进入。
4. 每一个 `G` 角点在缝前必须同时通过：
   - 正确腿侧；
   - 正确前后侧；
   - 距离容差；
   - 连续轨迹无穿越；
   - 局部面朝向未翻转。
5. 一个瞬间距离接近不能直接锁成永久接缝；需要在连续子步中保持闭合后再合并空间自由度。
6. 裆部完成后重新核对腰口一个、裤脚口两个，不能生成第四个隐蔽开口或跨腿盖面。

## 9. 求解器策略

### 9.1 装配态与穿着态分离

装配阶段使用较慢的准静态求解：

- 小时间步；
- 自适应子步；
- 分阶段缝线激活；
- 每阶段收敛检查；
- 连续碰撞和严格交会复核；
- 失败回退。

通过后保存平衡态缓存。实际人物动作从这个已验收状态开始，使用较轻的动态 XPBD 路径。不能每次打开页面都从九块散布重新缝 420 步。

### 9.2 不再用“增加迭代次数”作为修复手段

材料顺应度、时间步和迭代预算需要共同标定。迭代数用于求解同一个正确问题，不能替代正确的初始放置、送料和碰撞。

### 9.3 接触与厚度

- 布料中面之间保留明确厚度间隔；
- 点—面和边—边连续碰撞都必须启用；
- 当前距离检查与步间轨迹检查并行；
- 缝边只有在真实针脚完成后才获得局部相邻豁免；
- 身体接触使用最终人物姿势和真实身体三角面；
- 不通过着色器、法线或隐藏面伪造分离。

### 9.4 回退原则

每 5–10 个固定子步保存轻量检查点。出现以下任一情况，立即恢复到最近通过点并减小步长或停止当前阶段：

- 新的严格布面交会；
- 连续碰撞不确定或预算耗尽；
- 身体严格交会；
- 左右归属翻转；
- 裤脚环面积接近零；
- 裆补片剪口越侧；
- 原布主应变超过阶段上限；
- 非有限位置、速度或约束乘子。

## 11. 验收门禁

### 11.1 源码与纸样门禁

- 原九片裁片身份明确；
- 源 UV、经纬方向、三角拓扑、质量没有被装配代码改写；
- 所有接缝方向和剪口配对通过；
- 闭合后拓扑为一个腰口和两个裤脚口；
- 没有扫描网格、外部服装模型、图片贴图或烘焙顶点进入仓库。

### 11.2 静态物理门禁

- 19 条接缝真实闭合；
- 未完成针脚没有被假合并；
- 当前严格布面交会为零；
- 连续碰撞不确定数为零、预算未耗尽；
- 身体严格交会为零；
- 两个裤脚环保持独立和正面积；
- 左右裤片身体归属没有翻转；
- `G` 四个剪口空间次序正确；
- 原有最终材料门槛保持不放宽；较高阈值只可作为中途诊断，不能冒充验收。

### 11.3 固定视角视觉门禁

在同一人体、同一光照和同一镜头下输出：

- 正面；
- 背面；
- 左侧；
- 右侧；
- 裆部下视；
- 斜前近景；
- 390×844 移动端全身。

必须能直接看到：

- 两裤腿之间是真开口；
- 没有跨腿块面或“破水”桥片；
- 裆部不反转、不塌成尖刺；
- 接缝没有亮缝、重叠闪烁或翻面；
- 腰头连续但不过度悬空；
- 裤脚自然垂落且左右独立。

### 11.4 动作门禁

静态通过后才允许：

1. 重力静置 10 秒；
2. 原地转身；
3. 左右各迈一步；
4. 连续行走；
5. 坐下；
6. 起身；
7. 小幅下蹲。

每个动作检查腰头稳定、裆部余量、两个裤脚独立、布—布和布—身无穿透、动作结束后能恢复。没有完成这些动作，不能称为可供 NPC 使用的短裤。

## 13. 实施批次

### R2.1：合同与源数据审计

只建立 `PanelRegistry`、`SeamGraph`、剪口和装配阶段；不运行布料。证明左右裤筒、裆部和腰头关系无歧义。

### R2.2：真实身体分区与刚性初摆

在最终人物姿势中生成左腿、右腿、骨盆和前后方向的稳定分区。只显示九块刚性原布，截图核对摆放，不缝合。

### R2.3：左、右裤筒分别闭合

独立形成两条裤筒。达到双裤筒中间门禁后保存冻结检查点。

### R2.4：前后裆与补片装配

按有向剪口和分阶段缝线完成裆部，加入失败回退。

### R2.5：腰头、侧开口与准静态松弛

完成整裤，运行静态数值门禁和固定视角视觉审查。

### R2.6：动作穿着

在已冻结平衡态上测试走、转、坐、起和下蹲。动作通过后才提交用户验收截图。

## 14. 当前现实约束

1. 浏览器中的高精度布料连续碰撞成本高，因此装配作者态必须与运行态分层；不能要求手机每次实时重做完整缝制。
2. 当前纸样是候选纸样，不是实物裁缝试穿数据；即使消除穿插，臀围、裆深和活动量仍需通过坐下和迈步确认。
3. 原人体有多种体型参数；默认人物通过不等于所有 NPC 通过。第一轮先冻结一个权威默认体型，再加入纤细、宽胯和粗腿回归。
4. 亚麻材质的视觉正确与力学参数正确是两回事。当前亚麻着色可以保留，但密度、拉伸、剪切、弯曲和摩擦仍需单独标定。
5. 这次不以“测试数量通过”替代成衣截图和动作证据，也不在失败时放宽原有验收阈值。

## 15. 本轮停止条件

只有同时满足源码、静态物理、固定视角视觉和动作四类门禁，才把结果标为 `visualAcceptance=true` 并提交截图。

在此之前，所有图片均注明具体阶段，不把散片、单裤筒、中途状态或失败候选称为修复完成。
