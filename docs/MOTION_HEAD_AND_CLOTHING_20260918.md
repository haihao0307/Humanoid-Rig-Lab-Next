# 头颈修正与服装模块拆分

用户追加要求检查“头老是歪着”和穿模，并授权把草裙独立为服装系统。头颈修正进入默认动作路径；服装模块已接入，但新布料求解没有通过视觉验收，默认关闭。原显示路径的穿插问题仍存在，不能写成“无穿模已完成”。

## 头颈原因与实现

地面动作原样套用了 CMU 113_08 的头颈绝对通道。其初始站立头倾斜约 23.419°，起身片段的原始合成朝向最高约 47.337°，并带有偏航偏置。不同人体重定向后，再叠加为掌部可达性增加的躯干倾斜，实际截图呈现持续侧歪。

四个地面片段共用一个站立帧作为校准基准，按世界朝向变化重建颈部和头部通道；没有改写原始动捕数据，没有每切一段重新归零。随后只在地面动作中加入工程定义的视平线响应：身体直立时减小头部倾斜，躯干接近水平时逐渐关闭，避免躺下时把头强拧为直立。修正分布到颈椎链和头部，不旋转单独头部网格；完整骨长、父子连接、手脚接触继续验证。进入过渡时随混合权重渐入，防止重复校正造成首帧跳动。

可选输入为 `floorHeadBalance/floorHeadWeight`，输出 `headBalance` 的原始倾斜、最终倾斜和响应权重，明确 `measuredGaze:false`。它是当前片段的姿态适配，不是眼动、前庭或医学模型；行走、转身和站立手势保留原有朝向策略。

## 独立服装与已否决试验

`clothing/ClothingSystem.js` 负责每个人物的实例及资源生命周期；`GarmentClothSolver.js` 是候选低分辨率布料求解；`ProceduralGrassSkirt.js` 保留原程序化外观并提供显示适配。人体渲染器仅调用统一的更新、绘制、释放接口，并保留旧 `skirt` 诊断入口。

默认模式复用原骨骼驱动和大腿净空规则。候选模式由 `compact.clothing.setSimulation(true)` 显式启用；它的节点连接、三角形中心采样、身体代理插值、腰部同源蒙皮固定点已经可独立试验，但真实深蹲和坐起截图出现上翻及拉伸，因此不默认启用。射线推出衣物曾产生硬环状膨胀，也已否决。没有靠隐藏皮肤、删掉衣物或改变镜头来宣称穿模消失。

成熟引擎的做法、接口及下一步见 `clothing/README.md`。下一步重点是分段拟合碰撞体、近髋蒙皮与骨段差异、拉伸及翻转约束、连续碰撞和自碰撞；对大量 NPC 的降频与休眠必须先测成本，当前没有人数容量结论。
