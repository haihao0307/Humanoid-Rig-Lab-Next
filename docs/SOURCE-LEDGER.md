# 来源与自主程度

本文件说明当前身体原型实际依赖什么，不以改文件名、采样、压缩或函数拟合消除来源。

| 层 | 当前实现 | 仍保留的来源关系 |
| --- | --- | --- |
| 数学与矩阵 | BodyMathR01，项目数值实现 | 为保留旧调整，兼容原坐标与求逆约定 |
| 形态和骨架求值 | BodyShapeR01、BodyMHRFieldsR01、BodyTargetBindingR01、BodyMHRAdapterR01、BodyDriverR01 | 旧系统Anny/MHR形态系数、修正网络数值、骨架名称、映射和完整权重 |
| 身体隐式表面 | BodyImplicitWorkerR15，方向采样、原核正则最小二乘、多精度标量场、着色方向函数、关节方向分区 | 9253个校准采样及参考法线由原身体导出，不是从独立原创人体数据建立 |
| 直接显示 | BodyRayR15，函数求交与零点细化、混合着色法线、点图元屏幕执行 | 不加载原模型，不使用人物三角面或外部显示库；使用旧EB1灯光变量但光学近似不同 |
| 肤色及微表面 | 项目材质函数、连续噪波、参考坐标 | 不导入皮肤图片；当前尚未恢复旧平台所有材质层次 |
| 参数、文件及界面 | BodyImplicitAppR02 | 1916项原参数目录及旧人物档案兼容结构；头部值保留而不在本板块生成头部 |

数值包为data/body-function-program.json，含2256个数值数组，共43128599个数值元素。其内没有多边形连接，但仍有采样索引、骨骼索引、权重和对应关系；不是少量独立原创人体常数。

原R15离线MHR数据缺失，已按其记录的固定公开Git提交补齐23个分块，保留在data/mhr及qa/body-field-download.json、qa/mhr-packet.json。联网只发生在准备参照数据阶段；新交付的实际运行检查没有远程请求。

原R15参照文件为Human-Skin-Appendages-R01-20261018/delivery/人物_R15_眼部层次与湿润感.html，冻结SHA256为f63c538a548108f3f61657ddbec3c0c05fbb4f4456770ba7668c67b948247edd。BODY项目没有覆盖它。

当前结论：**计算和显示表示已重写为无人物三角面的路径，但校准数据尚未独立。不能标为全部自主，不能据此判断可以公开发布。** 后续独立数据替换必须分别处理形态母体、形态变化场、骨架/权重、修正系数、校准采样和命名映射，并重新检查视觉与参数响应。

## R17 无损整理与真实迭代

`BodyControlR17`、`BodyImplicitAppR17`和`BodyImplicitWorkerR17`的控制路由、增量记录与只读系数解码由本项目实现。R17的形体、场拟合和求交函数保持R15计算，未声称重新建立人体基础数据。

原数值包保留，R17加载`data/body-function-program-r17.json`。2256个逻辑数组经字节核对，将734个完全相同副本合并，实际存1522个唯一数组。原始数值、完整元数据树、来源字段与旧参数键不变。压缩、重命名、调参和增量迭代不会取消原数据的来源。

## R18 校准与局部躯干函数

BodyCalibrationR18和BodyTorsoR18的参数分离、有限支持宽体积函数、完整影响运输与档案适配由本项目编写。BodyShapeR18保留原完整形态算子，另求支撑参考；没有把旧形态数据或绑定权重重标为自主母体。R18继续使用与R17相同哈希的无损包。具体数学尺度、函数职责和失败记录见[TORSO-CALIBRATION-R18.md](TORSO-CALIBRATION-R18.md)。

用户在本轮明确要求同步GitHub，并确认使用haihao0307/Humanoid-Rig-Lab-Next独立分支。同步的是实现与检查点；不是人体来源完全独立或总平台已验收的声明。

公开操作层可使用项目自定义参数名称。内部仍保留来源边界、固定参照哈希及每次真实修改的记录。新增变量增量记录在`person.bodyFunctionSystem.iterations`，包含基础包哈希、具体修改和计算完成时间；不是把整份旧数据重标为自主生成。

本轮只读研究了项目库的分层样条、稀疏残差、共用导数、稳定噪波、足迹过滤和曲线绒毛方法，未导入其中人物资产和拟合系数，详见PROJECT-METHODS-R17.md。完全自主状态仍为false。
