# 来源与自主程度

本文件说明当前身体原型实际依赖什么，不以改文件名、采样、压缩或函数拟合消除来源。

| 层 | 当前实现 | 仍保留的来源关系 |
| --- | --- | --- |
| 数学与矩阵 | BodyMathR01，项目数值实现 | 为保留旧调整，兼容原坐标与求逆约定 |
| 形态和骨架求值 | BodyShapeR01、BodyMHRFieldsR01、BodyTargetBindingR01、BodyMHRAdapterR01、BodyDriverR01 | 旧系统Anny/MHR形态系数、修正网络数值、骨架名称、映射和完整权重 |
| 身体隐式表面 | BodyImplicitWorkerR15，方向采样、原核正则最小二乘、多精度标量场、着色方向函数、关节方向分区 | 9253个校准采样及参考法线由原身体导出，不是从独立原创人体数据建立 |
| 直接显示 | BodyRayR15，函数求交与零点细化、混合着色法线、点图元屏幕执行 | 不加载原模型，不使用人物三角面或外部显示库；使用旧EB1灯光变量但光学近似不同 |
| 肤色及微表面 | 项目材质函数、连续噪波、参考坐标 | 不导入皮肤图片；当前尚未恢复旧平台所有材质层次 |
| 参数、文件及界面 | BodyImplicitAppR02 | 1916项原参数目录及旧人物档案兼容结构；头部值保留而不在本板块生成头部 |

数值包为data/body-function-program.json，含2256个数值数组，共43128599个数值元素。其内没有多边形连接，但仍有采样索引、骨骼索引、权重和对应关系；不是少量独立原创人体常数。

原R15离线MHR数据缺失，已按其记录的固定公开Git提交补齐23个分块，保留在data/mhr及qa/body-field-download.json、qa/mhr-packet.json。联网只发生在准备参照数据阶段；新交付的实际运行检查没有远程请求。

原R15参照文件为Human-Skin-Appendages-R01-20261018/delivery/人物_R15_眼部层次与湿润感.html，冻结SHA256为f63c538a548108f3f61657ddbec3c0c05fbb4f4456770ba7668c67b948247edd。BODY项目没有覆盖它。

当前结论：**计算和显示表示已重写为无人物三角面的路径，但校准数据尚未独立。不能标为全部自主，不能据此判断可以公开发布。** 后续独立数据替换必须分别处理形态母体、形态变化场、骨架/权重、修正系数、校准采样和命名映射，并重新检查视觉与参数响应。

## R17 无损整理与真实迭代

`BodyControlR17`、`BodyImplicitAppR17`和`BodyImplicitWorkerR17`的控制路由、增量记录与只读系数解码由本项目实现。R17的形体、场拟合和求交函数保持R15计算，未声称重新建立人体基础数据。

原数值包保留，R17加载`data/body-function-program-r17.json`。2256个逻辑数组经字节核对，将734个完全相同副本合并，实际存1522个唯一数组。原始数值、完整元数据树、来源字段与旧参数键不变。压缩、重命名、调参和增量迭代不会取消原数据的来源。

## R18 校准与局部躯干函数

BodyCalibrationR18和BodyTorsoR18的参数分离、有限支持宽体积函数、完整影响运输与档案适配由本项目编写。BodyShapeR18保留原完整形态算子，另求支撑参考；没有把旧形态数据或绑定权重重标为自主母体。R18继续使用与R17相同哈希的无损包。具体数学尺度、函数职责和失败记录见[TORSO-CALIBRATION-R18.md](TORSO-CALIBRATION-R18.md)。

用户在本轮明确要求同步GitHub，并确认使用haihao0307/Humanoid-Rig-Lab-Next独立分支。同步的是实现与检查点；不是人体来源完全独立或总平台已验收的声明。

公开操作层可使用项目自定义参数名称。内部仍保留来源边界、固定参照哈希及每次真实修改的记录。新增变量增量记录在`person.bodyFunctionSystem.iterations`，包含基础包哈希、具体修改和计算完成时间；不是把整份旧数据重标为自主生成。

本轮只读研究了项目库的分层样条、稀疏残差、共用导数、稳定噪波、足迹过滤和曲线绒毛方法，未导入其中人物资产和拟合系数，详见PROJECT-METHODS-R17.md。完全自主状态仍为false。

## R19 躯干大形与肩带

BodyStructureR19的宽体积、肩部有限支持、个体变量响应、完整影响运输和导数方向由项目编写。R19没有新增人物资产、皮肤图片、形态系数包或绑定权重。原无损包与R18保持相同哈希，BodyShapeR18及R01基础算子保留原来源；显示直接复用未修改的BodyRayR18。

新结构由档案中的structureVersion=19选择，旧档不静默套用。分离试验中的邻域方向混合未作为最终默认；最终用结构函数的中心差分导数和余因子矩阵运输方向。公式尺度、近似边界与失败记录见[TORSO-STRUCTURE-R19.md](TORSO-STRUCTURE-R19.md)。这仍是局部修正，不是整身母体与绑定数据的自主替换完成。

### R20工作中的来源划分

新增外形函数 `BodyAnatomyR20`、关节刚性混合修正 `BodyArticulationR20`、局部掌指/足趾函数 `BodyDigitsR20` 与 `BodyFeetR20`、标量场调理及显示代码均由项目编写。它们表达估计的外表结构，不是已观测内部解剖。掌指和足趾的尺寸、端点、形态响应与绑定仍从当前来源数据校准，必须继续标为 `sourceDerivedCalibration`；局部替换不是整个人体或整只手足已完全自主的证明。原2256逻辑数组/1522唯一数组的程序包和完整权重、原档案、头部状态仍保留。具体候选的哈希、检查范围及未完成状态查阅BUILD与DELIVERY，不以实现说明代替完成证据。

R20后续加入的接触场、闭合内部支撑和颈口封口分别保留其来源：接触分组使用现有静止对应点和法线；内部支撑是从外表校准得到的保守动画体积，不是已测得的内部骨骼或肌肉；颈口平面来自本人物当前保留的身体侧边界。窗口布局与画布尺寸修正不改变这些身体函数或其来源。整体数据、绑定与所有组合的视觉能力仍未认证为完全自主。

## R21 来源复刻纠正

用户新增一比一原数据规则后，R18–R20 的估算形体、局部替代、平滑、填充、融合和封口均不作为通过的原母体；R21 不应用这些研究改形。旧隐式表面本身也未通过来源复刻验收。

新来源分段对照从冻结原版实际显示表面（包含原颈部后处理）编译多图表决策与仿射求交函数，保留原表面分区信息、法线、原固定材质坐标和属性。运行时没有原顶点表或面连接，也不生成或光栅化人物三角面；但源分面信息仍在，不能称自主母体或完整函数化迁移。九个固定状态来自原参数及原显示流程，不能称连续参数能力。

肤色来自原 SkinDNA/OwnSkinReflectance RGB 方程生成的 Float32 表；微表面来自原 csHash/csNoise/csHeight，保留原身体静止坐标、干燥度和原参数幅度；粗糙度、基础与窄反射瓣来自原材质公式。未采用外部皮肤图片或新合成的噪声纹理。GGX/Fresnel 数学函数的 Three.js r170 来源及 MIT 许可保留于源代码、独立 HTML 和 licenses/THREE-MIT.txt。检查光与原场景完整环境、阴影、散射仍不同，不能称完整光学复刻。

逐域覆盖、原公式读回和同机位逐像素对照各自记录缺失及最大差异。屏幕差值跨越不同身体层会造成假高光，已改为同一来源表面的四像素辅助射线求差；没有改动或平滑身体。掠射边缘的材质和光栅覆盖差异仍未完全消除。全部验收标记保持 false；最终数据与报告哈希见 BUILD/DELIVERY。详见 SOURCE-FIDELITY-R21.md。


## R22 原颈部、实际身体皮肤与无损字段

BodyNeckSourceR22 保留原 contour/fairing/harmonic 的顺序与数值舍入；1398 个头侧输入来自原阶段，只作为接口输入而非头部生成。17 种状态的逐阶段精确回放不取消原算子/邻域/形态/绑定的来源。任意连续状态头侧提供方仍未接入。

BodyOriginalSkinR22 使用原版实际启用的身体材质片段，四个原程序生成的完整多级噪波字段、原环境与九个固定状态的可见性缓存。它们是原项目数值系数，不是下载的皮肤照片；字段和阴影仍为 source-derived，不代表自主肌理、动态光学或来源独立。完整片段虽包含共享头部函数，身体常量输入使头部路径不参与显示，未生成或修改头部。该来源候选尚未视觉验收。

BodyFieldPagesR22 仅省去缺省值完全同位的砖块，保留所有非缺省 Float32 字节。上传恢复原 GPU 数据与原 R21 GLSL。压缩、缓存及技术检查均不改变旧隐式表面未验收和母体未自主的结论。

固定外观下的原顶点 color 并非全 1。实际启用的身体片段随后以 psBase 完整覆盖 diffuseColor，原 color 不影响该固定外观的最终结果。该常量消除只适用于本候选固定原外观，不能据此声称任意外观变化已迁移；不匹配外观的档案在来源对照页被拒绝并保留上一人物。
