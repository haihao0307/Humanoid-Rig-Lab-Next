# R19 躯干大形与肩带过渡

## 范围和保留项

本轮继续R17路线的第一优先级，以R18为冻结对照，检查胸廓、肩带、腰腹、背腰与骨盆的大形。新增修正由函数和个体变量表达，没有生成身体三角面、面连接、人物网格或皮肤图片。头部与共享R15未纳入修改，底层形态系数、9253个校准采样及完整绑定权重继续保留原来源。

R18源码与交付文件保持原哈希。新档通过`bodyCalibration.structureVersion=19`明确选择新规则；没有该标记的旧档仍按R18/原人物规则求值，不静默套用新造型。新界面另有“R18成人校准对照”，并保留1916项原目录、965项身体控制和34对左右联动。

## 先做的分离检查

`qa/torso-r19-baseline/`是在本轮重新离屏运行R18拍摄的15张半身图，覆盖正、侧、背、斜前和斜后，以及当前表面、几何法线着色和法线方向。相机、灯光、肤色和粗糙度没有为某张图调整。

在当前采样点上，以7mm差分估计标量场梯度，与R18定向法线比较：胸前317点中位夹角约2.29°、95分位约6.71°；腰腹157点约2.79°/12.38°；背部369点约2.53°/6.65°。这些是当前函数场和采样方向的内部一致性抽查，不是与真人解剖的误差，也没有覆盖全部身体。

结论限定为：仅改变着色法线不足以完成宽面结构。本轮保留同一套显示与材质函数，主要处理实际表面采样位置及其一致的方向响应。

## 自编结构函数

`BodyStructureR19`工作在共同静止空间，单位为米、Z向上。沿用R18的髋中点、髋至颈高度和半肩带尺度，以无量纲纵向u和横向a描述区域。它们是本人物的动画支撑参考，不是恢复出的内部骨骼。

新增宽分量包括：胸前中线的宽缓补平、胸前体积与下缘转折、锁骨区域到肩部的宽过渡、胸廓侧向支撑、腰部收束、腹前宽面、肩胛与背部体积、骨盆和臀部宽体积，以及肩部外侧的圆缓连接。使用高斯宽函数和五次平滑有限支持，不用噪波刻画这些结构。

躯干范围在u≤-0.40、u≥1或a≥1.10时为零；肩带范围在u≤0.55、u≥0.99、a≤0.50或a≥1.48时为零。区域边缘渐变，肩部修正能覆盖R18横向衰减之后的近端区域。手足、远端四肢和颈口之外的采样不被本层位移改写。

常数幅度约2—10mm，再按当前支撑尺度和个体变量缩放。这是项目校准选择，没有将这些常数当作人体统计测量。胸前中线补平用于减弱当前校准档的过深沟状转折；性别形态增大时减弱男性胸前分量，保留原胸部控制。丰满时宽结构定义逐步被覆盖；新增侧腰收束在肌肉提高时减弱，避免本层继续放大细腰效果。

R19在R18静止形体上增加局部位移，再将同一位移分配到每个完整影响贡献，按当前皮肤矩阵与权重运输。两套驱动共用该路径。支撑参考矩阵不因本层改变，当前全部原控制仍参与底层形态计算。

## 法线与结构函数一起变化

第一候选尝试将当前邻域主方向与旧方向按65%混合。分离实拍没有显示足够明确的收益，未作为最终默认规则。该候选和源码保存在`qa/structure-r19-trial1/`。

最终候选从R18方向出发，以新位移函数的空间导数构造J=I+∂d/∂p，并通过余因子矩阵运输法线。导数使用0.25mm中心差分。动作中的方向通过完整权重形成的局部皮肤变换映射，随后归一化。它使方向变化来自同一个形体修正，不另画高光或凹槽。

独立数值检查以两条切线的有限差分变形、叉乘作为参照，核对了非均匀尺度和剪切下的法线结果。零强度保持原方向，有限支持之外保持原采样方向。本方法仍沿用R18输入方向，且局部皮肤变换忽略权重的空间导数；不能称为全局精确表面微分或全部关节变形已经正确。

最终显示继续使用未修改的`BodyRayR18.js`。原灯光、肤色、粗糙度和微表面配置保留，实际图元仍为GL_POINTS。额外将两盏灯的方位同时旋转180°用于背面检查，属于明确标记的观察条件，不写入产品默认配置，也不等于全部环境已经验收。

## 失败、取舍和防止重复

1. 初始数值检查误用了B驱动第30通道作为肩动作，该通道按原目录锁定为0，正确触发限位错误。改为按实际目录选择`spine_twist1`第13通道和`l_uparm_rz`第45通道，没有修改或放宽限位。
2. 第一候选单纯加强邻域方向混合，没有通过效果收益判断；保留形体/方向分离对照，最终改为结构函数导数运输。第一候选未当作视觉完成。
3. 第二候选补入胸前中线宽面，并对照旧方向与导数运输，记录在`qa/structure-r19-trial2/`。随后只调整了新增侧腰分量的肌肉响应。最终候选重新构建、冻结，再完整检查，旧候选截图不作为最终版本截图。
4. 初次编写时主页面只需要校准档函数，完整模块直接访问工作线程数学对象会产生初始化边界问题，已在构建检查阶段改为延迟使用数学依赖，正式离屏试验前修正。

## 验证、限制与后续

数值脚本：`tools/test-structure-r19.cjs`。检查两套驱动的原人物/成人/偏瘦/丰满/肌肉旧档逐值兼容、新模式支撑不变、有限支持、完整影响包、区域映射对称性、取样雅可比正向和法线切线独立对照。雅可比检查是有限取样，不是对整个定义域的数学证明。

浏览器脚本：`tools/qa-structure-r19.cjs`。覆盖正常距离全身正侧背、半身、五组形态、A驱动躯干/肩部分量及B驱动已命名通道，检查R18画布、旧档、新档真实下载与同档重复载入、参数批量操作、点图元与运行时哈希。通用旋转分量只按实际测试值记录，不当作关节完整活动范围或动作语义验收。

最终证据以`BUILD-R19.json`、`qa/structure-r19/numeric.json`和`qa/structure-r19/browser.json`为准。胸肩、背腰和骨盆的宽面得到本轮修正，但主体仍较简化。肩腋的更大动作、髋部、肘膝腕踝、手足细碎起伏、全部组合和总平台均需后续；本轮不宣布整身自然度、自主母体或全范围动作完成。
