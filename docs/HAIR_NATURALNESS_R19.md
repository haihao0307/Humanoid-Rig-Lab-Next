# R19 发型自然度修正

2026-09-13。用户指出 R18 的八款发型“不够自然”。本轮保留 R17 已认可的生长区和原先六个预设，修改八款新增发型的外层发束、曲线层次和材质。R18 截图属于本轮修正前的效果。

## 修改

- 连续外壳改为两层相互错开的发束。每束有稳定种子、独立宽度、细微弯曲、长度差和逐丝发尾遮罩；发尾差异控制在较小范围，避免变成参差尖刺。
- 内层体积缩回外层发束之下，避免从头顶穿出后形成硬边。耳上、耳后、枕部与颈后原有发根范围不变。
- 长度坐标和横向坐标跟随各自发束。高光切线结合平滑法线与横向曲面导数计算，避免每段多边形产生一条独立亮带；新材质不使用旧版等间距的正弦条纹。
- 横截面的微小弧度同时反映到法线中，让相邻发束有不同的高光。内部保持足够遮挡，只有边缘与发梢逐步透出，避免整层半透明造成颗粒感。
- 细发曲线与长度分别变化，波波头的颈后根部从其实际高度往发尾过渡。耳侧发束更细、翘起更低，马尾从扎点逐渐收细。

实现仍为函数、配方和程序化材质，不增加照片纹理、预制发型网格或烘焙顶点资产。新外层和所有 LOD 索引继续计入原来的 432,000 / 1,296,000 / 3,456,000 B 毛发几何上限，另有固定 44 B 共享索引及四角。每个人的毛发最多两次绘制。渲染报告中的 `coverageLocks` 记录外层发束数量；`strands` 继续表示独立曲线条带数量，两者都不表示真实毛囊计数。

## 查阅的技术来源

- [Epic：Digital Humans（4.27）](https://dev.epicgames.com/documentation/en-us/unreal-engine/digital-humans?application_version=4.27)：发片根部错落、根梢变化和内部遮蔽，避免玩偶式发型的制作经验。
- [Epic：Photorealistic Character（4.27）](https://dev.epicgames.com/documentation/en-us/unreal-engine/photorealistic-character?application_version=4.27)：透明度、根梢、发丝 ID 与沿毛发生长方向的切线分别控制外观。
- [SideFX：Generating hair cards for games](https://www.sidefx.com/docs/houdini/fur/haircards.html)：分组发片及发束、轻微弯曲与根梢颜色的控制方式。

这里只借鉴上述建模和材质原则，未使用其模型、图片资产、纹理或着色器代码。造型照片参考仍见 [R18 说明](HAIR_STYLES_R18.md)。

## 验证

文件检查使用 `node tools/build-pure.mjs`、`node tools/check-pure.mjs` 和 `tools/audit-files.py`。外部生成脚本检查 58 组预设、开销档及长度/密度/种子边界；检查根部归属、有限值、分段长度、各 LOD 总预算、颜色与几何独立性，以及 R17 默认几何和生长区来源哈希未变。

视觉审阅在隐藏浏览器内通过审阅 URL 切换发型和视角，不操作桌面鼠标。截图保存在本轮 `hair-natural-r19` 外部审阅目录。文件检查与实景截图分别记录；最终自然度仍由用户查看实际效果判断，不据此宣称照片级真实、发丝动力学或全姿态碰撞验收。
