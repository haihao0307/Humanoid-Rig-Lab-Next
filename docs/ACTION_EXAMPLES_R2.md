# 动作打磨 R2：固定镜头与场景组合示例

2026-09-08。按用户反馈继续调整：动作仍僵硬，默认镜头跟随导致画面晃动，需要直接点击查看场景组合动作。先联网调研，再修改代码；只检查文件内容。

## 本轮调研与判断

- [Daniel Holden：Inverse Kinematics and Foot Locking，2026-07-30](https://theorangeduck.com/page/inverse-kinematics-foot-locking)：讨论接触锁定、接触切换的惯性过渡及接近腿长极限时的柔化处理。本轮没有引入文章整套算法；保留原有 IK，针对脚掌支点切换和接近伸直状态的突变做局部改进。
- [Code vs Data Driven Displacement](https://www.theorangeduck.com/page/code-vs-data-driven-displacement)：导航位移、动作位移与接触必须协调。代码检查发现 R1 在每个中间路点都按剩余距离制动，路径经过障碍时会反复减速；这轮改为看完整剩余路线，并根据拐角幅度局部减速。
- [Microsoft Xbox Accessibility Guideline 117](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/117)：建议提供关闭自动镜头移动的选项。本轮默认关闭跟随，并且“人物近景”、组织显示切换不再暗中开启跟随。

以上为结构设计依据。角度、速度、时间、滤波参数都是现有程序化人物的工程设定，不是从真人视频或动捕曲线测量得到的结果。R1 的真人步态资料仍见 `NATURAL_LOCOMOTION_R1.md`。

## 动作变化

1. 普通路点保持连续移动，终点才完整制动。大转角提前减速，依旧沿原避障折线路径行走，不通过切角绕开碰撞规划。
2. 脚部运动中，实际前摆区间从 76% 延长到 84%，改用三次平滑曲线降低中段速度集中；最高抬脚位置提前，后半段逐步伸腿迎接地面。
3. 脚底支点在腾空阶段从前掌向脚跟连续转移，取消脚掌角度经过零时直接切换支点的行为。继续计算脚底代理的最低位置补偿。
4. 支撑侧移、身体起伏、摆臂信号和转向姿态采用保留速度的临界阻尼响应，减少每次换支撑腿时突然改变运动趋势。它不是全身动作片段重定向或完整惯性混合系统。
5. 骨盆偏航系数从 0.032 调到 0.046 rad，侧移从 9 调到 12 mm；增加轻微转弯内倾与颈部提前朝向，手臂摆动系数从 0.30 调到 0.34 rad。
6. 步行时腿长约束额外预留最多 6 mm，并平滑接近高度上限的过程，降低膝盖在近伸直状态下的锁死感；骨长和关节限制保持不变。

## 镜头

- 初次打开主页面采用固定全景。
- 人物近景和正侧背面仍可手动选择；选择视角不会开启跟随。
- 主场景“视图”菜单新增“镜头跟随人物”，初始未勾选；身体页原来的跟随选项也初始关闭。
- 点击动作示例时只进行一次全景构图，播放中固定机位；用户仍可拖动与缩放。
- 手动开启跟随时，站立步行的取景高度固定，避免将骨盆每一步的上下起伏传给镜头。

## 一键组合动作

主场景上方显示可折叠的“动作示例”，按钮随当前场景变化。共 11 个配方，默认智能生活空间显示 5 个。

| 场景 | 示例 | 内容 |
| --- | --- | --- |
| 智能生活空间 | 到交流区迎客 | 去交流区 → 站稳 → 打招呼 → 短暂停留 |
| 智能生活空间 | 整理后打招呼 | 搬箱到工作区 → 去交流区 → 打招呼 |
| 智能生活空间 | 去休息区坐一会 | 去休息区 → 坐地 → 停留 → 起身 → 打招呼 |
| 智能生活空间 | 三区巡游 | 工作区 → 交流区 → 休息区 → 敬礼 |
| 搬运与分类 | 分区整理 | 箱子进一区 → 球进二区 → 打招呼 |
| 障碍绕行 | 绕障碍巡查 | 按避障路线经过三区 → 敬礼 |
| 狭窄通道 | 穿过通道报到 | 到通道终点标记 → 停稳 → 敬礼 |
| 混合训练场 | 观察点与区域巡游 | 去观察点 → 停留 → 去三区 → 打招呼 |
| 空场地 | 起停与转向 | 一区停稳 → 转向三区 → 打招呼 |
| 自定义场景 | 当前区域巡游 | 动态使用前两个区域 → 打招呼；缺少区域时禁用 |
| 所有场景 | 挥手与敬礼 | 打招呼 → 放松片刻 → 敬礼 |

这些是当前能力的组合。“休息”指坐在地上，没有伪装成坐长凳。点击不会更换场景或重置人物，不会移动固定家具。配方引用的物体或区域被删除后，对应按钮禁用并说明原因。

示例通过已有命令调度器和语义任务队列执行，保留逐步能力校验、现有物理预检设置、场景版本检查、持物保护、暂停/继续/停止与任务完成反馈。没有第二条直接操纵关节的执行通道。已在执行的任务不会被示例按钮抢占；失败后保留原组合和原因，不把示例标题自动改写成别的任务。点击即授权播放这一组显式动作，不经过自然语言重新猜测，也不额外打开确认步骤。
