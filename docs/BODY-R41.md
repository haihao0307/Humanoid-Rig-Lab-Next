# R41 动作、关节体积与脚底接地

本轮按用户指定的 **P2.4 动作专项**推进，沿用既有 P1～P5 路线。当前迭代身体、体型参数、皮肤、动作库和完整人物档案继续保留。身体仍直接求交数学函数，不生成人物三角面；独立头部工程没有修改。

## 已接入工作页

- **关节体积保护**：在已有变形上叠加有上限的双四元数旋转修正，主要作用于四肢关节的混合影响区。强度可调到零，修正上限随腿部尺度变化。保留 B 骨架既有姿态修正；R20 旧档继续使用原有关节修正，避免重复叠加。
- **平地接触**：地面高度可调。依据实际身体函数边界上的脚底极值放置人物；可自动平放没有明确指定踝姿态的支撑脚，保留手动指定的踝姿态。开启碰撞时也检查其他身体部位的最低点。播放中每帧重新检查函数极值，并同步更新函数系数、逆映射、保守求交范围和附件参考。地面是解析平面，脚下软影是简单的接触提示。
- **接地行走**：A、B 两套骨架均提供「行走」。步幅、抬脚高度和周期可调，包含 60% 支撑期与 40% 摆动期、脚踝屈伸和轻微脚掌滚动、交替摆臂。腿部旋转通过脚底表面锚点反向求解，骨长不变。短腿会限制实际步幅与抬脚高度；前进距离按实际步幅累计，镜头随前进方向跟随。
- **暂停与存档**：暂停行走后重新计算完整身体，再转成可继续编辑的普通关节姿势。接地、关节保护、步态设置和前进位置随完整人物存档保存，播放期间的皮肤调整保留。可「回到起点」。不修改头部参数；头颈边界继续记录人物局部输入，场景放置另有记录。
- **有限身体避让**：支持两小腿、两大腿、两前臂，以及左右前臂与躯干的五类胶囊对。通过关节旋转减少重叠；交叉腿联合求解，最后重新统计残余重叠。界面显示未能消除的胶囊重叠。可关闭避让以保留指定姿势。
- 保留原来的 16 个内置动作、自定义动作库、逐关节和关键帧编辑，以及动作播放中的 22 项身体皮肤控制。

## 检查范围

后台使用无窗口浏览器，不操作用户鼠标。只用少量临时画面检查外形，不交付截图集。

- A、B 默认身体的多个步态相位；两套骨架的胖体、精瘦高肌肉体型和儿童比例，深屈髋、屈膝、屈肘与行走抽样。
- 数值检查包括有限结果、脚底接触、前进后的中间帧保守范围、共享边界、关闭新层后的 R40 函数及法线一致性，以及真实 R20 旧档。
- 真实工作页检查行走循环、暂停后普通姿势、完整人物往返、头部信息、皮肤保留、原动作库和错误设置回退。
- 记录位于 `qa/motion-r41/`。测试阈值只用于相应数值行为，不代表全部体型或人体视觉效果已验收。

## 本条仍未覆盖

1. **完整软组织接触**：当前是关节体积修正和胶囊避让，尚未实现腹股沟、腋下、腹部与大腿等深屈曲贴合处的物理挤压、褶皱和体积转移；极端姿势仍需按实际外形继续调整。
2. **复杂地形和移动**：目前为平地前进行走；斜坡、台阶、跳跑、转弯、路径规划、受力平衡和动态跌倒未实现。支撑脚仍受有限采样、原表面变形和反向求解误差影响。
3. **完整碰撞系统**：胶囊对只覆盖上述范围；身体所有表面之间、手指、衣物、墙体和任意场景物体尚未求解。播放中的胶囊避让在动作样本处求解，中间预览不等于逐帧完整碰撞模拟。
4. 其他平台任务保持原编号：P1 整体形体与骨软分离、P3 旧档专用手足细节、P4 更多设备及完整体积散射、P5 独立头部和附件总平台联调均未整体完成。

实际查看以三维工作页为准，R40 保留为回退版本。
