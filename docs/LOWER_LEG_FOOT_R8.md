# R8：小腿、踝部与足部

2026-09-08。入口仍为 `index.html`。先联网调研，再修改源码；本轮只检查文件内容、JavaScript 语法、模块与打包一致性。没有构造或运行人体，没有启动浏览器、WebGL、动作测试或截取修改后图片。用户提供的修改前图片保存在 `tests/lower-leg-foot-r8/user-before.png`。

## 生成路径

1. **骨架与硬基底**：保留股骨、胫骨、腓骨、跗骨、跖骨和趾骨的几何尺寸、骨长及层级。读取实际生成骨顶点，在各侧胫骨和足关节的绑定坐标系建立周期径向网格。小腿网格 73×48，足网格 49×48；足网格读取跗骨和跖骨，趾骨仍使用各自独立关节链。硬基底显示独立骨几何副本，支撑体由相同网格生成。
2. **小腿体积**：比目鱼肌位于深层，腓肠肌内侧头的分布比外侧头向远端延伸；前外侧另设胫骨前肌和腓骨肌群。正值厚度按层相加，最外层添加皮下覆盖。肌肉示意直接读取同一硬基底和厚度场，不再从皮肤反向裁剪这五组肌肉。两侧共生成十个闭合肌肉示意体。
3. **膝下与踝部**：上端平滑接回原大腿与膝部；踝前增加环列。小腿终端位于踝关节上方 26 mm，通过五层中间环连接足背开口；两端保留原邻接顺序，按空间角度对应。踝区权重连续分配给胫骨和足关节。
4. **足底与前脚掌**：截面分别指定上、下半径，内侧足弓单独抬高；跗骨及跖骨径向采样为足背、足底提供构造余量。足底下界使用光滑函数，避免硬 `max` 的导数折角。前脚掌按五个跖骨头的前后错列建立趾根与趾间边界，再以三层过渡环接回足部。
5. **脚趾**：不再调用手指通用管体生成脚趾。脚趾有独立横宽、背侧厚度、跖侧趾垫、远端圆帽和趾尖覆盖量；最初一段被趾根包裹。仅调整趾链在绑定姿势中的朝向，不改变各节骨长。短趾骨的关节权重过渡半宽取相邻骨节长度的 42% 与 6 mm 中较小者，因此相邻过渡带不相互覆盖。跖趾区还平滑混合足关节权重。
6. **趾甲**：在最终细分皮肤上投影采样，取远端趾关节局部 `+Z` 的背侧表面，并增加 0.10–0.28 mm 覆盖量。宽度随趾尖圆帽收窄。若一片趾甲有采样缺失，就记录并省略该片，不用猜测高度放置。该做法检查的是生成时的贴合，活动时仍采用远端趾骨刚性绑定。

小腿与足部共享人体主皮肤的边界和 Catmull–Clark 细分流程；没有加第二层独立皮肤来遮住接缝。主表面原有的闭合边检查、可定向检查和单连通分量检查仍在生成路径中，运行时发现非法拓扑会中止构造。本轮未执行这些运行时检查。

## 本角色的主要设计值

| 参数 | 数值 |
| --- | --- |
| 股骨 / 胫骨长度 | 440 / 425 mm，保持原值 |
| 拇趾至小趾根部横向半径 | 12.3 / 9.0 / 8.4 / 7.8 / 7.2 mm |
| 趾链静止跖屈朝向 | 14 / 22 / 24 / 26 / 29°，是造型绑定值，不是关节活动范围 |
| 趾尖骨长之外的皮肤覆盖量 | 拇趾 4.5 mm，其余 3.5 mm |
| 趾根包裹长度 | 11 mm 与该趾表面长度 27% 中的较小值 |
| 男 / 女小腿皮下覆盖 | 5.5 / 7.0 mm，两套示例参数 |
| 比目鱼肌、腓肠肌内侧头、外侧头、胫骨前肌、腓骨肌群峰值厚度 | 22 / 31 / 27 / 16 / 12 mm，分别在各自分布峰值取值，不代表同一点总厚度 |

| 足弓附加抬高幅度 | 最高 12 mm，经过纵向、内侧和足底方向掩码 |

## 用户检查入口

打开 `index.html` 后点击 **小腿与足部**：

- 灰模、肤色、骨骼、硬基底、支撑体和肌肉示意共用当前姿态和相机。
- 正面、背面、斜侧及俯视显示双侧；外侧查看右腿，内侧查看左腿。侧面只选择原皮肤中对应腿的三角形，避免另一条腿挡住所选面；俯视的皮肤与骨骼图层只选择足部，避免上身遮挡脚趾。显示裁剪不改变人体主网格，顶点与蒙皮数据仍共享原人体；肌肉图层仅包含本轮的小腿肌群。
- 自然站立、踝背屈、踝跖屈、屈膝和脚趾屈曲由按钮触发，不自动播放。预览先恢复基准姿态，再经过原约束系统；离开工作台恢复原场景姿态与暂停状态。
- **保存当前视图** 导出 PNG；**导出结构检查报告** 导出骨元素数量、采样包络残差、肌肉体积异常、趾甲采样缺失及当前约束信息。
- 切换男女预设会重建人体，保留该工作台、观察方向和图层，动作恢复自然站立。

优先检查小腿内外头与跟腱的过渡、踝部收窄是否过急、足弓和跟垫的侧面轮廓、前脚掌厚度，以及趾间是否出现尖折。再查看踝与脚趾屈伸时的连接。
