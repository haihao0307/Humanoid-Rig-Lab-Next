- 原版与重算绑定矩阵在 Float64 末位不同，会使少量接近零的身体坐标改变。新候选直接保留原版严格模板的绑定结果和原始运算数，再编译有理标量函数；不设阈值抹零。
- 原位置仍按原顺序完成原生蒙皮、目标映射及颈口的 Float32 写入。

不可变数据仍明确标为来源派生，保留原分区、裁剪及边界支撑信息。原点表、面表和原几何只在隔离的离线编译及对照中读取；运行时求函数交点，以屏幕 POINTS 呈现，没有人物顶点/索引缓冲、人物三角面或原网格回退。
