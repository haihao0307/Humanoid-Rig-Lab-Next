# R21 原数据对照与未完成工作

本轮从 2026-10-24 02:26:17 UTC 开始，最迟 05:26:17 UTC 停止。范围仅身体，不修改共享 R15 和头部。以可操作三维网页交付，不生成截图画廊。

## 为什么调整路线

R18–R20 的成人默认档、估算解剖隆起、手足椭球/胶囊替代、接触融合、场平滑、内部填充及颈口封闭，不能作为用户要求的一比一迁移基准。它们保留为未验收研究版本，R21 不套用这些改形。R17 的旧隐式场也不能因输入采样一致而宣称表面一致。

离线原版检查发现：原人物还有身体数值驱动之后的颈部轮廓、fairing 和 harmonic 表面阶段。原身体包遗漏这些显示阶段，九种状态中颈部显示位置差最大约 12.388 毫米。原驱动本身的复现误差只有浮点数值量级，这两项不能混为一谈。详见 `qa/fidelity-r21/original-cases.json`。

## 两个页面，各自的能力边界

默认的 `delivery/身体_R21_原母体函数对照.html` 是来源分段对照候选。它把原表面的分区编译为多图表决策与仿射求交程序，运行时不输入原顶点表或面连接，不输出人物网格，不创建人物顶点/索引缓冲，只以屏幕点执行直接求交。原版的分面分区信息仍然被保留，因此它不是自主结构母体，也不是完成函数化迁移的证明。它保留开口、薄层和首交关系，没有擅自封口或平滑。头部未接入。

九个固定状态分别是原人物、偏瘦、丰满、高肌肉、女性形态、动作 A 抬臂、动作 A 屈肘膝、动作 B 自然和动作 B 屈髋膝。它们来自原参数求值和实际原版显示后处理，属于离散对照状态，不能冒充连续参数功能。切换和保存保留完整原人物档案。

`delivery/人物身体_R21_原数据复刻检查.html` 保留完整 1916 项目录、965 项身体控制、34 对左右联动、两套驱动、原默认值、批量变量修改与完整档案。载入后的头部及颈部变量在身体复位时保留，失败操作完整回退。其表面仍使用旧隐式表达，尚未通过原表面、法线和首交验收。两个页面不能互相替代验收结论。

## 当前核对方式

拖动时显示 GPU 交互预览；停下后用 Float64 函数求交生成精确画面，再由同一套来源 GLSL 材质求值。相机、状态或窗口变化立即隐藏旧精确画面，只有当前完整帧生成后才显示。没有把精确画面保存为静态图片或替代三维交互。双击身体可定位局部，滚轮继续缩放，Shift 拖动平移。

原版的固定身体坐标、干燥度及原 csNoise/csHeight 微表面公式已接回，保留原幅度和种子，不另造皮肤纹理。原肤色表、油脂/干燥度生成的粗糙度、GGX 基础与窄反射瓣也分别保留。检查光仍是单独的观察环境；原场景环境、完整阴影和散射链路未恢复，不能称完整材质/光学复刻。

离线原三角模型只用于测量基准，不进入新显示运行时。抽查包括原表面每片的七个位置（含边界顶点）、正侧背斜侧及手足首交、GPU 深度与法线读回、实际精确帧的求交和材质坐标记录、状态切换和完整档案。另有独立逐域覆盖核对，重建每个 BSP 叶区域并累计原表面片的投影面积、边界外溢和源平面距离；该浮点诊断不是严格区间证明。报告列出缺失、额外命中、最大误差，而非仅平均误差。

`acceptanceTolerance` 保持 null；没有用户批准的正式数值容许范围，也没有宣告一比一视觉验收通过。`sourceFidelityAccepted`、`visualAccepted` 和 `completedMotherConversion` 均为 false。技术检查通过只说明相应行为。

逐像素对照另有明确的未解决项：在同机位、同检查光下，少量覆盖像素和掠射边缘的材质结果仍不同。跨层屏幕差值已改为同一来源表面的辅助射线求差，大幅降低假高光；仍有原光栅的子像素覆盖与解析首交选择不同的点，以及同一表面上的边缘材质差异。报告保留整幅差异、内部/边缘最大值和最差位置，不只保留平均数。这里的同检查光对照不包含原场景完整光学链路，不能称完整原版画面相同。详见 qa/fidelity-r21/source-pixels-browser.json 和修正前报告。

## 未采用的候选

Hermite、cardinal 和插值位置场虽然能在约束点附近得到很小误差，点间仍出现毫米级差异或足部法线翻转，不能采用。保守区间/立方求交实验出现漏交或启动编译超时，亦未采用。研究源码隔离在 `src/research/r21/`，报告在 `qa/fidelity-r21/`。原网格与大型中间数组留在本机离线资料区，不放入在线运行包。
