## 已实现的显示路线

原貌页的十个固定来源状态，在停止操作后使用整数谓词和有理数首交。共享边和顶点不再由浮点容差猜测归属。快速拖动期间仍是原有 Float32 交互预览；不能把这一路预览说成精确整数求交。

`BodyExactDomainR25` 将输入 Float64 射线转为准确的二进制整数比例，直接计算来源函数平面、闭区间裁剪、分区判断和首交排序。相等首交全部保留，最终距离按 nearest-even 转回 Float64。`BodyFilteredDomainR25` 只在 Number 区间能够确定时排除分支；不确定时重新走完整整数核。32×Number.EPSILON 是算术误差包围的一部分，不是几何扩张或验收容差。正式验收容差仍为 null。

来源函数法线、原材质坐标、干湿和掌跖系数保持原值。共享边相等命中时，最低来源函数编号决定属性归属；这与原生 GPU 光栅的子像素归属是两项不同问题。不能用数学首交通过，宣称原生画面每个像素已经相同。

仍然保留来源分面分区。这不是自主母体完成。输入包保留了 R24 研究编译器的原始 schema、selectedByDefault 等历史标记；R25 的实际运行选择由 BUILD、页面及精确核控制，不把历史研究数据改称自主原创数据。

## 参数工作页

完整参数页可以在同一工作流程中显示已匹配状态的原始细节。默认人物、校准档及其他已记录状态使用原貌显示；任意未匹配状态、不同头侧边界、尚未接入原貌的附加外观或灯光，继续使用明确标记的连续研究候选。

父页独占人物状态和档案，内嵌原貌页只负责身体显示。内嵌页不读取、确认或恢复标签中的人物交接记录，也不生成头部。父页保留完整 1916 项目录、965 项身体控制、34 对左右联动、A/B 驱动、头部状态及未知档案字段。相机在显示切换间保留；内嵌画布尺寸与父页支撑参照保持一致。

相同来源头颈包从存档恢复时，仍识别为相同来源，不因“外部传入”这个标签而退回连续近似。真正不同的当前头侧输入仍走原有校验和连续候选，没有冒充已接通任意连续头部。

原貌状态跳过旧隐式场的生成；工作页不同时持有两套身体 GPU 字段。切换到连续候选时才建立其必要字段和显示资源。纹理数量检查中的父页 12→0，仅指连续字段纹理释放，不包括子页的原皮纹、阴影和材质目标，也不代表全场景显存归零。四组原皮纹的 GPU 数据本身仍约 179 MB。

表面精度设置继续保存，用于连续候选；原貌固定状态保留原函数细节。仅修改身体色彩、毛孔等原有表面控制时，复用现有精确几何，不重复整幅求交。

在自动显示模式下，把附加外观或灯光恢复到原版值后，会自动返回原貌，不需要先切到连续模式再切回。当前人物、机位和原有身体表面控制继续保留。手动选择连续研究模式时仍保留用户的选择。

## 后台调度和恢复

32 行动态领取任务的调度候选已隔离保存。其几何输入缓冲在诊断中一致，但颜色自对照尚未建立稳定基准，不能据此宣布完整显示验证或提速通过。默认页继续使用已核对的等高分片派发；新机位取消旧任务，不做跳行、降分辨率或漏算区域。

仅传送求交需要的数据；后台初始化后释放原始整数文本包，运行时使用紧凑索引与数值系数。额外的机位谓词缓存仍隔离保存：虽然可减少部分重复计算，额外存储及净收益尚未建立，不接入默认页。

工作页内的原貌上下文中断后，可以保留人物和机位重建显示。短时间重复中断会停止自动重试并提供恢复按钮；不会反复重载父页、丢掉未保存人物。精确画面未完成或出错时，父页会显示实际状态。

`lastMS` 包含后台求交与显示提交等待，不是原生整场 FPS 或独立 GPU 耗时。调度变化的颜色、遮罩和行覆盖另做对照；不以任务数量减少或源码变短宣称提速。原有材质包装的两份相同页面，也出现过相同相机、相同几何缓冲和相同已查询 uniform 下的少量颜色差异。额外重绘与两种隔离材质试验未建立修复结论，默认材质保持原路线；该问题继续列为未完成。

追加的同页重复求值诊断进一步记录：641×826 的侧面、背面首次精确结果与随后第一次重新求值分别有 1346、1958 个颜色字节不同；三个材质中间目标也有变化，已查询 uniform 没有变化。再重复四次中的后续结果稳定。它缩小了问题发生位置，但没有证明根因，更不能以强制多画一次代替修复，或将重绘后的图作为已通过原版验收的证据。诊断没有生成新图片。
