# Bird Mother｜Seagull A 源拍翼运动合同台 R0.07

R0.07 不新增任何用户未提供的飞行姿态。本版只把 `seagull (A).zip` 中已经验证的 50 帧来源拍翼循环，继续蒸馏成可检查、可记录、可供以后独立重建使用的运动合同。

## 本版完成内容

- 继续保留来源网格：4,416 顶点、5,624 三角面；
- 继续使用来源 20 节点骨架、来源蒙皮权重和逐帧骨骼矩阵；
- 依据左右翼尖平均 Y 的方向与极值，建立五段数据相位合同；
- 固定来源数据锚点：下止点 F10、最快上举起始 F22、上止点 F41、身体最低 F45、最大翼展与最大不对称 F47、最快下击起始 F49；
- 建立三段翼链长度守恒审计、翼根仰角、翼肘折角、外翼折角、左右镜像 RMS 与身体相位滞后；
- 建立 `contract.json`，保存来源、许可、候选关节语义、层级、相位、事件、风险、可蒸馏内容与不可继承内容；
- 提供桌面与 390×844 手机端可直接操作的三维工作台。

## 重要发现

1. 左右三段翼链长度在 50 帧内基本保持不变，说明这部分骨架层级可作为后续独立动作系统的候选结构参考。
2. 翼尖平均 Y 的来源最低点为 F10，最高点为 F41；这两个帧可以作为当前来源循环的反转锚点，但不是通用鸟类常数。
3. 身体最低点出现在 F45，比上止点晚 4 帧。后续动作重建若把身体与翼尖完全同步，会更机械。
4. 最大镜像 RMS 出现在 F47，同时也是来源最大翼展附近。该不对称不能直接写成所有飞行动作的默认规律。
5. 外翼末段折角在来源数据中的变化小于 0.008°，说明来源外翼扇面可能主要依赖蒙皮和分离羽片运动，而不是有用的关节折叠；此部分必须重建。
6. 来源最快下击绝对速度约为最快上举的 2.16 倍。这只是该来源动画的事实，不足以证明真实生物学规律。
