# 人物蒙皮 V002 实机检查入口

## 打开方法

1. 解压完整工作包到一个新文件夹。
2. 进入 `src/modules/skin`。
3. 双击 `OPEN_SKIN_V002.bat`。
4. 等待构建验证页显示绿色通过状态。
5. 点击“打开 V002 人物编辑器”。

专用启动器只使用 `4192` 到 `4210` 端口，并且在复用端口前核对 `skin-build.json`。旧版网站仍占用 `4173` 时，不会影响本次检查。

## 通过标志

验证页必须显示：

```text
已确认当前端口属于 SKIN V002
```

编辑器左上状态卡必须显示：

```text
SKIN V002 唯一预绑定表皮已就绪
```

状态详情应包含：

```text
skin-v002-single-surface-guard
场景可见人体表皮 1 层
```

## 检查顺序

1. 选择“表皮”模式，确认只有一套完整人体轮廓。
2. 选择“同时”模式，确认画面由一套表皮与一套骨架组成。
3. 切换 A 姿势与 T 姿势，检查头部、肩部、腋下、胸腹、胯部、肘部和膝部。
4. 点击头部、躯干和四肢，确认不会出现黄色人体壳或第二套人体。
5. 选择实体、半透明和线框，确认材质切换不会生成重复网格。
6. 点击“重建表皮”，确认重建前后始终只有一套表皮。

## 关闭方法

双击同一目录中的 `STOP_SKIN_V002.bat`，可以停止专用 V002 本地服务器。
