# 帽子 R06：固定分类量配与头发接入边界

本轮完成范围是帽子与无发静态头形的尺寸匹配及最终佩戴状态，不是沿途无碰撞的真实戴入模拟。用户要求先把全部类别固定成程序，再决定后续方向。R05仅在本地交付的四款修正一并恢复；剩余七款加入明确的承托区域、分类方法与实际内带。

## 运行与版本

`app.js`、`core.mjs`、`contact.mjs`、`fit.mjs`、`support.mjs`、`tailored-band.mjs`、`legacy/*.mjs`等是实际可读生产源码。source seed仅用于首次向远端恢复这些文本；首次提交后不得用seed覆盖人工修改。`SOURCE_AUTHORITY.json`记录职责。

运行 `python build.py --source <本次真实源码提交>`，使用冻结R04中的MIT Three.js 0.179.1/OrbitControls/RoomEnvironment生成完整standalone.html和同质量公网index.html，不运行旧版应用。公开入口按需读取fa6e3842固定提交下已署名R03控制网/纹理/原头部包；这些不是失败的R03拟合结果。原R01–R04全部不变。

默认三种原头形都可选择，11款均锁定结构与戴位参数。每次从未拟合来源重新计算，不以A头的变形结果作为B头输入。颜色、表面质感、视角、剖面、测量显示和导出独立工作。换成新人物必须给出明确单位、右手坐标系、已校准佩戴基准和实际几何哈希；没有自动解剖定位功能。

## 分类承托

针织帽保留帽身/翻折/真实内层，按内承托带量配。宽檐帽排除饰带边界和外檐，使用真正帽口。鸭舌帽修复浅内衬并生成内汗带，来源映射仅包含来源分组/三角形/权重；射线重建不依赖任何目标头。空顶帽前后带沿不同高度贴合，前檐不算帽围。

新增七款中：巡逻帽、褶裥厨师帽改用真实源帽口，不用任意高度截面冒充承托；护耳帽保留源结构与布层、独立系带；窄檐、圆顶、高顶、钟形礼帽保持帽身饰带帽檐共同变换；五款定型/厨师帽新增有限厚度的内部汗带。新增汗带是本项目的构造，不是原作者已有部件或实物测量数据。

顶部空间与贴合误差分开统计。承托诊断从实际内带/内层的三角截面采样，不拿外饰带或整帽包围盒代表头围。帽型和材质厚度固定后，换头只重新量配，不开放会把结构拖坏的随意缩放。

## 检查与限制

`node verify.mjs`：11款×3原头形，另每个头形0.96/1.04倍的明确合成尺寸试验；检查输入保护、结构锁定、来源不变及确定性。后两组不是另外六个真实人物。

`python check_distance.py`：默认33组合的可见生成点及三角形中心与原头部最近三角面距离，有限厚度内带分别检查。绞花/护耳帽检查真实内层；颈肩以下的系带不在头部量配审计范围。径向承托间距、欧氏最近距离与材料厚度是不同指标。

`python qa.py`：真实file://单体浏览器；`--url <固定HTTPS>`：真实公网。`--memory`只属本地观察，绝不冒充file://或公网。原头形输入及每款A→B→C→A重复结果必须逐字节相同。Node与Chromium之间的派生帽体和汗带坐标按2e-8米上限逐项比较，数量、顺序和有限值必须一致；不舍入、不修改几何。原失败首例仅一个Float32末位不同，实际误差9.313225746154785e-10米。所有最终通过范围由DELIVERY.json和qa记录，不预填成功。

几何采样不是连续碰撞、自交证明、压力舒适度或制造验收；当前只是三个校准静态样本的候选。新人物、毛发体积、动态戴入和所有极端尺寸不由当前检查自动覆盖。长发具体细节按用户要求暂不实施。
