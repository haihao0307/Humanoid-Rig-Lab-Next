# 固定帽型—头部量配方法 R06

固定母型结构，不是固定所有人的号码；锁定可复现程序，不是锁死某个已拟合网格。

从来源生成 → 识别帽口/承托区 → 读取原人物/单位/基准 → 测实际皮肤截面 → 按类别量配 → 生成需要的内带或材料层 → 检查承托与整帽尺寸 → 对照来源 → 保存人物/母型哈希。

`cable`：真实开口、翻边及3.6mm默认材料内层；帽口承托，冠顶保留来源松量。
`fishing`：帽冠相连的真实内圈，不读取外饰带/外檐作帽围；檐长独立保留。
`flatcap`：来源浅内衬的来源射线对应重建，外观冠与前檐保留，1.2mm有限汗带承托；不以外帽形状直接贴皮。
`visor`：源前额带/后带分区沿各自高度适配，前檐剔出头围计算。
`patrol`：源帽口及其上承托条带，帽顶和前檐保留；不能使用旧错误平面把上头皮切入。
`chef`：实际源开口定位、褶裥冠保留，新增内汗带把支撑与膨大外冠区分。
`sherpa`：完整上帽体量配，布料内层2.8mm；护耳片与窄绳/顶部装饰分开，不能将绳索并入帽围或整体加厚。
`trilby/bowler/top`：来源内腔椭圆与全层共同变换，保持饰带和帽身层次；新增内汗带承托，冠顶空腔不是贴合误差。
`cloche`：来源完整30mm内腔截面，目标22mm工程佩戴圈；低檐保留。旧不完整截面不再冒充支撑圈。

新生成的五款汗带先寻找完整源内腔截面，必要的2mm步进向上定位及共同微量扩容都有实际诊断；内部条带下段按原头皮轮廓定尺寸，上段接近帽体内腔，默认1.2mm实体厚度。它是本项目新增构造，非实物测量或原作者纸样。

## 质量含义

结构参数不可被材质、换头、配方导入或异步旧请求意外改写。颜色/织纹可变，不能改变几何。没有来源开口、头部轮廓不完整或出界时明确拒绝，不能猜零半径、缩小人物、放宽成功标准或悄悄返回旧件。

实际支撑从三角面截出的内层/内带测，不把整顶帽子到头皮的中位距离叫帽口空隙。最近三角距离审计和浏览器数组哈希对应；哈希完全一致只证明重复性，不自动证明解剖定位和审美正确。

无发静态量配、物理戴入、毛发耦合、材料压力、用户视觉接受分别记账。每种新人物仍须有坐标基准、原头部哈希和适用范围；本轮未认证全部36人物或任意真实头型。

## 对平台框架的增补

当前用户将目标明确收敛为“先把帽子—头部量配做完”。因此不让长发进度阻塞尺寸程序，也不抢先实现不可靠长发占位。

真正固定一个母型，至少固定来源身份、内外结构、实际承托、坐标/单位、不可变尺寸规则、失败条件、输出记录与回归。类别不同可以使用不同内核，但输入身份和回归协议统一。

资料老师、来源控制网、自己的拟合代码和最终几何身份分开记录。来源控制网驱动并非完全独立解析重构；新汗带不是来源已有原件。错误版本保持历史，不把未通过样本改写为用户认可。

本目录只处理本轮帽子工作；不自动改写其他工作台或在后台运行。未来母本/执行者可显式引用该固定提交，不宣称全系统已经自动采用。
