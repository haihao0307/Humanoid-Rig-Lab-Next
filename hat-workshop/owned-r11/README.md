# R11 帽型精修候选

用户明确否定R10.2影视级画质。本轮以截图中的便帽为重点重做，不把功能测试通过等同影视级验收。新目录owned-r11，旧R10.2和更早版本不写入。

便帽重建低冠戴位、独立侧壁与顶片、缝合松量、夹层曲檐、翻折包边、锁式缝线与细小棉纤维。其余十类保留，并吸收已在R10.1验证的冠檐搭接和帽带真实高度修正。材质改为实时生成的纱线截面贴图、法线、粗糙度、绒光和逐级过滤，不下载旧帽包。

帽子影棚是EB1方向的本地适配，不冒充已经统一六个工作台。地面接触阴影为轮廓投影近似，自阴影仍由Three.js处理；不是离线路径追踪。试戴头改为中性头楦，明确不冒充影视人物。

保留十一类、三头形、参数、配方、取消和有限缓存。Three.js 0.179.1 MIT仍是第三方依赖。静态量配不等于动力学或任意参数全曲面无相交，眼圈为凹入绣圈并非贯通气孔。微观棉纤维非逐纱线物理。手机只做视口测试。
