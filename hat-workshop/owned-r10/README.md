# KAOPU 自有帽型工作台 · HAT-R10.2

接续上一轮保存但未发布的 R10 独立源码，保留十一类帽子，重新设计帽冠、帽檐、内外壳、织纹、结构线和配方。旧 R09 及更早版本不修改；新运行目录不输入参考帽包资产。

## 继承的 R10.1 修正

厨师帽 fullness 现在实际影响冠体体积；材质细节及随机种子的 uniform 状态不再依赖首次编译闭包；同头形同头围换帽复用程序测试头；重复的同一待执行选择不反复启动 Worker。受头顶空间限制而钳制冠高时，界面明确显示限制。着色器失败不得标作就绪，测试同时记录编译错误和实际像素。

保留全部十一类三维缩略图、旋转缩放、内衬/剖看、三种程序头形、头围/冠高/檐宽/丰满度/厚度/松量参数、主色和织纹、配方保存载入、导入导出及缓存清理。帽型缓存最多十一项、数组预算32 MiB；该预算不是整个浏览器内存硬上限。首次渲染仍受设备与网络影响。

## 源码

src/catalog.js：十一类新语义谱及输入验证。
src/shape.js：解析冠体与壳体、实体帽檐、缝线、绞花、静态头形包络。
src/material.js：程序毛毡/帆布/人字纹/针织/棉布与灯光环境。
src/viewer.js：独立工作台、Worker、有限缓存、生命周期、三维缩略图和配方。
shell.html：界面；build.py：官方依赖打包；publish.py：独立源码/构建/验收收据链。

## 构建与验收

npm ci（首次无锁文件时 npm install），node test-core.cjs，node test-r101.cjs，python build.py --source <实际源码提交>，python qa-browser.py --source <实际源码提交>。公网另用 --url <固定版本入口> 执行。必须使用安装的官方 Three.js，不允许从旧帽子网页提取引擎或资产混入构建。

最终事实以 DELIVERY.json、BUILD_MANIFEST.json、qa/core.json、qa/r101.json、qa/browser/report.json、qa/public/report.json 和 Actions 为准。构建清单的 publicVerified=false 是构建时状态，后续验证写独立 DELIVERY，不改写已冻结网页。尚未生成成功收据时不能宣称交付完成。

测试包括33品类/头形组合、主要壳体闭合、参数响应、确定性与依赖扫描，以及真实浏览器启动、11缩略图、4轮完整目录、取消/连点、配方恢复、断网后换帽与390×844视口。准备时间、真实点击到就绪和物理屏幕呈现不是同一指标；记录测量范围及慢切换，不能仅报中位数。

## 边界

Three.js 为第三方 MIT 引擎，许可保留，不称全部底层自研。业务层独立重实现不构成法律清查。老师、原作者与参考方法如实保存在 PROVENANCE.md，而非隐去来源。

目前为程序测试头的静态量配，未完成原扫描人物接入、头发压缩、动态戴入或布料力学；针织不是逐纱线仿真。手机视口不是实机。用户对造型与质感的认可始终单独记录为待确认。
