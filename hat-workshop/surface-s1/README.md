## 实际改变了什么

保留十一款原帽形、原控制网、UV 和原参考资料。材质自身不采样原颜色图、法线图或粗糙度图，颜色、高度、粗糙度与着色法线由程序计算。针织针目、绞花交叉、帆布经纬、人字纹、毛毡细纤维、印花和迷彩图案采用不同规则，不统一套一层随机噪声。

v3 将早期近景的圆孔网状针圈改为 V 形针目，分离绞花宏观交叉起伏与针目微起伏。表面参数包括密度、起伏深度、分股纤维、自然不均匀、磨耗、种子和颜色；提供自然、新料、旧料预设和可复制配方。材质坐标记录原帽面位置与 UV，随既有量头适配变形，不投射在世界坐标上。此轮表面没有几何位移，不增加帽子面数。

统一沿用 EB1 1.1 用户配方，权威源码固定于 beb3dda0a28f732e1e387dd68cc0d90f27ce8b7b/lighting/eb1。原材质参考与程序材质在同一画布、同一相机、同一光照下切换。只有明确切到原表面参考才请求原高清法线；加载原法线后再切回程序材质不会采样它。

## 可读源码入口

- surface.js：界面、参数、持久化、材质绑定、着色器适配和原生运行时接入。文件内早期 GLSL 是被替换的模板，不是 v3 最终着色器。
- field-v3.glsl：当前权威表面场源码。build.py 在组装时替换 surface.js 的 GLSL 段；BUILD_MANIFEST 分别记录模板、表面场和组装结果摘要。
- build.py：对冻结 S0 和底层 R09 校验摘要，保持原数据载荷逐字节不变，只在新页面增加渲染接入、renderer 访问和按需参考法线三处钩子。同步维护压缩传输的字节长度与摘要校验。
- preview_probe.py：三款帽子真实浏览器全貌及近景快检。
- qa.py：十一款完整本地／固定公网浏览器回归。
- publish.py：源版本与分支头检查，普通快进发布；遇并发修改停止，不强推、不重写历史。

## 人工视觉结论：尚未完成的部分

已检查修订版真实桌面和手机视口渲染。绞花针圈虽然不再使用早期圆孔形状，但仍偏规则、偏硬，有压纹表面的感觉，缺少原参考柔软的细毛羽和绒感；不能称自然肌理已经追平原图。后续优先继续这项，而不是换帽形或增加粗几何圆管。

部件材质区目前部分按连通部件或局部坐标推定，帽带、包边、印花边界仍需逐款精标。极近景、斜角和远景的纹理采样稳定性需要进一步验证。程序高度只改变着色法线，不产生真实纱线轮廓、自遮挡、毛羽剪影或织物力学。要补这些效果必须另立受控几何／体积表现及性能预算，不能仅靠调高法线幅度。

自有的是本轮编写的表面函数与配方，不是原帽形、原 UV 或参考图。原作者和各资产许可继续保留。后续接入人物时不得把原参考载体当作已完成独立程序化帽形生产。
