## 修正与默认预设

窄檐礼帽、钟形礼帽、厨师帽：旧内汗带上缘先减半个厚度，再向外增加整个厚度，导致外层越过帽壳约 0.6 mm。现在从真实帽腔截面安置完整 1.2 mm 厚汗带，整条带限制在腔内，保留外装饰带、原贴图和正常阴影；不是删除汗带或涂色遮挡。默认“汗带内藏标准款”。

绞花针织帽：帽口按当前头形量配，帽冠不再跟随头顶高度压短，保留源帽型自然冠高、完整针织内层和翻边。24 mm 是最小顶部余量规则，不代表每个头形的实际空腔都恰好 24 mm。默认“自然留空针织款”。

人字纹鸭舌帽：以原帽缝制坐标区分前檐与承托区，前檐不再参与帽冠内衬向上重建或承托区向外推挤，自由帽檐伸出量不随头围一起放大。R07.1 进一步修正仰视内衬空隙：废除被帽檐拉偏的测量中心和任意 20 mm 连接限制，改用同一个头部中心连接实际帽腔，形成有厚度的汗带与内衬收口。默认“前檐保形标准款”。

其他六款保留原款量头预设；原三头形上的帽体和内汗带坐标与 R06 做逐字节哈希对照。十一款和原缩略图目录全部保留。选帽自动应用已调好的本款预设，“恢复本款调好预设”恢复造型。材质颜色、粗糙度、微细节仍可独立修改。完整配方见 PRESETS.json。

## 切换性能

按几何和高度缓存精确三角形截面，多个方向共用计算结果；不降面、不减少采样角度，不改变最近交点规则。顶点原地变化时作废对应缓存。同一帽型/头形的拟合结果不再在校验与显示阶段重复求解。

每顶帽最多四份拟合结果；资源包缓存最多十四项；非当前渲染资产最多六件，并设 112 MiB 估算预算和淘汰。这个预算不是整个浏览器进程的硬内存上限，当前对象、源数据、浏览器解码与驱动开销另计。首次打开仍需联网，刷新或淘汰后的首次准备不同于热缓存切换。

页面状态栏显示实际本次准备类别和内部测时。qa/browser 与 qa/public 记录实际浏览器检查和固定公网成绩；不把 Node 测时或热缓存成绩当作所有电脑的联网首次加载承诺。

## 源码和证据

SOURCE_AUTHORITY.json 列出的可读模块是生产源码。SOURCE_DELTA.b64 仅用于首次传送；finish-r071.py 是一次性、SHA-256 保护的 R07.1 迁移，R071_APPLIED.json 阻止重放。此后不可用迁移覆盖可读源码。

`python build.py --source <真实源码提交>` 使用冻结 R04 引擎及原资产生成 index.html 与 standalone.html，不执行 R04 的旧应用代码。原署名、贴图许可和 Three.js MIT 许可保留。

数值适配检查包括三种原头形，以及每种 0.96/1.04 倍的明确合成压力夹具。98 组通过，另一组超出固定钟形母型的合成夹具被拒绝；不是九个真实人物，也不能说所有极端头形都通过。geometry-audit.mjs 独立检验汗带顶点及三角形中心相对帽腔的位置，核对缓存射线与旧算法，并核对另外六款未变。

check_distance.py 针对全部三十三个原头形/帽型组合及内带/针织内层，检查顶点和三角形中心至真实头部三角形的最近距离。浏览器输出与 Node 顶点坐标独立核对，误差门槛 2e-8 m。这不是连续碰撞、全局自交、压力舒适度或实物制造认证。

当前是三个无发静态头形。头发压缩、帽发耦合、动态戴入路径与实机手机性能不在本次完成范围。390×844 视口截图不冒充手机实机。用户视觉认可仍为待验收。最终入口、源码提交、构建提交与实际测试状态以 DELIVERY.json 为准。
