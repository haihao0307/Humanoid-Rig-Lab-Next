# 身体函数重构 R19

当前入口：[R19 躯干大形与肩带过渡](delivery/人物身体_R19_躯干大形与肩带过渡.html)。实际截图、可拖动R18/R19对照与自审：[R19结构对照与检查](delivery/身体_R19_结构对照与检查.html)。

本轮继续R17路线的第一优先级，修改胸前中线、胸廓下缘、肩带、侧腰、肩胛和骨盆的宽面结构，并通过同一结构函数的导数运输法线。保持原灯光、肤色和粗糙度配置，保留R18运行文件与旧档行为。

## 当前实现

- 默认成人校准档采用R19结构，可切换偏瘦、丰满、高肌肉及原人物；另有R18成人校准对照。旧档未带新结构标记时保持旧响应，不自动改变造型。
- 原1916项参数目录、965项身体控制、34对左右联动与完整人物档案保留。体量与支撑的分离沿用R18，显式身高和比例控制仍有效。
- 新局部函数具有平滑有限支持，完整影响权重运输使修正随两套驱动移动。丰满时减弱结构定义，新增侧腰收束在肌肉增大时减弱。
- 法线随位移函数的导数变化，并以独立的变形切线叉乘核对。显示继续使用未修改的BodyRayR18，只以点图元直接寻找隐式表面交点，没有人物网格、人物三角面、外部显示库或皮肤图片。
- 基础形态、参考采样、绑定权重与映射仍保留原来源。本轮是项目自编的局部结构层，整套自主母体尚未完成。

尺度、函数职责、分离试验、失败与取舍见[躯干结构知识](docs/TORSO-STRUCTURE-R19.md)。最终运行文件与证据以BUILD.json、DELIVERY.json和qa/structure-r19/browser.json为准。

## 检查与完成边界

最终候选通过27项数值检查、17项浏览器检查，拍摄71张当前三维实图。覆盖正常距离正侧背、半身、五组形态、两套驱动的有限躯干/肩部动作、补充灯位观察、实际保存、同档重复载入和旧档兼容。R18正侧背和半身画布逐像素一致，实际绘制只用点图元，运行没有外部请求。

数值和浏览器通过不等于整身自然度或所有参数组合已经验收。主体仍较简化，大幅度肩腋、髋部连接、肘膝腕踝和手足质量需要继续；自主母体、局部场计算优化、微观表面及头部/总平台整合仍未完成。下一步围绕肩腋到上臂及髋部的动作过渡，继续整体多体型对照。

## 构建与复核

```text
node tools/build.cjs
node tools/test-structure-r19.cjs
node tools/qa-structure-r19.cjs
node tools/finalize-structure-r19.cjs
```

默认构建选R19。R18源码和运行文件保持可回退，tools/build-r18.cjs可以重建R18；tools/build-r17.cjs重建R17。原控制映射检查仍为tools/test-controls-r17.cjs。不要从qa/legacy-comparison构建交付。

构建和数值检查只用Node.js内置模块。离屏检查使用Playwright与Chrome，脚本中的运行库路径可按机器配置修改。交付HTML自带程序和无损数据包，直接打开即可，不需要Node、联网或原模型。
