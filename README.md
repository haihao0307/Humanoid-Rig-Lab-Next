# 身体函数重构 R18

当前入口：[R18 躯干结构与体量校准](delivery/人物身体_R18_躯干结构与体量校准.html)。正常距离实拍与自审：[R18 校准与检查](delivery/身体_R18_校准与检查.html)。本轮按[R17路线](docs/BODY-AUDIT-AND-ROUTE-R17.md)的第一优先级实施，范围为成人校准、动画支撑/软组织体量分离与局部躯干结构。

默认进入成人校准档，可切换偏瘦、丰满、肌肉及R17原人物。全量1916项参数目录、965项身体控制、34对左右联动和完整人物档案保留。旧档不自动开启新校准；头部状态继续随档保存，当前页面只显示身体。

表示方式继续遵守函数、个体变量和噪波的约束：直接求隐式表面交点，只用点图元执行屏幕绘制；没有人物网格、人物三角面、外部显示库或皮肤图片。形态系数、参考采样、权重和对应关系仍有原来源，不称为整套自主母体已经完成。

## 本轮改动

- 成人校准将总体年龄形态轴设为0.5、体重0.5、肌肉0.35，清除身体局部增强，保留身高、比例、性别形态、基础混合及头部字段。年龄轴取值只是本项目的校准约定。
- 两套驱动共用软组织与支撑分离：体重、肌肉及被分类的局部体量控制改变表面，固定支撑参考；身高、比例和显式尺度/位置仍可调整支撑。
- 自编胸廓、腰腹、肩胛和骨盆的毫米级宽体积函数，具有平滑有限支持，并通过完整影响权重跟随动作。
- 增加几何法线诊断，降低校准躯干对参考着色方向的依赖。保留原人物对照，不针对单套灯光重调肤色、粗糙度。
- 新档保存校准规则、原人物状态和实际完成的切换/调整记录，保留旧档及重复载入能力。

具体来源、公式尺度、函数所有权、失败原因与下一步见[躯干校准知识](docs/TORSO-CALIBRATION-R18.md)。最终运行文件和证据以BUILD.json、DELIVERY.json、qa/calibration-r18/browser.json为准。

## 检查与完成边界

本轮实际离屏检查全身正侧背、半身、多体型、性别形态轴、两套驱动及躯干转动，并检查真实保存、同一文件重复载入、旧档兼容、R17原人物画布像素和实际绘制图元。数值和浏览器通过不表示所有参数组合或所有动作已自然。

当前仍未通过整体最终视觉验收：胸肩、腰背到骨盆的结构还较概括，肩腋过渡、手足细碎起伏和腕部问题仍需处理。自主数据替换、局部计算优化及头部/总平台整合尚未完成。下一轮继续第一优先级的躯干宽面和肩带检查，再进入关节与手足。

## 构建与复核

```text
node tools/build.cjs
node tools/test-calibration-r18.cjs
node tools/test-controls-r17.cjs
node tools/qa-calibration-r18.cjs
node tools/finalize-calibration-r18.cjs
```

默认构建入口选R18。R17运行文件和源码仍保留，可以用tools/build-r17.cjs重建；旧原型工具和清单仅作历史记录。不要从qa/legacy-comparison构建交付。

构建和参数检查使用Node.js内置模块。离屏检查使用Playwright和Chrome，检查脚本中的运行库路径可按机器配置修改。交付HTML自带程序和数据，直接打开即可，不需要Node、网络或原模型。
