## 动作与行为

| 内容 | 当前实现 |
| --- | --- |
| 初始站姿、步行、转向、停止 | 固定版本的 Motion-Lab R2.2 核心，使用 1/120 秒身体时钟和独立足部锚点 |
| 坐下、躺下、起身 | CMU `113_08` 四段区间，经同一姿态适配器提交；坐卧后保持完整姿态，起身后过渡到实验室站姿 |
| 挥手、问候 | CMU `113_27`，按来源骨架跟随误差判断完成 |
| 敬礼 | 公开队列规范与同源头手标记构成的接触目标，属于规范引导的适配 |
| 搬运、推动 | 实验室步态、来源下蹲参数与双手接触 IK；保留接触建立、抬放、力量预估及物体归位检查 |
| 长任务 | 整串预推演、步骤序列、等待、观察、条件分支、追加与替换、暂停与继续 |
| NPC 持续日常 | 三个身份、十项配方；原有八项工作及岗哨观察、集合报到，保留工具归位、休息和回岗闭环 |

基础动作按钮和文本指令使用同一任务入口。例如：`向前走1米，然后向左转90度，然后挥手，然后坐下`。搬运和推动会按当前场景、双手可达性及力量预估预检，无法完成的计划会给出原因。

敬礼、搬运和推动已恢复执行入口，但它们没有对应的负重动作采集，不能标成实测动作。逐关节自定义角度命令仍未开放。

## 人体与来源

项目保留 Visual R2 函数重建人体、头发、材质、场景编辑和关节分区显示。128 个同源控制节点和 14 类曲面分区继续使用相同参考骨架与表皮绑定；动作适配不缩放骨段。

曲面参数与静态关节估计来自 BodyParts3D。步行源数据来自 CMU `08_01`；坐卧和挥手来自其他受试者的公开采集。关节中心未进行功能标定，动态皮肤压缩、滑移和肌肉鼓包也未实测。当前双四元数蒙皮不能代表完整的真实软组织动力学。

`motion/vendor/` 中八个核心文件与独立实验室 R2.2 一致，哈希保存在 `motion/source-lock.json`。独立实验室目录未改动；主项目的世界、表皮和任务适配在核心之外。
