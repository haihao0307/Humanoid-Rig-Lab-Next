# Bird Mother｜Seagull A 冻结重放一致性语料台 R0.13

R0.13 承接已经完成来源限位、公共相位时钟和 66 字节精确交接包的 R0.10—R0.12。它不制作新鸟、不重建羽毛，也不补造用户尚未提供的飞行姿态；本版只把关键来源状态冻结成已知答案语料，验证独立消费者能否得到完全相同的字节包和通道结果。

## 本版完成

- 冻结 40 个 66 字节已知答案包；
- 覆盖 R0.11 的 8 个来源事件位置；
- 覆盖 24、30、60、90、120 Hz 五种受支持采样率；
- 覆盖 smoothstep、linear、暂停态、不同 cycleIndex，以及翼根、翼肘/中外翼、身体耦合、左右残差和周期缝候选的不同合法组合；
- 每个案例固定 packet hex、校验和、精确 phaseTicks、控制量、解码时钟和量化后通道值；
- 每次运行同时执行 R0.12 解码器和独立参考消费者；
- 每个案例都必须通过解码、重编码、Q16 通道复算、元数据一致性和单字节损坏拒绝；
- 任何 magic、schema、flags、采样率、相位、校验和、事件位或通道复算异常都会 fail-closed；
- 可点击任意案例，把其精确时钟和控制量恢复到工作台检查；
- 来源鸟体继续保持只读，语料只验证运动合同，不改写来源网格。

## 为什么需要这一阶段

R0.12 证明同一个实现可以稳定编码和解码，但未来进入另一个页面、游戏运行时、语言或设备时，仍可能因为字段顺序、默认值、量化和事件处理不同而产生“看起来差不多”的错误结果。R0.13 把 40 组答案冻结下来，使任何独立消费者都必须逐字节、逐通道对齐，而不是凭视觉近似通过。

## 边界

这组语料证明的是当前来源合同的重放一致性，不证明来源动作在生物学或空气动力学上正确。它不能解锁外翼扇面、展向扭转、飞羽展开、空气载荷，也不能生成滑翔、翱翔、转弯、起飞、着陆或逃逸。
