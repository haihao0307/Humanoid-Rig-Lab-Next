# 04｜当前真实状态、失败证据与未解决问题

## 1. 当前候选

版本：`Original Bird R0.17.1`

生产入口：

`Bird-Reconstruction-Lab/original-bird/workbench/original-bird-gull-form-r0171.html`

运行时：

`Bird-Reconstruction-Lab/original-bird/runtime/original-bird-gull-form-r017.mjs`

当前候选是独立程序化海鸥，不加载两只参考鸟的网格、贴图、骨架或动画作为运行时依赖。

## 2. R0.17 已暴露的失败

R0.17 是第一只真正可见的独立候选，但浏览器证据显示：

- 身体过短、过圆，整体接近球状；
- 头颈与身体关系僵硬；
- 眼睛过大且过于玩具化；
- 翼根像外挂零件，与肩胸没有连续体积；
- 右侧翼使用负缩放，造成三角绕序、法线和明暗错误；
- 尾部侧视像细杆和薄片；
- 腿足缺少海鸥蹼足关系；
- 前视相机方向错误，原因是相机 up 轴没有固定为 Z；
- 浏览器 QA 曾在截图阶段超时，仅形成部分证据；
- 因此 `visualAcceptance=false`，不得把 R0.17 当成完成品。

相关失败证据：

- GitHub Actions artifact ID：`10623732734`
- 该 artifact 来自早期 R0.17 浏览器 QA；只用于记录失败，不代表验收通过。

## 3. R0.17.1 已执行的修正

- 身体和头尾轴线拉长；
- 胸腹截面重新分配，降低球状体积；
- 使用 Catmull-Rom 密集纵向截面环平滑身体、颈、头和喙；
- 身体径向段提高到 52；
- 纵向细分设为 5；
- 翼展增加，翼面按翼根到翼尖渐缩；
- 翼根向肩部内嵌；
- 左右翼分别生成几何绕序，不再依赖负缩放；
- 右侧法线错误已在代码层修正；
- 眼睛缩小，并分成虹膜、瞳孔和角膜；
- 喙部增加喙缝和鼻孔；
- 尾部增加连续尾基载体；
- 保留 9 枚尾羽；
- 腿足改为双段腿、三前一后趾和蹼；
- 相机 up 轴固定为 Z；
- 基础拍翼保留；
- 高级飞行继续关闭。

## 4. R0.17.1 仍未解决

### 静态形体

- 五视角最终截图尚未全部完成并人工批准；
- 身体与真实海鸥比例仍需继续核对；
- 胸腹质量和尾部收束仍可能需要修正；
- 颈、头和喙的精确关系仍需高细源逐角度对照；
- 眼睛虽然缩小，但位置、外凸程度和眼眶关系尚未批准；
- 翼根嵌入已改，但是否真正消除外挂感尚未批准；
- 翼面平面形状、后缘和翼尖仍需五视角核对；
- 尾基和尾扇仍需三分之四、顶部和翼底视角核对；
- 腿足和蹼足比例、朝向和接触位置尚未批准。

### 连续性

- 身体—颈—头—喙是连续载体；
- 左翼和右翼各自是连续蒙皮表面；
- 尾基有连续载体；
- 但整只鸟尚不是单一连续表面；
- 因此 `continuousSurfaceBirdGenerated=false` 必须保留。

### 基础拍翼

- 基础拍翼已经接入，但只用于变形测试；
- 肩胸体积是否稳定尚未批准；
- 肘腕折叠是否自然尚未批准；
- 初级飞羽是否互相穿插尚未批准；
- 翼尖是否出现扭转或法线闪烁尚未批准；
- 身体和尾部响应是否机械尚未批准；
- 不得把当前动作称为完整飞行。

### 羽毛与材质

- 当前候选仍是早期几何和材质表达；
- 历史 R0.12.x 已有羽缘 Alpha、自动提取、Alpha Mask 和浏览器 QA 技术；
- 这些技术尚未完整迁移到 R0.17.1 独立海鸥；
- 覆羽、次级飞羽、初级飞羽和尾羽层次尚未达到 3A；
- 翼尖和尾缘的透明、半透明关系尚未完成；
- 白色身体、灰色翼面、深色飞羽、眼睛、喙和腿足材质尚未最终收敛。

### 正式资产

- 尚未输出正式独立 GLB；
- 尚未有最终 UV、PBR 贴图集或发布包；
- 尚未有正式规范动作库；
- 尚未有群体飞行运行时；
- 尚未有生态和捕食系统；
- 尚未形成批量鸟种生产线。

## 7. 当前最阻碍推进的问题

不是缺少高级飞行知识，而是：

**R0.17.1 仍缺一套完整、可重复、可人工逐项审查的五视角和基础拍翼浏览器证据，然后根据这些证据继续直接修形。**

重新开线后应把时间用在浏览器观察和形体迭代，不再先扩展研究体系。
