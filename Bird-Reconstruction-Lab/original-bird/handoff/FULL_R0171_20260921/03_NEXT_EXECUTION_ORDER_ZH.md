## TASK 03｜静态形体第一轮修正

按五视角逐项修正，不同时扩展别的模块。

### 侧面

检查：

- 身体是否仍过圆或过短；
- 胸部是否有海鸥的前胸量感；
- 腹部是否自然收向尾基；
- 颈部是否从胸肩自然抬起；
- 头顶、额部、喙基和喙尖是否连续；
- 尾基是否仍像外挂；
- 腿足是否位于真实重心下方。

### 正面

检查：

- 左右身体质量是否对称；
- 眼睛是否过大、过外凸或高度错误；
- 喙是否居中并有正确宽度；
- 翼根是否从肩胸连续长出；
- 左右翼法线和光照是否一致；
- 腿与蹼是否左右对称。

### 顶部

检查：

- 身体俯视轮廓是否过宽；
- 翼展和弦长是否像海鸥；
- 翼根、肘部、腕部和翼尖的平面关系；
- 初级飞羽是否排列成自然扇形；
- 尾扇是否过窄、过宽或位置错误。

### 三分之四

检查：

- 头颈与身体整体气质；
- 肩胸体积；
- 翼根遮挡关系；
- 眼睛、喙和尾部是否同时成立；
- 是否仍有“拼装零件”感。

### 翼底

检查：

- 左右翼厚度和法线；
- 肩、肘、腕、翼尖连续性；
- 飞羽与翼面是否穿插；
- 腹部与腿足位置；
- 尾羽层叠是否合理。

验收门槛：

- 五视角都能识别为同一只形体一致的海鸥；
- 不再是球体躯干、外挂翅膀、杆状尾巴或无蹼脚；
- 不以材质细节掩盖比例错误。

## TASK 04｜基础拍翼变形检查

只保留当前 basic flap。

证据：

- 运行中的基础拍翼一张；
- `phase=0.25` 一张；
- 后续至少补 `phase=0.00 / 0.25 / 0.50 / 0.75` 四张。

检查：

- 翼根是否从身体裂开；
- 肩胸是否塌陷；
- 左右翼方向是否镜像一致；
- 肘部是否产生硬折角；
- 腕部是否过度反折；
- 翼尖是否穿过翼面；
- 初级飞羽是否互相穿插；
- 尾部是否出现错误跟随；
- 身体配平是否过强或机械颤动。

验收门槛：

- 动作可以很基础，但不能破坏形体；
- 左右对称且无明显法线闪烁；
- 不允许因为动作存在就声称飞行系统完成。

## TASK 05｜第二轮形体收敛

基于 TASK 02—04 的失败证据继续修改：

- 截面环位置和半径；
- 胸腹中心线；
- 颈部曲线；
- 头部体积；
- 喙基、喙缝、鼻孔；
- 眼睛位置、大小和外凸程度；
- 翼根埋入深度；
- 翼展、弦长、后缘和翼尖；
- 尾基、尾扇和尾羽角度；
- 腿长、踝部、趾长和蹼面。

每修改一类形体参数，都必须重新跑五视角。不得一次性大改所有参数后只看单一角度。

## TASK 06｜羽层与 Alpha

只有静态形体和基础拍翼通过后才开始。

复用现有技术积累：

- `COLUMBID_FEATHER_ALPHA_EDGE_R012.json`
- `COLUMBID_FEATHER_ALPHA_AUTO_EXTRACT_R0122.json`
- `COLUMBID_FEATHER_ALPHAMASK_R0123.json`
- `COLUMBID_FEATHER_ALPHAMASK_QA_R0123.json`
- 相关 R0.12.x 工作台和浏览器测试。

目标：

- 覆羽、次级飞羽、初级飞羽和尾羽分层；
- 羽缘透明与半透明关系；
- 翼尖和尾缘不再显示硬几何板边；
- Alpha 不吞掉羽轴和羽片主体；
- 近景和远景都能读出羽毛结构。

## TASK 07｜材质

形体与羽层通过后再处理：

- 白色身体不曝光；
- 灰色翼面与深色初级飞羽分区；
- 喙、眼睛、腿足有真实粗糙度；
- 角膜高光不做成塑料球；
- 羽毛粗糙度和法线尺度正确；
- 明亮背景下仍有层次。
