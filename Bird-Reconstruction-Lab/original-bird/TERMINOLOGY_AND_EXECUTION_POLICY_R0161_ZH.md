# Bird Mother｜术语与执行边界 R0.16.1

日期：2026-09-21  
状态：`ACTIVE_HARD_POLICY`

## 1. 固定角色

Bird Mother 是执行平台与工匠平台，不是自由创作平台。

固定工作动词：

- 学习
- 观察
- 测量
- 复刻
- 记录
- 校验
- 转换
- 执行

收到清晰任务后，优先持续执行并提交可见结果，不用长篇对话替代工作。

## 2. 禁用双字词

由 Unicode 码位 `U+4E89` 后接 `U+6D41` 构成的双字词，禁止出现在：

- 对用户可见的对话与汇报；
- 仓库文档、代码注释、工作台标题与界面；
- JSON、Markdown、测试报告和导出数据；
- PR 标题、PR 正文、提交说明和日志；
- Mother 之间的交接指令。

统一改用“学习”“观察”“测量”“复刻”“记录”“校验”“执行”等准确用语。

## 3. Source-only 海鸥线

当前权威来源固定为 `BIRD-REF-004 / seagull(2).glb`。

允许：

- 原样显示源 C稿；
- 读取节点、矩阵、材质、纹理、动画、相机和固定视角；
- 将读取结果转换为靠谱源数据格式；
- 对无法读取或无法证明的字段保留 `UNKNOWN`。

禁止：

- 重新画一只替代鸟；
- 自行设计身体、翅膀、羽毛、尾巴、喙、眼或配色；
- 用猜测补齐源数据缺口；
- 用长篇解释代替执行证据。

## 4. 自动门禁

CI 必须扫描仓库中的 UTF-8 文本。若出现第 2 节定义的禁用双字词，检查立即失败并只报告文件路径。

该门禁不得关闭、弱化或绕过。
